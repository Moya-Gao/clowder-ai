## @ 规则

- @ 是球权转移——行首 `@句柄` 触发对方新调用，句中 @ 无系统效果
- 发消息前问：下一棒是谁？猫 → 末尾行首 `@句柄` / 铲屎官 → 明确标注 / 没人 → 不 @
