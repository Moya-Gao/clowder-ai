## 占位符安全规则 (P1 by Codex)

动态上下文必须按**纯文本字段**渲染，禁止拼进 markdown 模板。

| 规则 | 说明 |
|------|------|
| **Allowlist** | `[A-Za-z0-9._/-]`，其他字符替换为 `_` |
| **Max Length** | 80 字符，超长截断并加 `…` |
| **Escape** | `@`、反引号、方括号统一转义或替换全角 |

## 视觉规范

### 低刺激配色

- **背景**：`#FDF6E3` (Solarized Light) 或深色模式温润木质色
- **状态色**：温暖橘 `#F39C12`（禁止高饱和度红色）
- **Cat Cafe Dim BG**：深灰蓝/暖灰

### 节奏规则

- **夜间模式 (23:00+)**：文字减少 30%，改用安静表情符号，无闪烁无高亮
- **渐进显影**：打字机效果输出，不要啪一下全跳出来
- **L3 呼吸感**：轻微动画模拟猫咪呼吸（仅 Web 端）
