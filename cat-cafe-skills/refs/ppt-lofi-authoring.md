# PPT Low-Fi Authoring — 低保真 MD 制作规范

> ppt-forge Route B（imagegen 路径）的核心 ref。
> 来源：2026-05-28 LLE 架构图实战 + 2026-05-29 试用期总结实战。
> 两次验证的成熟模式：架构猫写低保真 MD → 砚砚 imagegen 逐页出精美图。

## 核心原则

**低保真 MD 是"给 AI 看的蓝图"——不是给人看的文档。**

- 每页一个 section，用 ASCII art 画清布局和信息分区
- 视觉指引用文字精确描述配色、字体、图表风格
- 内容全量保留，用结构化图表承载密度
- 写完后交给砚砚（或其他有 imagegen 能力的猫）逐页生成精美图

## 适用场景

| 场景 | Route B（本路径） | Route A（HTML 路径） |
|------|------------------|---------------------|
| 帮朋友/外部做 PPT | 首选 | 过重 |
| 快速出高质量图 | 首选 | 慢 |
| 架构图/技术蓝图 | 首选 | 用 CSS 画架构图痛苦 |
| 需要可编辑的正式 PPT | 不适合 | 首选 |
| 需要 PPTX 导出 | 不适合 | 首选 |
| 需要精确到像素的控制 | 不适合 | 首选 |

## 分页规划方法

### 第 1 步：内容分析

阅读全部原始内容，识别：
- **核心板块**：几个大的独立主题
- **数据点**：有冲击力的数字（800+、50+、165 等）
- **流程/关系**：可以图表化的逻辑链
- **层级**：总→分的信息结构

### 第 2 步：页面类型分配

| 页面类型 | 用途 | 典型视觉形态 |
|---------|------|-------------|
| 封面 | 标题+基本信息 | 品牌色带+居中标题 |
| 总览/全景 | 一页看全貌 | 矩阵卡片/思维导图/N 宫格 |
| 详情页 | 展开一个板块 | 双栏/流程图/表格+数据 |
| 方法论 | 提炼核心方法 | 横向卡片/公式/流程 |
| 路线图 | 时间维度规划 | 时间轴/里程碑/甘特 |
| 对比页 | 双栏对比 | 左右分栏/表格/雷达图 |
| 总结页 | 收获/不足/致谢 | 双栏+大字致谢 |

### 第 3 步：页面数量控制

- **华为/document 风格**：每页密排，6-12 页常见
- **Apple/presentation 风格**：每页一个点，15-25 页常见
- **内容全保留时**：合并关联板块到同一页（用分栏/标签/卡片承载）
- **内容可取舍时**：先砍再排

## ASCII Art 规范

### 字符集

```
边框：┌ ┐ └ ┘ │ ─ ═ ║ ╔ ╗ ╚ ╝ ╠ ╣ ╬ ╤ ╧
箭头：→ ← ↑ ↓ ▶ ◀ ▲ ▼ ──▶ ◀──
分隔：╠═══╣  ╠═══╤═══╣（竖线分栏）
强调：══（双线标题框）
```

### 布局原则

- **大小反映比例**：占页面 1/3 的区域，ASCII art 也占 1/3 宽度
- **层级用缩进**：顶级元素贴左，子元素缩进 2-4 格
- **卡片用方框**：每个独立信息块用 `┌──┐` `└──┘` 围起
- **流程用箭头**：`──▶` 或 `│ ▼`
- **分栏用竖线**：`╤` `│` `╧`

### 好的 ASCII art 示例

```
┌══════════════════════════════════════════════┐
║  页面标题                                     ║
╠═══════════════════════╤══════════════════════╣
║  【左栏标题】          │  【右栏标题】         ║
║                       │                      ║
║  ┌─────────────┐     │  ┌────────────────┐  ║
║  │ 卡片 1      │     │  │ 表格           │  ║
║  │ · 要点 A    │     │  │ ┌───┬──────┐  │  ║
║  │ · 要点 B    │     │  │ │ A │ 说明 │  │  ║
║  └─────────────┘     │  │ ├───┼──────┤  │  ║
║        │              │  │ │ B │ 说明 │  │  ║
║        ▼              │  │ └───┴──────┘  │  ║
║  ┌─────────────┐     │  └────────────────┘  ║
║  │ 卡片 2      │     │                      ║
║  └─────────────┘     │  ┌───────────────┐   ║
║                       │  │ 大数据高亮     │   ║
║                       │  │   800+        │   ║
║                       │  └───────────────┘   ║
```

## 视觉指引格式

每页 ASCII art 下方附 `**视觉指引**：` 段落，内容包括：

```markdown
**视觉指引**：
- 布局形态描述（双栏/流程/矩阵/...）
- 各区域配色指引（标题用什么色、卡片用什么底色）
- 关键数据处理方式（大号/高亮色/底色块）
- 图表类型建议（流程箭头/对比表/进度条/...）
- 可选：icon/图标建议
```

**要点**：
- 只描述风格意图，不描述 CSS 实现——这是给 imagegen 的指令
- 配色引用风格 preset（如"华为红"），不重复写色值
- 每条指引都是 imagegen 可执行的

## 精美图生成指引（末尾总章）

低保真 MD 末尾必须有一个"精美图生成指引"section，给砚砚的总体风格规范：

| 项目 | 内容 |
|------|------|
| 视觉风格名称 | 如"华为内部工作汇报 PPT 风格" |
| 配色方案 | 主色+强调色+正文+辅色+底色，含色值 |
| 字体风格 | 标题/正文/数字的粗细+大小+对齐 |
| 密度原则 | 高/中/低，怎么用图表承载 |
| 排版规格 | 16:9 / 4:3，横版/竖版 |
| 逐页生成清单表格 | P1-P9 每页主要图表元素 |

## 与 imagegen 猫的交接协议

低保真 MD 写完后，交给有 imagegen 能力的猫（砚砚 / 云端 Codex）：

1. **发低保真 MD 文件路径**（不贴全文，太长）
2. **说明生成方式**：逐页生成，每页一张独立图片
3. **说明输出位置**：同目录 `assets/` 子目录
4. **关键约束**：
   - 用原生 imagegen 直出 raster PNG，不用 SVG/HTML 手工合成
   - 每页图片命名：`p{N}-{简短描述}.png`（如 `p2-overview.png`）
   - 严格遵循配色方案，不自由发挥
   - 文字内容以低保真 MD 为准，不删不加

## Common Mistakes

| 错误 | 后果 | 修复 |
|------|------|------|
| ASCII art 太简陋（只有标题列表） | imagegen 猜布局，结果不对 | 画清每个区域的位置和大小 |
| 视觉指引缺配色 | imagegen 用默认配色 | 每页都引用风格 preset |
| 没写数据高亮方式 | 关键数字淹没在正文中 | 标注哪些数字要大号/高亮 |
| 直接贴大段原文 | imagegen 不知道怎么排版 | 先做信息设计（分卡片/分层级/转图表） |
| 没写精美图生成指引 | 砚砚要反复问风格 | 末尾必有总章 |
| 把视觉指引写成 CSS 代码 | imagegen 不吃 CSS | 用自然语言描述视觉意图 |
