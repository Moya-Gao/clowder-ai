# PPT 风格 Preset — 华为

> ppt-forge 华为风格完整定义。Route A（HTML）和 Route B（imagegen）共用。
> 来源：F144 华为密度实战 + 2026-05-28/29 两次 imagegen 实战验证。

## 风格定义

**一句话**：白底 + 红黑配色 + 极致密排 + 图表化 + 直角 + 数据说话。

华为 PPT 的核心美学是**信息密度最大化**——每页都像一张完整的信息看板，不浪费一寸空间，但用结构化（表格/矩阵/流程图/卡片）承载密度，不是一大段文字。

## 配色方案

| 用途 | 色值 | 说明 |
|------|------|------|
| **主色（华为红）** | `#CF0A2C` / `#C7020E` | 标题、关键连线、强调色块、重点数字、色带 |
| **正文** | `#333333` | 所有正文内容 |
| **辅色（深灰）** | `#666666` | 次要文字、注释、分割线、副标题 |
| **卡片底色** | `#F5F5F5` / `#FAFAFA` | 浅灰底色区分区域 |
| **背景** | `#FFFFFF` | 纯白 |
| **表头底色** | `#CF0A2C`（华为红） | 表头用红底白字 |
| **状态-完成** | `#52C41A`（绿） | 已完成标记 |
| **状态-进行中** | `#1890FF`（蓝） | 进行中标记 |
| **状态-待开始** | `#999999`（灰） | 待开始标记 |

**配色铁律**：
- **不用蓝色做主色**——蓝色是华为竞品色调，华为用红
- **不用橙色**——橙色偏阿里/互联网风
- 强调只用华为红，不用渐变、不用多色系
- 黑和红足够，不需要第三种强调色

## 布局特征

| 维度 | 华为风格 | 对比 Apple |
|------|---------|----------|
| 圆角 | **直角（0px）** | 大圆角 12-16px |
| 密度 | **高（模块化 Boxy）** | 极低（每页一件事） |
| 留白 | **最小化** | 最大化 |
| 字重 | 粗体标语 + 细体数据 | 超大超粗标题 |
| 图标 | 面性/实心 | 线框/SF Symbols |
| 分栏 | 常用双栏/三栏/矩阵 | 极少分栏 |
| 色块 | 大量浅灰底色区分区域 | 极少色块 |
| 数据 | 大量数字高亮+图表 | 只放关键 1-2 个数字 |

## 密度原则

华为密度 = **信息最大化 + 结构化承载**。

- 每页至少一个图表化元素（不能全是纯文字列表）
- 关键数据必须突出（华为红大号）
- 用卡片/表格/矩阵组织信息，不用大段落
- 底部留一条红底白字总结条是华为的标志性手法
- 不怕密——怕密但乱。有结构的密是高级的

## Common Mistakes

| 错误 | 后果 | 修复 |
|------|------|------|
| 用蓝色做主色 | 不是华为味 | 主色只用华为红 #CF0A2C |
| 用橙色强调 | 偏互联网/阿里风 | 强调只用华为红 |
| 圆角卡片 | 偏 Apple/互联网 | 直角（0px） |
| 大面积留白 | 不是华为密排风 | 减少留白，加图表/卡片填充 |
| 每页只有文字列表 | 缺图表结构感 | 至少一个表格/流程/矩阵 |
| 渐变色/透明叠加 | 华为不用这个 | 纯色+白底 |
