# Common Mistakes

| 错误 | 后果 | 修复 |
|------|------|------|
| 概念先行，案例后补 | 读者第 3 段就走了 | Phase 1：先场景后概念 |
| 内部术语不翻译 | 外部读者觉得是黑话 | Phase 2：翻译句纪律 |
| 排比句/对仗满天飞 | "AI味"，读者反感 | Phase 3：AI味自检 |
| 所有话用同样确定语气 | 头号 AI 味 | Phase 1：证据标注 `[事实]/[推断]` |
| 写完全文才跑 AI味检查 | 改不动，门禁变建议 | Phase 3：每章写完立刻检查 |
| 摘要 = 章节标题列表 | 没有传递任何思想 | Phase 4：冲突→方法→结论 |
| 推广语数字打架 | 读者第一眼困惑 | Phase 4：数字自洽 |
| 被批"读不懂"就防御 | 错过最好的 eval 信号 | Phase 5：修表达守内核 |
| 多人差评归为"噪音忽略" | 丢掉聚类强信号 | Phase 5：多个独立差评 = 主动挖根因 |
| 教程硬塞反直觉点 | 为了钩子扭曲叙事 | Phase 0：按文章类型选钩子 |
| 凭记忆写推广语/摘要 | 数字编错、结论失真 | Phase 4：先读源文再动手 |
| 用结构化三点分析回应"AI味"批评 | 用被批评的方式回应批评 | 先说人话，克制结构化冲动 |
