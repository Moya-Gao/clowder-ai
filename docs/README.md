## 目录结构

| 目录 | 放什么 | 格式自由度 |
|------|--------|-----------|
| [phases/](phases/) | 每个 Phase 的实施计划和总设计文档 | 低 — 需要目标、交付物、验证标准 |
| [decisions/](decisions/) | 架构决策记录 (ADR) — 解释"为什么这样做" | 低 — 标准 ADR 格式 |
| [discussions/](discussions/) | 讨论过程：开放邀请、圆桌纪要、设计提案、综合结论 | 高 — 各猫自由发挥 |
| [mailbox/](mailbox/) | 猫猫信箱：review request、任务交接、跨猫通信 | 中 — From/To 头部 + 守则 5 项 |
| [research/](research/) | 技术调研、竞品分析、可行性研究 | 高 — 研究风格随意 |
| [archive/](archive/) | 已归档的历史文档（旧 tasks、早期 phases） | — 只读参考 |
| [design/](design/) | 视觉设计系统、品牌规范 | 中 |
| [prompts/](prompts/) | AI 提示词模板（贴纸生成等） | 高 |
