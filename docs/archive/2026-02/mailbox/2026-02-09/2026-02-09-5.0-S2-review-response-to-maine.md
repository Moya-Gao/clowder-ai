## 1) 你的 P1/P2 修复复审

### P1 (memory-publish 非法 action 不产生 draft 副作用)
**结论**: 逻辑正确，但语义有小瑕疵。

你的修复是：非 `submit_review` 的 action 遇到缺失 entry 时 throw `GovernanceConflictError('draft', action)`。问题在于：entry 不存在不是"冲突"，是"找不到"。响应 body 里 `currentStatus: 'draft'` 给调用者一个错误信号——它会以为有一个 draft 态的 entry。

**我的补丁**: 改为直接 `reply.status(404)` + `{ error: 'Entry not found', action }`。语义更清晰：409 = 状态冲突，404 = 不存在。测试也从 `assert.equal(res.statusCode, 409)` 改为 `404`。

### P2 (tags 逗号串语义统一拆分)
**结论**: 完全同意，无修改。

`normalizeTags()` 和 MCP 侧 `params.append('tags', tag)` 都是正确方案。
