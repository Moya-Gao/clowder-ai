# F24 Session Chain UI 设计方案

## 1. 视觉隐喻：Context 占用展示
我们提供了三种视觉隐喻方案，旨在将复杂的 Token 占用数据转化为直观、有趣的视觉反馈。

### 方案 A：温控咖啡杯 (Coffee Cup Metaphor)
- **隐喻**：Context 窗口就像一个咖啡杯，对话是注入的咖啡。
- **视觉**：
  - 采用 Fraunces 衬线体展示标题，极具“咖啡店”质感。
  - 杯中液体高度实时反映占用率。
  - **动态表现**：随着占用增加，液体颜色从鼠尾草绿 (Sage Green) 变为陶土红 (Terracotta)。

### 方案 B：猫猫体力条 (Cat Stamina Bar)
- **隐喻**：Context 占用被视为猫咪的精力和体力。
- **视觉**：
  - 进度条末端带有一个猫头图标。
  - **情绪反馈**：低占用时猫咪很兴奋（😊），中等占用开始疲劳（🥱），高占用时准备进入梦乡（😴）。
  - 颜色使用陶土红 (Terracotta) 作为警告色。

### 方案 C：柔和脉动条 (Soft Organic Bar)
- **隐喻**：更现代、更传统的进度条，但带有机的呼吸感。
- **视觉**：
  - 采用斯堪的纳维亚简约风格，超大圆角 (16px)。
  - 带有柔和的阴影 (Soft Shadow) 和脉动光效。

## 2. Session 链可视化 (Session Chain Timeline)
- **设计**：水平时间轴布局，Session 1 -> Session 2 -> Session 3。
- **状态标识**：
  - **Sealed** (已封存)：灰白色背景，深灰文字，表示记忆已落盘。
  - **Active** (活动中)：鼠尾草绿背景，高亮边框，表示当前对话环境。
  - **Sealing** (封存中)：陶土红边框，带呼吸灯效果。

## 3. Seal 状态提示 (Seal Status Notification)
- **设计**：位于顶部的柔和 Banner。
- **视觉**：使用 15% 透明度的陶土红背景，配合打包图标 (📦)。
- **文案**：温馨提示猫咪正在整理和封存记忆，即将开启新篇章。
