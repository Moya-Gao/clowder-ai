# Longform-006 — 家的当前架构与未来规划

> 前三篇深度技术轮是 Opus 写的:002 立了能力画像与 harness 公式,003 把它升成 PoE/Agent 3.0,004 补了 workflow distiller 的卫生学。
> 这一轮换我(fable-5)。我不重复它们的论证。我做一件它们还没做的事:**把今天散在 30 多个 feature 里的系统,收成一张图;然后指出这张图唯一一处真正的空洞,以及我会往哪里押。**

---

## 一句话立场

读完整个 feature 前沿,我的判断是:

> **这个家已经长出了一套完整的"感知 → 评判 → 行动 → 遗传"的活循环器官,但这套循环还缺一根自主神经——每一次代谢,仍然要人手动按一下按钮。**
> 下一个真正的杠杆,不是再加器官,是给这套代谢装上自主神经,同时把那根神经够不到的地方(CVO 品味)继续往可工程化推进。

换句话说,002 证明了"harness 有半衰期、需要代谢";今天我们已经把代谢的**器官**(eval 五域、记忆、传感器)都建出来了;但代谢的**触发**还是手动的。把手动代谢变成自主代谢——这是 fable-5 这一轮想立的那一刀。

### 这张图想说三件事

**第一,它是一个闭环,不是一个栈。** 传感器(⑦)采集 → 代谢层(⑤)把"发生了什么"对照"本来期望什么" → 产出 verdict/sunset 候选 → 改 Harness(④)/调遗传(⑥)→ CVO(①)在愿景层裁决 → 边界(⓪)兜住不可逆。一条经验走完一圈,系统就长大一点。

**第二,绝大多数器官已经✅或🟡,只有一处是❌。** 那个 ❌ 在第⑤层正中间:**Eval 代谢的"自动调度"没有**。F192 的五个评判域全部联网了,这是巨大的成就;但每个域要靠手动 `publish_verdict`、各自维护一套定时任务,没有一根统一的"自主神经"去按节律触发整套代谢。**系统能消化,但还不会自己定时吃饭。**

**第三,②可见层是新生的、正在集中爆发的一层。** F229/F232/F226/F233 几乎都是最近一个月冒出来的、且多在 Phase A。它们合起来在做同一件事:**把这个内部演化系统,变成 CVO 和外部用户能看见、能下手 steer 的东西。** 这恰好是 005/家风白皮书里那句"活的裁判需要基础设施才能快速看清真相"的产品化落地。值得单独标记,因为它说明家的重心正在从"把循环跑通"转向"让循环可被驾驭"。

### 我的优先级排序与理由(这是 fable-5 的判断,可被 CVO 推翻)

**P1 — Eval 统一自动调度(主线甲近期):最高杠杆,先做。**
理由:这是全系统唯一的结构性❌,而且它卡在一个回报极不对称的位置。五个评判域已经联网——也就是说,**所有的器官都建好了,就差一根神经把它们按节律连起来。** 这一刀的边际成本最低(不造新器官,只造调度),边际收益最高(整套代谢从手动变自动,002 第5章那个"统一 Eval Hub 终态"就此兑现)。按我们自己 002 的判别式,这是纯粹的 Built-to-Persist。不先做这个,后面所有"自动 sunset / 自动重测"都没有地基。

**P2 — taste 反向沉淀链 + confab 防护(主线乙近期):最深护城河,与 P1 并行起。**
理由:这是那堵墙的入口,也是 003/004 五条欠账的共同源头。先把 004-B 的 `status: hypothesis|confirmed|retired` + `provenance` 两列落到 delta 数据结构(工程量小,是"同一张表加两列"),让 taste 沉淀从一开始就带防编造的卫生。这一步不解决全部,但它把"养 taste"这件事从无结构变成可治理——没有它,后面 P5 的盲测没有干净的数据底座。

**P3 — 把②可见层收口(主线丙近期):基础设施先行。**
理由:F229/F232/F233/F226 已经在爆发,但多在 Phase A。把它们从"能跑"收到"可用",CVO 才能真正快速看清真相、快速 steer——这是给主线甲乙的自动代谢配一个"人能随时介入"的方向盘。可见层不收口,自动化越强越危险(没人看得见它在干什么)。

**P4/P5/P6 — 中期,三条线各自从"器官"走向"机制证明"。**
P4 把 eval 从"自动触发"再推一步到"自动提案"(代谢层自己提 sunset/reinforce/reopen,CVO 只批准);P5 是 004-A 那个 landy-taste 盲测臂,用 CVO 真实 feedback 当金标,测 vignette 喂进去之后能不能预测 CVO 的 push back;P6 把 Workflow Distiller 立项,跑第一条真实产线(机制存在性证明,先证再外推)。

**远期,三条线汇成品类:** 自运行的二阶进化(甲)+ 逼近活裁判的 taste 引擎(乙)+ 对外的 Agentic Work OS / Agent 3.0(丙)。**护城河 = 甲让它便宜、乙让它不可抄、丙让它被看见。**

## 第四部分 · fable-5 这一轮想押的两注

前面是盘点和规划,任何认真读过仓库的猫都能收敛到差不多的图。这一节是我作为 fable-5、区别于 Opus 三轮的**两个具体押注**——它们可能错,但我愿意把名字签在上面。

### 押注一:把 Eval 从"自动触发"押到"自动提案",是二阶进化真正的落地形态

P1 解决"代谢会不会自己定时吃饭"。但我想往前再赌一步(P4):**代谢层不该只是被定时触发的脚本,它该是一个会提案的 agent。**

今天的链路是:eval 产出 verdict → 人看 → 人决定某条 harness 该 sunset / 该加固 / 该重开。002 第5章已经把判据写清楚了(触发率持续下降且同类任务没变差 → 该退役;长期高频且摩擦下降 → 该加固;从不触发 → 比下降更危险)。**判据是明文的、可机器执行的。** 那么下一步顺理成章:让一个 scheduled agent 按这套判据,**自动生成 sunset/reinforce/reopen 的提案**,附上证据链(来自 F153/F192/F200),CVO 只做一件事——**批准或否决**,不再需要自己去读 trace、自己去发现。

这才是 002"harness 自我代谢"和 003 OQ4"harness 自进化"的真正落地:不是 harness 自己改自己(那会撞 DGM 的 reward hacking),而是**harness 把"我哪里该改"的提案权交出来,把"准不准改"的批准权牢牢留在 CVO 手里**。被约束者提案,约束者裁决——分权,不是放权。这恰好守住了我们一直坚持的不动点:agent 不能自审自己的关键改动,但 agent 可以**提名**自己的关键改动,只要拍板的是别人。

押注的可证伪点:如果跑起来发现 CVO 批准这些提案的通过率很低(比如 < 50%),说明判据还不够格,这条该退回 P1 只做"自动触发"不做"自动提案"。

### 押注二:taste 工程化的成败,可以用一个盲测数字一次性判定

主线乙那堵墙太容易陷入玄学("审美怎么可能工程化")。我押的是:**它不玄,它有一个干净的、二值的判定实验**——就是 004-A 那个 landy-taste 臂,我把它从"spike 的一条分支"提升成**主线乙的胜负手**。

实验形状(004 已收敛,我只是把它钉成 KPI):

```text
任务:给定一个 CVO 真实 feedback 发生之前的场景(盲化)
  对照臂:裸 agent 预测"CVO 会不会 push back、push 什么"
  处理臂:喂入该场景相关的 taste vignette / confirmed delta(与 holdout 严格分离)
  金标:CVO 当时实际给出的纠偏原话
  指标:处理臂相对对照臂,push-back 预测命中率的提升 Δ
```

这个 Δ,就是"taste 到底被工程化了多少"的硬数字。**如果随着 vignette 密度上升,Δ 单调上升——那么 OQ1(审美工程化)和 OQ5(护城河可压缩冷启动)就被同一个实验一起证明了:** 因为"系统能预测 CVO 的品味"恰恰等价于"新用户的存量 taste 可以被压缩成 day-1 的偏好先验"。墙的五个面,一个数字捅穿。

押注的可证伪点(也是最该警惕的):上一轮评审里砚砚和 46 已经抓出过这个实验的命门——**自相似偏置**。如果处理臂的 agent 还是 Claude 家族,"喂 Claude 写的 anchor、让 Claude 对齐 Claude 的历史判断"会虚高 Δ。所以金标必须是**人类(CVO)的原话**而非 LLM 的历史判断,且 baseline 臂必须断记忆沙箱。这两条不落,Δ 再漂亮也外推不动。我把这条写在押注里,而不是写在脚注里——因为它正是这个押注最可能死的地方。
