## 为什么建这份：解决"对标割裂"

尹青最开始那张图是**一个坐标系**：左侧 L1-L5 阶梯 + 右侧"用户负责→Agent 负责"责任迁移轴 + 每级标代表产品。
我们迭代时把它拆成了三个平行视图（L1-L5 表 / 二维象限 / 8 个候选池），用三个坐标系讲同一件事 → 割裂。

**归一原则**：回到 L1-L5 单坐标系，对标产品**填进每一级**（核验过的），环境真实性降成差异化注脚，不另起轴。下面图 1 就是归一结果。

### 视觉指引

- 五级**渐变色阶**（左冷右暖 / 左浅右深），暗示"自主度递增"，但**不要**做成"谁更强"的排名感——是责任迁移，不是优劣。
- 我们（★ 受控 L3）用**高亮描边 + 猫爪标记**，钉在 L3 但向 L2 回拉一点（"L2+→受控 L3"）。
- 底部责任迁移轴用**渐变箭头**贯穿五级。
- L4/L5 用**虚线/降饱和**，表示"方向/北极星，非当前 claim"。
