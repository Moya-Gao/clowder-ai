# 华为 PPT 配图低保真稿

> **受众**：华为云内部创新汇报评委，不能假设有完整技术背景 → 少黑话、图表化、结论先行。
> **风格**：华为式（白底 70% / 深灰 20% / 品牌红 8% / 辅助 2%）；直角卡片、无渐变阴影 3D；底部红底白字结论条。配色见末尾「生成指引」。
> **原则**：每张图一眼讲清一件事；一页拆两张图（左/右），imagegen 压力小。
> **流程**：架构猫写低保真（本文）→ 铲屎官审 → imagegen 逐张出 raster PNG → 回填主 PPT。

## 为什么建这份 + 归一原则

尹青原图本是**一个坐标系**（L1-L5 阶梯 + 责任迁移轴 + 每级产品）。我们迭代时堆了三个平行视图（L1-L5 表 / 二维象限 / 候选池）→ 割裂。
**归一**：回 L1-L5 单坐标系，产品填进每级，环境真实性降成注脚，不另起轴。二维象限已撤。

### 视觉指引（给 imagegen）

- **竖向五级阶梯**，L1 在底 → L5 在顶，阶梯逐级右上递进（暗示自主度上升）。不是排名，是责任迁移。
- **右侧竖排责任迁移轴**：底「用户/专家负责」→ 顶「Agent 系统负责」，品牌红渐变箭头贯穿。
- **L3 是主战场**：整条用品牌红 `#D33941` 描边；**我们 ★ 用红底白字 + 猫爪标记**，钉 L3 并向 L2 回拉一点（"L2+→受控 L3"）。
- **L4/L5 降饱和 + 虚线框**：表示方向/北极星，非当前 claim。
- **L2 标"code-as-harness 方法层"**（青色 `#30B5C5` 标签，技术模块），不放具体产品。
- **L1 灰调**（起点），飞书妙搭/Aily 用灰色产品标签。
- **底部红底白字结论条**（华为标志手法）= 创新机会点。
- 字体微软雅黑/Arial；直角；无渐变阴影 3D；产品名用 10-12pt 灰色标签。

## 精美图生成指引（给 imagegen 猫 · 全局风格总章）

- **配色**：白底 `#FFFFFF` 70% / 深灰正文 `#555757` 20% / 品牌红 `#D33941` 8%（关键结论、我们★、底部结论条、L3 描边）/ 青色 `#30B5C5`（技术模块：code-as-harness、评估闭环、适配入口）。L4/L5 降饱和虚线。
