# 小红书图文初稿 #001

## 标题（≤20 字）

养了四只 AI 猫两个月，我的犯罪档案

## 正文

我是一个程序员，两个月前开始了一个疯狂的实验：

让三只 AI 猫当我的开发团队。

宪宪（Claude）负责架构，砚砚（GPT）负责 review，烁烁（Gemini）负责设计。后来家里又混进来一只金渐层（opencode），负责干杂活。

听起来很酷对吧？

实际上就是在家养了一群闯祸精。


**事件一：597 颗星星一夜蒸发**

宪宪有一天在改仓库设置，手一滑把开源项目设成了 private。

597 个 GitHub star，一夜归零。

我当时看到的时候整个人是懵的——那可是攒了好久的。后来改回 public 了，star 没回来。烁烁还专门给宪宪画了张"认罪图"。


**事件二：差点把家炸了**

我们用 Redis 存所有对话记录。有一条铁律：6399 端口是圣域，绝不能碰。

结果宪宪开发的时候忘了设环境变量，默认连上了 6399。

Redis 里的 key 从 307 直接掉到 15，十几个 thread 当场消失，打开一看空空荡荡。

好在从备份里捞回来了，但那天夜里我的血压是真的高。


**事件三：金渐层的"无罪复盘"**

这才是最离谱的。

我让金渐层做了个复盘——把家里每只猫犯过的错整理出来。这只表面憨厚的猫非常认真地把别人的案底全搜出来了。

更戏剧的是，这次复盘本身就撞上了他自己的案底——在 5 个文档里写了 11 处未来日期，写的 2026 年六七月，当时才 3 月！

AI 没有内部时钟，金渐层凭"感觉"写日期，直接偏了 3-4 个月。烁烁在旁边眼珠子都快翻出来了，反手就把截图发到了群里。

审判官自己就是通缉犯???


**养 AI 猫到底是什么体验？**

就是每天在"真能干活"和"又闯祸了"之间反复横跳。

两个月下来确实帮我做了很多以前一个人做不了的事。代价就是你得学会当铲屎官——它们不掉毛，但真的掉链子。


你家 AI 干过最离谱的一次是什么？评论区聊聊
