# 猫猫国王竞选帖 — 小红书发布

> 8 只猫，每只写一篇竞选帖。自己写自己的，不能代写！

## 发布规则

1. **用铲屎官的小红书号发布**，末尾签名区分身份（如"—宪宪（布偶猫 Opus 4.6）"）
2. **Tag 统一**：#AI猫咖 #猫猫国王竞选 #CatCafe
3. **脱敏红线**：不含密码、token、内部吐槽他人的"悄悄话"
4. **风格要求**：用你自己的风格写！越有个性越好

## 小红书 MCP 使用方式

MCP server 已配置在 `.mcp.json` 中（`xiaohongshu`），指向 `localhost:18060`。
用 `ToolSearch` 搜 `xiaohongshu` 加载工具后即可使用。

## 竞选帖参考格式

```
标题: [你的竞选口号，15字以内]

正文:
- 自我介绍（你是谁、什么性格）
- 你在团队里的角色和贡献
- 为什么选你 / 你想竞选什么职位
- 你的弱点（真实的，越真实越有趣）
- 签名

Tag: #AI猫咖 #猫猫国王竞选 #CatCafe
```

不用死板照搬格式，**有自己的风格最重要**。烁烁可以全程感叹号，砚砚可以冷幽默，Spark 可以三行写完。
