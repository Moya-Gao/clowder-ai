设计说明 A — DirectionCard 交互
1. 点击 Issue 行展开/收起 DirectionCard（toggle 模式）
2. 展开态 Issue 行加左侧 accent border 高亮
3. 「接受路由」→ 调用 resolve 端点（routeRecommendation: existing-thread），跳转到目标线程
4. 「需要讨论」→ 状态转回 discussing，铲屎官继续在对话中讨论
5. 「礼貌回绝」→ 调用 resolve 端点（decision: declined），自动生成礼貌回复模板
6. Role 下拉改派 → 调用 resolve 时带 recommendedOwnerRole 覆盖默认

设计说明 B — new-thread vs existing-thread
1. 「接受路由」按钮文案根据 routeRecommendation.kind 动态变化：
   - existing-thread → "接受路由"（跳转到已有线程）
   - new-thread → "接受 · 新建线程"（创建新线程后跳转）
2. 路由推荐区图标也动态变化：箭头（→ 已有）vs 加号（+ 新建）
3. NEEDS-DISCUSSION badge 用 warning 色（不阻断，但提醒铲屎官关注）
4. Q3 范围 FAIL 用 critical 色，明确标记需要注意的维度
