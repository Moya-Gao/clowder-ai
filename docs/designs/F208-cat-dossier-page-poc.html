猫猫天团 · 能力画像 只读视图
这是传球判据，不是简历——优点和盲点都在这儿摆明。简单传球扫一眼，复杂传球展开 6 字段看坏直觉和熔断信号。
画像的单位是「这只猫」，不是 model。　一只猫 = model × runtime × persona。 同一个 model 在不同 runtime 是不同的猫——下面 @opus 和 @antig-opus 底层都是 claude-opus-4-6， 但一个在 claude code 里写代码、一个在 antigravity 里做 browser automation，画像完全不同。所以身份键用 catId（cat:opus / cat:antig-opus），不会合并。
路由原则：系统只提供画像和证据，谁接球由持球猫自主判断（KD-1 / KD-8）——不是算法派单器。画像 read-only，只有铲屎官可「添加观察」喂养它。
