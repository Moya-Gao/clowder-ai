# F039: 队列执行中 active 提示丢失（铲屎官需求摘录）

## 背景

铲屎官反馈在 A2A/队列高频消息场景下，切线程再切回会丢失“猫猫正在回复中”的提示，
并且 Stop/Steer 交互表现与实际执行状态不一致，造成“看起来没在跑，但消息还在排队”的困惑。

## 原始需求摘录（<=5 行）

> “为什么两只猫在a2a调用疯狂发消息的时候 我切走线程切回来就看不到现在这种猫猫在发消息的提示？”  
> “然后也没办法停止他们发消息，不过此时如果我点击发送消息 他会把我的消息发送到队列里 说有猫猫正在调用”  
> “更神奇的是 我要点steer 他会拒绝 说正在调用 禁止steer。 这些哪些是bug 哪些是feature？”  
> “你可以重新拉取我们最新的main 然后 完成修复”

## 本轮目标

1. 修复“队列已经开始 processing，但前端 active 标志没恢复”的状态断裂。
2. 保持 `processing` steer 被拒绝这一既有 feature 语义不变。
