## 移动版（窄屏）

### 猫粮看板

- 总览三卡改为纵向堆叠（`状态总览 -> 数据更新时间 -> 操作建议`）
- 主按钮单独一行，保持可触达高度（>= 40px）
- 平台卡改为 `1 列`，避免三列压缩导致文字断裂

### 通知设置

- 能力矩阵改为 `2 列 x 多行`
- “修复建议”保持可折行，不出现横向滚动
- “发送测试通知”始终在可见区域，不埋到屏底

## 视觉锚点

- 浅背景 + 高对比信息卡（`bg-white / bg-gray-50`）
- 状态色统一：正常绿 / 关注橙 / 失败红
- 每屏只保留一个主按钮（避免操作冲突）
- 文案语义：状态 > 原因 > 下一步动作

## 验收锚点（对齐 AC）

- AC-16: 输出桌面/移动截图并与本 wireframe 对照
- AC-20: 以该文档作为 UI gate 记录，进入实现与测试
