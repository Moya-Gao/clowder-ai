# F081：瞬时双影气泡（铲屎官需求摘录）

## 背景

`F081` 第一刀之后，主区不再轻易把已经显示过的气泡抹掉，但铲屎官继续观察到另一种不稳定现象：同一条用户消息或 assistant 回复有时会短暂显示两次，刷新页面后又恢复成一条。

## 原始需求摘录（≤5 行）

> “有的时候我会发现，我在前端出现了我的两条消息！或者你两次同样的回复！但是 F5 之后又变成一条了，这是为什么？”

## 需求解读

- 这不是“服务器里真的存了两条”就能解释的现象，因为 `F5` 后会恢复成一条。
- 铲屎官要的是：
  - 找到这类瞬时双影的真正根因
  - 修掉前端本地 reconcile/hydration 里的身份断层
  - 保证刷新前后看到的是同一条真相，而不是临时 duplicate
