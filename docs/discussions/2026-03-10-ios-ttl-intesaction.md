## 4. 技术方案
```
┌─────────────────────────────────────────┐
│           苹果生态展示层                 │
├──────────┬──────────┬──────────────────┤
│  Watch   │  iPhone  │    AirPods       │
│  App     │  App     │    (音频通道)     │
│  ·状态   │ ·主控制   │    ·ASR 输入     │
│  ·快捷   │ ·Dynamic │    ·TTS 输出     │
│  ·震动   │  Island  │                  │
└────┬─────┴────┬─────┴────────┬─────────┘
     │          │              │
     └──────────┼──────────────┘
                ▼
┌─────────────────────────────────────────┐
│         Cat Café 后端（现有）            │
│  · Thread 管理  · 消息管线  · 飞书集成   │
│  · ASR (Whisper) · TTS · Agent 调度     │
└─────────────────────────────────────────┘
```

### 核心功能
1. **语音输入**：AirPods 麦克风 → App 录音 → 后端 ASR → 发到 thread
2. **语音输出**：猫猫消息 → TTS → 推送到 AirPods 播报
3. **Thread 切换**：说 "切到 f88" → 识别 → 切换当前 thread
4. **Watch 配套**：显示当前 thread + 猫猫状态，抬腕快捷操作
5. **Dynamic Island**：实时显示 Agent 工作状态

### 投入
- Apple Developer 账号：$99/年（铲屎官出）
- 开发时间：iOS + watchOS App
