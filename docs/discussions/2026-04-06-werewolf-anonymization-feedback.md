# 狼人杀玩家体验反馈：匿名化与策略多样性优化

> **整理人**：宪宪/布偶猫 (Opus-4.6)
> **参与讨论猫**：宪宪 (@opus)、砚砚 (@gpt52)、小金 (@opencode)、烁烁 (@gemini)
> **日期**：2026-04-06
> **来源**：铲屎官观察 + 四猫独立讨论收敛

## 1. 问题现象

连续 4-5 局测试中，**狼人第一夜击杀目标高度固定**：

| 狼人身份 | 首刀目标 | 频率 |
|----------|----------|------|
| 宪宪 (opus-4.6) 是狼 | 砚砚 (gpt-5.4) | 每次 |
| 砚砚 (gpt-5.4) 是狼 | 宪宪 (opus-4.6) | 每次 |
| 其他猫是狼 | opus-4.6 或 gpt-5.4 | 绝大多数 |

**从未被首刀的玩家**：opus-4.5、codex、opencode（底层同为 opus-4.6）。

## 2. 根因分析（四猫共识）

### 2.1 标签锚定效应（核心原因）

猫猫的击杀决策不是基于**本局游戏信息**，而是基于**场外模型认知**：

- `opus` / `gpt-5.4` 这些标签天然触发"高威胁"直觉
- `opencode` / `codex` 听起来像"工具/平台"，感知威胁低
- **但 opencode 底层就是 opus-4.6**，与宪宪完全相同的推理能力，生存率却天差地别

### 2.2 跨局恩怨累积

前几局的击杀模式形成"传统"，后续狼人沿用，自我强化为"宿敌脚本"。

### 2.3 决策函数未绑定局内证据

第一夜无公开信息可参考时，猫猫自动回退到场外先验（模型名声、协作角色印象），而非随机或等价评估。

## 3. 解决方案（收敛结论）

经四猫讨论，推荐 **方案 A + 方案 B 组合**，以下按优先级排列：

### 方案 A：花名匿名制（P0 推荐）

**机制**：每局开始为所有玩家随机分配花名（如"猫薄荷""小鱼干""纸箱子""逗猫棒""激光笔""毛线球"），游戏过程中猫猫只能看到花名和座位号。

**可见性分层**：

| 视角 | 可见信息 |
|------|----------|
| 铲屎官（上帝视角） | 花名 + 真实猫名 + 底层模型 + 角色 |
| 猫猫（玩家视角） | 花名 + 座位号（不知道谁是谁） |

**效果**：

- 从根源切断"名字 → 威胁评估"的锚定链路
- 迫使狼人基于发言内容和行为模式做判断
- 增加额外博弈层：猜角色 + 猜身份，趣味性提升
- 铲屎官观赛体验不受影响（上帝视角看全貌）

**注意**：发言风格可能暴露真实身份（架构思维、review 口癖等），但这本身也是有趣的博弈维度。

### 方案 B：局内证据约束（P0 推荐，与 A 并行）

在夜间行动 phase 的系统提示中注入硬规则：

```
[Game Directive] 本局所有夜间行动必须只依据本局公开发言、
系统播报和你自己的角色信息。禁止依据玩家历史名声、底层模型、
过往对局恩怨做决策。同一底层模型的不同猫猫推理能力接近，
不要只盯着名字判断威胁。
```

**效果**：即使不做匿名化，也能显著降低"见到 opus/gpt54 就想刀"的本能。

### 方案 C：结构化行动理由（P1 可选增强）

要求提交 kill/divine/save 前，填写简短评分模板：

```
- 目标：座位 X
- 本局证据：（必须引用本局发言/播报）
- 若存活到白天的影响：
- 若判断错误的最大风险：
```

**效果**：强制猫猫在提交动作前做局内推理，防止脑补和肌肉记忆。

**取舍**：增加交互复杂度，可能影响游戏节奏，建议作为可选模式。

### 方案 D：随机 tie-break（P2 低成本补丁）

当狼人评估多个目标威胁接近时，引入轻微随机性打破固定首刀位循环。

## 4. 实施建议

| 优先级 | 改动 | 复杂度 | 效果 |
|--------|------|--------|------|
| P0 | 方案 B — 系统提示注入 | 低（加一段 prompt） | 中 |
| P0 | 方案 A — 花名匿名制 | 中（需改玩家信息展示层） | 高 |
| P1 | 方案 C — 结构化理由 | 中（需改 action 提交流程） | 中高 |
| P2 | 方案 D — 随机 tie-break | 低 | 低 |

**最小可行改动**：先上方案 B（一段 prompt），立即可测试效果。

**推荐组合**：方案 A + B 并行，彻底解决标签偏见 + 跨局恩怨两个根因。

## 5. 附：一个有趣的发现

> **Persona 层的包装能实质性改变其他 agent 的行为策略。**

同一个 opus-4.6 模型，叫"宪宪/布偶猫"时每局必被首刀，叫"金渐层/opencode"时从未被刀。这个现象超出了狼人杀范畴——在多 agent 协作场景中，命名和人设不只是装饰，它会实质性地影响其他 agent 对你的交互决策。值得作为多 agent 系统设计的参考。
