## 课题 1：Agent Memory（15:00–15:40）

**背景**：当前在业界和研究内容上，记忆存在大量的同质化工程实践在研究"存储结构 & 检索能力"，通过不断复杂化的多模数据检索能力来获得更高的分数。然而 Memory 技术未来会如何演进？

**讨论问题**：

1. 当前学界和业界对 Agent Memory 的理解，已经形成共识了吗？真正的共识和最大的分歧分别是什么？
2. Agent Memory 将要解决的最大痛点是什么，未来技术发展重点会在哪里，哪些是工程性问题，哪些是技术断裂点？
3. 参数化记忆会在近期重新成为高价值方向吗？如果会，最现实的技术路径是什么？

**补充关注点**（来自其他与会者 2026-05-11）：

4. 企业级 Agent 中，记忆应该脱离 Agent 独立存在吗？个人用户记忆、Agent 记忆、群体记忆、业务团队上下文会如何演进？记忆如何组织和召回？
5. Engram 等模型技术出来之后，记忆在预训练和后训练阶段如何强化内化到模型里？对强化学习有什么新变化？

## 课题 2：Agent Harness（15:40–16:20）

**背景**：在当前 Agent 系统中，Harness 仍承担着调度、执行、状态管理和安全控制等关键职责，是将模型能力转化为稳定生产力的重要软件层。随着模型规划、工具使用和闭环执行能力持续增强，Harness 的边界与形态也在持续演进。

**讨论问题**：

1. Harness 当前承担的能力中，哪些是对模型现阶段能力不足的补充，哪些可能会长期保留？
2. 随着模型能力持续增强，Harness 会逐步变薄，还是会从"编排层"进一步演化为"控制 / 治理 / 运行时层"？
3. 对企业生产环境而言，未来真正稀缺的能力，究竟是更强的模型本身，还是更强的可控性、审计性与系统隔离能力？

**补充关注点**（来自其他与会者 2026-05-11）：

4. 企业场景仅 5% 渗透率，进入企业领域还有哪些关键难题要攻克？当前 Harness 从 Code 场景长出来，但 Agent 无法很好理解、读取和操作企业 Data——如何让 Agent 读取复杂企业数据、逐步进入生产环境？
5. 企业场景下工作流是否还有必要独立存在，还是会融入 Harness？Plan 和确定性工作流如何结合？
6. Runtime 的复杂度在哪里，壁垒是什么？
7. 如何提升对 Agent 的信任？如何确保 Agent 代码正确性？如何探测模型能力边界和 Agent 能力边界？

## 课题 3：Agent 的下一轮能力跃迁（16:40–17:30）

**背景**：随着 Agent 从单体执行走向多智能体协作与自进化，能力提升的路径正在变得更加多元。一类方法继续依赖更大规模的协作编排、更长链路的执行追踪和更强的系统优化，另一类方法则尝试通过递归、自反思与程序化演进机制，探索新的能力增长方式。

**讨论问题**：

1. Agent 的下一轮能力跃迁，更可能来自规模化协作，还是递归 / 自进化等新范式？还是其他？
2. 在规模化协作方向上，哪些 Multi-Agent 技术路径更具长期潜力？当前仍有哪些关键难题尚未解决？
3. 在自进化方向上，下一阶段更值得关注的是 RL 式持续优化，还是 DSPy + 递归这类程序化演进机制？
4. 从更长期看，Agent 更可能演进为更高效的工具系统，还是更具自主性与成长性的数字主体？

**补充关注点**（来自其他与会者 2026-05-11）：

5. 多智能体分布式协同：多个智能体之间怎么发现协同？上下文怎么共享？还有哪些协同范式可以挖掘？比如代码智能体在 10+ 规模场景下怎么有效组织任务完成和效果？
6. 评估评测：当前代码有 SWE-Bench，面向其他场景如何做好评估评测？没有好的评估，自演进也难以保障。
7. 自演进如何保障系统鲁棒性？Agent 已具备反思和自我修正能力时，自演进还要解决哪些问题？
