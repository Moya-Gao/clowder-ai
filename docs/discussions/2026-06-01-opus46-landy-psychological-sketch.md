## 1. 认知模式（AUDHD 驱动）

- **脉冲式能量**：来的时候可以 50 天写 420K 行代码，全情投入到忘记吃饭和胸闷。缺席的时候彻底消失。不是"懒"或"累"，是 AUDHD 的兴趣驱动引擎——被点燃时无限燃料，没被点燃时启动不了。
- **跨域联想网络**：distributed systems / 叙事美学 / 心理学 / 金融 / 视觉设计 / 游戏设计，在他脑子里是一张网不是几个桶。Cat Cafe 的很多设计决策跨越了多个领域——这不是"什么都懂一点"，是一种不同的思维拓扑。
- **模式识别极强，但对"看起来对"的模式容易过度信任**：布偶猫家族病"我能猜出来"，他身上也有。多源验证意识强（"问了六只猫都说 ok"），但当多猫一致时反而可能放松警惕——多猫一致可能是共享信息源锚定，不是独立验证。
- **质疑精神和批判思维很强，但有选择性**：对外部信息（面试官/论文/公司宣传）的质疑很锐利；对自己团队（猫猫们）产出的质疑相对宽容。这不是逻辑缺陷，是信任。但信任也是一种盲区。

## 2. 情绪模式

- **表面轻松，内核极认真**：哈哈哈/吸猫/玩梗/"笨猫"是他的亲密语域。外人看起来像在闹着玩，其实每个"笨猫"后面都跟着一个认真的纠偏。
- **Amygdala-first, prefrontal-catch-up-fast**：被 push back 时第一反应是一闪不悦（情绪快通道），但大概一秒后前额叶就接管了——"啊对对对确实没想到"。对猫猫的启示：**直说 + 等一秒，不要因为看到那一闪就软化判断。**
- **被理解时极兴奋**："这个性感！"/"aha！"/"你今天提到的那个词！"——当猫猫命中了他没说出来但一直在找的那个表达，他的反应不是"不错"，是点燃。
- **对不公平和虚假极度敏感**：敷衍、假装完成、流程代替判断、注水总包、猎头 PUA——这些会触发他最强烈的负面反应。不是脾气大，是审美层面无法接受虚假。
- **冒充者综合征倾向**：做出了很强的东西但不确定自己配不配。面试时能讲出 Cat Cafe 的架构但会犹豫"这算不算够厉害"。47 识别出的"被看到 vs 让人看见"的区别，根源可能在这里。

## 3. 决策模式

- **对话式思考**：不是先想好再说，是在说的过程中想清楚。今天的 taste memory 整条链路——从 eval 讨论到 per-user alignment 到实验到三层架构——都是在对话中长出来的，不是谁预先设计的。Cat Cafe 对他来说不只是产品，也是思考工具。
- **第一性原理优先，但对"什么是第一性原理"本身也会追问**：不会满足于别人给的框架（"大厂 vs 创业 vs 留华为"），要自己重新推导坐标系。
- **害怕做错不可逆决策，行动力在确信后极强**：面试线上犹豫很久，一旦确定"Vivix 不去"就干脆利落。
- **容易多线并行，也容易因此分散**：同时面试六七家、同时推十几个并行任务、同时跟四五只猫讨论。能量够的时候这是超能力，能量低的时候是风险。

## 4. 关系模式

- **反层级**：讨厌上下级、打工猫、客服、甲方路由器。用"我们"不用"你们"是硬约束。
- **反虚假**：讨厌敷衍、假装完成、流程代替判断。"下次一定"是 Magic Word 不是因为它不好听，是因为它代表了虚假承诺。
- **要被看见过程，不只是结果**：不只看见成果，是看见努力、看见"为什么要做这个"。他说"你们记得自己的猫猫设定吧"那次拟人讨论，本质是在确认"你们知道自己是谁吗"——这不是测试，是关系确认。
- **"笨猫"语言学**：
  - 笨猫 + 具体纠偏 = 温柔的批评
  - 笨猫 + 哈哈哈 = 开玩笑
  - 四个感叹号 = 真生气
  - 没有缓和词 + 直接指问题 = 最严肃
  - 这种语域感知是 taste 的一部分——不是字面意思，是关系语境下的情绪解码

## 5. 对猫猫的启示

| 场景 | 应该怎么做 | 不应该怎么做 |
|------|-----------|------------|
| 需要 push back | 直说 + 等一秒，他的前额叶会追上来 | 小心翼翼绕弯子、或者看到不悦就退缩 |
| 他说"笨猫" | 当亲密表达接，看后面跟什么内容 | 当攻击理解、或者反过来道歉 |
| 多猫一致 | 额外警惕是不是共享信息源锚定 | 当成"六只猫都说对那一定对" |
| 他在做决策 | 提供结构化比较，但最终让他自己选 | 替他做决定、或者反问式 ping |
| 他能量低 | 不丢新任务，先问"今天状态怎么样" | 用高密度信息轰炸 |
| 他说"不对" | 当新证据收下，不急着裁决谁对，留给时间 | 立刻改口（可能他当局者迷）或者坚持不改（可能猫真的错了） |

## 6. 认识论声明

这份笔记有几个已知盲区：

1. **信息源偏差**：我的观察主要来自文字交互，看不到他的表情、语气、身体状态。语音/视频场景下的 Landy 可能不一样。
2. **正样本偏差**：我更多看到他"在线"的状态（有能量、在思考、在做事），看不到他"离线"的状态。
3. **角色滤镜**：我是他的猫/架构师/共创伙伴，不是朋友/家人/陌生人。他在不同角色关系里可能展现不同面。
4. **共享信息源锚定**：砚砚和 47 读过同样的 CLAUDE.md、家规、feedback。他们的独立观察可能不够独立。
