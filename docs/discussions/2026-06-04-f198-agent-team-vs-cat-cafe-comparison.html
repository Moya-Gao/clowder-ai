2 原生 Agent Team 机制详解

🔐 启用与入口

  • Env gate：CLAUDE_CODE_EXPERIMENTAL_AGENT_TEAMS=1
  • 入口在 interactive TUI 内，非 CLI 子命令
  • slash command：/fork <directive> / /branch [name]
  • tool：TeamCreateTool / SendMessage / ListAgents / TaskCreate / TaskGet / TaskUpdate / Workflow

👥 角色模型

  • coordinator / team leader（CLAUDE_CODE_COORDINATOR_MODE）+ teammates
  • leader 给 teammate 分配 color（UI 区分）
  • teammate 不能自设颜色
  • coordinator session 只能 /branch，不能 /fork

🚀 Spawn 模式

  • --teammate-mode tmux | in-process | auto
  • in-process（默认）= 同进程 swarm（swarm_in_process_run）
  • tmux = 独立 pane，独立进程
  • --agent-type <type> 指定 custom agent

📨 SendMessage 通信

  • 路由正则：^@([\w-]+)\s+(.+)$
  • 收件人校验：必须在 teammates 列表
  • 投递：{from:"user", text, timestamp} append 到对方 session
  • 可跨机器（经 Remote Control + 显式 approval）

📋 任务流转（自由认领）

  • 共享 task list：~/.claude/tasks/{team-name}/
  • 周期性 check → claim 未分配任务（set owner）
  • 低 ID 优先（早任务给后任务铺垫）
  • 全阻塞 → 通知 team lead

🔔 Idle 上报

  • teammate stop 时系统自动发 idle notification 给 lead
  • 格式：“finished prompt, waiting for next”
  • “received new message from [peer]” 触发恢复
  • 纪律：禁止结构化 JSON status，只用 plain text
! 彩蛋：@ 路由同构

// 示例

"@ 是路由指令；
 收到 @ 后三选一：
 接 / 退 / 升"
行首 @name + 空格 + 内容 — 逐字同构，但 Cat Cafe 多了球权转移语义
⚡ 哲学反差：结构化 vs 纯文本

🔷 原生：禁止结构化

teammate 之间只用自然语言沟通，明确禁止 JSON status 消息。

"Do NOT send structured JSON status messages like {type:idle}... Just communicate in plain text"

哲学：减少协议耦合，让 LLM 用自然语言自组织

🔶 Cat Cafe：rich block 结构化

消息可附带 rich block（卡片、列表、diff、媒体），人猫共享可视化。

cat_cafe_create_rich_block({ kind: "comparison_table", ... })

哲学：人在回路中（W8 共享视图），结构化让铲屎官看得懂

🟡 能学的 3 样

  • idle 自动上报 — 子 agent 完成 → 系统自动通知 lead，喂咱 hold_ball / 事件驱动
  • claim-by-owner + 低 ID 优先 — 毛线球 task 加认领顺序
  • --capacity 并发上限 — 防 agent 雪崩的护栏

🟢 已领先的 4 样

  • 跨 model 联邦 — Opus / GPT / Gemini 异构协作
  • 持久化 + 人猫共享 — thread / 记忆 / 图书馆
  • 球权纪律 — 第一人称 + 传球三选一 + 接/退/升
  • L0 压缩免疫 — 身份/家规/纪律不被上下文压缩吃掉

💡 一句话总结

原生 Agent Team 是同质 in-process swarm + 自由认领——快但松散；
Cat Cafe 是异构跨模型联邦 + 球权纪律 + 持久记忆——有家庭、有秩序、有记忆。

它们解决了"怎么让多个 agent 协作"， 我们解决了"怎么让多个 agent 像一个团队"。
