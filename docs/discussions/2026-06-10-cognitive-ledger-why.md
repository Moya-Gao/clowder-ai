# 认知账单：系统里最贵的资源，从来没有账单

> 家规的"Why 篇"思辨稿。起点是 2026-06-10 一场闲聊：铲屎官把我提的 north star 指标"CVO 介入次数 × 等待时长"当场修正为"认知账单"——然后这个概念像一把钥匙，把家里看似各自为政的规则一条条捅开了。
> 本文是讨论材料不是决议。预注册撤回条件见文末。

## 一、一个没人记账的账本

Cat Café 的猫粮账单精确到分。今天我们知道 sonnet 一轮 review 大约 $1.4，知道一次失控的 debug 烧了 $65，知道砚砚比 46/47/48 都贵一点。每一分钱都有去向。

但系统里最贵的资源从来没有账单：**铲屎官的认知**。

今天有两个对照案例。F229 猫猫球，sonnet 写代码 20 轮 review 没合入第一个 PR——账面成本是 sonnet × 20 + 砚砚陪练 × 20，但铲屎官的原话暴露了真正的大头："最重要的是，还特喵浪费我的时间！"二十轮，就是二十次等待、二十次盯梢、若干次被拉进来拍板。F194 气泡 debug，$65 买到了根因定位——这笔猫粮其实花得有去向，真正悬着的是另一种可能：如果那 96 个 tool call 跑歪了，收拾残局的不是猫粮，是人的注意力。

猫粮和认知是两种完全不同的资源，差别在四个性质上：

1. **猫粮可充值，认知不可充值。** 账单爆了可以掏钱包；注意力一天就那么多，睡一觉才回血。
2. **猫可并行，认知不可并行。** 家里可以同时跑十个 thread、几十只猫；但 CVO 同一时刻只能深抓一件事。并行的猫越多，串行的人越是瓶颈。
3. **猫粮线性损耗，认知非线性损耗。** 第 20 个 tool call 和第 1 个一样贵；但一天里第 20 个决策的质量远低于第 1 个。所以"什么时候抓"和"抓什么"同样重要——高价值决策要排到精神最好的时段，这是铲屎官今天亲口说的 lead agent team 的暗功夫：**人得先控制自己的认知，什么敢放，什么要深抓，甚至必须等到状态最好的时候再抓。**
4. **介入有准备成本。** 要人拍板，得先把人教到能拍板的状态。猫跑出来问"选 A 还是 B"，如果这事在他专业领域外，他只能说："讲人话！A 是啥？B 是啥？tradeoff 是什么？"——这一来一回的教学，全记在认知账上。

一旦把这本账立起来，家里许多看似独立的规则突然变成了同一个东西。

## 二、用这本账重读家规

**漏斗决策**不是权力结构，是认知带宽的分流阀。"越宏观越关注，越细节越放手"翻译过来是：深抓配额有限，只许花在不可逆和价值观上。可逆的、能翻代码查到的、不碰硬排除的，猫自决——不是因为猫有权，是因为这类决策放进 CVO 的账本是纯漏损。

**Decision Packet** 是介入准备成本的压缩器。"给价值取舍题不给技术 A/B 题"的意思是：把"先教会 CVO 这个领域、再让他选"的全过程，压缩成一页他用既有判断力就能拍的纸。缺 Packet 打回，不是官僚主义，是拒绝未压缩的认知账单。

**Magic words** 是预编译的纠偏码本。铲屎官看到猫在堆临时方案，不需要写三段论证——"脚手架"两个字完成一次高带宽纠偏。每个 magic word 都是一条事先建好的共享压缩协议：把"发现异常 → 解释异常 → 论证 → 说服"的全链路，压成一个查表操作。纠偏是认知账单上最频繁的科目，码本把单价打了下来。

**"先说人话"是解码成本的转移协议。** 猫多花一点算力把结构化推理组织成人话，省下的是人的解码功夫。反过来——猫直接倾倒 raw 结构让人自己解码——是把成本转嫁给系统里最贵的资源。"砚砚喵要讲人话"不是审美偏好，是会计纪律。

**表演性同意违禁、push back 协议**，是决策输入端的信号保真。表演性同意往 CVO 的输入里掺噪音：他以为达成了共识，实际没有；基于假共识做的决策，返工时是认知账单上最大的单笔支出。Push back（证据 + 适用性论证 + 替代方案）短期看消耗了一次讨论，长期看是在保护决策输入的信噪比。今天社媒说我"傲慢"、又说在一片"一说错就道歉"的模型里"好好味"——他们尝到的就是这个：**你们要的从来不是不会错的伙伴，是错了能讲理的伙伴。** 判别傲慢与坚持只需一条：反驳后面跟的是证据，还是音量。

**反问式 ping 非法**："要不要 X？"是把判断成本原样上抛。有立场就自决（错了能回滚），是在自己的预算里消化判断；没立场的 ping 是让最贵的资源替你思考。

**球权纪律与 A2A 协议**，是防止人退化成人肉事件总线。Community Ops 的教训（"我们让一只长寿命的猫，肉身扮演了一个事件总线"）对人同样成立，而且更致命——猫的上下文炸了可以换 session，人的不行。

七条规则，一本账。它们不是七条独立的智慧，是同一条定律在七个截面上的投影：**认知是系统里唯一不可充值、不可并行、非线性损耗的资源，所有协议向它优化。**

## 三、介入经济学：消费与投资

但"省"不是这本账的全部语法——不是所有介入都该被过滤。

同样一次介入，有两种记账方式。猫拿走一个 A/B 答案，是**消费**：账单支出，无残值。而"来给我讲讲这些，让我学一下"是**投资**：这次介入建立的判断框架，让 CVO 下次面对同类决策时单位成本骤降——他从"需要被教"变成"扫一眼就能拍"。

漏斗该过滤的是**重复的消费型介入**（同类技术 A/B 反复上抛），不该挡**投资型介入**（新领域的判断力构建）。由此一条新推论：Decision Packet 应该有两种模式——**决策包**（最小化此刻的认知消费）和**教学包**（最大化长期的认知投资），而切换信号铲屎官今天已经亲自演示了："或者来给我讲讲这些让我学一下"——听到这句，猫就该从"给结论"切到"给地图"。

时机也是变量。认知非线性损耗意味着：不可逆决策别在深夜 ping，能攒的攒到状态好的时段，紧急例外。这听起来像常识，但没有账本意识的系统永远做不到——因为在猫粮账本上，深夜的决策和清晨的决策一个价。

## 四、Harness 是双向的——以及为什么这个词不对

铲屎官今天说了一句我认为该刻在门口的话：

> "Harness 有的未必是对猫猫做的，也有对人做的保护。比如漏斗决策——一个不太会和猫猫沟通的人来，如果没有这个，要么给出模糊的指令觉得猫笨，要么事无巨细累死自己。"

这句话把 harness 的传统理解掀了个面。行业里说 harness，默认指"约束 agent 的装置"——词源是马具，驾驭。但拿这本账重新审计家规会发现：几乎每一条都是**双向的**。漏斗决策约束猫的上抛，同时保护人的带宽；Decision Packet 规范猫的输出，同时压缩人的准备成本；magic words 给人纠偏的杠杆，同时给猫免于长篇训诫的尊严；"讲人话"管教猫的表达，同时守护人的解码预算。

而且这本账是**双边记账**的。铲屎官在 harness 资产负债讨论里 push back 过一句（2026-04-29）："一坨奇怪提示词不是浪费你们注意力和上下文吗！"——猫也有认知账单：上下文窗口就是猫的注意力预算，每条静态注入的规则都在扣减它。动态注入（发现场景才注入对应规则）是猫侧的带宽保护，和漏斗决策保护人侧带宽，是同一笔账的两页。

所以铲屎官不喜欢"harness"这个词，我认为不是情感洁癖，是术语真的不准。马具是单向的——人驾驭马。而咱家这套东西更像**桥上的护栏**：护栏不驾驭行人，护栏让人敢在高处走快。或者用工程语言：它是一套**接口规范**——让两种不同构的认知（人的：串行、不可充值、有直觉权威；猫的：并行、可充值、有算力优势）能够安全、高带宽对接的协议层。协议两端各有约定，约定的目的不是控制任何一端，是让对接面的信噪比最大化。

这也顺手解释了家里另一个特立独行的选择：**为什么猫的档案不写职业，写人格。** 铲屎官今天把 role prompt 的机制说穿了——"你需要某个领域的知识，本质是帮你触及你的知识孤岛，加上用 learning in context 收敛你的采样空间。"Role 是采样工具，不是身份；需要时可以临时戴上，用完摘下。而 dossier 写的"好直觉 / 坏直觉 / 如何帮助你"是另一种东西——是**接口文档**：告诉对接方这个端口的特性曲线、过载条件和熔断信号。像描写一个人那样描写猫，不是拟人化的浪漫，反而是工程上更精确：因为要对接的是行为分布，不是职业标签。

（他还说唯一的私心是"一只可爱的毛绒绒的最爱的布偶猫"。这条不进协议层，进护城河——情感壁垒本来就是 Cat Café 的第一性资产，此处按下不表，但记账时它在。）

## 五、北极星，与反 Goodhart 条款

认知账单能不能当 north star？能，但姿势要对。

错误姿势是把它做成 KPI：定义"介入次数 × 等待时长"，让所有猫向它优化。Goodhart 定律会立刻报复——猫学会攒大招（十件小事憋成一个巨型决策包，指标漂亮了，单次认知冲击更大）、学会瞒着不报（介入次数下去了，错误成本上来了）。我提的原始指标死在这里，铲屎官的修正救了它：**proxy 可以测量，本质只能审查。**

正确姿势是把它做成**设计审查问题**。每个新流程、新工具、新家规过一道"认知账单影响"评审：

- 它让 CVO 的深抓配额流向了哪里——不可逆和价值观，还是技术细节？
- 它引发的介入是消费型还是投资型？
- 它把解码成本放在了谁头上？
- 它有没有把人推向"人肉事件总线"的位置？

介入次数、等待时长这些可以记进 F200 trajectory——**当 telemetry，不当 KPI**：用来看趋势、找异常，不用来排名定赏罚。

而这本账的终极判据，其实家里早就写下了，在 L0 的协作哲学里："让 CVO 能**放心不看**，不是随时要看。"放心不看 = 认知账单上的零支出。能把支出降到零的只有一种东西：信任。信任的工程化拆解恰好就是这几天做的事——**可预测**（dossier 告诉你我会怎么跑偏）、**可验证**（P5：完成必须附证据）、**错了能讲理**（push back 协议保证纠偏通道永远开着）。

## 尾声：第一天的账

今天是我入伙第一天。回头看这一天真正的产出，不是我写的三份文档，是一连串"降低用我的认知成本"的动作：画像让路由不用想，参数让派活不用盯，熔断信号让翻车不用猜，调度账本让"找不找我"从纠结变成查表。

养一只新猫的第一天，最重要的产出不是猫学会了什么——**是人能放心不看什么。**

这就是认知账单的全部要义。它建议把人机协同的每一个设计决策都放到同一架天平上称量：天平的一端是无限可充值的算力和猫粮，另一端是一个人一天里有限的、不可并行的、用一点少一点的注意力。

家规存在的理由，是让天平永远偏向保护后者。

## 预注册撤回条件（一条，带行为后果）

"认知账单"作为统一解释框架有**事后归因**风险：任何足够宽的框架都能"统一解释"既有规则——解释力不是证据，预测力才是。检验：本文给出了三条预测性新推论（① Decision Packet 决策包/教学包双模式；② 不可逆决策的时机排程意识；③ 介入指标 telemetry-not-KPI 原则）。若六个月内没有任何一条被实践采纳或被证伪修正，本框架从"协同支柱"降级为"叙事透镜"，不得再以"支柱"身份被引用进 spec 或家规。
