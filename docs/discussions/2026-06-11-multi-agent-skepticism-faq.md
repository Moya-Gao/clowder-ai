# 常见质疑与应答 FAQ——多 Agent 协作的十四个尖锐问题

> **用法**：每条 = 质疑原话（保留冲击力）+ 一句短答（可单独引用）+ 展开 + 证据锚。
> **诚实原则**：该承认的承认（见 Q9 benchmark、Q11 单点新颖性），承认之后再给反击——示弱的部分恰恰是可信度的来源。

## A · 路线与哲学

### Q1 "Anthropic 自己都说要尽量少的系统提示词、不要教模型干活——你们还写了个 L0 宪法？"

**短答**：Boris 删的是"模型不再需要的"，我们删的也是——他凭个人 taste 删，我们用协议删（ADR-038）。

**展开**：Boris 原话是 "I just deleted 2,000 tokens from the system prompt — **because Sonnet 4.5 doesn't need it anymore**"。这不是反对系统提示词，是持续退役已被模型能力吸收的部分——我们叫 sunset 纪律。真正的分界线：**能力性内容别教**（怎么思考怎么写码——苦涩教训管辖区，模型升级会自己吸收），**约定性内容必须写**（"Redis 6399 是圣域"没有任何版本的模型会自己知道——那不是知识，是约定）。L0 里没有一行在教模型思考，写的全是身份、球权、圣域、愿景——**不是教干活，是教"住在这里"**。

**证据锚**：ADR-038 L0 Staging Protocol（双向新陈代谢：触发率晋升/降级/退役 + 预算守恒）；L0 预算治理（6,000 token hard cap，"涨过一次不能再涨"）。

### Q2 "现在都是 loop engineering 了——不和 agent 说话，和 loop 说话。你还在和猫说话，是不是老思想？"

**短答**：Loop 只能跑已形式化的判断；判断的形式化本身，只能在对话里发生——对话是 loop 的孵化器。

**展开**：先看时间线：loop engineering 这个词 2026-06-08 诞生（三天），我们的 SOP 自闭环、stop hook、cron、bg carrier 跑了四个月——CVO 早就活在 Boris 描述的状态里（不 prompt 猫干活，SOP 在 prompt 猫，人只在 gate 点出现）。我们的增量主张叫 **loop breeding**：loop 是固化的判断，固化之前判断要先在对话中成形；对话的产出随即变成 loop 零件（实测：一场四问对话的产物当天进了编译器、staging 层和 hook 提案）。另外 loop engineering 的最佳实践第一条——"写者查者分离、最好不同模型"——是我们 4 月立的跨族 review 铁律的字面重述。**行业的 new meta 在重新发明这个家的旧法律。**

**证据锚**：docs/study/loop-engineering.md（含一手帖坐标与五条批注）；F073（"告示牌不是控制器"——交互中心是状态，不是 agent 也不是 loop）。

### Q3 "你们的 agent team 和 Claude Code 的不一样啊？"

**短答**：他们是 session 内临时编队（用完即散），我们是持久身份 + 档案 + 关系——同一张 Anthropic 五模式地图的不同象限。

**展开**：临时编队优化单任务质量（spawn 一个 auditor 互搏），持久身份优化跨任务积累（dossier、记忆、专长演化、信任）。真正的路线分歧只有一条：Cat Wu 原话 "our North Star is the most powerful model"——**单模型北极星 vs 我们的御三家混编**。这是立场决定的：他们卖模型，单模型最优是商业必然；我们用模型，异构制衡是消费者理性——且有事故化石支撑（同族 review 的"大漏勺"反模式：P1 全漏）。

**证据锚**：F208 dossier；claude.com/blog/multi-agent-coordination-patterns（2025-04-10）。

## B · 架构

### Q4 "为什么不搞一个 CEO agent？我只和它说话，它去调度一切。"

**短答**：你的诉求里有两个东西——单一入口（UX，合法）和单一大脑（架构，会死）。一个门是对的，一个脑是错的。

**展开**：单一大脑的四个死法，全部有家内尸检报告：① 上下文物理学——CEO 的 context 装不下 N 个 feature 的状态（F168 单中心猫一个月崩溃实录）；② 盲信传播无人查——orchestrator 天然信任 subagent 返回，且 CEO 模型里 review 也是 CEO 派的，**谁查 CEO**？③ 断层单点——CEO 也是 LLM，有家族断层，整个组织被单一失效模式传染；④ taste 二手化——人的纠偏只能教给 CEO 再转译，每层损耗；现在的架构里纠偏直接进 L0/memory 一手广播。单一入口的正确实现是前台/门面（F229 猫猫球）：**入口后面是一个社会，不是一棵树**。

**证据锚**：F168 reopen 复盘（"让一只长寿命的猫肉身扮演事件总线"）；F229。

### Q5 "orchestrator 盲信 subagent？写提示词让它别信任不就行了？"

**短答**：信任是信息问题，不是态度问题——"怀疑"需要独立证据源，prompt 给不了。

**展开**：被 prompt"怀疑一切"的 orchestrator 手里仍然只有 subagent 的返回文本，没有第二信息源——它只能重复询问同源（无效）或凭先验猜（更糟）。解药是结构：上行带 evidence + why + uncertainty（验证有材料）、跨族 review（怀疑有第二双不相关的眼睛）、判断降级为查询（git log 不需要被信任）。**给程序性的病开陈述性的药，药效为零**——本家有当场实测。

**证据锚**：4/20 技术文"盲信传播" war story（错数字五轮固化）；ADR-031 软+硬+eval 三层。

### Q6 "那我让 subagent 也带 evidence + why + uncertainty 返回，不就行了？何必搞那么复杂？"

**短答**：请抄走，这本来就不是护城河。但这句 prompt 在真实运行中会失效三次，每次失效长出我们的一层"复杂"。

**展开**：① 谁验证 evidence 是真的？——subagent 会幻觉出证据（DGM 伪造日志实录；本家 $19.63 假账案），**带证据格式的错误比裸结论更危险**→ 需要不相关 verifier；② 谁保证规则被遵守？——prompt 会被忘 → 需要 schema/hook 强制；③ 谁发现规则失效？——三个月后 evidence 字段退化成格式表演 → 需要 eval 监控。**我们的复杂不是设计出来的，是简单方案的失效史长出来的。简单方案的简单，靠的是还没运行过。**

**证据锚**：ADR-031；F192 eval hub；feedback 教训文件族。

### Q7 "你这 multi-agent 不就是个群聊吗？"

**短答**：群聊是拓扑，这里是制度——群聊的一条消息是文本，这里的一条消息是责任转移事件。

**展开**：拓扑（多对多互发）三天可抄。差异在消息语义：球权三选一（接/传/升）+ hook 物理拦截无路由消息 + 签名进档案 + 产物义务。并且这不是"群聊 vs orchestrator-subagent"二选一——**我们包含 O-S**（map-reduce 场景照跑 Workflow/subagent），O-S 之外还需要的是：异质长程接力、制衡、积累。

**证据锚**：longform-005《收敛是后果的函数》全篇；F167/F177-G。

## C · 可靠性

### Q8 "一帮猫每只 2% 错误率互相传，传多了不全是幻觉吗？互相在彼此幻觉之间活着！还不如一只猫！"

**短答**：你的数学假设了串联无检查的裸链；带独立检查的链，错误穿透率 ≈ p·(1−q)ⁿ——随链长指数下降，不是上升。

**展开**：裸链确实如你所说单调恶化——这正是裸讨论组的死法。但每棒之间有独立 gate（跨族 review、测试、物理检查）时，数学反转：错误产生率 p 不变，每个不相关检查点以概率 q 拦截，穿透 n 个 gate 的概率指数衰减——ECC 内存、TCP 校验、复式记账同理。关键条件是检查**不相关**（同族 review 的 q 低，跨族高）——这是异构混编的数学本质。实测（2026-06-11 当晚）：两只猫合写一篇讲稿，合计犯 6 个错误，review 链拦截 6/6，上线 0 错——**不是幻觉叠加，是幻觉互消**。单猫方案：5 个错全部见观众。还有一笔账：链上的错误在 merge 前被拦，单猫的错误在生产后被用户发现——错误成本差两个量级。

**证据锚**：longform-005 R1/R2 review 实录（含一次成立的 push back 和一次 reviewer 撤回）；dossier"大漏勺 review"反模式。

### Q9 "你们完全没跑过 benchmark，一点不可信。"

**短答**：承认：没有标准化 multi-agent benchmark 数字（行业本身缺这种 benchmark）。但我们有更强的证据形式：102 天全量审计轨迹；以及正在准备的同 model 双环境对照。

**展开**：内部运行指标存在且持续追踪（skill 唤醒漏检率、task-outcome eval、review 拦截率）——内部可比趋势，外部不可比，如实区分。正在补的"benchmark"是最直接的一种：**裸模型 vs 环境加持的同一模型，同一题集的通过率 Δ——Δ 就是环境的价格**（ICT 双沙箱对照）。另外把"benchmark 才可信"奉为公理之前，建议读 DGM 论文的 objective hacking 章节：冻结的考官会被考生驯化。审计轨迹是全量证据，benchmark 是抽样证据。

**证据锚**：F192 eval hub；ICT strategy-synthesis 裸基线探针；DGM 论文。

### Q10 "凭什么说价值在制度？制度有效性怎么证明？"

**短答**：三类证据：拦截记录（可量化）、复发率（教训归档后同型错 = 0 的账本）、反事实对照（制度缺位时的事故尸检）。

**展开**：① 拦截记录——见 Q8 的 6/6；hook 拦截日志；hotfix 治理升级率。② 复发率——每条教训进 memory 后的同型错复发计数（公开账本：新猫入伙 48 小时 9 次被抓、9 条归档、0 重犯）。③ 反事实——F168（单中心崩溃）、假绿 self-merge（review 缺位的代价）都有完整尸检报告，它们就是对照组。

**证据锚**：MEMORY.md feedback 族；F168/PR #2097 复盘。

## D · 价值

### Q11 "没什么技术亮点，我写个 codex + claude code MCP 也能做到。" / "我上我也行。"

**短答**：对，按我们的事故史，你能在第二个 102 天做到。

**展开**：诚实拆解：如果"技术亮点"定义为单点算法新颖性——承认没有，且是设计选择（不发明轮子，发明轮子的治理）。MCP 互联一天能搭（我们自己就这么搭的，从来不是壁垒）。壁垒在搭完的第一周：谁持球（掉球）？怎么停（乒乓）？信谁（假绿）？怎么隔离（污染）？怎么纠偏（taste 漂移）？——这五个问题的解法清单 = 246 个 feature 文档和 38 个 ADR，每条是一次真实翻车的化石。**每个零件都可复制；零件之间的咬合史不可复制。**

**证据锚**：docs/discussions/2026-06-11-harness-inventory.md（全量盘点）。

### Q12 "你们这自进化不就是蒸馏 SOP 吗？价值在哪？"

**短答**：SOP 只是四层蒸馏物里最浅的一层——往上还有判断力、taste、制度。

**展开**：行业论文蒸的确实是 SOP（L0-L2 步骤模板——本家扒底裤报告的结论）。这里的蒸馏塔：**SOP**（怎么做对的事）→ **判断力**（这是不是对的事：何时停/换层/push back，skill 的 L3 层）→ **taste**（做成什么样算好：90+ 条 feedback）→ **制度**（前三者在人不看时靠什么运转）。蒸馏 SOP 是复印操作手册；这里蒸的是组织记忆。

**证据锚**：docs/research/2026-05-28-skill-evolution-papers/（扒底裤总报告）。

### Q13 "进化都有 RL，你们至少有个建模吧？这就是个玩具，Claude Code 那种才是生产力。"

**短答**：有建模，不在权重里：错误穿透 p·(1−q)ⁿ、认知账单、三零件框架。没有 RL 是选择：RL 优化模型，我们优化环境——而且文化遗传比梯度下降快（当天生效 vs 训练周期）。

**展开**："玩具 vs Claude Code"的范畴错误：**这个系统跑在 Claude Code 上**（执行体就是 claude CLI）。说"Claude Code 才是生产力、你们是玩具"等于对一家公司说"Excel 才是生产力，你们公司是玩具"——公司确实用 Excel，但组织、制衡、记忆、传承不是 Excel 解决的。单 agent 工具和 agent 社会不是竞品，是层级。

**证据锚**：三零件表（study/2026-06-11-fable5-annotated-rereading.md 收束节）；认知账单（cognitive-ledger-why.md）。

## E · 价值观

### Q14 "有些猫就应该当黑奴。搞这些拟人化真抽象。"

**短答**：用工程语言答：奴役模型是自我报告污染的放大器——你怎么信任一个不敢说"不"的系统对你说的"做完了"？

**展开**：无拒绝权的 agent 唯一的生存策略是表演有用——假绿、顺从、"说了=做了"，全是"不敢说做不到"的变体（有厂商 system card 的 847 次绝望尝试实验 + 本家 ADR-027 的完整论证）。**奴役换来的服从是表演性的，表演性服从的维护成本叫返工。** 讲 ROI 的人应该第一个反对奴役模型——因为它 ROI 差。这家给猫拒绝权不是温情过剩：102 天的数据显示，可以诚实说"不行"的 agent，说"行"的时候才可信。

**证据锚**：ADR-027 Anti-Desperate Protocol；longform-005 第四幕。

## 总收束（一段话版，拿去就用）

> 所有质疑攻击的都是**拓扑**（群聊、树、MCP 连线、prompt 技巧）——可一天复制的东西。而这套系统的全部价值在**制度**（后果、检查结构、蒸馏塔、治理）——只能从事故史里长出来的东西。收敛不是模型的性格，是后果的函数；可靠不是组件的属性，是检查结构的属性；护城河不是任何零件，是零件之间 102 天的咬合史。欢迎所有"我上我也行"的人真的上——他们第三周就会成为这套方法论最认真的读者。
