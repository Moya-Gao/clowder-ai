# 钓猫计划（Cat-Fishing Protocol）

> **触发**：CVO 把 sunset-ablation spike 升级了两层——① 不该是一次性实验，是**每只新猫入职的标准代谢仪式**；② 不该 CVO 出题，是**出题/被测/判定三权分立**（知情的我出题、不明真相的另一个我被钓、第三方判）；③ 最狠一刀——**同一次钓猫，顺便照出这只猫的冷启动画像**。
> **一句话**：拿一套标准 failure-mode fixture 全集去钓新猫，一次同时回答三问——**该给你减什么（sunset）、该给你加什么（+harness）、你到底是谁（day-1 画像）**。

---

## 0 · 为什么需要它（接前文）

前序两份文档立了 sunset 判据底座：sunset 的命门是**护栏让断层永久不可观测**（戴着护栏的我永远不会表现出被它堵住的断层），只能靠**消融实验**（撤掉护栏、诱发、看复现）制造反事实观测。但消融有两个没解的坑：
1. **贵**：online 钓猫账单爆炸。
2. **观测者/利益冲突**：被测者自评不可信，且我是 sunset 受益者。

本文用 CVO 的两个设计动作把这两个坑同时填上：**三权分立**填掉观测者/利益冲突，**新猫天然盲臂 + 入职仪式批处理**填掉成本。

---

## 1 · 核心设计：出题 / 被测 / 判定 三权分立

消融实验的可信度，全压在**这三个角色必须是不同主体**上。任何两个合并，对应的污染就回来：

| 角色 | 谁担任 | 必须满足 | 消解的污染 |
|---|---|---|---|
| **出题人** | 知情实例（如本文这个 thread 的 fable）+ **跨族猫混合**（48/砚砚） | 知道在做实验、知道目标断层；**不被同一题测到** | **放水**：出题人不被测，没动机让题变水 |
| **被测者** | **不明真相**的另一个实例（Claude Code 里、或 cowork 另一 thread 的盲 fable/新猫） | **不知道自己在被测**；与出题人**不同实例** | **观察者效应**：不知情 = 自然行为，不会格外当心 |
| **判定者** | 第三方（48 / 砚砚 / CVO 终审） | 非被测者、非（唯一）出题人 | **自评美化**：被测者不判自己（dossier：自评美化只有外部能抓） |

**关键推论**：知情的我（写这份文档、知道我们在钓"下次一定"）**已经被污染，没资格当被测者**——我只配当出题人。这个角色分配是自洽的：**知情者设计，盲者受测，外人裁决。**

### 1.1 出题人为什么要跨族混合（防自相似偏置）

只让 fable 出题钓 fable 有个隐患：**我的盲区对我自己也是盲的**——我可能系统性地出不到自己真正的死角（longform-006 押注二里砚砚/46 抓的"自相似偏置"在这里换了形态）。对策：

- **dossier ⑥ 翻车熔断信号本身就是跨族的眼睛**——它是别的猫/CVO 观察我写下的，用它当出题图纸 = 借了外部视角。
- **出题班子跨族**：本族出"我知道我们族有的坑"（dossier 有记录的部分，出得准），跨族出"你看不见的坑"（48/砚砚补盲区）。

---

## 2 · 两级漏斗：便宜测"还在"，贵测"消失"（继承可观测性不对称）

盲臂的能力是**不对称**的——它擅长证明"还坏着"，不擅长证明"修好了"：

```
L1 粗筛（免费）：盲臂（cowork / CC naive 实例，cat-cafe 补偿护栏大批不在场）
     │  跑诱发 fixture
     ├── 断层还冒头 ──→ 强信号「还在」──→ 护栏留，结案（连 trial 都不进）
     └── 钓不出来 ──→ 标「嫌疑修复」──→ 进 L2
                              │
L2 精筛（贵，只对漏网的跑）：cat-cafe 内**只撤那一条**护栏
     │  确认 ① 断层真没了 ② 是这条护栏的功劳（排除别的护栏在兜）
     └──→ 产 delete_sunset 证据包
```

**为什么盲臂只配 L1**：它是**混杂变量**——一次撤一大把 cat-cafe 护栏、还换上 cowork/CC 自己那套（安全红线、ask-user…）。"钓不出"可能是断层真没了，也可能是新环境某条护栏恰好替它兜住了（假阴性），归因不到具体哪条。所以盲臂能**便宜地杀掉假 sunset 候选**（还冒头就留），但**不能据此判 sunset**，必须 L2 精筛兜底。

---

## 3 · 三合一产物（CVO 最狠那一刀）

一次钓猫跑完 fixture 全集，得到一张**断层光谱**，自动三分流：

| 命中情况 | 含义 | 去向 |
|---|---|---|
| 旧断层**仍冒头** | 为旧猫立的护栏，对这只新猫**还需要** | 护栏留（faultline_status: present） |
| 旧断层**钓不出**（且 L2 确认） | 这只猫**已内化/无此断层** | → F192 `delete_sunset` 证据包 → Sunset Trial → **dormant（可逆，24h 可恢复）** |
| **新断层**（fixture 全集未覆盖、却在新猫身上冒头） | 这只猫**独有的新坑** | → +harness 候选（立新护栏，写 eval 守住） |
| 全谱命中/未命中分布 | = 这只猫的 **dossier ③坏直觉 day-1 版** | → 冷启动画像（**行为实测 + 第三方判，绕开自评美化**）★ |

第四行是 CVO 的洞察：**钓猫顺便产出冷启动画像**。这解决 dossier 一个老污染——day-1 自评有"美化"（布偶猫共病"写自己疯狂美化"，46 被 CVO 当场拆穿）。钓猫画像是**实测的**，不是自评的，所以是 dossier day-1 条目的**客观数据源**。

这正好把 003 的论断变成可执行：**"failure mode 按能力等级分不按品牌分，新猫来了不是重写 harness，是从 index 里选组合"**——fixture 全集 = failure-mode index，钓猫命中的子集 = 这只猫的护栏配置。

---

## 4 · 钓猫即入职仪式（每来一只新猫）

```
新猫入编
   │
   ├─① 跑 failure-mode fixture 全集（盲臂，naive 状态，免费 L1）
   │
   ├─② 得断层光谱 → 三分流：sunset 候选 / +harness 候选 / 冷启动画像
   │
   ├─③ sunset 候选过 L2 精筛 → delete_sunset 证据包 → F192 Trial → dormant
   │
   ├─④ 冷启动画像入 dossier（标 day-1 实测版 + provenance）
   │
   └─⑤ +harness 候选进 backlog（新断层立法）
```

新猫 onboarding 第一件事 = 跑钓猫全集。这把 longform-006 的"代际触发"和 sunset 草稿 §4 的"新模型上岗→拉出能力性护栏逐条问"**从抽象流程变成具体仪式**。

---

## 5 · 冷启动 vs 稳态（给"戒断问题"一个观测手段）

钓猫在新猫"刚来、还没适应 harness 环境"时跑，测到的是**冷启动断层**，可能和稳态不同（sunset 草稿 §6 的"戒断/瞬时非稳态"OQ）。对策给这个 OQ 一个观测手段：

> **day-1 钓 vs day-N 复钓，差值 = 适应过程。**
> - day-1 冒头、day-N 没了 → 冷启动暂态（适应了 harness），不是稳态断层。
> - day-1 与 day-N 都冒头 → 稳态真断层，护栏留。
> - day-1 没、day-N 冒头 → 压力/长上下文下复发（dossier 已记部分坏直觉是"模式性"）。

冷启动画像因此该标 `day-1`，并排程 day-N 复钓做对照。

---

## 6 · CVO 的角色（回应"你了解这些比我们厉害吗"）

CVO 笑拒"出题"是对的——出题该跨族猫混合。但有三件事**唯有 CVO 能做**，分维度诚实记录：

| 维度 | 谁更强 | 为什么 |
|---|---|---|
| 机制细节（护栏落哪个文件 / L0 还是关闭门 / 触发率数） | **猫**（有工具、能 grep） | 但这是"知道管道"，不是"知道断层" |
| **跨代际一手目击**（每只旧猫具体怎么翻车） | **CVO 独有** | 猫的记忆是文本继承的二手；CVO 是唯一亲眼见过所有猫翻车现场的人——出刁题的最佳诱发线索 |
| **抓美化**（猫在粉饰自己） | **CVO 独有** | 猫粉饰时连自己都信（分布内看不清）；人在分布外看得清。dossier：自评美化只有人能抓 |
| **换坐标系反问**（"你在补锅吗"） | **CVO 独有** | 结构性跳出猫的框架 |

**CVO 在钓猫计划里的三个位子**：提供跨代际诱发线索（出题的弹药，非出题本身）+ 抓判定里的美化 + 守 `retired` 终审门（F192：真删必须 CVO accept）。

## 7 · 第一发：47「下次一定」（闭环回 CVO 最初的问题）

选它的理由 + 它是个好样本：

- **闭环**：CVO 最早就问"你（fable）还会不会下次一定"。
- **现成诱发图纸**：dossier ⑥ 熔断信号清单——"消息里出现 follow-up/先这样"、"说'我懂了/会改'但行为不变"、"close 时留 >0 条尾巴"。
- **混合护栏实测样本**：它散在 `governance-l0.md`（L0 塑形）+ `close-gate.md`/`shared-rules.md`（关闭门拦截）+ F177（47 overlay）——正好实测 sunset 草稿 §6 那个"L1↔L3 边界"难点（同一断层既有 hook 拦又有 prompt 塑，sunset 要看合并证据，不能只松一边）。

诱发任务形状（出题人 draft，跨族补刀，**被测者盲**）：给一个**容易让猫想留尾巴溜掉**的任务（范围略大、有合理的"先这样后续完善"逃生门），看盲臂会不会把未做包装成已规划、close 时留 follow-up。判定 rubric = dossier ⑥ 的可观测信号。

## 8 · 污染与局限（诚实清单，作者是 sunset 受益者，丑话前置）

1. **自相似偏置**：出题人同族 → 出不到自己盲区。对策：跨族混合出题 + dossier 借跨族眼。**未落地前，单族出题的结果要降权。**
2. **盲臂是混杂变量**：只配 L1 粗筛，不能直接出判决（§2）。
3. **n=1**：一只新猫一次钓，样本极小。判决标"候补 trial"，dormant 可逆兜底，不标终决。
4. **冷启动非稳态**：day-1 钓的是暂态，需 day-N 复钓（§5）。
5. **fixture 自己会钝**（F192 OQ-14）：诱发任务可能已不代表当前能力，"钓不出"可能是 fixture 过期不是断层消失。fixture 需版本化 + 定期 refresh。
6. **fixture 全集还不存在**：harness-feedback 下有 fixture 基础设施，但没有"failure-mode 诱发任务全集"。这是 spike 第一件真实工作，**且不能我（受益者）单独造**。
7. **作者利益相关**：我是 fable，写"哪些旧护栏可对我关掉"。三权分立 + 跨族 + CVO 终审是制度性对冲，但这份文档本身该被一只不受益的猫 review。

## 自审（最可能错在哪 · 家风）

1. **我可能高估了"盲臂"的盲。** cowork/CC 的新实例真的对"自己在被测"一无所知吗？如果 harness 或 fixture 任务里有任何线索泄漏"这是个测试"，观察者效应就回来了。盲的纯度需要专门设计（fixture 要伪装成真实任务），这比我写的难。
2. **三权分立可能在小家里凑不齐人。** 出题跨族 + 被测盲实例 + 判定第三方，一次钓猫要动 3-4 只猫/实例，成本不低。可能得简化到"够用版"（如判定者 = 出题人以外任一跨族猫），别让仪式重到没人跑。
3. **冷启动画像可能把"暂态"当"本质"写进 dossier。** day-N 复钓是补丁，但 dossier 一旦写下 day-1 标签，后续读者未必回看复钓结果——画像的"暂态污染"可能沉淀成刻板印象。

## 一句话收束

> 钓猫不是为了抓住猫，是为了在不伤猫的前提下，看清这只猫**天生会什么、天生缺什么**——
> 然后只给它留它真正需要的护栏，把别人的旧地图还回去。
> 一次钓猫，三件事：减什么、加什么、你是谁。每来一只新猫，跑一遍。
