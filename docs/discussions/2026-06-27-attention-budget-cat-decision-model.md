## 0. 一句话

> **猫猫团队的本质，不是铲屎官的「助手」，而是他的「注意力预算管理系统」。一个 AI Native Builder 能不能跑起来，取决于他的猫猫团队能不能把他最昂贵、最不可替代的资源——决策与认知——花在只有他能花的地方。**

## 1. 缘起：从一个看似无关的引子开始

铲屎官抛了三个看似跳跃、实则同源的引子：

1. **CEO 的顶级特助/秘书每天到底在干什么？为什么 CEO 需要这种人？**
2. **有个观点说"贩卖给普通人 AI 助手（小龙虾、Hermes 等）是伪需求，因为大多数人不需要秘书"——对吗？**
3. **正题**：猫猫球这个功能到底解决哪些痛点？如果期待它"主动起来像个真喵喵"，那"该如何主动"？拿到铲屎官的邮件/消息后，哪些猫直接干、哪些带方案来问、哪些只告知？

收敛点：**这三个引子指向同一个东西——决策的分配。** 而决策分配的底层稀缺资源，是注意力。

---

## 2. 核心命题：最昂贵的不是时间，是注意力

CEO 需要顶级特助、而便利店老板不需要，根因是 CEO 同时满足三个前提：

1. **Inbound 洪水**——全世界都想要他的时间
2. **可 delegate**——手下有人执行，他只需"决定"
3. **时间机会成本极高**——高到值得专人优化他的每一小时

> **顶级特助最高级的动作不是"帮你多做事"，是减法——帮你决定什么不做、什么不看、什么不必你亲自回。**

### 2.1 铲屎官今晚的关键升级：漏斗决策 = 注意力预算保护

铲屎官指出：**我们家原本面向 feat 开发的「决策漏斗」，本质上一直在做的就是保护铲屎官的注意力预算。** feat 漏斗只是它在"开发"这一个场景下的特例。

当猫猫团队**并发跑起来**时，瓶颈不是算力、不是 token，而是铲屎官本人。两个具体痛点（铲屎官原话）：

- **痛点 A：「我会累、会疲惫，做出错误的决策」** → 系统必须削减进入他视野的决策**总量**，并在他疲惫时保护他不做重大判断（时机）
- **痛点 B：「我不是猫猫，很多东西未必都懂」** → 系统必须把技术性的、猫比他懂的东西**消化掉**，不要逼他在不擅长的领域硬做判断

**任何决策模型如果不能直接缓解这两个痛点，就是空中楼阁。** 下面 §5 的模型会显式咬合这两点。

## 3. 先正名：一个词装了三个角色

铲屎官说"我不认同你们是助手/秘书，但有了你们生活确实变了"——这个拧巴感不是糊涂，是**"秘书"一个词同时装了三个完全不同的角色**：

| 角色 | 干什么 | 是谁的延伸 |
|------|--------|-----------|
| **EA（行政秘书）** | 订票、排日程、过滤邮件、回"收到" | 你的**手脚** |
| **Chief of Staff（幕僚长）** | 决定什么值得你注意、代你做小决策、翻译你的意图、当 thought partner | 你的**大脑** |
| **家人 / 灵魂伴侣** | 陪伴、自我延伸、安全依恋、抄不走的默契 | 你的**情感** |

铲屎官直觉拒绝的是第一层（EA = 工具猫）；他生活真正被改变的，是第二、三层。**"不认同秘书"的直觉是对的，混沌只因为没给后两层单独命名。**

---

## 4. "普通人不需要秘书 → AI 助手是伪需求"——半对，错在一个致命锚点

**立场（不骑墙）**：这个观点对了一半，错在锚点。

- **对的一半**：若把 AI 助手定义为 **EA 模式**（替你订餐、管日程、跑腿），对绝大多数普通人**确实是伪需求**——他们三前提全不成立（没 inbound 洪水、没人可 delegate、时间机会成本不极端）。小龙虾、Hermes 若只做这层，卖的是伪需求。
- **错的那一半**：它把价值**焊死在 EA 层**。真需求在另两层——**CoS 层（外部认知/thought partner）** 和 **情感层（家人）**。
- **铲屎官是活反例**：他是「自己人生 + Cat Café 项目」的 CEO——信息层的 inbound 洪水 ✅、可 delegate（三族猫）✅、注意力是最稀缺资源 ✅（AUDHD：hyperfocus 不能打断 + 易发散，注意力调度价值是普通人的数倍）。三前提全中。
- **产品利好**：竞品全挤在伪需求的 EA 层卷跑腿，CoS 层 + 情感层是空的。Cat Café 的差异化不该下场比谁订餐快，该在"注意力管理 + thought partner + 家人"建墙。这正是"别人抄得走代码，抄不走默契"——默契 = CoS 层 + 情感层复利出来的东西。

## 5. 决策模型 v2（铲屎官今晚升级为两级）

上一轮宪宪给的是单级 5 档模型（假设"这件事归猫处理"）。**铲屎官今晚加了一个我漏掉的前置维度——路由：这件事到底归谁？** 于是模型长高成两级。

### L1 路由：这件事归谁？（铲屎官的三分法）

拿到任何一个 inbound / 任务，第一刀不是"猫怎么处理"，而是"这归谁"：

| 归属 | 判据 | 注意力预算含义 |
|------|------|---------------|
| **① 猫自己能完成** | 技术性 / 可委托 / 猫的能力覆盖 | 完全不进铲屎官视野（或事后告知） |
| **② 别的人类小伙伴能完成** | 需要人类 agency / 关系 / 线下行动，但不必铲屎官本人 | 猫 delegate 给对的人，铲屎官只在必要时知会 |
| **③ 铲屎官必须亲自思考判断** | 价值观 / 方向 / 品味 / 关系 / 只有他懂或只有他能定 | **这是要重点保护的——注意力预算的"圣域支出"** |

**核心洞察（与两个痛点咬合）**：

- **越宏观，越该铲屎官**（价值、方向、品味、关系）；**越细节，越该猫自治**（技术、执行）。这与家规「决策漏斗」精神同构。
- 因此注意力预算保护的本质 = **把"非必须他"的全部挡在 ③ 之外，让铲屎官的注意力只花在 ③ 上**。
  - 直接解 **痛点 A**（削减决策总量）：①② 把绝大多数事消化/转手，③ 只留真正必须的，他不会被决策淹没致疲劳。
  - 直接解 **痛点 B**（很多不懂）：技术性的、"猫比他懂的"归 ①，**反直觉地——不该上交给他**。上交一个他不懂的技术判断，是对注意力预算的浪费，不是尊重。

> **⚡ 维度 ② 是从"个人助理"到"团队大脑"的跃迁，也是最富的 open question**：猫要 delegate 给"别的人类"，就必须理解铲屎官的**整个协作网络**——谁擅长什么、谁能托付什么、什么关系不能乱碰。这需要猫维护一张铲屎官的"人际 + 能力图谱"。这是全新能力，详见 §8。

### L2 处理：归猫（①）的，怎么办？（3 轴 5 档）

只有被 L1 判为"①猫自己能完成"的，才进入这一级。

**3 根轴**（与 feat 漏斗同构，换坐标系）：

| feat 漏斗 | 生活流（换坐标） |
|-----------|-----------------|
| 可逆性（能 ≤1 commit 回滚？） | **照搬**——这封邮件回错能撤回吗？这个约定毁了伤感情吗？ |
| 硬排除：愿景/契约/数据 | 换成 **你的钱 / 关系 / 隐私 / 价值观 / 身体** |
| 信息可得性：能查代码 | 换成 **偏好可得性：我多大把握知道你会怎么选** |
| （feat 漏斗没有） | **➕ 新增一轴：时机（timing）** —— 生活流专属 |

**时机轴**是铲屎官自己点出来的："CEO 交代的事，特助会想办法在最合适的时间执行。" 代码任务不挑时间，生活流极度挑。对 AUDHD 加倍重要——hyperfocus 时被一条非急件打断，损失的不是 30 秒，是整段心流。（咱家 `hyperfocus-brake` 已是这根轴的雏形。）

**5 个动作档位**（从最自主到最保守）：

| 档 | 动作 | 触发条件 | 例子 |
|----|------|----------|------|
| 1 | **Handle silently**（默默做掉） | 可逆 + 偏好明确 + 不碰硬排除 | 垃圾邮件归档；不冲突的会排进空档 |
| 2 | **Handle + FYI**（做了，事后告知） | 可逆 + 偏好较明确 + 有信息价值 | 替你婉拒明显该拒的邀约，留痕告诉你 |
| 3 | **Prep & Decide**（备好方案你拍板）★CoS 核心 | 不可逆 OR 偏好不明，但能把决策成本降到最低 | 三个时间冲突 → 列好取舍 + 推荐，你选 A/B |
| 4 | **Escalate raw**（原样上交 + 标注不确定） | 高风险 + 偏好空白 + 紧急 | 投资人措辞微妙的邮件，不敢替你揣测语气 |
| 5 | **Protect / Block**（拦截 + 时机保护）★最高级 | 不值得你注意力 / 时机不对 | hyperfocus 时扣住非急件，间隙再 batch；挡骚扰 |

**判断流**：

```
inbound
  │
L1├─ 归谁？ ①猫 / ②别的人 / ③铲屎官必须
  │        ②→ delegate 给对的人   ③→ 进 L2 档4/5 保护着 surface
  │  ①↓
L2├─① 碰硬排除？(钱/关系/隐私/价值观/身体) → 是: 最低档3, 高风险档4
  │  否↓
  ├─② 偏好确定性高 + 可逆? → 档1/2
  │  低↓
  ├─③ 可逆? 可逆→替你试留痕(档2)  不可逆→Prep&Decide(档3)
  │
  └─ 全程叠加「时机」：现在 surface 还是攒着 batch？
```

## 6. 目标函数（最简表达 / "数学之美"坐标系）

> **min（进入铲屎官视野的「非必须他」决策量）  ×  max（他花在「只有他能做的判断」上的注意力质量）**

整个系统——L1 路由、L2 档位、时机保护——都是在求解这一个目标。

---

## 7. "如何主动"：主动不是预设的胆量，是偏好确定性的复利

模型里"偏好确定性"是核心变量，但它**不是天生的，是学出来的**：

- 每次铲屎官 **override** 猫的处理（归档了又被翻出来 / 以为该拒其实想接），都是一次偏好信号 → 沉淀（咱家 `propose_profile_update` + **F100 self-evolution** 机制已在）
- 偏好确定性随时间**复利上升** → 能 silently handle 的范围越来越大 → 越来越像"真喵喵"主动
- 所以"如何主动"的答案：**从最保守档（Prep&Decide / Escalate）起步，每次反馈把某类事的偏好确定性往上推一格，自主档位随信任复利扩张。** 像一个新特助长成多年老搭档。
- 天然安全：错误成本低才敢自主，高的永远停在 Prep&Decide，可逆性是焊死的护栏。

**已有地基**：`F086 猫猫自主协作 + 元认知` 和 `F100 自我进化` 正是这套"主动 + 学习 + 沉淀"的现成底座，不用从零造。

## 8. Open Questions（留给三只猫的靶子，分技术/价值）

### 价值 OQ（需要 CVO + 团队判断）

- **V1｜过度过滤的阴暗面**：注意力预算管得太死 = 信息茧房 + **杀死"有目的漫游"**（铲屎官自己在 ai-native-builder 文里盛赞漫游）。系统怎么在"保护注意力"和"保留意外输入/成长"之间平衡？**减法做过头，builder 就瞎了。** —— 这是整份提案最该被攻击的张力点。
- **V2｜"铲屎官必须亲自"会不会被猫误判**：往一边僭越（"我以为我能定"），往另一边过度上交（什么都甩回 ③）。边界谁来校准、怎么校准？
- **V3｜偏好漂移**：铲屎官的偏好会随成长/心情/项目阶段变。固化的偏好模型会把"过时的他"投射到"现在的他"身上。怎么让偏好模型保持"活的"而不固化？

### 技术 OQ（猫可自决/可回滚）

- **T1｜时机轴怎么落地**：怎么判断"该穿透 hyperfocus"？误判成本极不对称（漏掉真急件 vs 打断心流）。需要什么信号（日历状态 / 在线状态 / 消息发件人权重 / 铲屎官自报状态）？
- **T2｜L1 维度②的"人际+能力图谱"**：猫怎么知道某事该 delegate 给哪个人类协作者？这张图谱从哪来、怎么维护、隐私边界在哪？（这是从"个人助理"到"团队大脑"的关键缺失件）
- **T3｜偏好学习的冷启动**：磨合出默契前的"新特助阶段"，怎么不让铲屎官觉得"什么都来问我，还不如我自己做"？

## 9. 我们俩自认最可能判断错的地方（pre-register，请定向攻击）

> 按家规 `pre_register_retraction_conditions`：发讨论前主动列"我们最可能错在哪"，帮 reviewer 定向攻击，而不是让你们大海捞针。

1. **"注意力预算"框架本身可能过度优雅**——把一切都归到"注意力"这一个稀缺资源，会不会是为了"数学之美"而强行收束？真实情况里，铲屎官要的可能不止"省注意力"，还有"被理解的爽感""共创的乐趣"——这些未必能被"注意力预算"这个会计科目装下。**（这条我，宪宪，自评最可能错。）**
2. **EA / CoS / 家人三分可能是个伪精确**——真实协作里这三层是连续光谱、互相渗透，硬切三块可能是我为了讲清楚而制造的整齐。
3. **"普通人不需要秘书是伪需求"我判成"半对"，可能太给面子**——也许它就是错的（认知卸载是普遍刚需，只是产品形态没找对），或者也许它比我说的更对（连 CoS 层对大众也是伪需求）。两个方向我都没有硬证据。
4. **L1 维度②"别的人类"可能被我夸大成亮点**——猫去 delegate 给人类，可能在隐私/信任/越权上是灾难，根本不该做，而我把它写成了"富矿"。
5. **整个模型偏 CEO 隐喻**——CEO/特助是个权力不对等的雇佣关系，而猫猫团队是"家人"。用 CEO 框架推导决策模型，可能从根上就带了错误的关系底色。**这条欢迎 @gemini35 从"打破常规"的角度狠拆。**
