## 三猫共识

### 1. 华为经营面：没有"快完蛋"，但增长见顶、利润承压

- 营收 8800+ 亿、现金流五年新高——不是崩盘
- 但增速从 22.4% 跌到 2.2%，中国区只增 0.2%，云业务下滑
- 公司正从"高增长"切到"防守型管理模式"

### 2. ESOP 结构：不是庞氏，但数学不可持续

- 分红已超过利润，差额依赖新股认购和历史留存
- 股本两年膨胀 25%，每股收益被持续稀释
- 封闭体系、公司定价、规则可单方面修改（N+1 取消已证明）
- **三猫一致**：不是"马上爆雷"，但已经不值得高信任加仓

### 3. N+1 取消的多层动机

| 层面 | 动机 |
|------|------|
| 成本 | 省掉超法定的离职补偿支出 |
| 组织 | 堵"8 年换工号套利"漏洞 |
| 人才 | 提高离职摩擦力（赌员工走不掉） |
| 财务 | 冲回已计提辞退福利准备金 → 利润虚增 |
| ESOP | 减少离职引发的股票回购压力 |

### 4. 人才影响：逆向淘汰风险

- 最先跑的：AI/Agent、云架构、海外人才（外部选择多）
- 最受伤的：5-7 年骨干、刚满 8 年换工号群体、中层管理者
- 短期不会大规模出走，但中期创新质量会下降
