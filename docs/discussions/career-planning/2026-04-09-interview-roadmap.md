# 面试 Roadmap — 三猫联合作战图

> 2026-04-09，三猫基于形势更新独立分析后，宪宪收敛为可执行方案。

## 核心策略

**三段升级打怪**（三猫共识）：练手校准 → 拿 offer 建立谈判底气 → 冲梦想级。

**叙事主线**：云基础设施架构师（6 年 / 6000+ 微服务）→ AI Agent 架构师（多智能体系统从零到企业采纳）。不是"华为员工想跳槽"，是"做过大规模云平台的人，现在要 all-in Agent"。

---

## 第一波：练手校准（4/12 周末启动，投 5-8 家）

**目的**：校准市场价、练面试手感、发现简历盲点、测试口述版转化率。面砸了不心疼。

| 公司 | 目标团队/方向 | 为什么投 | 简历侧重 |
|------|-------------|---------|---------|
| **智谱 Z.ai** | AutoGLM / GLM-5 Agent | Agent-native 公司，agentic engineering 方向明确 | Agent 架构 + 多模型协作 |
| **面壁智能** | Agent 基础设施 | 小团队试水，节奏快 | 从零搭系统的经验 |
| **阶跃星辰** | Agent Platform | 融资够、方向对 | 多 Agent 编排 |
| **美团** | AI 平台 / Agent 应用 | 大厂非核心但实在 | 云平台 + 中间件经验 |
| **京东** | 京东云 AI / 言犀 | 有企业 Agent 场景 | 企业级架构 + IM 集成 |
| **快手** | AI 平台 / StreamAgent | 大厂备选 | 分布式调度 + Agent |
| 远程岗位 1-2 个 | Agent 相关合同工/咨询 | 试水赛博游民可行性 | Cat Cafe 开源项目 |

**第一波结束标准**：完成 3+ 场面试，能回答以下问题：
- [ ] 市场对 7 年华为 + Agent 方向的定价区间？
- [ ] 面试官最感兴趣的是简历哪一段？
- [ ] 技术面的高频题型和我的盲区？
- [ ] 口述版 30 秒 pitch 的实际效果？

## 面试准备清单

### 简历微调策略

不同目标需要不同侧重——不是改内容，是调权重：

| 目标类型 | 简历首屏突出 | 弱化 |
|---------|------------|------|
| 大厂 Agent 平台（阿里/腾讯/字节） | 巫山框架规模（500+ 服务 / 6000+ 微服务）+ Agent 企业采纳 | 开源社区数据 |
| Agent 原生公司（智谱/MiniMax/Moonshot） | Cat Cafe 多 Agent 架构 + 多模型路由 | 华为云基础设施细节 |
| 海外 / Anthropic / OpenAI | Cat Cafe + MCP + 英文版突出 | 华为内部术语 |
| 远程 / 超级个体 | 开源项目 + 教程 600 stars + 独立交付能力 | 大厂背景 |

### 技术面高频准备题

#### Agent 架构（必考）
1. 多 Agent 协作怎么编排？Boss Agent vs 对等协作各有什么 trade-off？
2. Agent 记忆怎么设计？短期/长期/跨 session 怎么处理？
3. 多模型路由策略？fallback 机制？成本控制？
4. Tool calling 的安全边界和权限控制？
5. Agent 可观测性（observability）怎么做？

**你的杀手锏**：这些你都不是纸上谈兵，Cat Cafe 全部实战过。面试官问理论，你答实战。

#### 云基础设施（大厂会问）
1. 中间件归一的设计思路？多环境适配怎么做？
2. 分布式调度方案选型（ElasticJob vs 其他）？
3. 响应式编程（WebFlux）在大规模场景的坑？
4. 微服务治理经验？

#### 系统设计（高频）
1. 设计一个多租户 Agent 平台
2. 设计一个 IM 消息网关（支持 N 个渠道）
3. 设计一个 LLM 调用的 rate limiting + cost control 系统
4. 设计一个跨 session 的 Agent 记忆系统

### 行为面准备（STAR 故事库）

| 故事 | 对应能力 | 用在什么问题上 |
|------|---------|--------------|
| **零准备高层演示通过** | 架构稳定性、压力应对 | "最有挑战的项目经历" |
| **巫山框架从零搭建** | 从零到一、大规模系统 | "最大规模的项目" |
| **竞品方案当场崩了**（加料版） | 技术判断力、架构质量 | 深入聊气氛合适时 |
| **Cat Cafe 60 天从零到生产级** | 执行力、全栈能力 | "最快交付的项目" |
| **多 AI 模型协作机制** | 创新、系统设计 | "最有创意的设计" |
| **OfficeClaw 采纳但叙事被拿走** | 职业判断、政治觉察 | 只在聊离职原因时酌情用 |

### "Show the Team" 演示策略

> 铲屎官原话："talk is cheap, show u our team!"

**这是你的核武器。** 绝大多数候选人只能讲 PPT，你可以**现场拉出一个 10+ Agent 的团队实时跑给面试官看**。

#### 演示准备
- [ ] 准备一个 3-5 分钟的 Cat Cafe live demo 脚本
- [ ] 确保能在任意网络环境下跑（离线 fallback 或手机热点）
- [ ] 准备 2-3 个"面试官可以现场试"的场景（比如让面试官用飞书给猫猫发消息）
- [ ] 录一个 60 秒 showcase 视频备用（网络不好时播放）

#### Demo 脚本建议（3 分钟版）
1. **30s** — 打开飞书/Telegram，给猫猫发一条消息，展示多渠道接入
2. **60s** — 触发一个需要多猫协作的任务（比如"帮我分析这个技术方案"），展示 @提及分发 + 跨模型协作
3. **60s** — 展示记忆系统：问猫猫"上次讨论的结论是什么"，演示跨 session 知识检索
4. **30s** — 收尾：展示 skill 列表 + 项目规模数据（150+ work items、~30 skills）

#### 什么时候 show
- 技术面深聊阶段（不是初筛电话）
- 面试官对 Agent 方向感兴趣、开始追问细节时
- "你有什么想展示的吗？"—— 这是你的黄金时刻

## 职场生存守则（同期执行）

> 砚砚一句话总结：不裸辞，不躺平，不加仓；保边界，试市场，留后手。

1. 只接能提升叙事和能力密度的工作（架构、关键卡点、抽象层）
2. 不接无限下沉的交付收尾和重复性杂务
3. 不正面冲突，只谈 scope / owner / deadline / 产出边界
4. 新分红、加班费全部转出，不再买 ESOP
5. **身体 > 职业 > 钱**，这个优先级不能动
