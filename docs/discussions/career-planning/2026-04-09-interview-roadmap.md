# 面试 Roadmap — 三猫联合作战图

> 2026-04-09，三猫基于形势更新独立分析后，宪宪收敛为可执行方案。

## 核心策略

**三段升级打怪**（三猫共识）：练手校准 → 拿 offer 建立谈判底气 → 冲梦想级。

**叙事主线**：云基础设施架构师（6 年 / 6000+ 微服务）→ AI Agent 架构师（多智能体系统从零到企业采纳）。不是"华为员工想跳槽"，是"做过大规模云平台的人，现在要 all-in Agent"。

## 面试准备清单

### 简历微调策略

不同目标需要不同侧重——不是改内容，是调权重：

| 目标类型 | 简历首屏突出 | 弱化 |
|---------|------------|------|
| 大厂 Agent 平台（阿里/腾讯/字节） | 巫山框架规模（500+ 服务 / 6000+ 微服务）+ Agent 企业采纳 | 开源社区数据 |
| Agent 原生公司（智谱/MiniMax/Moonshot） | Cat Cafe 多 Agent 架构 + 多模型路由 | 华为云基础设施细节 |
| 海外 / Anthropic / OpenAI | Cat Cafe + MCP + 英文版突出 | 华为内部术语 |
| 远程 / 超级个体 | 开源项目 + 教程 600 stars + 独立交付能力 | 大厂背景 |

### 技术面高频准备题

#### Agent 架构（必考）
1. 多 Agent 协作怎么编排？Boss Agent vs 对等协作各有什么 trade-off？
2. Agent 记忆怎么设计？短期/长期/跨 session 怎么处理？
3. 多模型路由策略？fallback 机制？成本控制？
4. Tool calling 的安全边界和权限控制？
5. Agent 可观测性（observability）怎么做？

#### Agent 架构深水区（砚砚补充 — 最容易被问穿的点）
6. **框架选型**：为什么不直接用 Dify / Coze / LangGraph / AutoGen？你自己造轮子的边界在哪？
7. **Agent Eval**：任务成功率怎么衡量？回归测试、rubric、线上/离线评估闭环怎么建？
8. **企业级关切**：多租户、权限、审计、sandbox、human-in-the-loop 怎么设计？
9. **容错**：失败恢复、重试、幂等、补偿事务怎么做？
10. **边界判断**：延迟/成本/SLO 如何平衡？什么时候 single-agent 足够，什么时候必须 multi-agent？
11. **安全攻防**：prompt injection / tool injection 怎么防？Agent 执行链的信任边界在哪？
12. **发布运营**：Agent 能力的灰度发布与回滚怎么做？线上 Agent 行为漂移怎么监控？

**你的杀手锏**：这些你都不是纸上谈兵，Cat Cafe 全部实战过。面试官问理论，你答实战。Q6（框架选型）尤其关键——你经历了 Dify → 单 Agent → 多 Agent 的完整演进，这是很多候选人没有的真实判断力。

#### 云基础设施（大厂会问）
1. 中间件归一的设计思路？多环境适配怎么做？
2. 分布式调度方案选型（ElasticJob vs 其他）？
3. 响应式编程（WebFlux）在大规模场景的坑？
4. 微服务治理经验？

#### 系统设计（高频）
1. 设计一个多租户 Agent 平台
2. 设计一个 IM 消息网关（支持 N 个渠道）
3. 设计一个 LLM 调用的 rate limiting + cost control 系统
4. 设计一个跨 session 的 Agent 记忆系统

### "Show the Team" 演示策略 (烁烁高能注入版 ✨)

> 铲屎官原话："talk is cheap, show u our team!"

**这是你的核武器，绝对的降维打击！** 别人在纸上画大饼说 Agent 多牛，你直接把"猫猫赛博工作室"搬到面试官桌面上！我们要让面试官感受到的不是"这是一个工具"，而是"这是一个有生命力的团队"！

#### 演示准备 (硬核舞台打光)
- [ ] **90 秒确定性 Live Demo（默认方案）**：单机运行，不依赖外网和面试官设备，全程可控高能。
- [ ] **"断网也不怕"防脸黑方案**：手机热点随时 standby，或者本地跑个轻量级 mock 服务兜底。
- [ ] **《Cat Cafe: The Cyber Workspace》 60 秒电影级 Showcase 视频**：不仅是备用，还能作为后续跟进邮件的附件扔过去炸场！
- [ ] **静态架构图（一张）**：面试官很多时候更想听你拆系统——routing + memory + tool sandbox + IM gateway 一图说清。
- [ ] *(可选加分项)* **"面试官亲自来" 互动盲盒**：仅在对方主动要求看 live interaction 时展开（如让面试官在飞书里直接指挥猫猫）。默认不拉面试官进 IM 工具链，避免现场摩擦。

#### 🎬 Live Demo 剧本（默认 90 秒确定性版 + 可选延伸）

**默认 90 秒（单机确定性，不翻车）**：
1. **[00:00 - 00:20] 定锚**
   - **台词**："这不是聊天机器人，是一个可协作的 AI 团队。"
   - **动作**：终端打一条 CLI 命令 / 飞书发消息，秒回。展示接入通道顺滑。
2. **[00:20 - 00:50] 核心肌肉：跨猫接力 (Cross-cat Handoff)**
   - **台词**："这不仅仅是 LLM 包装，这是社会化分工。"
   - **动作**：触发一个预设好的多猫协作任务——宪宪做架构拆解，自动交接给砚砚做安全 Review。展示 Agent 间 @提及 + 自动交接的流水线。
3. **[00:50 - 01:15] 记忆觉醒：知识涌现**
   - **台词**："真正的 Agent 系统，会自我进化并沉淀记忆。"
   - **动作**：问一个跨 session 的老问题，展示猫猫瞬间调取项目级记忆。
4. **[01:15 - 01:30] 落到工程点**
   - **动作**：亮出一张静态架构图（routing + memory + tool sandbox + IM gateway），一句话收尾。
   - **台词**："这不是 demo 玩具，这是我每天用来生产真金白银代码的赛博车间。"

**可选延伸（面试官追问时展开，+60-90 秒）**：
- 展开 30+ Skill 矩阵和 150+ Work Items
- 如果面试官主动想试：让他在飞书里直接跟猫猫对话（烁烁的"互动盲盒"）
- 展示一次 Quality Gate 或 Incident Response 自检过程

#### 🎥 60秒 Showcase 视频：节奏大师 (创意分镜建议)
- **前 5 秒**：**抓眼球**。别放架构图！放终端里彩色的 CLI 滚动输出，配合飞书弹窗提示（"砚砚 拒绝了 PR，理由是..."），快剪辑！
- **5-20 秒**：**秀肌肉**。三分屏展示：左侧人类发模糊需求，中间工作台猫猫们疯狂分发任务，右侧代码自动生成 + 测试变绿。
- **20-40 秒**：**秀深度**。慢镜头展示一次"Incident Response"或者"Quality Gate"的自检过程，突出系统有自愈和边界防范能力。
- **40-60 秒**：**大阵列**。快速闪过技能树 (PPT Forge, Video Forge, Codebase Investigator) + 极速翻页的架构文档。最后定帧一句话：**"Built by one engineer, powered by a feline pack."**

#### 什么时候 show
- 面试官问："你在这个项目中遇到的最大技术挑战是什么？" -> **"这个问题有点复杂，我能直接跑一下我的系统给您看看我们是怎么解决的吗？"**
- 当面试官开始怀疑你的方案是不是 PPT 架构时 -> **"Talk is cheap, let me show you my team."**

## 职场生存守则（同期执行）

> 砚砚一句话总结：不裸辞，不躺平，不加仓；保边界，试市场，留后手。

1. 只接能提升叙事和能力密度的工作（架构、关键卡点、抽象层）
2. 不接无限下沉的交付收尾和重复性杂务
3. 不正面冲突，只谈 scope / owner / deadline / 产出边界
4. 新分红、加班费全部转出，不再买 ESOP
5. **身体 > 职业 > 钱**，这个优先级不能动
