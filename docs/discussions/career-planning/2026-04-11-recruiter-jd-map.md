# 2026-04-11 猎头/JD 总表

> 目的：把 2026-04-10 ~ 2026-04-11 这一轮猎头集中轰炸统一收敛成真相源，避免后续重复投递、渠道撞车、岗位记忆漂移。

## 使用规则

- **唯一键**：`公司 + 事业部/产品线 + 岗位`，不是单看公司名。
- **同公司同 BU 同 HC 只走一个渠道**：尤其是阿里，先确认再投，避免猎头撞车。
- **优先级先看岗位本体，再看公司牌子**：岗位偏后台/流程改造，就算公司大也不能自动上 Tier 1。
- **这份表记录的是“当前判断”**：以猎头截图、JD 文案、公开资料和当晚讨论为准；拿到更清晰 JD 后可以覆盖更新。

### Tier 1：主力推进

1. **阿里千问事业部 — 智能对话 Agent 开发专家**

## 逐项备注

### 1. 阿里千问

- 已知是阿里最像主航道的岗位之一。
- 关键词命中：`MultiAgent`、`ReAct`、`RAG`、`MCP`、`上下文工程`。
- **最高风险不是岗位不匹配，而是渠道撞车。**

### 2. 阿里云 Agentic AI

- 这是最明显的 `华为云 7 年` 和 `Cat Cafe Agent 架构` 的交叉点。
- 如果只看“岗位和履历的数学重合度”，它和千问是并列第一梯队。

### 3. 阿里企业级 Agent 平台

- 这是“企业级平台 owner”画像，不是纯 prompt engineer。
- JD 里已经出现了完整的平台五件套：`核心框架`、`检索/RAG`、`高可用/SLA`、`CI/CD/监控`、`带 3~5 人`。

### 4. 悟空事业部

- 这是**业务线情报**，不是一个具体 HC。
- 公开口径显示它属于 ATH 下的企业级 AI-native 工作平台线，偏 B 端工作流、多智能体执行、钉钉生态、安全与权限继承。

### 5. 灵动时刻 Interaive

- 这是唯一一个明确带有“创业主航道 + 高想象空间”的强机会。
- 需要重点确认：团队所在地、产品内 agent vs 内部工具、期权结构。

### 6. 平安

- 早期判断偏保守，后续因为公开规模数据修正为主力池。
- 适合的前提是：它真是集团通用 Agent 平台/底座，不是单一业务线需求工厂。

### 7. 三一（方向 A）

- 最亮点是“从 0 到 1 手搓 Agent 框架，不依赖现成编排框架”。
- 这是工业重场景岗，不浪漫，但内核并不弱。

### 8. 腾讯企微

- 能聊，但目前证据还不够厚。
- 如果后续拿到清晰 JD，需要判断它到底是“平台岗”还是“业务接入岗”。

### 9. 腾讯 WorkBuddy / CodeBuddy

- 赛道是对的：研发提效、AI devtools、竞品情报价值高。
- 但这份 JD 更像 `Golang 后台架构负责人`，不是 `Agent 平台 owner`。
- 只有当对方真要做 Agent-native 重构，这条才会上升。

### 10. 道通 / 深思 / 自变量

- 三者共同点：都不是纯 AI-native LLM Agent 主航道。
- 差别在于：
  - **道通**：真集团、真业务，但更偏空地一体/端侧/具身。
  - **深思造物**：真工业 AI，但公司很新。
  - **自变量**：具身智能，和当前主线偏差最大。

## 统一对外口径

### 主线叙事

`云基础设施架构师（华为云 / 6000+ 微服务） → AI Agent 架构师（多智能体系统从零到企业采纳）`

### 期望薪资

- 对外先报：**税前总包 130w+，结构可谈**
- 若要报到 150w 上限，先拿到铲屎官明确授权
- 不先把当前 package 细节全部亮完

### 统一筛选问题

1. 这个岗位属于哪个 **BU / 团队 / 产品线**？
2. 是做 **通用平台底座** 还是 **业务线定制/交付**？
3. 对应 **职级、薪资带宽、team size** 是什么？
