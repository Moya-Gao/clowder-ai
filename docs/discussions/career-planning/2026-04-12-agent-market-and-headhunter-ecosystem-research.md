# 2026-04-12 Agent 赛道与猎头生态调研

> 目的：回答三个实际问题：  
> 1. 这两天大量猎头来加，是不是真热；  
> 2. 为什么很多人对 Agent 一知半解却也在推；  
> 3. 我们该如何筛掉噪音，避免浪费时间。

## 一页结论

- **不是纯虚火。** 2026 年春招里，AI/Agent 赛道的岗位需求和薪酬都是真热。
- **但有明显“噪音放大”。** 平台、HR SaaS、猎头都在用 AI 降低搜人和触达成本，导致很多不懂 Agent 的人也会批量触达。
- **现在不是“所有 AI 岗都值钱”，而是“少数真正能落地的岗更值钱”。** 市场已从“拼想象力”转向“拼落地能力”。
- **对我们这种背景，最稀缺的是“云原生/平台底座 + Agent/RAG/记忆 + 工程化落地”交叉项。** 所以 inbound 多，不奇怪。
- **行动原则**：不是所有猎头都值得搭理。默认先看 `岗位本体 + 团队清晰度 + 猎头专业度`，不满足门槛就不跟。

## 1. 为什么最近这么多猎头来加

### 1.1 市场整体确实在升温

- BOSS 直聘披露，**2025 年 AI 相关岗位月均新发职位数同比增速达到 74.1%**，明显高于 2023 年和 2024 年。  
  来源：<https://finance.sina.com.cn/jjxw/2026-01-23/doc-inhihsry0980502.shtml>
- 脉脉 `2026 年 1-2 月` 春招报告显示，**AI 岗位数量同比增长约 12 倍**，在新经济岗位中的占比从 `2.29%` 升到 `26.23%`；**平均月薪 60738 元**。  
  来源：<https://finance.sina.com.cn/tech/roll/2026-03-09/doc-inhqkxfr6893569.shtml>
- 科锐国际的数据被《每日经济新闻》转引：**全国已有 3.5 万+ 企业发布 AI 相关岗位，岗位总量突破 14.5 万个**。  
  来源：<https://finance.sina.com.cn/roll/2026-03-17/doc-inhrhicu2191609.shtml>

### 1.2 你的画像正好踩在供需错位点上

市场现在最缺的不是“会用一下 AI 工具”的人，而是：

- 能把模型接进真实业务的人
- 能做 Agent/RAG/记忆/上下文工程的人
- 同时又懂稳定性、SLA、部署、治理的平台型工程师

公开报告里也在往这个方向收敛：

- 脉脉报告显示，AI 领域人才供需比是 `0.97`，低于新经济整体 `1.79`；其中 **高性能计算工程师供需比仅 `0.15`**。  
  来源：<https://finance.sina.com.cn/tech/roll/2026-03-09/doc-inhqkxfr6893569.shtml>
- 猎聘报告显示，**66.3% 企业在 2025 年进一步加大研发投入，93.4% 企业启动未来 1-3 年 AI 人才前瞻布局**。  
  来源：<https://finance.sina.com.cn/tech/roll/2026-02-05/doc-inhkutyw1881081.shtml>

我们这几天收到的 JD 也验证了这一点：阿里云、阿里企业级 Agent 平台、平安、大疆、深信服，真正高质量的岗位都在找**“平台/基础设施/Agent 工程化”复合型人才**，不是只找 prompt 使用者。

## 2. 为什么很多猎头一知半解也来推

### 2.1 触达成本被 AI 大幅降低了

这波“猎头变多”，不一定代表他们都更专业，更可能代表他们**更容易批量找到并联系你**。

- BOSS 直聘财报口径里，企业端已经上线 **AI 极速招聘、AI 智能托管、智能筛选** 等工具。  
  来源：<https://finance.sina.com.cn/roll/2026-03-20/doc-inhrreqy4104621.shtml>
- 北森公开材料里更直接：它的 AI 招聘系统已经做到 `寻聘-筛选-面试-复盘` 全流程 Agent 化，还提到 **自动评估上万份简历、10 分钟生成 JD、主动沟通候选人**。  
  来源：<https://www.beisen.com/res/2204.html>

结论很简单：**搜人和触达的边际成本下降了**。  
所以现在会出现大量“知道几个关键词就开始加人”的猎头，这不是你错觉。

### 2.2 市场里有大量“AI 标签膨胀”

- 脉脉报告显示，**34.39% 的新发岗位描述中明确提及 AI 或大模型技能**。  
  来源：<https://finance.sina.com.cn/tech/roll/2026-03-09/doc-inhqkxfr6893569.shtml>

这意味着很多岗位会出现以下情况：

- 岗位本体是后端/流程/数据/产品，AI 只是加分项
- 招聘方说“Agent”，实际只是单模型问答或内部知识库
- 猎头拿到 title 就开始推，自己并不理解 `MultiAgent / Context Engineering / Agent Memory / RAG Eval` 的差别

所以“很多人来加你”不能直接等于“很多真机会在抢你”；它更像：

**真实热度 × 平台降本 × AI 关键词膨胀 = 触达数量爆炸**

## 3. 这是不是“虚假繁荣”

我的判断：**不是虚假繁荣，而是“理性繁荣 + 噪音放大”。**

原因：

- 《每日经济新闻》这篇的关键判断很对：AI 招聘已经**告别“只要沾边就抢人”的狂热**，转向 **“拼落地能力”**。  
  来源：<https://finance.sina.com.cn/roll/2026-03-17/doc-inhrhicu2191609.shtml>
- 同文还提到，企业越来越看重：
  - 真实项目经验
  - 工程化部署能力
  - 场景落地与商业转化能力

这和我们这几天收的 JD 完全一致：

- 高质量岗位：阿里云 Agentic AI、阿里企业级 Agent 平台、深信服 MultiAgent
- 中低质量岗位：把 AI 只当加分项的传统后台/流程岗

所以问题不在于“市场是不是假热”，而在于：

**热是真的，但不是每一个打着 Agent 旗号的岗位都值得你花时间。**

## 4. 猎头要不要搭理：给一个硬筛选框架

### 4.1 值得继续聊的猎头，至少要能回答这 5 个问题里的 4 个

1. 具体 **公司 / BU / 产品线 / 团队** 是什么
2. 岗位本体是 **通用平台底座** 还是 **业务线定制/交付**
3. 汇报线、团队规模、当前阶段（0→1 / 重构 / 规模化）是什么
4. 薪资带宽或至少 compensation 结构有没有基本范围
5. 为什么这个岗位现在开，缺的是哪种能力，不是泛泛而谈

### 4.2 四档分类

#### S 档：值得优先聊

- 能讲清 BU、团队、HC 背景、汇报线
- 理解 Agent，不会把 RAG、Workflow、MultiAgent 混成一个词
- 愿意先讲岗位本体，再要简历

#### A 档：可以继续试探

- 公司和方向靠谱
- 但细节还没完全摸透
- 至少能回答产品线、团队阶段、基本薪资逻辑

#### B 档：只值一次性追问

- 只会说“大模型/Agent 很火，岗位很适合你”
- 不知道具体团队和工作边界
- 上来就要简历、要授权、要当前薪资

这类给一次追问模板，答不上来就结束。

#### C 档：直接忽略

- 连公司/团队都说不清
- 把任何 AI 岗都叫 Agent
- 拒绝说预算、拒绝说 JD、本质在刷 KPI

## 5. 对你最有用的实际策略

### 5.1 不要被“很多人加你”抬高情绪曲线

这波 inbound 说明两件事：

- 我们的画像确实被市场识别到了
- 但其中有很大一部分只是低成本批量触达

所以正确心态不是“我是不是要起飞了”，也不是“是不是全是假”，而是：

**这是一堆未经筛选的原始线索，不是 offer。**

### 5.2 把时间预算锁死

- 每天花 `20-30 分钟` 统一处理 inbound
- 只对 `S/A 档` 继续投入
- `B 档` 一次追问模板
- `C 档` 直接不回

### 5.3 对你这种背景，优先级只看三类

1. **Agent 平台 / 企业级通用智能体底座**
2. **云原生 Agentic AI / 工具链 / 研发效能平台**
3. **多智能体 + 记忆 + RAG + 上下文工程的核心研发**

凡是偏下面这些的，默认降级：

- 只是“会用 AI 工具”的普通后台岗
- 流程改造/BPM 挂 AI 标签
- 内部知识库问答，但不做平台沉淀

## 6. 最终判断

如果你问我一句最短的话：

**这波不是虚假繁荣，但大部分 inbound 不是“高质量机会”，而是“AI 招聘系统和低门槛猎头一起放大的噪音”。**

你不需要把每个猎头都当回事。  
你只需要把真正懂 `Agent 本体 + 团队边界 + 平台价值` 的那一小撮人留下来。

## 7. 三猫交叉收敛（2026-04-12）

> 说明：本节吸收了宪宪与烁烁在同一 thread 的独立观点，但只保留了与本研究主结论一致、且不依赖额外未核数据的部分。

### 7.1 共识

- **市场热度是真实的，噪音也是真实的。**
- **我们不该把“猎头数量”直接理解为“高质量机会数量”。**
- **筛选核心不是寒暄质量，而是岗位本体是否清晰。**

### 7.2 来自宪宪的有效补充

- 可以把当前市场理解成一个分层结构：  
  顶层是 `Agent 平台 / 多智能体 / 企业级底座`，中层是 `RAG / 大模型应用`，底层是“只会调模型 API 的泛 AI 岗”。
- 我们当前画像更接近顶层，所以被大量搜到并不奇怪；真正要防的是“猎头把顶层和底层都混叫成 AI 人才”。
- 实操上，**统一回复模板做第一轮筛选** 是对的，不要每次临场发挥。

### 7.3 来自烁烁的有效补充

- **不要把“猎头本人懂不懂 Agent”当成第一道门。**  
  这是个重要修正。因为很多真实 HC 也会通过不懂技术的猎头流出来。
- 更好的第一道门是：  
  **对方能不能把 JD、BU、团队边界、岗位目标讲清楚。**
- 可以把猎头当成 `JD 搬运机 / 线索 API`，而不是职业顾问。  
  这和本研究“低成本批量触达”的结论是兼容的。

### 7.4 因此，我们的最终过滤顺序调整为

1. **先看岗位本体**：是不是 Agent 平台/多智能体/上下文工程/企业级底座
2. **再看团队边界**：BU、汇报线、team size、通用平台 vs 业务定制
3. **最后看猎头质量**：是否懂行、是否能持续跟进、是否会乱撞车

也就是说：

- **“猎头不懂 Agent”不自动淘汰**
- **“岗位讲不清 + 团队讲不清 + 预算讲不清”才淘汰**

这比单纯按“聊天时是否专业”过滤更稳，也更不容易错杀真实机会。
