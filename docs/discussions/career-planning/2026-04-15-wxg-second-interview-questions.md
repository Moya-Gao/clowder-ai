# WXG 二面提问稿 — 明天到底问什么

> 目标不是“显得会提问”，而是判断三件事：  
> 1. 这个团队是不是在企业微信现在最值钱的方向上  
> 2. 进去以后是做平台级杠杆，还是做碎需求搬运工  
> 3. 他们对 `AI Native 企业级 IM` 的理解，到底停在“接个模型”，还是已经在想“工作界面 + 组织记忆 + 执行闭环”

---

## 先摆清楚：我们为什么这么问

结合官方公开信号，企业微信现在对外强调的是四条主线：

1. **连接微信**
2. **AI 助力智能办公**
3. **协作工具与 OA 应用**
4. **全面安全保障**

另外，最近两个公开动作也很关键：

- `2026-03-18`：开始把 OpenClaw / API 模式能力开放给个人和小团队
- `2026-03-29`：官方 CLI 开源，消息、日程、文档、智能表、会议、待办、通讯录等能力开始明确面向 AI Agent / 开发者生态

所以二面不该问“你们用什么模型”这种轻问题，而应该问：

- 你们到底押哪条主线？
- AI / Agent 在你们这里是包装层，还是工作流重构层？
- 开放生态、组织记忆、权限合规这些硬问题，你们真的在想没有？

---

## 明天最推荐的开场

```text
我看了你们最近对外的公开信息，感觉企业微信现在不是单纯做一个办公 IM，
而是在把“连接微信、AI、协作工具和开放能力”绑在一起往前推。
尤其最近 CLI / OpenClaw 这条线很明确，所以我比较想确认一下，
你们这个团队具体压在哪条主线上，以及你们现在最难的那个问题是什么。
```

这段话的作用：

- 显示你做过功课
- 把对话从“泛泛 HR 问答”拉到“方向判断”
- 顺手把 CLI / Agent 生态埋进去，方便后面接 showcase

---

## 必问 8 题

### 1. 团队主线

**问法：**

> 你们这个团队在企业微信当前几条主线里，最核心负责的是哪一条？今年的北极星指标是什么？

**为什么问：**

这是判断“核心团队还是边缘团队”的第一题。

**好答案信号：**

- 能直接说出主线
- 能说出指标，例如活跃、留存、付费、渗透、AI 使用率、生态接入数
- 能说清楚为什么今年是这个优先级

**坏答案信号：**

- “我们什么都做”
- 只有功能列表，没有目标

---

### 2. AI/Agent 的真实级别

**问法：**

> AI/Agent 在你们这里是一号工程，还是现有产品上的增强层？现在真正上线并且被持续使用的两个场景是什么？

**为什么问：**

这题专门筛“AI PPT 团队”。

**你想听到的不是：**

- “我们也在看这个方向”
- “会做一个助手”

**你想听到的是：**

- 已上线场景
- 谁在用
- 怎么评估效果
- 当前卡点是权限、延迟、准确率、幻觉还是 adoption

---

### 3. 开放生态到底是不是认真的

**问法：**

> 我看到你们最近把 CLI 和 OpenClaw 这条线公开得更清楚了。你们怎么看企业微信在 AI Agent 生态里的角色？更像工具层、平台层，还是应用分发层？

**为什么问：**

这题直接对应我们的强项，也最能区分“只是做功能”还是“在想平台”。

**追问：**

> 你们内部更希望第三方 / 自建应用 / 官方 Agent 形成什么关系？是竞争、互补，还是平台 + 生态分层？

---

### 4. 组织记忆 vs 个人记忆

**问法：**

> 如果企业微信真的往 AI Native 企业级 IM 走，我觉得迟早会碰到“组织共享记忆”和“个人私有记忆”的边界问题。你们内部会把这看成核心问题吗？更卡在产品设计、权限模型，还是合规治理？

**为什么问：**

这题不是炫技，是为了看他们有没有往“聊天之外”的真正企业能力想。

**如果对方接得住：**

- 说明他不是把 Agent 理解成会回复消息的 bot
- 说明他知道企业产品的难点在权限和边界

**如果对方接不住：**

- 也没关系
- 你就知道他们现在还没走到这一层

---

### 5. 工作流 vs 单点功能

**问法：**

> 你们更希望 AI 帮用户完成单点操作，还是希望它把聊天直接落成一条完整工作流？比如文档、表格、待办、会议这种跨资产闭环。

**为什么问：**

这是把 F162 的 showcase 价值点翻译成面试问题。

**好答案：**

- 认可“对话即工作流入口”
- 能讲出跨资产闭环的意义
- 会提到审计、回贴、接管、可追踪

---

### 6. 岗位真实问题

**问法：**

> 如果我加入，前三个月你最希望我解决的那个最硬的问题是什么？

**为什么问：**

这是最直接的岗位真相题。

**好答案：**

- 问题具体
- 有边界
- 有期望结果

**坏答案：**

- “先熟悉业务再说”
- “哪里缺人补哪里”

---

### 7. 跨团队边界

**问法：**

> 企业微信和微信、腾讯会议、腾讯文档、腾讯云这些能力之间，边界是怎么划的？你们这个团队现在最重的跨团队依赖是什么？

**为什么问：**

大厂很多坑不在技术，而在依赖链路。

**你要判断的是：**

- 这个岗位是不是天天被别的团队卡脖子
- 这个团队是不是有自己的主导面

---

### 8. 成功标准

**问法：**

> 你们眼里这个岗位“做得特别好”的人，和“普通合格”的人，差别到底是什么？

**为什么问：**

这题可以直接看这个岗位到底偏：

- 架构和方向
- 平台和抽象
- 落地和执行
- 跨团队推进

---

## 如果对面是技术负责人，再追这 4 题

### A. 单 Agent 还是多 Agent

> 你们现在默认是单 Agent + skill / tool，还是已经碰到必须多 Agent 才能拆开的约束？

这题能筛掉“为了多 Agent 而多 Agent”的花活，也能自然衔接我们自己的思考。

### B. 评估怎么做

> 线上怎么定义一个 Agent 系统做得好？更看成功率、尾延迟、人工接管率，还是别的指标？

做过生产系统的人会给实话。

### C. 权限和人类接管

> 你们现在更倾向于让 Agent 直接执行，还是在关键动作上走人类确认？哪些动作你们觉得必须可审计、可回滚？

这是企业产品的硬底座问题。

### D. 标准化 vs 定制化

> 企业微信天然会面对大客户需求，你们现在最难的 trade-off 是标准化平台能力和行业定制需求之间怎么平衡吗？

这题能看出团队是不是长期会被大客户拖进泥潭。

---

## 如果对面是 leader / hiring manager，再追这 4 题

### A. 今年最关键的判断

> 今年这个方向最关键的判断是什么？是“AI 能不能做出来”，还是“客户是否愿意真的把工作流交给 AI”？

### B. 为什么是现在

> 为什么你们觉得这个时间点企业微信适合把 Agent 往前推？是技术成熟了，还是产品位置变了，还是组织能力到位了？

### C. 客户画像

> 你们最想打透的是哪类客户？大企业、行业客户，还是更轻量的团队协作场景？

### D. 这个岗位的杠杆

> 这个岗位最大的杠杆来自写代码、做抽象、做产品判断，还是跨团队推进？

---

## 如果时间只够问 3 个

优先级我建议是：

1. **你们团队最核心负责哪条主线，今年的北极星指标是什么？**
2. **AI/Agent 在你们这里到底是一号工程，还是增强层？现在持续被使用的两个场景是什么？**
3. **如果我加入，前三个月你最希望我解决的最硬问题是什么？**

这 3 个问题足够判断：

- 团队位置
- 方向真假
- 岗位重量

---

## 哪些问题别问

- 不要问“团队氛围怎么样”
- 不要问“你们技术栈是什么”
- 不要问“贵司竞品是谁”
- 不要太早问薪资、福利、加班

这些问题信息密度太低，且不能帮你判断这个岗位值不值得去。

---

## 最后一条：怎么把问题自然接回 showcase

如果对方聊到 AI / 工作流 / 开放能力，你可以顺手接一句：

```text
这也是我为什么对你们这个方向感兴趣。
我最近刚好做了一条很贴近企业微信的链路：
一句话把聊天落成文档、表格、待办和会议。
所以我会特别关心，你们内部是把这类能力看成功能点，
还是看成企业工作界面的下一代范式。
```

这句话的作用不是“卖弄 demo”，而是把提问从抽象判断，顺滑切回你已经做出来的东西。
