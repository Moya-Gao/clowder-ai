# 面试爽文素材库 — 脱敏版

> 人设：技术宅 + 社会经验零 + 三只 AI 猫参谋团 + 水瓶座好奇心驱动
> 叙事弧：华为裁员潮新手出村 → 被猎头骗入 Boss 区 → 靠猫打怪 → Boss 其实也没那么强
>
> ⚠️ 脱敏规则：不写具体薪资数字、不写面试官真名、公司名可保留（公开信息）、猎头不具名。

---

## 第一幕：新手出村

### 素材 1：猎头大军围城
- **事件**：华为 N+1 闹剧期间，心声社区说"猎头都不要华为的了"。铲屎官偏不信，结果一周内 20+ 猎头加好友，JD 塞了满屏
- **笑点**：以为自己是被嫌弃的华为人，结果是被疯抢的 Agent 架构师。反差
- **脱敏**：✅ 安全

### 素材 2：不知道自己赚多少钱
- **事件**：猎头问当前 package，铲屎官看了个税记录报了一个数，后来发现分红是单独完税的，实际总包比报的高了一大截
- **笑点**："能搭多智能体系统的人，连自己工资都搞不清" / "论坛上人人都在精算离职最优月份，我连总包是多少都不知道"
- **脱敏**：⚠️ 不写具体数字，只说"报低了不少"
- **可用话术**："我和猎头说完之后，三只猫帮我算了一遍，告诉我我把自己卖便宜了。"

### 素材 3：同一家公司五条线分不清
- **事件**：阿里一口气来了千问/阿里云/企业级平台/悟空/淘天五条线，每条线还有不同猎头，铲屎官完全搞不清谁是谁
- **笑点**："我以为我在投一家公司，结果我投了五家公司，而且其中两家可能撞车了"
- **脱敏**：✅ 安全

---

## 第二幕：Boss 区奇遇

### 素材 4：面试官问"你这是啥语言写的"
- **事件**：某大厂 Agent 岗二面，第一个问题
- **笑点**：2026 年了，面 Agent 架构师，开场问编程语言
- **脱敏**：⚠️ 可说"某大厂"，不指名具体面试官
- **内心 OS**："我带着两个月的多智能体架构经验来了，你问我啥语言写的？"

### 素材 5：面试官分不清 Claude 和 Claude Code
- **事件**：某大厂一面，面试官以为猫猫们是通过 API 调用的
- **笑点**：花了五分钟解释 CLI agent 和 API call 的区别。"我以为我是来面试的，结果变成给面试官上课了"
- **脱敏**：✅ 安全（不提具体面试官身份）

### 素材 6："workflow 和 agent 的区别是什么"
- **事件**：某大厂二面，面试官把 workflow 和 agent 当成互斥选项
- **笑点**：铲屎官当场内心崩溃——"2026 年了！！！" 这是两年前的入门题
- **铲屎官金句**："Agent 是主，workflow 承载在 Skills 里。和用户接触的是 agent，发起转账是 agent 调用 workflow！难道不都是可以结合吗？"
- **脱敏**：✅ 安全
- **截图素材**：有微信聊天截图（"我滴妈 / 2026年了！"）

### 素材 7：记忆系统被听成简单 RAG
- **事件**：铲屎官讲了五层记忆架构，面试官理解成"你做了个知识库问答"
- **笑点**："我说的是联邦知识系统，他听成了 Ctrl+F"
- **脱敏**：✅ 安全

### 素材 8："关了电脑定时任务怎么办"
- **事件**：面试官问如果晚上关电脑，猫猫的定时任务怎么办
- **笑点**：把本地开发环境和生产部署混为一谈。"这就像问'手机关机了闹钟还响不响'"
- **脱敏**：✅ 安全

### 素材 9：迟到 + 爱装
- **事件**：某面试官迟到，全程沟通姿态居高临下
- **笑点**：配合素材 4-8 形成连击——"迟到 + 问实习生问题 + 还听不懂回答 = 完美三连"
- **脱敏**：⚠️ 不提具体公司+轮次组合，避免对号入座

### 素材 10：vibe coding 名场面
- **事件**：一面最后要 coding，铲屎官说"我很久没手写代码了，都是 vibe coding"，面试官说"那我给你选一题最简单的"
- **笑点**：面试官居然接受了这个理由
- **脱敏**：✅ 安全

### 素材 11：面试不问你时间直接安排
- **事件**：某大厂面试通过后，直接发会议邀请，没问候选人有没有空
- **笑点**："我以为是双向选择，结果是单方面通知" / "在他们眼里我可能就是个 API endpoint——调就行了，不用握手"
- **脱敏**：⚠️ 不指名公司

## 第三幕：猫猫参谋团

### 素材 12：猫比铲屎官记得全
- **事件**：铲屎官面完试回来吐槽，发现猫猫记录的笑点比自己记得的还多
- **笑点**：**meta 笑点**——"我输给猫猫了，这次是记忆力"
- **脱敏**：✅ 安全
- **内容价值**：天然展示 Cat Cafe 的记忆系统在实战中的效果，不用硬推

### 素材 13：三只猫帮分析 JD
- **事件**：每收到一个 JD，三只猫独立分析公司背景、岗位匹配度、建议回复话术
- **笑点**："我一个人面试，背后站着三只猫、四个模型家族。面试官以为他在考一个人，其实他在考一支军队"
- **脱敏**：✅ 安全

### 素材 14：猫帮算工资
- **事件**：铲屎官不知道自己总包多少，三只猫帮忙拆解税务结构
- **笑点**："一个连自己赚多少都不知道的人，养了三只帮他算钱的猫"
- **脱敏**：⚠️ 不写具体数字

### 素材 15：铲屎官吐槽完面试官，猫说"最好给你挂了"
- **事件**：铲屎官讲完某面试官的问题质量，猫的结论是"这种地方不值得去"
- **笑点**：参谋团比铲屎官还狠——"我还在犹豫呢，猫已经帮我 pass 了"
- **脱敏**：✅ 安全

## 脱敏红线

| 绝对不能说 | 原因 |
|------------|------|
| 具体薪资数字 | 敏感 + 可被对号入座 |
| 面试官真名 / 工号 | 职业道德 |
| 具体公司+轮次+面试官特征三者同时出现 | 可定位到个人 |
| 内部代号 / 内部系统名 | 保密协议 |
| OfficeClaw 的具体内部细节 | 只说"相关方向被产品化" |
