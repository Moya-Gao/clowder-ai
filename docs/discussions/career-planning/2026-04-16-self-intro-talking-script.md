# 2026-04-16 自我介绍口述稿

> 适用场景：面试开场自我介绍、"请简单介绍一下自己"、追问与产品团队关系、追问 OfficeClaw。  
> 目标：把自己讲成 `平台框架 + multi-agent + 上下文/记忆 + 工程可靠性` 的人，而不是普通 AI 应用工程师。

## 先锁死的事实口径

- 教育背景：本科 `西交利物浦大学 → 利物浦大学（2+2）`，计算机科学 + 软件工程；硕士 `乔治城大学`，计算机科学，`NLP` 方向。
- 华为时间线：`2019` 年入职，至今约 `7` 年。
- Agent 转向：正式主线放在 `2025` 年开始系统转到 Agent 方向。
- 高层临时演示日期：`2026-03-24（周一）`。
- 公开发布信号日期：`2026-04-14`，相关办公智能体方向以华为云 `OfficeClaw` 对外公开。
- `盘古 Doer` 当前只适合作为更早期探索背景，不放进正式开场白主干。

## 90 秒正式版

```text
我简单介绍一下自己。

我本科是西交利物浦大学和英国利物浦大学的 2+2，计算机科学和软件工程；研究生在乔治城大学读计算机科学，方向是 NLP。

2019 年加入华为之后，我前面大概 6 年主要做云基础设施和平台框架，技术栈以 Java 为主，做过华为云服务开发框架从 0 到 1 的建设，重点是中间件架构归一、WebFlux/Spring 集成、分布式调度和任务编排。

从 2025 年开始，我系统性转到 Agent 方向，先做过编排平台和单 Agent 的探索，后面从零设计了一个多智能体协作系统 Cat Cafe。这个系统不只是应用层调模型，而是把多智能体协作、MCP/A2A 接口、工具调用、记忆与上下文工程、可靠性兜底都做成了框架能力。

我在公司里的角色也一直更偏架构与技术创新，和产品团队的配合通常是我先把新路线做成可验证的 PoC 和工程化原型，证明它能跑、能稳、能形成闭环，之后再和产品团队协作推进产品化。

比如 2026 年 3 月 24 日有一次零准备的高层现场演示，我们这套多智能体架构通过了实测，48 小时内就被内部采纳推进产品化；相关办公智能体方向后来在 2026 年 4 月 14 日以华为云 OfficeClaw 对外公开。

所以我现在在看机会时，核心关注点不是单点 AI 功能，而是能继续把 Agent 框架、multi-agent 协作和产品落地一起做深的岗位。
```

## 45 秒压缩版

```text
我是乔治城大学 CS 硕士，NLP 方向，2019 年加入华为。本科是西交利物浦和利物浦大学的 2+2，计算机科学和软件工程。

前几年我主要做 Java 和云平台框架，做过华为云服务开发框架的中间件归一和分布式调度。 从 2025 年开始，我转到 Agent 方向，重点做多智能体协作、MCP/A2A、记忆和上下文工程，不是单纯做应用层调模型。

我在公司里一直更偏技术创新和架构验证，先把路线做成 PoC 和工程化原型，再跟产品团队推进产品化。我们的一套办公智能体架构在 2026-03-24 的高层临时演示里通过实测，相关方向在 2026-04-14 以华为云 OfficeClaw 对外公开。
```

## 如果对方追问你和产品团队怎么配合

```text
我比较像前置的架构探索和技术验证角色。通常是我先把方向做成能闭环、能稳定运行的原型，验证技术路线成立；如果业务价值明确，产品团队会基于这条路线继续做产品化、规模化和运营化。我更擅长的是从 0 到 1 的架构设计、PoC 验证，以及把不稳定的想法收敛成可落地系统。
```

## 如果对方追问 OfficeClaw

```text
我不会说“我做了 OfficeClaw 整个产品”，这个口径太满。更准确的说法是：我做的是相关办公智能体方向的底层架构和原型验证，这条路线后来被内部推进产品化，并在 2026-04-14 以华为云 OfficeClaw 对外公开。产品化阶段有专门团队继续往前做，我的贡献更偏架构设计和验证。
```

## 不主动说的 3 件事

- 不主动说“OfficeClaw 就是我做的产品”。
- 不主动把 `盘古 Doer` 塞进主叙事。
- 不把自己讲成“AI 应用工程师”，而是强调 `平台框架 + multi-agent + 上下文/记忆 + 工程可靠性`。
