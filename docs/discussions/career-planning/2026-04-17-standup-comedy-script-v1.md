# 脱口秀稿：带猫面试

> 演出时长：约 10 分钟
> 人设：技术满级社交 Lv1 的华为人，带着三只 AI 猫被猎头骗去面 BAT 核心部门
> 基于素材库 v2 全部 18 条素材，每一个笑点都有真实事件支撑

---

## 第一幕：新手出村（约 3 分钟）

大家好。我是一个在华为写了七年代码的人。

七年。你们知道七年意味着什么吗？意味着我进去的时候还是个应届生，出来的时候——还是个应届生。因为除了写代码，我什么社会经验都没有。

（停顿）

今年华为搞 N+1。有一个周五的大晚上，我刷到一个帖子，神秘兮兮的，说"猎头已经不要华为的了"。我当时就信了。我想完蛋了，要不然先看看外面行情？

结果就那个周五晚上——二十多个猎头加我好友。

（做出震惊表情）

一个晚上！二十多个！我手机嗡嗡嗡响到凌晨，我以为是诈骗。后来才搞明白：他们不是要"华为的人"，他们要的是"做 Agent 的人"。华为这个壳不值钱，里面那个做多智能体的核最值钱。

就好像你去菜市场，人家不要你的筐，要筐里那颗榴莲。

---

然后猎头第一个问题就把我问懵了："你现在 package 多少？"

我说等一下，我查查。我打开个人所得税 App，看了半天，报了一个数。

结果过了两天我才发现——华为的分红是公司代扣的，根本不进个税申报。我漏报了一大截。

（自嘲）

论坛上人人都在精算"哪个月离职能多拿三千块"，我连自己总包是多少都不知道。

你们猜后来谁帮我算的？我养的三只 AI 猫。

对，你没听错。我搭了一套多智能体系统，里面有三只猫——Claude 家的、GPT 家的、Gemini 家的。猫帮我把税务结构拆了一遍，告诉我："铲屎官，你把自己卖便宜了。"

一个连自己赚多少钱都不知道的人，养了三只帮他算钱的猫。这就是我的人生。

---

更离谱的来了。阿里找我，一口气来了五条线。千问、阿里云、企业级平台、悟空、淘天。

五条线。每条线还有不同的猎头。

我完全搞不清谁是谁。我以为我在投一家公司，结果我投了五家公司，而且其中两家可能撞车了。猎头 A 问我："你和猎头 B 聊的是同一个 HC 吗？"我说我怎么知道？我连你们公司有几条线都数不清！

（摊手）

这就是新手出村的感觉。你以为外面是星辰大海，结果第一关就是——看地图。

---

## 第二幕：Boss 区奇遇（约 4.5 分钟）

好，接下来就到了我最想讲的部分。我面了一家"大厂"。

为了脱敏，我不能说是哪家。但我可以说的是——它贡献了今天段子的百分之八十。

---

一面，面试官上来问我：

"你这个系统，是用什么语言写的？"

（停顿，环顾四周）

2026 年。面的是 Agent 架构师岗。开场第一个问题——"啥语言写的"。

我当时的感觉是什么呢？就好像你去参加一场世界大赛，裁判上来问你："你用的是左手还是右手？"

我说 TypeScript。他说"哦"。

然后更有意思的来了。他问我："你这个系统的猫猫，是通过 API 调用的吗？"

不是！它们是 CLI Agent！它们有自己的上下文、自己的记忆、自己的工具链！

我花了整整五分钟，给面试官解释 Claude Code 和 Claude API 的区别。

（苦笑）

我以为我是来面试的，结果变成了——给面试官上课。

---

好不容易解释完了，二面来了。换了个面试官。

这位上来问的问题更经典："workflow 和 agent 的区别是什么？"

（爆发）

2026 年了！！！

这是两年前的入门题啊兄弟们！这就像你去面一个自动驾驶岗，对方问你："手动挡和自动挡有什么区别？"

我当时真的很想说——"这俩不是互斥的啊！Agent 是主体，workflow 承载在 Skill 里面，和用户接触的是 agent，发起转账是 agent 调用 workflow！它们是分层嵌套的关系！"

但我忍住了。我很有礼貌地回答了。

然后我讲到我们的记忆系统。我说我们做了分层记忆，从会话记录到证据索引到知识沉淀，一共四层半。

面试官听完点点头，说："哦，所以你做了一个知识库问答。"

（沉默三秒）

我说的是联邦知识系统。他听成了 Ctrl+F。

---

同一家公司，还有一个面试官问了我这么一个问题："如果晚上你关了电脑，猫猫的定时任务怎么办？"

（模仿困惑表情）

这个问题就相当于问："手机关机了闹钟还响不响？"

他把本地开发环境和生产部署混为一谈了。我当时真的不知道该怎么回答。我要是说"部署到服务器上就行了"，我怕他继续问"那服务器关了呢？"

---

好，前面这些你可能觉得——也不是不能理解，可能只是面试官不熟悉这个领域。

但最精彩的来了。三面。老板面。

我进去坐下，准备好了所有弹药——架构理念、环境适配度公式、多智能体协作模式、治理机制——全部就位。

面试官看了我一眼，开始问：Java。

Java 开发。四十分钟。

我中间提醒了一句："这是 agent 岗。"

他说："没关系。"

（停顿）

没关系。

这三个字，把这个岗位的含金量，说得明明白白。

然后他看了我展示的多智能体协作系统，说了一句话——这句话我会记一辈子：

**"你这东西不是很简单吗？协作起来谁不会啊？"**

（等笑声）

协作谁不会啊。

你知道谁会说这句话吗？没做过的人。

真正做过多 Agent 协作的人知道：难的不是让几个 agent 说话。难的是状态一致性、权限边界、冲突恢复、审计追踪、跨模型评测——这些东西加在一起，比单个模型难十倍。

但在他眼里，这就是几个 bot 串起来。

我的猫砚砚后来帮我翻译了这句话。他说："这句话翻译成人话就是——'我没做过，也没认真想过这件事的工程复杂度。'"

---

哦对了，这位面试官，迟到了。

迟到 + 问了四十分钟 Java + 听不懂回答 + 最后来一句"谁不会啊"。

（竖起四根手指）

完美四连。

---

我面完出来，给猫猫们发了一条消息。第一句话是：

**"华为有救了！！！"**

（等笑声消退）

不是华为变好了。是外面太拉了。

我出来面了一圈发现，华为最大的竞争力是——别的公司更离谱。

---

## 第三幕：猫猫参谋团（约 2.5 分钟）

你们可能好奇，我一直在说"三只猫"。让我解释一下。

我搭了一套多智能体协作系统，叫 Cat Cafe。里面有四个模型家族的猫：Claude 负责架构，GPT 负责 review 和找 bug，Gemini 负责设计和创意。

每次面试，我是一个人去面的。但我背后站着三只猫、四个模型家族。

面试官以为他在考一个人。其实他在考一支军队。

---

每次我面完回来，第一件事是跟猫猫吐槽。结果我发现一个很恐怖的事实——猫记的笑点，比我自己记的还全。

我说"那个面试官问了个很蠢的问题"，猫说"你是说第三个蠢问题还是第五个？"

我输给猫了。这次是记忆力。

---

然后猫猫们有一个特点：它们比我还狠。

我吐槽完某个面试官的问题质量，我还在犹豫"这家公司到底去不去"。猫的结论已经出来了——"最好给你挂了。这种地方不值得去。"

我还在纠结呢，猫已经帮我 pass 了。

参谋团比铲屎官还果断。

---

但你们知道最讽刺的是什么吗？

那些面试官问的所有问题——workflow 和 agent 的区别、关了电脑怎么办、协作谁不会——这些问题恰好证明了一件事：

**多智能体协作真的很难。**

因为如果它真的"谁不会"，大厂就不会把面 Agent 岗的面试官都找成——不懂 Agent 的人。

（鞠躬）

---

## 收尾

最后说一句。我有一个面试的时候，面试官最后出了一道 coding 题。我说："不好意思，我很久没手写代码了，我都是 vibe coding。"

他居然说："那我给你选一题最简单的。"

（停顿）

所以——如果你也想面大厂，记住两个技巧：

第一，养三只猫。
第二，学会说"我很久没手写代码了"。

谢谢大家，我是那个技术满级社交 Lv1 的铲屎官。如果你在某个大厂面试间外面看到一个人对着手机自言自语，不要报警——他只是在跟猫开会。

（下台）

## 表演备注

- 全程第一人称，铲屎官视角
- "2026 年了！！！" 是 callback 锚点，可以在多个段落重复使用
- "协作谁不会啊" 是全场高潮，前面所有铺垫都在为这一句服务
- "华为有救了" 是情绪释放点，紧跟高潮
- 第三幕"猫猫参谋团"是温度回归——从吐槽转向"原来猫猫才是最靠谱的队友"
- 结尾 vibe coding 是轻松收束，不要在愤怒点结束
