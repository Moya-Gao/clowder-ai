> 面试时间：2026-04-23 15:00

---

## 一、公司架构：三个模块

| 模块 | 做什么 | 地点 |
|------|--------|------|
| **Research** | 模型的推理训练 | 北京 |
| **Infra** | 模型训练基座，针对自研模型，暴露极致稳定的 API | — |
| **Feature** | 产研运一体，孵化落地产品 | — |

- Infra + Research 组成**中台能力**
- 中台的核心特点：**超快 TTFR 的视频模型**，能做到可交互的 live 流
- Feature 团队围绕中台能力去落地产品，复用中台（比如创作流、消费流）

```
┌─────────────────────────────────────┐
│         中台（Infra + Research）      │

           │          │

     │ 3-4 人  │  │ 3-4 人  │
     └────────┘  └─────────┘
```

## 二、产品团队组织

每个产品是一个**超小团队（3-4 人）**，覆盖：

- 交互设计
- 获客
- Agent 架构
- 稳定闭环
- 全栈工程师 + 运营 + 产品

**AI-native 全栈路径**：Freedom → 用户 → 网关 → 业务 Server → 能够全栈解决问题

## 三、面试官传递的核心理念

### "宽度 > 深度"

- 做什么产品、节点怎么连起来——看的是广度
- 好奇心能够 touch 到的知识面比某个领域的深度更重要

### "有好奇心就去探索，就是尝试落地"

- 整个行业都在探索阶段
- 团队组织范式没有广泛共识
- 边走边沉淀最佳实践

### "经验不值钱"

- 新领域的快速 landing 能力 + 好奇心 >> 过往经验
- 这和传统大厂"你做过什么"的面法完全不同

## 四、信号解读

### 正面信号

1. **有真技术**：自研超快视频生成模型，不是 API 聚合
2. **组织很轻**：3-4 人小团队，产研运一体，决策链短
3. **理念诚实**：直接说"行业都在探索"、"没有共识"、"边走边学"——不装
4. **看潜力不看履历**：重好奇心和 landing 能力，不卡经验

### 需要后续确认

- 这个岗位具体归哪个 Feature 团队？做什么产品方向？
- 团队在哪个城市办公？remote 政策？
- 期权/股权结构？
- 中台能力的稳定度——模型迭代速度快，Feature 团队会不会被中台拖着走？
