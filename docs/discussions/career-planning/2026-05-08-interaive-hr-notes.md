# 2026-05-08 Interaive / 灵动时刻 HR 面记录

> 这轮不是技术面，重点是把组织、岗位归属、合同主体和薪酬激励的模糊信息变成明确口径。

## HR 明确给出的信息

### 1. 老板 / 归属方向

- 目前**还不能完全确定最终老板是谁**
- 需要等**下一轮面试官聊完之后**再定
- 当前候选方向有三类：
  - 偏业务
  - 偏创作工具
  - 偏赋能 agent，让更多团队/职能部门使用 agent

**解读**：
- 这说明岗位归属还在动态匹配，不是一个完全锁死的单一 HC
- 好处是可塑性高
- 风险是角色边界和汇报线还不稳定

### 2. 合同主体 / 薪酬 / 期权

- 合同主体：**深圳公司**
- 薪酬结构口径：**类似字节，`12 + 3`**
- 有期权 / 股权
- 但**目前没有回购政策**

**解读**：
- “深圳主体”把此前实体问题往前推进了一步，但还不等于所有权结构完全清楚
- “类似字节 12+3” 说明基本工资 + 奖金结构偏成熟，不是完全野路子创业公司
- “没有回购政策”是关键风险点：期权价值实现路径更不确定

### 3. 后续流程

- 还会安排**一个 agent 方向的同事再面一次**

**解读**：
- 这说明 HR 面之后流程**还没结束**
- 下一轮更像是补一轮专业方向校验
- 也说明他们对“你到底更适合哪个方向”仍在收敛

## 对之前待确认问题的更新

结合二面笔记里列的待确认项：

- `期权 / 股权 / 薪资结构`：已有初步答案
- `合同主体`：已有初步答案（深圳）
- `老板 / team 归属`：**仍未确认**
- `A / B 岗位最终落点`：**仍未确认**

## 当前判断

### 正面

- HR 没有把你往一个模糊池子里随便扔，而是明确承认“还在匹配最合适的方向”
- 说明你不是被当成普通填坑 HC，而是被当成可放在多个方向里评估的候选人
- 薪酬结构至少不是完全空白，说明内部已有相对成型的 compensation 框架

### 风险

- **老板和岗位归属还没定**，这在 offer 前必须确认
- **期权没有回购政策**，要警惕纸面价值高、兑现路径弱
- 下一轮还要补一个 agent 同事面，说明技术线最终是否真的匹配，仍有一道门
- **现金包可能压不住预期**：HR 明示“`130` 有点高”，说明至少当前现金预算带偏紧

## 现金门槛的即时决策

铲屎官当前明确判断：

> **总包 `130` 不去。**

理由不是单纯“嫌低”，而是综合权衡后认为：

1. 在华为当前节奏下，`130` 这个量级未来 `1-2` 年内有较大概率能靠自然发展达到
2. 当前在华为的一个核心隐性收益是：**每天做什么具有很高自由度**
3. Interaive 这条线虽然方向很心动，但：
   - 老板 / team 归属还没锁定
   - 期权无回购政策
   - 现金部分又表现出预算偏紧

所以如果现金不能显著拉开差距，仅靠“创业空间 + 期权故事”不足以覆盖离开当前平台的机会成本。

## 对后续谈判的影响

- 不要因为 HR 说“`130` 有点高”就主动自降锚点
- 但内部判断上，**如果最后总包只能到 `130` 左右，这条线当前不值得跳**
- 真正能让这条线继续有吸引力的，只剩两种情况：
  1. **现金明显高于 `130`**
  2. **岗位授权、老板归属、产品主线、期权条款都明显优于当前预期**

## 下一轮最该继续问的 4 个问题

1. 最终汇报线是谁？对应哪个方向 / 哪个老板？
2. A / B / “赋能 agent” 三条线里，当前最希望你去哪一条？
3. 期权的授予主体、行权条件、离职处理机制、流动性安排是什么？
4. agent 同事那轮面试，重点是在判断技术深度、岗位落点，还是团队 fit？

## 一句话结论

这轮 HR 面把 `合同主体 + 基本薪酬结构 + 流程未完` 三件事说明白了，但**最关键的“最终老板是谁、最后去哪条线”还没定**。Interaive 仍然是高优先级机会，但还没有到可以只看 package 做决定的阶段。
