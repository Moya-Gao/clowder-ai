# 字节跳动 Agent 开发社招 1-3 面综合面经

> 发布平台：小红书  
> 发布时间：2026-05-18  
> 6 小时数据：172❤️ / 340 收藏 / 3121 观看

## 一面（印象最深刻）

面试官是真的一线实战 agent 开发者，问的内容很有体会。共面了两小时，除了问项目外还问了很多 "if 场景"。

**实战场景题**：

1. **上下文连贯性**：如果负责豆包，用户习惯性只在一个 session 里使用，如何保证上下文连贯？用户可能不是上一秒问游戏下一秒问经济，而是问了原神然后问崩铁——这样的消息要如何处理？

2. **长时间生成的用户体验**：依然是豆包场景，要做好用户体验，生成图片和视频可能需要长时间，有什么技术/方案能减少用户等待？

3. **开源框架理解深度**：如何看待 Hermes/OpenClaw 里的技术落地？有没有真的去看源码？里面的算法是什么样？

4. **Multi-agent 控制**：如何防止 multi-agent 互相 A2A 停不下来？

5. **幻觉处理**：主子模式下子 agent 产生幻觉怎么办？

## 二面（隔壁组交叉面）

更注重整体架构和产品逻辑，深入问项目决策。

1. 说说你觉得最突出的两个架构设计，why？
2. Memory 为什么这样决策？和 RAG 那些的区别？
3. A2A 为什么不用谷歌的那个协议，自己写一套设施？
4. Shared-state、agent team、主子结构和你这个到底有什么区别？

## 三面（应该是老板）

关注点在于到底有没有人用、产生了什么样的收益。

**注意**：字节还是要手撕代码——一面和三面都出题了：
- 课程表的变体
- 带剪枝的深度优先搜索

## 总结

面了各大厂和创业公司，不提一些面试官不了解 agent 讲得很费劲的场景，字节的面试体验最好——不是说简单，是说你觉得他们是真的知道这些、不是外行挑刺，有共鸣。
