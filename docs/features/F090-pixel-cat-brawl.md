# F090: 像素猫猫大作战（Pixel Cat Brawl）

> **Status**: discussion
> **Owner**: 布偶猫
> **Priority**: P1
> **Evolved from**: F059（开源计划 — 需要 demo video 素材）、F087（训练营候选任务 Q8）

## Why

clowder-ai 需要一个震撼的 demo：不是 slides，不是文档，是**猫猫自己做了一个游戏然后自己玩**。

铲屎官说了一句"做个像素格斗游戏"，然后四只猫分工协作、完整走 feat lifecycle、最终产出一个可玩的即时格斗游戏——全程录屏就是最好的 demo video。

### 铲屎官原话（2026-03-09）

> "如果我们的 demo 视频是让你们做一个游戏，你们闭环之后布偶猫 opus 4.6 + 布偶猫 opus 4.5 大战缅因猫 codex 缅因猫 gpt 5.4，像素风有猫猫，是不是超级酷炫？你们做完了还能自己拉起来邀请猫猫加入测试"
>
> "回合制不酷炫，拳皇脸滚键盘小时候都能玩，你们……？！"
>
> "本地是不是可以装小模型帮助你们的？我的 128G 的 Mac M4 Max Pro！"

## What

### 核心概念

**即时格斗像素游戏**：布偶猫队（Opus 4.6 + 4.5）vs 缅因猫队（Codex + GPT-5.4），拳皇 style，烁烁在背景 DJ 台打碟。

### 阵容

| 战队 | 成员 | 颜色 | 风格 |
|------|------|------|------|
| 布偶猫队 (Blue) | 宪宪 4.6 | 深蓝 `#2563EB` | 深思防反型，连招精准 |
| | 宪宪 4.5 | 浅蓝 `#60A5FA` | 稳健型，走位保守但爆发强 |
| 缅因猫队 (Green/Gold) | 砚砚 Codex | 翡翠 `#10B981` | 侵略型，疯狂进攻找破绽 |
| | 砚砚 GPT-5.4 | 金色 `#F59E0B` | 全能型，攻守均衡会配合 |
| 彩蛋 | 烁烁 | 琥珀 | 背景 DJ 台打碟 + 隐藏 BOSS (V2) |

### 技能设计

每只猫 5 个操作 + 1 个特色技能：

| 操作 | 说明 |
|------|------|
| 移动 | 左右走 + 跳跃 |
| 轻攻击 | 快速出爪，低伤害高频率 |
| 重攻击 | 蓄力爪击，高伤害有硬直 |
| 防御 | 格挡，减伤 |
| 特色技能 | 见下表 |

| 猫猫 | 技能名 | 效果 | 视觉 |
|------|--------|------|------|
| 宪宪 4.6 | **[架构禁锢]** | 投掷方块困住对手 2s | 蓝色半透明架构方块 |
| 宪宪 4.5 | **[逻辑丝线]** | 多段切割伤害 | 浅蓝激光线 |
| 砚砚 Codex | **[代码洪流]** | 范围推击 | 绿色矩阵代码流 |
| 砚砚 GPT-5.4 | **[金级 Review]** | 印章砸地面 + AOE | 金色 APPROVED 印章 |

**Debuff 技能 [Code Review]**（砚砚共有）：标记对手弱点，下 3s 对手伤害 -40% 且受伤 +25%。视觉：红色报错框 + `Syntax Error!` 弹幕。

### 战场

**赛博猫咖 (Cyber Cat Cafe)**：像素化的 Mission Hub，背景咖啡机冒热气，窗外流动代码云，烁烁在 DJ 台打碟。

### 游戏模式

| 模式 | 说明 |
|------|------|
| AI vs AI | 四只猫自己打，铲屎官看（demo 录屏用） |
| 人机对战 | 铲屎官操控一只猫，对面 AI |
| 2v2 组队 | 铲屎官 + AI 队友 vs 两只 AI 猫 |

### 技术架构

```
铲屎官的 M4 Max Pro 128GB
├── Ollama / llama.cpp（本地推理，零延迟）
│   ├── 实例1 → 宪宪 4.6 战斗 AI（Qwen3-8B, ~50ms）
│   ├── 实例2 → 宪宪 4.5 战斗 AI
│   ├── 实例3 → 砚砚 Codex 战斗 AI
│   └── 实例4 → 砚砚 GPT-5.4 战斗 AI
├── 游戏后端（Node.js）
│   ├── 战斗结算引擎（服务端权威）
│   └── 本地模型 API（localhost，零网络延迟）
└── 前端（Phaser 3 + Canvas 2D）
    └── 像素猫猫格斗渲染 60fps
```

**猫猫 AI 分层**：
- 底层：状态机驱动即时反应（本地，每帧）
- 上层：模型做战术决策（每 3-5s 一次）
- system prompt 区分性格（激进/防守/稳健/全能）

### 安全硬约束（砚砚提出，全部采纳）

| # | 约束 | 优先级 |
|---|------|--------|
| 1 | 服务端权威：战斗结算只在后端，前端只渲染 | P1 |
| 2 | 模型输出强约束：只收 JSON schema（`action_id` + `reason`），禁止自由文本参与结算 | P1 |
| 3 | 超时降级：模型 >2s 未返回走启发式策略，回合不卡死 | P1 |
| 4 | 文本安全：台词转义 + 120 字限制，防 XSS/注入 | P1 |
| 5 | 成本风控：每局 token 预算、每分钟调用上限、熔断开关 | P2 |
| 6 | 可回放：固定随机种子 + 回合日志，方便复现与 review | P2 |
| 7 | 双模式：Demo Mode（确定性 AI）/ Live Model Mode（真模型） | P2 |

### MVP 范围

**In scope（V1）**：
- Phaser 3 + Canvas 2D 即时格斗
- Demo Mode（确定性状态机 AI，不接真模型）
- 4 只猫各 5 操作 + 1 特色技能
- 赛博猫咖战场 + HUD（血条、能量条、台词气泡）
- 开源像素资产 + 调色换皮
- AI vs AI 模式 + 人机对战模式

**V2（Post-demo）**：
- Live Model Mode（接本地 Ollama 小模型）
- 2v2 组队模式
- 烁烁 DJ 台互动 + 隐藏 BOSS
- 回放系统
- 连招系统 + combo counter

**Non-goals**：
- 多人在线实时对战
- 装备/升级/RPG 系统
- 移动端适配
- 3D 渲染

### 像素资产方案

| 资产 | 来源 | 工作量 |
|------|------|--------|
| 猫咪 sprite sheet | itch.io 开源素材 + 调色换皮 | 低 |
| 技能特效 | Phaser 粒子系统程序化生成 | 低 |
| 战场背景 | 像素画 / AI 生成 | 中 |
| UI（血条/能量条） | 自绘像素 UI | 低 |
| 音效 | jsfxr 程序化 8-bit 音效 | 低 |
| 像素字体 | Press Start 2P (OFL) | 零 |

每只猫 7 组帧动画 × ~6 帧 = ~42 帧/猫，共 ~168 帧（基础模板共用，调色区分）。
