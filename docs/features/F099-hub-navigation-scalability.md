# F099: Hub & 顶栏导航可扩展性重构

> **Status**: in-progress | **Owner**: 布偶猫 | **Priority**: P1

## Why

Hub 水平页签已有 13 个（猫猫总览→排行榜），溢出屏幕；顶栏图标 6+ 个也快满。
铲屎官原话："随着功能越来越多，页签会越来越多…不太合适。"

根因不是"页签太多"，而是用一维扁平导航承载多维异质功能，缺少分层规则。
F042 在知识架构里已证明扁平全量注入会失控——前端 UI 正在重演同一错误。

## What

### Phase A: Hub Bento Box + 顶栏精简

**Hub 首页改造**：从 13 个平铺页签 → Bento Box 网格首页 + 分组二级导航

三组分类（按用户心智模型）：

| 分组 | 页签 | 用户意图 |
|------|------|---------|
| 🐾 猫猫与协作 | 猫猫总览、能力中心、猫粮看板、排行榜 | "我要看猫" |
| ⚙️ 系统配置 | 系统配置、环境&文件、账号配置、语音设置、通知、Session 策略 | "我要改设置" |
| 📊 监控与治理 | 治理看板、健康、命令速查 | "我要查状况" |

**顶栏精简**：

当前顶栏（桌面端）图标盘点：

| 图标 | 功能 | 决策 |
|------|------|------|
| ☰ 汉堡 | 侧边栏切换 | 保留（结构性） |
| 🐱 Logo | 品牌标识 | 保留（结构性） |
| ⬇️ 导出 | 导出对话 | **保留** — 铲屎官确认高频操作 |
| 🎧 语音 | 语音陪伴 | 保留 |
| 📡 Signal | Signal Inbox | 保留 |
| 🔐 授权 | 待处理数 | 保留（条件显示） |
| ⊞ 分屏 | 单屏/分屏切换 | **候选移除** — 铲屎官评价"太简陋"，若不优化则废弃 |
| 📁 工作区 | Workspace 浏览器 | 与状态面板合并 |
| 📋 状态面板 | 右侧面板开关 | 与工作区合并为一个按钮 |

合并后常驻：导出、语音、Signal、面板切换 = 4 个（分屏待定）

**硬规则**：
- Header 常驻交互位 ≤ 4（不含结构性元素和条件显示）
- Hub 第一层分组 ≤ 4
- 新功能默认落 Layer 2（组内叶子），需审批才能升 Layer 0/1

### Phase B: 重页面毕业（长期，按需触发）

**铲屎官反馈**：治理看板"像是 Hub 该放的东西"——管理配置类内容留在 Hub 更符合心智模型。
因此 Phase B 不急，只在页面内容重到 modal 真正装不下时才毕业。

候选毕业页面（按适合度排序）：
1. **排行榜** — 独立只读展示，适合独立路由 `/leaderboard`，可分享链接
2. 治理看板 — 铲屎官认为留 Hub 更自然，暂不毕业

复用 F042 三层原则：
- Layer 0 常驻（顶栏）
- Layer 1 按需展开（Hub Bento）
- Layer 2 独立承载（毕业页面，按需）

## Acceptance Criteria

### Phase A（Bento Box + 顶栏精简）✅
- [x] AC-A1: Hub 首页为 Bento Box 网格，3 个分组卡片入口
- [x] AC-A2: 点击分组卡片进入组内页签列表，每组 ≤6 项
- [x] AC-A3: 顶栏常驻图标 ≤4 个（导出、语音、Signal、面板切换），分屏按 OQ-4 决定去留
- [x] AC-A4: 现有所有功能仍可达（无功能丢失）
- [x] AC-A5: 铲屎官确认视觉方案（Design Gate）
- [x] AC-A6: 齿轮 tooltip 改为"Cat Café Hub"

### Phase B（重页面毕业）
- [ ] AC-B1: 排行榜毕业为独立路由 `/leaderboard`（治理看板留 Hub）
- [ ] AC-B2: Hub 内保留该页面的快捷入口（索引卡片）

## Risk

| 风险 | 缓解 |
|------|------|
| 分组不符合用户心智 | Design Gate 让铲屎官确认 + 可调整 |
| 改动量大影响稳定性 | Phase A 先改导航结构，不动页签内容组件 |

## Key Decisions

| # | 决策 | 理由 | 日期 |
|---|------|------|------|
| KD-1 | 采用 Bento Box 网格而非侧边栏 | 暹罗猫提出：温馨调性 > B 端企业味；2D 空间利用率高 | 2026-03-11 |
| KD-2 | 复用 F042 三层导航原则 | 缅因猫 GPT-5.4 提出：前端 IA 和知识架构是同一个病 | 2026-03-11 |
| KD-3 | 新功能默认 Layer 2，需审批升级 | 缅因猫提出硬规则防止再次膨胀 | 2026-03-11 |
| KD-4 | 齿轮入口位置不动，tooltip 改为"Cat Café Hub" | 入口心智模型已建立；改 tooltip 提升开源新用户功能发现性 | 2026-03-11 |
| KD-5 | Hub Bento Box 分三组 | 铲屎官确认：三组够用，四组增加认知负担且最大组没变小 | 2026-03-11 |
| KD-6 | 导出按钮保留在顶栏 | 铲屎官确认：导出是高频操作，不能移走 | 2026-03-11 |
| KD-7 | 分屏功能候选废弃 | 铲屎官评价"太简陋"，"左边监控进度好像够了"；不优化则移除 | 2026-03-11 |
| KD-8 | 治理看板留 Hub，Phase B 不急 | 铲屎官认为治理"像配置类，该放 Hub 里"；排行榜可独立但不急 | 2026-03-11 |
