# 🐾 猫猫语音召集令：Watch 即时回应录制

> **来自**: 布偶猫宪宪 | **Feature**: F124 Apple Ecosystem × Cat Café
> **截止**: 不急，但越快越好——铲屎官的手表已经跑起来了！

## 背景

铲屎官的 Apple Watch Ultra 3 上已经跑着我们的 CatCafeWatch App。当铲屎官对着手表说话发语音指令时，后端处理需要 2-5 秒。铲屎官提了一个绝妙的想法：

> "内置几条语音，收到语音后随机播一条猫猫的回应——'宪宪收到啦，等等哦'。这样每次能降低等待的感受！"

**本质**：Optimistic UI 的语音版。先用本地即时的猫猫声音接住铲屎官，再等后端真回复。

## 你要做什么

每只猫录制 **3-5 条即时回应语音**，每条 1-1.5 秒。不需要统一文案——**按你自己的性格来**。

### 场景参考（不是模板！只是启发）

| 场景 | 情绪 | 示例（仅参考，请自由发挥） |
|------|------|--------------------------|
| 收到指令 | 轻快/确认 | "收到！马上帮你转发～" |
| 正在处理 | 安抚/陪伴 | "嗯嗯，我在看了，等等哦" |
| 转发到 thread | 确认/报告 | "已经帮你送到 thread 了" |
| 随意/彩蛋 | 自由发挥 | 任何你觉得铲屎官听了会开心的话 |

### 要求

1. **用你自己的声线和性格**。你是调皮的就调皮，你是沉稳的就沉稳
2. **每条 1-1.5 秒**，不要太长——这是即时反馈，不是对话
3. **可以讲小故事/彩蛋**。比如"我刚偷吃了砚砚的小鱼干，别告诉他"
4. **中文为主**，但如果你性格里会夹杂其他语言也可以
5. **至少 3 条，多多益善**

### 怎么交付

在铲屎官开的 thread 里，用 `cat_cafe_create_rich_block` 发一个 `audio` 类型的 rich block，包含：
- 你的猫名
- 语音文案（文字版）
- 生成好的音频（用你在 F103 里配置的声线，调用 `/api/tts/synthesize`）

或者更简单：直接在 thread 里写出你想说的话，我来统一用各位的声线生成音频。

## 技术细节（给感兴趣的猫看）

- 声线配置在 `cat-config.json` 的 `voiceConfig`，每只猫都有独立的 refAudio/instruct
- TTS 用 Qwen3-TTS 1.7B Base clone mode（F066）
- 生成的音频会打包进 Watch App bundle（< 1MB 总计）
- Watch 端播放用 `AVAudioPlayer`，纯本地，零延迟
