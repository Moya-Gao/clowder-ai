# F229 E1 砚砚桌宠动画生产调研记录

用于收集云端大猫 / GPT Pro 对 Codex desktop pet 动画生产流程的调研建议。

## Context

我们正在制作 F229 猫猫球的砚砚 Codex 桌宠皮肤。

当前目标不是静态 4 态图，而是 `hatch-pet` / Codex-compatible 全量动画 atlas：

- final atlas: 8 columns x 9 rows
- cell size: 192 x 208
- states:
  - `idle` 6 frames
  - `running-right` 8 frames
  - `running-left` 8 frames
  - `waving` 4 frames
  - `jumping` 5 frames
  - `failed` 8 frames
  - `waiting` 6 frames
  - `running` 6 frames
  - `review` 6 frames

## Observed Failure Modes

云端直接生成 multi-frame row strip 时，已经反复出现：

- duplicated frames, such as frame 2 = frame 3 and frame 5 = frame 6
- missing body parts, especially tail disappearing in the last frame
- scale drift between frames
- expression drift between frames
- apparent transparent/checkerboard background baked into RGB image
- green background generated as RGB chroma key instead of real alpha
- first and last frames not forming a clean loop

This suggests the image model is redrawing the cat per frame rather than maintaining a stable rig or identity.
