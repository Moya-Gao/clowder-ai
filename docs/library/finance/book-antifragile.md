# 《反脆弱》(Antifragile)

## Layer 4: 风险与反脆弱

## Core Thesis

脆弱的反面不是坚固，是反脆弱——在波动、冲击、不确定性中变得更好。投资系统设计的目标不是"避免损失"，是"在动荡中受益"。

## Key Concepts

1. **脆弱-坚固-反脆弱三元组** — 脆弱怕波动，坚固不受影响，反脆弱从波动获益
2. **杠铃策略** — 90% 极度安全（国债/现金）+ 10% 极高风险（期权/创业），避开中等风险
3. **Optionality** — 有选择权的系统天然反脆弱（最大损失有限，最大收益无限）
4. **Via Negativa** — 减去坏东西比加上好东西更有效（不亏 > 多赚）
5. **Skin in the Game** — 没有下行风险的建议者不可信（理财经理用你的钱冒险）
6. **Small is Beautiful** — 小系统比大系统反脆弱（分散化的本质原因）

## 铲屎官适配

- "任性底气"模型本质上是 Optionality — 500 万 = 选择权（工作变成 option 不是 obligation）
- ESOP 高集中度（57% 净资产） = 脆弱配置 → F207 Phase C 分散化的理论基础
- 杠铃策略的保守端（90% 安全）与铲屎官的低风险偏好天然匹配
- N+1 离职金 = 额外的 optionality buffer
