# 《黑天鹅》(The Black Swan)

## Layer 4: 风险与反脆弱

## Core Thesis

极端事件（黑天鹅）不可预测但影响巨大，且事后总能找到"合理解释"（叙事谬误）。基于历史数据的风险模型在黑天鹅面前失效，因为它们假设正态分布，但现实是肥尾分布。

## Key Concepts

1. **黑天鹅三特征** — 极端罕见、影响巨大、事后可解释
2. **肥尾分布** — 金融回报不是正态分布；极端事件发生概率远高于模型预测
3. **叙事谬误** — 人类天生需要"故事"来解释随机事件，制造虚假的因果关系
4. **火鸡问题** — 1000 天的数据说"没有风险"，第 1001 天是感恩节
5. **沉默的证据** — 幸存者偏差让我们只看到成功案例，忽略失败的绝大多数
6. **中位斯坦 vs 极端斯坦** — 身高是中位斯坦（正态），财富是极端斯坦（幂律）

## 铲屎官适配

- 4% 法则的局限性之一：不考虑黑天鹅（战争、货币危机）
- FIRE 计算中"考虑投资收益"的假设建立在历史数据上 → 黑天鹅可能打破
- 安全边际（Room for Error）的哲学根基：为不可预测留空间

## AUDHD 连接

- ASD 对不确定性的焦虑在塔勒布框架下被验证为"合理的" — 世界确实不可预测
- 但解决方案不是回避（拉窗帘），是设计能承受黑天鹅的系统（→ 反脆弱）
