# 《指数基金投资指南》

## China Practical: 中国实操

## Core Thesis

指数基金是普通中国投资者最适合的工具，但中国市场的指数体系和交易规则与美国不同，需要本土化的操作指南。

## Key Concepts

1. **中国指数体系** — 沪深 300（大盘）、中证 500（中小盘）、创业板指 等
2. **估值定投** — 根据 PE/PB 百分位决定定投金额（低估多买，高估少买/卖）
3. **ETF vs LOF vs 场外指数基金** — 不同渠道的费率和流动性差异
4. **行业指数 vs 宽基指数** — 宽基更适合入门，行业指数需要判断能力
5. **港股通/QDII** — 中国投资者配置境外资产的合规渠道

## 铲屎官适配

- Bogleheads 三基金在中国的实操翻译
- 沪深 300 + 中证 500 ≈ A 股全市场（替代 VTI）
- QDII 全球指数基金 ≈ 国际部分（替代 VXUS，但额度受限）
- 估值定投比美国的"无脑定投"更适合 A 股的高波动特征
