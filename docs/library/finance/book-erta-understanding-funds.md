# 《解读基金》

## China Practical: 中国实操

## Core Thesis

中国基金市场产品繁多、营销套路深，普通投资者需要理解基金运作机制、费率结构和评价体系，才能避开"基金赚钱基民不赚钱"的陷阱。

## Key Concepts

1. **基金分类** — 股票型/混合型/债券型/货币型，风险收益特征不同
2. **费率结构** — 申购费/赎回费/管理费/托管费，长期影响巨大
3. **基金经理评价** — 任期回报/最大回撤/夏普比率，不看短期排名
4. **基金公司治理** — 公司文化、投研体系比明星经理更重要
5. **定投 vs 一次性买入** — 定投平滑波动，但牛市末期开始定投可能亏损

## 铲屎官适配

- 如果不纯用指数基金，需要本书的基金评价框架筛选主动基金
- 费率敏感性：ASD 对细节敏感的优势 → 适合审阅基金条款和费率
- 基金销售渠道选择：银行/券商/互联网平台 费率差异大
