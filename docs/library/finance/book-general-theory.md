# 《就业、利息和货币通论》(The General Theory)

## Layer 5: 深度理解（选读）

## Core Thesis

市场不会自动达到充分就业均衡；有效需求不足时，政府需要通过财政政策干预经济。

## Key Concepts

1. **有效需求** — 总需求决定产出和就业，不是供给
2. **流动性偏好** — 人们持有现金的动机（交易、预防、投机）决定利率
3. **动物精神** — 投资决策受信心和情绪驱动，不仅是理性计算
4. **乘数效应** — 政府支出通过链式反应放大经济影响
5. **节俭悖论** — 个人节约理性，但全体节约会导致总需求下降→衰退

## 投资应用

- 理解政府经济政策（降息、财政刺激）的理论基础
- "动物精神"是理解市场非理性波动的另一个框架（补充勒庞的群体心理）
- 节俭悖论提醒：宏观层面，你的储蓄 ≠ 经济增长
