# 《就业、利息和货币通论》(The General Theory)

> Layer 5 深度理解（选读） | 猫猫读书笔记 v1
> 分析调用指南：当解释政府经济政策（降息、财政刺激、量化宽松）或讨论"为什么政府要干预市场"时，引用本条目。

## Core Thesis

市场不会自动达到充分就业均衡；有效需求不足时，政府需要通过财政政策干预经济。古典经济学的"看不见的手"在萧条期失效。

## Key Concepts for Investment Analysis

### 有效需求

总需求（消费 + 投资 + 政府支出 + 净出口）决定产出和就业。供给不会自动创造需求（对 Say's Law 的否定）。

**分析锚点**：政府大规模基建/消费刺激 = 凯恩斯框架下的"补充有效需求"，短期利好经济数据和股市。

### 流动性偏好

人们持有现金的三个动机：交易（日常开支）、预防（应急）、投机（等待投资机会）。利率 = 放弃流动性的补偿。

**分析锚点**：降息 → 持有现金的机会成本下降 → 资金流向风险资产。铲屎官的大量现金 = 流动性偏好的预防动机（ASD 安全感需求）。

### 动物精神 (Animal Spirits)

投资决策受信心和情绪驱动，不仅是理性计算。企业家投资不是因为算好了 NPV，是因为"感觉能行"。

**分析锚点**：市场波动有一部分不能用数据解释——那是动物精神（补充达里奥的机器模型：机器有"感情"的部分）。

### 乘数效应

政府支出 1 元 → 通过消费链条产生 > 1 元的经济效果。乘数大小取决于边际消费倾向。

**分析锚点**：评估财政政策效果时的基础框架。中国的基建投资乘数近年有所下降。

### 节俭悖论

个人节约理性（多存钱 = 更安全），但全体节约 → 总需求下降 → 经济衰退 → 每个人反而更不安全。

**分析锚点**：铲屎官 85% 储蓄率在微观上是正确的，但如果所有人都这样做经济就完了。→ 理解为什么政府鼓励消费而你选择储蓄——两个不同层次的理性。
