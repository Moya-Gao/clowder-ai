# 《说谎者的扑克牌》(Liar's Poker)

## Layer 2: 市场认知

## Core Thesis

华尔街的利益结构决定了金融从业者的推荐往往不符合客户利益。理解金融行业的激励机制，才能在信息不对称中保护自己。

## Key Concepts

1. **利益冲突** — 经纪人/理财经理的佣金结构激励他们推销高费率产品
2. **信息不对称** — 卖方永远比买方知道得多，复杂产品是利润来源
3. **金融创新的两面性** — 新产品往往是包装复杂性以收取更高费率
4. **文化与激励** — 交易室文化奖励冒险和短期利润，不奖励客户长期回报
5. **Mortgage-Backed Securities** — 金融工程如何把风险从创造者转移到购买者

## 投资应用

- 理财经理推荐什么 ≠ 你应该买什么
- "免费咨询"不存在，成本藏在产品费率里
- 产品越复杂，信息不对称越大，普通投资者越吃亏
- 自主学习 + 低费率指数基金 = 绕过整个利益冲突链

## 学完应该能回答

> 理财经理在卖给我什么？他的利益和我的利益一致吗？
