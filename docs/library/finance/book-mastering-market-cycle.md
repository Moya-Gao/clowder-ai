# 《周期》(Mastering the Market Cycle)

## Layer 3: 系统与周期

## Core Thesis

市场周期不可避免，但可以识别。投资者的核心技能不是"预测周期何时转向"，而是"判断当前在周期的哪个位置"，据此调整风险暴露。

## Key Concepts

1. **钟摆理论** — 市场在贪婪和恐惧之间像钟摆一样摆动，极少停在中间
2. **周期叠加** — 经济周期、信贷周期、房地产周期、心理周期相互叠加放大
3. **"知道在哪"** — 不需要预测未来，只需要评估当前温度（过热/过冷）
4. **Risk-On / Risk-Off** — 市场情绪极端时做相反的事：别人恐惧时贪婪
5. **Second-Level Thinking** — 一级思维："好公司→买"；二级思维："好公司但定价已反映→不买"

## 铲屎官适配

- 护栏 §4（Panic 防护）的理论依据 — 市场大跌 = 钟摆到恐惧极端，不该行动
- 年度再平衡的节奏天然适合"判断温度"而非"预测转向"
- 二级思维训练对 ASD 系统化推理是有趣的升级
