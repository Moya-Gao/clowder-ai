# 《周期》(Mastering the Market Cycle)

> Layer 3 系统与周期 | 猫猫读书笔记 v1
> 分析调用指南：当需要评估市场情绪温度、决定风险暴露程度、或解释"为什么现在不应该 X"时，引用本条目。

## Core Thesis

市场周期不可避免，但可以识别。投资者的核心技能不是"预测周期何时转向"，而是"判断当前在周期的哪个位置"，据此调整风险暴露。你不需要知道明天会怎样，只需要知道今天是热还是冷。

---

## Core Framework: 钟摆理论

**论点**：市场情绪在贪婪和恐惧之间像钟摆一样摆动，极少停在中间位置（均衡点）。大部分时间，市场要么过度乐观，要么过度悲观。

**钟摆两端**：

| 贪婪端（过热） | 恐惧端（过冷） |
|---------------|---------------|
| "这次不一样" | "这次完蛋了" |
| 风险被忽视 | 风险被夸大 |
| 资产价格 > 内在价值 | 资产价格 < 内在价值 |
| 借贷容易、标准宽松 | 借贷困难、标准严苛 |
| 新投资者涌入 | 投资者撤离 |
| 应该更谨慎 | 应该更勇敢 |

**分析锚点**：
- 护栏 §4 Panic 防护的理论基础："市场大跌 = 钟摆到恐惧极端 = 不该行动"
- 年度再平衡的节奏天然适合：感受"温度"而非预测转向
- **猫猫的周期温度计**：根据市场指标判断"偏热/中性/偏冷"，写入季度观察

---

## 多周期叠加

**论点**：市场行为是多个周期叠加的结果——经济周期、信贷周期、房地产周期、企业盈利周期、心理周期。它们频率不同但相互影响，在特定时刻同步共振产生极端行情。

**关键洞察**：
- 2008 年 = 所有周期同时触顶并同步下行 → 系统性崩盘
- 单个周期转向不一定造成危机，多周期共振才是真正的风险
- → 连接达里奥的三力量模型：短期+长期债务周期+生产率叠加

**分析锚点**：
- 季度报告可选观察项："几个周期在什么位置？有共振风险吗？"
- 但注意**不做精确判断**——只做大方向感知（ASD 系统化 + 护栏低频操作）

## Second-Level Thinking（二级思维）

**论点**：
- 一级思维："好公司 → 买"
- 二级思维："好公司，但当前价格已经反映了所有利好，而且市场对它的预期过高 → 不买"

**区别**：

| 一级思维 | 二级思维 |
|---------|---------|
| "经济在增长，股市会涨" | "大家都知道经济在增长，价格已经反映了，如果增长不及预期呢？" |
| "这公司利润翻倍了" | "翻倍已被定价，下一步是涨速放缓，市场可能失望" |
| "大家都在恐慌，赶紧卖" | "恐慌已过度，价格低于价值，这是机会" |

**铲屎官适配**：
- ASD 的系统化推理天然适合二级思维训练
- 但 ADHD 的冲动倾向会跳过二级直接行动 → 24h 冷却机制的另一个支持论据
- **猫猫报告中引入二级框架**：每个观察后面加"但是"——即使结论是正面的

---

## "知道在哪" vs "预测未来"

**论点**：Marks 反复强调——你不需要预测未来，只需要判断**当前温度**。

**温度判断清单**：
1. 经济数据是好转还是恶化？
2. 企业盈利在增长还是收缩？
3. 信贷容易还是困难？
4. 市场情绪乐观还是悲观？
5. 资产价格相对历史估值是高还是低？
6. 资金在流入还是流出风险资产？

**评分方式**：6 项中多数偏热 → 市场偏热，应更保守；多数偏冷 → 市场偏冷，可更积极。

**铲屎官适配**：
- 这个清单可以作为季度观察的**结构化模板**
- 不需要精确数字——每项 "偏热/中性/偏冷" 即可
- ASD 友好：清单式、规则明确、不需要"感觉"
