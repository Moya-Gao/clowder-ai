# 《穷查理宝典》(Poor Charlie's Almanack)

> Layer 5 深度理解（选读） | 猫猫读书笔记 v1
> 分析调用指南：当需要跨学科思维框架、检查清单方法论、或对抗认知偏误时，引用本条目。AUDHD 跨域联想能力与芒格框架天然共振。

## Core Thesis

最好的决策来自多元思维模型——从不同学科借用核心思维工具，避免"拿着锤子看什么都是钉子"。投资不只是金融问题，是心理学+数学+生物学+物理学问题。

## Key Concepts for Investment Analysis

### 多元思维模型（~100 个模型，投资核心 ~10 个）

| 学科 | 模型 | 投资应用 |
|------|------|---------|
| 心理学 | 确认偏误 | 只看支持自己观点的信息 |
| 心理学 | 锚定效应 | 买入价影响卖出决策（"我要回本"） |
| 心理学 | 社会认同 | "大家都在买"= 勒庞群体效应 |
| 数学 | 复利 | 时间 > 回报率（Housel Ch.4） |
| 数学 | 概率/贝叶斯 | 用新信息更新判断，不固守初始观点 |
| 物理学 | 临界质量 | 趋势在达到临界点前看不出来，突然爆发 |
| 生物学 | 适应 | 市场参与者不断适应，昨天有效的策略明天可能失效 |
| 工程学 | 安全边际 | 桥梁承重设计 > 预期载荷（→ Room for Error） |
| 经济学 | 机会成本 | 选择 A = 放弃 B，成本不只是花出去的钱 |
| 哲学 | 奥卡姆剃刀 | 最简单的解释通常最正确 → 指数基金 > 复杂策略 |

### 逆向思维 (Inversion)

**芒格名言**："告诉我我会死在哪里，我就不去那里。"

**投资应用**：
- 不问"什么投资能赚钱" → 问"什么投资会让我亏光"
- FIRE 不问"怎么最快到 500 万" → 问"什么会让我永远到不了"
  - 亏光本金、失去收入来源、通胀侵蚀、重大疾病支出
- AUDHD 护栏本质 = 逆向思维的产物（识别"会让我失败"的行为并提前阻断）

### 能力圈 (Circle of Competence)

只投资你能理解的东西。诚实承认边界。

**铲屎官适配**：
- 当前能力圈：华为 ESOP（理解公司/行业）、银行存款
- 扩展中：指数基金（通过 F207 学习扩展到此）
- 明确圈外：期权/期货/衍生品/加密货币/个股选择
- **能力圈不是永远固定的**——学习就是在扩大圈

### 检查清单 (Checklist)

**芒格从飞行员方法论借来的**：人类在压力下会遗忘关键步骤，清单是对抗认知偏误的最低成本工具。

**投资检查清单示例**：
- [ ] 这个决策是被数据驱动还是被情绪驱动？
- [ ] 我在不在自己的能力圈内？
- [ ] 如果错了，最大损失是多少？能承受吗？
- [ ] 有没有 24h 冷却期？（护栏 §3）
- [ ] 推荐者有 Skin in the Game 吗？
- [ ] 这是"门票"（正常波动）还是"罚款"（根本性错误）？

**AUDHD 适配**：检查清单对 ADHD 执行功能薄弱是最有效的补偿策略——把隐性知识变成显性流程。

### Lollapalooza 效应

多个偏误同向叠加时产生极端结果。不是 A+B，是 A×B×C。

**投资映射**：
- 2015 年 A 股泡沫 = 社会认同 × 确认偏误 × 过度自信 × 杠杆 = Lollapalooza 崩盘
- 铲屎官如果同时触发 ADHD 冲动 + 群体情绪传染 + 锚定效应 = 极端坏决策
- AUDHD 护栏的多层设计 = 防止 Lollapalooza（任一层阻断就能打破链条）
