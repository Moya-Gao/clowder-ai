# 《穷查理宝典》(Poor Charlie's Almanack)

## Layer 5: 深度理解（选读）

## Core Thesis

最好的投资决策来自多元思维模型——从不同学科（心理学、数学、物理学、生物学）借用思维工具，避免"拿着锤子看什么都是钉子"。

## Key Concepts

1. **多元思维模型** — 不同学科的核心思维工具（~100 个），交叉运用
2. **逆向思维** — "告诉我我会死在哪里，我就不去那里"
3. **能力圈** — 只投资你能理解的东西，诚实承认边界
4. **检查清单** — 用清单对抗人类认知偏误（飞行员检查清单方法论）
5. **Lollapalooza 效应** — 多个偏误同向叠加时产生极端结果

## AUDHD 连接

- 多元思维模型与 AUDHD 的跨域联想能力天然共振
- 铲屎官的文理兼修背景（CS + 语言学/心理学兴趣）= 天然多元模型库
- 能力圈概念是 ASD 系统化思维 + ADHD 过度自信的平衡器
- 检查清单方法论对 ADHD 执行功能薄弱是有效补偿策略
