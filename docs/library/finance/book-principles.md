# 《原则》(Principles) — 经济机器部分

## Layer 3: 系统与周期

## Core Thesis

经济是一台有规律的机器，由三个叠加的力量驱动：生产率增长（长期趋势线）、短期债务周期（5-8 年）、长期债务周期（75-100 年）。理解机器 = 预测位置。

## Key Concepts

1. **经济机器模型** — 交易是经济的原子单位；所有周期都是交易行为的汇总
2. **短期债务周期** — 信贷扩张→通胀→紧缩→衰退，~5-8 年一循环
3. **长期债务周期** — 债务/收入比持续上升→去杠杆化→"美丽去杠杆"或"丑陋去杠杆"
4. **生产率趋势线** — 长期唯一重要的东西；短期波动是噪声
5. **Deleveraging** — 减少支出、债务重组、财富转移、印钞 四种手段的组合

## 铲屎官适配

- ASD 系统化驱动的最佳匹配 — 经济机器模型正是"把不可控拆成可理解的系统"
- 周期判断能力为 Phase C 分析框架提供宏观背景
- 不需要"预测市场"，只需要知道"大概在周期的哪个位置"
