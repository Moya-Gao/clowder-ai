# 《乌合之众》(The Crowd)

## Layer 1: 心理底座

## Core Thesis

个体进入群体后智力下降、情绪传染、判断力消失。群体行为由情感驱动而非理性，且极易被简单口号和形象操纵。

## Key Concepts

1. **群体心理** — 个体在群体中丧失独立判断，形成"集体心灵"
2. **情绪传染** — 恐惧和贪婪在群体中呈指数放大
3. **匿名性** — 群体给予"法不责众"的错觉，降低个体责任感
4. **简化倾向** — 群体只接受简单、绝对的判断；复杂推理无效
5. **领袖效应** — 群体需要偶像，不需要证据

## 投资应用

- **羊群效应** — "大家都在买 X" 是最危险的买入信号
- **恐慌抛售** — 市场崩盘时的集体行为是非理性的情绪传染
- **社交媒体放大** — 现代投资论坛/群组是勒庞群体心理的数字版本
- **逆向思维基础** — 理解群体非理性是逆向投资的心理学根基

## AUDHD 连接

- ADHD 的社交敏感性可能使铲屎官更易受情绪传染 → 护栏 §4 Panic 防护的理论基础
