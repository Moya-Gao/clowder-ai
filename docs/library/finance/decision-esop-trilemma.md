# ESOP 三合一决策

## Decision

铲屎官在 2026-04-22 面临三合一决策：华为升级(17J)、ESOP 续持、JD 机会评估。最终选择：**留守升级 + ESOP 续持 + 暂不跳槽**。

## Context

- ESOP 145,600 股 ≈ 114 万 RMB，占净资产 ~57%
- ESOP 分红率从 23.7% 降至 14.8%，趋势下行
- 升级到 17J 已完成
- 外部 JD 机会评估后决定不跳

## Key Insights

1. **集中度风险** — 57% 净资产在华为 ESOP = 高度集中；收入+资产都绑定同一实体
2. **分红下降趋势** — 23.7% → 14.8%，如果持续，ESOP 的被动收入价值在降低
3. **锁定效应** — ESOP 离职需退出，创造"金手铐"效应
4. **分散化需求** — 这是 F207 Phase C 投资分析的核心输入之一

## Decision Rationale

- 升级窗口期不适合离开（沉没成本+升级收益）
- ESOP 短期仍有 10%+ 回报，优于现金
- 但长期需要逐步降低华为依赖（分散化路径在 Phase C 规划）
