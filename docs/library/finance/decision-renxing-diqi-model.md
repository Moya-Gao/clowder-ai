# 任性底气模型

## Decision

铲屎官的 FIRE 目标不是"完全不工作"，而是"工作变成选择不是必须"。目标 2031 年达到 500 万净资产。

## Model

- **2026-2031**：在华为"任性工作"（有能力随时离开但选择留下）
- **分散化投资**：降低华为 ESOP 单一依赖
- **达到 500 万后** → 工作变成 100% optional
- **本质**：Barista FIRE / Coast FIRE 的混合

## Parameters (CVO 决策 2026-05-18)

| Parameter | Value |
|-----------|-------|
| FIRE 目标 | 500 万 RMB |
| 当前净资产 | ~200 万 |
| 缺口 | ~300 万 |
| 年储蓄 | ~45-50 万 |
| 纯存钱到达 | ~6 年 (2032) |
| 考虑投资收益 | ~5 年 (2031) |
| N+1 离职金 | ~60 万（额外 buffer） |

## Why 500 万 Not 300 万

铲屎官原话："不然打工都有那么多了！"
- 300 万 = 6 年纯存钱就到了，没有投资的意义
- 500 万 × 4% = 20 万/年 ≈ 当前年支出上限，4% 法则安全

## Key Risk

- 通胀 15 年后 500 万购买力 ≈ 350-400 万
- ESOP 分红趋势下降影响被动收入
- 医疗预留（心内科就诊记录）
