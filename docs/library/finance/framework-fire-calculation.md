# FIRE 测算模型 (Financial Independence, Retire Early)

## Core Formula

**到达 FIRE 的年数** 主要取决于储蓄率，而不是收入绝对值。

| 储蓄率 | 到达 FIRE 年数（假设 5% 实际回报） |
|--------|----------------------------------|
| 50% | ~17 年 |
| 60% | ~12.5 年 |
| 70% | ~8.5 年 |
| 80% | ~5.5 年 |
| 85% | ~4 年 |
| 90% | ~3 年 |

## FIRE 变体

| Type | Description | 铲屎官适配 |
|------|-------------|-----------|
| **Lean FIRE** | 极简生活，年支出 < 4 万美元 | 接近（15 万 RMB ≈ 2 万 USD） |
| **Regular FIRE** | 正常生活水平退休 | 更接近这个 |
| **Fat FIRE** | 富裕退休，年支出 > 10 万美元 | 不是目标 |
| **Barista FIRE** | 半退休 + 兼职 | "任性底气"模型本质是这个 |
| **Coast FIRE** | 已存够，等复利长到退休金额 | 接近——200 万在 5% 复利下 ~15 年到 500 万 |

## 铲屎官的"任性底气"模型

不是传统 FIRE（完全不工作），而是：
- 2026-2031：在华为"任性工作"（工作是选择不是必须）
- 分散化投资降低华为单一依赖
- 达到 500 万后 → 工作变成 100% optional
- 本质是 Barista FIRE / Coast FIRE 的混合

## 关键风险

1. 通胀侵蚀：中国 CPI 2-3%/年，15 年后 500 万购买力 ≈ 今天的 350-400 万
2. 医疗支出：无家庭但自身健康（心内科就诊记录）需要预留
3. ESOP 分红下降：从 23.7% 降到 14.8%，趋势如果持续，影响被动收入
4. 汇率风险：如果配置全球资产，人民币汇率波动影响实际购买力
