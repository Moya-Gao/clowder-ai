# 4% 法则 (Safe Withdrawal Rate)

## Core Idea

Trinity Study (1998) 结论：如果退休时从投资组合中每年提取不超过 4%（通胀调整），有 95%+ 概率 30 年内不会花光。

## 公式

- **FIRE 目标金额 = 年支出 × 25**
- 等价于：年提取率 = 4%

## 铲屎官适用计算

| Parameter | Value |
|-----------|-------|
| 年支出 | 15-20 万 RMB |
| FIRE 目标（取上限） | 20 万 × 25 = 500 万 |
| 当前净资产 | ~200 万 |
| 缺口 | ~300 万 |

## 重要前提和局限

1. **基于美国历史数据** — 1926-1995 年 S&P 500 + 美国债券
2. **30 年期限** — 如果退休年龄很早（如 35 岁），需要 50+ 年，4% 可能偏高
3. **不适用于单一市场** — 如果只投 A 股，历史波动率不同，安全提取率可能需要调低到 3-3.5%
4. **通胀假设** — 基于美国 CPI，中国通胀结构不同
5. **不考虑黑天鹅** — 系统性风险（战争、货币危机）不在模型内

## FIRE 社区的修正

- **保守 FIRE**：3.5% 或更低（特别是 early retirement）
- **动态提取**：好年份多提，差年份少提（Guyton-Klinger rules）
- **Bucket 策略**：短期开支用现金/债券，长期用股票
- **边际收入**：FIRE 不等于零收入，兼职/被动收入降低提取压力

## 铲屎官特殊因素

- 华为 N+1 离职金（~60 万）= 额外缓冲
- ESOP 分红（当前 ~10%/年）= 虽然趋势下降但仍可观
- 年支出"大概率花不到 15 万" = 实际提取率可能 < 3%
- 无房贷/无家庭负担 = 支出弹性大
