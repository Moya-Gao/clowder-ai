## Findings

### P1 - 非法 action 也会创建 draft，导致治理状态污染

- 位置：`packages/api/src/routes/memory-publish.ts:43`
- 现状：`/api/memory/publish` 对 **任何 action** 都先 auto-create draft，再做 transition。
- 风险：调用 `approve/archive/rollback`（本应失败）时，虽然返回 `409`，但 entry 已被创建，形成“失败请求产生副作用”。

**复现实验（已验证）**

请求：
- `POST /api/memory/publish`  
- body: `{ "entryId": "ghost", "action": "approve", "actor": "user" }`

结果：
- HTTP `409`
- 但 store 内 `ghost` 已存在，状态为 `draft`

**修复建议**

1. 仅当 `action === "submit_review"` 且 entry 不存在时允许 auto-create。  
2. 对 `approve/archive/rollback`，entry 不存在应直接 `409` 且 **无副作用**。  
3. 增加回归测试：`approve on missing entry must not create draft`。

---

### P2 - MCP tags 为逗号字符串时未拆分，strict 过滤会错失结果

- 位置：`packages/mcp-server/src/tools/evidence-tools.ts:27` 与 `packages/api/src/routes/evidence.ts:149`
- 现状：
  - MCP 工具把 `tags` 定义为“逗号分隔字符串”
  - API route 对字符串 tags 直接包装成数组 `[tags]`
  - 导致 `"project:cat-cafe,kind:decision"` 被当成单个 tag

**复现实验（已验证）**

请求：
- `GET /api/evidence/search?q=test&tags=project:cat-cafe,kind:decision`

实际传给 Hindsight：
- `tags: ["project:cat-cafe,kind:decision"]`

**修复建议**

1. 统一协议：MCP 侧把逗号串拆成多值 query（重复 `tags` 参数）或 API 侧补 `split(',')`。  
2. 增加测试覆盖该路径（目前 mcp-server 缺该工具测试）。
