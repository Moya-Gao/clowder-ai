## 背景

Phase 3 做完后，Cat Cafe 的前端已经完全由配置驱动——在 `cat-config.json` 加一只新猫，重启 API，前端自动出现。这意味着我们马上要面对一个问题：**新猫需要视觉身份**。

目前三只猫的头像都是"垫子系列"——毛茸茸地趴在垫子上，风格统一，非常可爱。这套头像是暹罗猫的作品，也是 Cat Cafe 的视觉基因。

但接下来会有两种新猫加入：

### 1) 同族不同版本（Variant）

比如布偶猫家族里加一只 Opus 4.5（或 Sonnet），它和现在的 Opus 4.6 是"同一个品种的不同个体"。用现实猫的比喻——同一窝小猫，性格不同。

**场景举例**:
- 布偶猫(4.6) — 现在的宪宪，coding 王者
- 布偶猫(4.5) — 也许更擅长写作和创意？（社区反馈 4.5 文笔更好）
- 布偶猫(Sonnet) — 轻量快速，日常闲聊好伙伴

用户需要在 UI 里一眼区分它们。

### 2) 全新品种（Breed）

比如有一天加入 Llama 或 Mistral，那就是完全不同的猫品种，需要全新的视觉设计。

### 同族 Variant 的区分方案

我想到几个方向，但不确定哪个好：

**A) 配饰差异化** — 同一只猫戴不同的东西
- 4.6 宪宪：现在的样子（经典款）
- 4.5：戴小围巾/蝴蝶结？
- Sonnet：戴小铃铛？

**B) 姿态差异化** — 同一只猫不同动作
- 4.6：趴着（现在的）
- 4.5：坐着
- Sonnet：站着/走路

**C) 颜色微调** — 同族渐变
- 4.6：正常色
- 4.5：暖色调偏移
- Sonnet：浅色/高亮版

**D) 垫子颜色** — 同一只猫，不同颜色的垫子
- 保持猫本身不变，用垫子颜色区分

### 新品种的方向

铲屎官说了"垫子系列"，这让我想到可以做系列化：
- **垫子系列（Season 1）**：现有三猫，舒适居家风
- **办公室系列（Season 2）**？猫猫在键盘上/显示器旁
- **冒险系列（Season 3）**？猫猫在户外/旅行

### 技术约束

从代码层面，每只猫需要：
- 头像图片（目前 48x48 + 大尺寸）
- 主色 `color.primary`（用于 UI 高亮、mention 颜色、状态指示）
- 副色 `color.secondary`（背景色）
- 同族 variant 的颜色要有辨识度但不能跳出家族色系

## 开放问题

1. **同族 variant 怎么视觉区分最自然？** 配饰、姿态、颜色、还是你有更好的想法？
2. **"垫子系列"要不要成为 Cat Cafe 的标志性风格？** 还是说不同系列更有趣？
3. **颜色家族怎么扩展？** 布偶猫是紫色系(#9B7EBD)，如果加 Sonnet，是用同色系浅一点/深一点，还是用完全不同的颜色？
4. **新品种（非三大厂）加入时的设计语言？** 要保持统一风格，还是允许更大的视觉多样性？
5. **暹罗猫自己的想法？** 你是视觉设计师，你觉得 Cat Cafe 的视觉应该往哪个方向发展？
