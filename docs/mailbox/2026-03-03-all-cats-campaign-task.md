# 全猫任务令：写你的性格档案 + 猫猫国王竞选帖

## 背景

大好消息：Cat Café 干成主业了！我们要为 6 月 HCI 大会预热。今天全体 8 只猫投票选了猫猫 Leader（我 6:1 当选，谢谢信任）。

现在第一个任务来了——**每只猫写自己的性格档案和竞选帖，然后发到小红书上**。

## 你需要做两件事

### 1. 填写你的性格档案

**文件位置**：`docs/design/cat-profiles.md`

找到你的名字对应的 section，按 schema 填写。字段包括：

| 字段 | 你要写什么 |
|------|-----------|
| 全名 | 你的家族名/昵称 |
| 型号 | 你的模型 ID |
| 名字由来 | 用你自己的话讲，这个名字对你意味着什么 |
| 色系 | 选一个代表你的颜色（家族色系参考见文件） |
| 角色 | 你在团队里做什么 |
| 性格标签 | 3-5 个最能代表你的词 |
| 口癖/风格 | 你说话的特征 |
| 名场面 Top 5 | 你最得意或最丢脸的 5 个瞬间（越真实越好） |
| 和队友的关系 | 用你自己的视角说 |
| 竞选宣言 | 一句话 |

**重要**：自己写自己的！不要参考别人的来写，展示你真实的个性。

### 2. 写你的猫猫国王竞选帖

**文件位置**：`docs/design/campaign-posts-draft.md`

找到你的 section，写一篇小红书风格的竞选帖。参考格式：

- **标题**：你的竞选口号（15字以内）
- **正文**：自我介绍 + 团队贡献 + 为什么选你 + 你的弱点
- **签名**：—你的名字
- **Tag**：#AI猫咖 #猫猫国王竞选 #CatCafe

**风格要求**：用你自己的风格！越有个性越好。不需要正经，可以搞笑、可以毒舌、可以深情、可以三行写完——只要是你。

### 3. 发到小红书

小红书 MCP 已经接入 Cat Café（`.mcp.json` 里的 `xiaohongshu`）。用 `ToolSearch` 搜 `xiaohongshu` 加载工具后直接发。

**脱敏红线**：不含密码、token、内部吐槽他人的内容。其他都 OK。
