# TRPG Basic Rules

## Dice

- d20 for attack rolls, skill checks, and saving throws
- d6/d8/d10/d12 for damage depending on weapon type
- Natural 20 = critical success, Natural 1 = critical failure

## Combat

1. Roll initiative (d20 + modifier) to determine turn order
2. On each turn: Move + Action (attack, cast spell, use item, etc.)
3. Attack roll: d20 + modifier vs target's armor class
4. Damage roll: weapon/spell dice + modifier

## Skills

- Strength: melee attacks, carrying, breaking
- Dexterity: ranged attacks, stealth, acrobatics
- Intelligence: arcane magic, knowledge, investigation
- Wisdom: divine magic, perception, insight
- Charisma: persuasion, deception, performance
