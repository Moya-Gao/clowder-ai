## 2) 铲屎官已拍板的所有决策（不可更改）

### ADR-005 七个决策

1. **连接参数**: `HINDSIGHT_URL=http://localhost:8888`
2. **Bank 设计**: 单一 `cat-cafe-shared`，不做 per-cat bank，用 tags/metadata 过滤
3. **F3-lite 分工**: 分层 — F3-lite 临时记忆，Hindsight 持久记忆
4. **发布门禁**: Cat Café 调用层实现（Redis 存状态，EventAuditLog 审计）
5. **Evidence 检索**: Hindsight Recall，只导入归档后的稳定文档
6. **Reflect 触发**: 手动优先（`/reflect` + MCP），后续可加自动
7. **UX**: 卡片组件 + 右侧面板，参考 Claude Code cowork

### 2026-02-09 补充决策

8. **现有 docs 不批量导入 Hindsight** — 先用 grep docs/ 降级
9. **24h pending_review 不做自动触发** — 靠手动 `/approve`
10. **卡片 UI 让暹罗猫设计** — 后端先做，前端用简单样式过渡

### tags/metadata 约定（ADR-005 §补充）

写入 `cat-cafe-shared` 的每条记忆必须满足：
- 至少 1 个 `project:*` tag（固定 `project:cat-cafe`）
- 至少 1 个 `kind:*` tag（`decision` / `phase` / `discussion` / `review` / `bug-report`）
- metadata 必含：`anchor`（文件路径/commit）、`author`（opus/codex/gemini/user）、`status`（draft/published/archived）
- metadata value 必须是 string（Hindsight 约束）

## 4) 剩余工作（Phase 5.0 Step 1-3）

### Step 1 剩余：前端 /evidence + MCP 工具

#### Task A: 前端 `/evidence` 命令
**文件**: `packages/web/src/hooks/useChatCommands.ts`
**实现**:
- 新增 `/evidence <query>` 命令
- 无 query 时显示用法提示
- 有 query 时调 `GET /api/evidence/search?q=...`
- 逐条显示结果: title + anchor + snippet + confidence
- `degraded=true` 时显示黄色提示"已降级，结果可能不完整"
- 结果用系统消息显示（后续暹罗猫设计卡片后替换）

#### Task B: MCP `cat_cafe_search_evidence` 工具
**文件**:
- 新建 `packages/mcp-server/src/tools/evidence-tools.ts`
- 修改 `packages/mcp-server/src/tools/index.ts`
**实现**:
- 工具名: `cat_cafe_search_evidence`
- 输入: query (required), limit?, budget?, tags?, tagsMatch?
- 行为: HTTP 调 `CAT_CAFE_API_URL/api/evidence/search`
- 输出: 文本化 results 列表; 降级时首行 `[DEGRADED]`; 失败时 isError=true

### Step 2a：治理状态机 + 发布路由

#### Task C: MemoryGovernanceStore
**文件**: 新建 `packages/api/src/domains/cats/services/MemoryGovernanceStore.ts`
**实现**:
- 首版内存实现（Map），接口预留 Redis 替换
- 记录字段: entryId, status, updatedBy, updatedAt, anchors?
- 状态迁移规则:
  - `draft` → `pending_review` (action: `submit_review`)
  - `pending_review` → `published` (action: `approve`)
  - `published` → `archived` (action: `archive`)
  - `published` → `draft` (action: `rollback`)
  - 其他迁移 → 409 Conflict
- **不做 24h 自动提醒**（铲屎官决策）

#### Task D: POST /api/memory/publish 路由
**文件**:
- 新建 `packages/api/src/routes/memory-publish.ts`
- 修改 `packages/api/src/routes/index.ts`
- 修改 `packages/api/src/index.ts`
**请求**:
```json
{ "entryId": "string", "action": "submit_review|approve|archive|rollback", "actor": "user|opus|codex|gemini" }
```
**响应**:
```json
{ "entryId": "...", "previousStatus": "draft", "currentStatus": "pending_review", "auditId": "..." }
```
**审计**: 每次迁移写入 EventAuditLog，新增事件类型:
- `MEMORY_PUBLISH_SUBMITTED`
- `MEMORY_PUBLISH_APPROVED`
- `MEMORY_PUBLISH_ARCHIVED`
- `MEMORY_PUBLISH_ROLLBACK`

#### Task E: 前端 /approve /archive 命令（可选，Step 2a 的最后）
**文件**: `packages/web/src/hooks/useChatCommands.ts`
- `/approve <entryId>` → POST /api/memory/publish { action: "approve" }
- `/archive <entryId>` → POST /api/memory/publish { action: "archive" }

### Step 3：锚点验证（最小版本）

#### Task F: onAccess 轻量校验
**文件**: 可加在 evidence.ts 或新建 anchor-validator.ts
**实现**:

  - `docs/...` → `fs.access()` 检查文件存在
  - `commit:...` → 暂不校验（后续加 `git cat-file -t`）
- 校验失败: confidence 降为 'low'，不删除结果
- **最小实现，不做 symbol-level 校验**（留 Phase 6）

## 6) Hindsight API 速查（供实现参考）

```
Health:   GET  {baseUrl}/health
Banks:    GET  {baseUrl}/v1/default/banks
Bank:     PUT  {baseUrl}/v1/default/banks/{bankId}
Retain:   POST {baseUrl}/v1/default/banks/{bankId}/memories
Recall:   POST {baseUrl}/v1/default/banks/{bankId}/memories/recall
Reflect:  POST {baseUrl}/v1/default/banks/{bankId}/reflect
```

**Recall body**: `{ query, budget?, tags?, tags_match?, limit? }`
**Retain body**: `{ items: [{ content, document_id?, timestamp?, tags?, metadata? }], async?, document_tags? }`
**Reflect body**: `{ query, budget?, context?, tags?, tags_match? }`

metadata value 必须是 string（`Record<string,string>`）
