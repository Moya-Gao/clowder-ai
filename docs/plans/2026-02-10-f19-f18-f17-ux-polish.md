## 背景

基于 `docs/archive/2026-02/discussions/2026-02-10-ux-polish-brainstorm/README.md` 的用户研究，铲屎官提出三个体验痛点：

1. **F19**: 猫猫运行时看不到动态计时，不知道有没有卡死
2. **F18**: 工具调用列表太长，占用屏幕空间，且无活动指示
3. **F17**: 需要分享对话记录，手动截图麻烦

本次设计一次性解决三个问题，按优先级排序：F19 → F18 → F17

## 设计目标

### F19 动态累积计时器
- **核心价值**: 让铲屎官安心 — 看到数字在动，就知道猫没卡死
- **验收标准**: 运行中显示 `0.0s → 0.1s → ...`，完成后显示静态 `29.7s`
- **显示位置**: 顶部状态栏 + 右侧面板

### F18 工具栏收起+滚动
- **核心价值**: 节省屏幕空间 + 保持活动指示
- **验收标准**: 可收起/展开，收起时单行滚动显示最新工具 + 动态指示
- **参考效果**: Claude Code / Codex thinking 显示

### F17 导出对话长图
- **核心价值**: 分享对话记录、保存重要讨论、制作 showcase
- **验收标准**: 前端按钮一键导出，支持全量/range，输出 PNG
- **实现方式**: Chrome headless (后端路由 + puppeteer)

## F19 详细设计：动态累积计时器

### 核心 Hook

```typescript
// packages/web/src/hooks/useElapsedTime.ts
import { useState, useEffect } from 'react';

export function useElapsedTime(startedAt: number | undefined): number {
  const [elapsed, setElapsed] = useState(0);

  useEffect(() => {
    if (!startedAt) {
      setElapsed(0);
      return;
    }

    // 立即计算一次，避免首次渲染延迟
    setElapsed(Date.now() - startedAt);

    const interval = setInterval(() => {
      setElapsed(Date.now() - startedAt);
    }, 100); // 0.1s 精度

    return () => clearInterval(interval);
  }, [startedAt]);

  return elapsed;
}
```

### 格式化函数

```typescript
// packages/web/src/components/status-helpers.ts (新增)
export function formatElapsed(ms: number): string {
  return (ms / 1000).toFixed(1) + 's';
}
```

```typescript
function CollapsedToolView({ events }: { events: ToolEvent[] }) {
  const [currentIndex, setCurrentIndex] = useState(0);

  useEffect(() => {
    const interval = setInterval(() => {
      setCurrentIndex((i) => (i + 1) % events.length);
    }, 2000); // 每 2s 滚动一次
    return () => clearInterval(interval);
  }, [events.length]);

  const current = events[currentIndex];

  return (
    <div className="px-3 pb-2 overflow-hidden h-8 relative">
      <div
        key={currentIndex}
        className="animate-slide-up font-mono text-xs text-gray-600 truncate absolute inset-0 flex items-center"
      >
        {current.type === 'tool_use' ? '🔧' : '📋'} {current.label}
      </div>
    </div>
  );
}
```

**ExportImageButton.tsx** 组件：
```typescript
'use client';

import { useState } from 'react';
import { apiFetch } from '@/utils/api-client';

export function ExportImageButton({ threadId }: { threadId: string }) {
  const [loading, setLoading] = useState(false);

  const handleExport = async () => {
    setLoading(true);
    try {
      const res = await apiFetch(`/api/threads/${threadId}/export-image`, {
        method: 'POST',
      });

      if (!res.ok) {
        throw new Error('导出失败');
      }

      const blob = await res.blob();
      const url = URL.createObjectURL(blob);
      const a = document.createElement('a');
      a.href = url;
      a.download = `chat-${threadId}-${Date.now()}.png`;
      a.click();
      URL.revokeObjectURL(url);
    } catch (error) {
      console.error('导出失败:', error);
      alert('导出失败，请重试');
    } finally {
      setLoading(false);
    }
  };

  return (
    <button
      onClick={handleExport}
      disabled={loading}
      className="px-3 py-1.5 text-sm bg-blue-500 text-white rounded-lg hover:bg-blue-600 disabled:opacity-50 disabled:cursor-not-allowed transition-colors"
    >
      {loading ? '📸 导出中...' : '📸 导出长图'}
    </button>
  );
}
```

### 后端实现

**packages/api/src/routes/thread-export.ts**:
```typescript
import type { FastifyPluginAsync } from 'fastify';
import { ImageExporter } from '../services/ImageExporter';

export const threadExportRoutes: FastifyPluginAsync = async (fastify) => {
  fastify.post('/api/threads/:threadId/export-image', async (request, reply) => {
    const { threadId } = request.params as { threadId: string };

    // 验证 threadId 格式
    if (!threadId || typeof threadId !== 'string') {
      return reply.code(400).send({ error: 'Invalid threadId' });
    }

    try {
      // 渲染 URL: 前端的对话页面
      const frontendUrl = process.env.FRONTEND_URL || 'http://localhost:3000';
      const url = `${frontendUrl}/chat/${threadId}`;

      const exporter = new ImageExporter();
      const imageBuffer = await exporter.capture(url);

      reply.type('image/png').send(imageBuffer);
    } catch (error) {
      fastify.log.error('Image export failed:', error);
      return reply.code(500).send({ error: 'Export failed' });
    }
  });
};
```

**packages/api/src/services/ImageExporter.ts**:
```typescript
import puppeteer, { type Browser } from 'puppeteer';

export class ImageExporter {
  private browser: Browser | null = null;

  async capture(url: string): Promise<Buffer> {
    try {
      // 启动浏览器（如果还没启动）
      if (!this.browser) {
        this.browser = await puppeteer.launch({
          headless: true,
          args: [
            '--no-sandbox',
            '--disable-setuid-sandbox',
            '--disable-dev-shm-usage', // 避免内存不足
          ],
        });
      }

      const page = await this.browser.newPage();

      // 设置初始视口
      await page.setViewport({ width: 1280, height: 720 });

      // 导航到目标页面，等待网络空闲
      await page.goto(url, {
        waitUntil: 'networkidle2',
        timeout: 30000,
      });

      // 等待对话容器加载
      await page.waitForSelector('[data-chat-container]', { timeout: 10000 });

      // 获取整个对话容器的高度
      const height = await page.evaluate(() => {
        const container = document.querySelector('[data-chat-container]');
        return container?.scrollHeight ?? 720;
      });

      // 调整视口高度以包含所有内容
      await page.setViewport({ width: 1280, height: Math.min(height, 50000) });

      // 截图
      const screenshot = await page.screenshot({
        type: 'png',
        fullPage: true,
      });

      await page.close();

      return screenshot as Buffer;
    } catch (error) {
      // 确保页面关闭
      throw error;
    }
  }

  async close() {
    if (this.browser) {
      await this.browser.close();
      this.browser = null;
    }
  }
}
```

## 风险与缓解

| 风险 | 影响 | 缓解方案 |
|------|------|----------|
| puppeteer 启动慢 | F17 导出耗时长 | 复用 browser 实例，避免每次重启 |
| 长对话截图超时 | F17 导出失败 | 设置合理 timeout (30s)，限制最大高度 50000px |
| 前端 CSS 动画性能 | F18 卡顿 | 使用 CSS transform (GPU 加速) |
| 计时器精度偏差 | F19 时间跳动 | 100ms interval 足够平滑，无需优化 |
