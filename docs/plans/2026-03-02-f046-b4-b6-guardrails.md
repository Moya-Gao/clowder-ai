# F046 B4+B6 Guardrails Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use parallel-execution skill (Mode C) to implement this plan task-by-task.

**Goal:** 落地 F046 Phase B 的 B4/B6：为 `pnpm check:skills` 增加 manifest 一致性门禁，并为同族 reviewer 场景增加 identity handshake gate。

**Architecture:** B4 采用“shell 看板 + Node lint 子检查器”模式：保留 `check-skills-mount.sh` 输出结构，新增 `check-skills-manifest.mjs` 做结构化校验并返回阻塞失败。B6 采用“路由标记 + Prompt 明确要求 + 响应校验”三段式：同族 review 请求被识别后，注入握手要求并在响应端验证，不满足即标记 review 无效。

**Tech Stack:** Bash, Node.js (`node:test`), TypeScript (packages/api), YAML parsing (`yaml` via `packages/api` dependency)
