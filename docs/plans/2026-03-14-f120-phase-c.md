# F120 Phase C: Auto-Open Browser + html_widget Rich Block — Implementation Plan

**Feature:** F120 — `docs/features/F120-hub-embedded-browser.md`
**Goal:** 猫能主动打开浏览器面板（不需用户点 toast），且能在聊天中内联渲染 HTML/JS 可视化组件
**Acceptance Criteria:**
- AC-C1: 猫可通过 API 触发 `preview:auto-open`，前端自动打开 browser panel（无需用户点击 toast）
- AC-C2: 新增 `html_widget` rich block，猫发送的 HTML/JS 代码在聊天中以 sandboxed iframe 内联渲染
**Architecture:**
- C1: 新增 `POST /api/preview/auto-open` → emit `preview:auto-open` socket 事件 → 前端监听后直接 setViewMode('browser')
- C2: shared 新增 `RichHtmlWidgetBlock` 类型 → web 新增 `HtmlWidgetBlock` 组件用 `srcdoc` iframe 渲染
**Tech Stack:** TypeScript, Fastify, Socket.IO, React, iframe srcdoc
**前端验证:** Yes — html_widget 需 Playwright/Chrome 实测 iframe 沙箱隔离

### Step 1: Create HtmlWidgetBlock component

```tsx
// packages/web/src/components/rich/HtmlWidgetBlock.tsx
'use client';

import type { RichHtmlWidgetBlock } from '@/stores/chat-types';

export function HtmlWidgetBlock({ block }: { block: RichHtmlWidgetBlock }) {
  const height = block.height ?? 300;

  return (
    <div className="rounded-lg border border-gray-200 dark:border-gray-700 overflow-hidden">
      {block.title && (
        <div className="px-3 py-1.5 text-xs font-medium text-gray-600 dark:text-gray-400 bg-gray-50 dark:bg-gray-800 border-b border-gray-200 dark:border-gray-700">
          {block.title}
        </div>
      )}
      <iframe
        srcDoc={block.html}
        sandbox="allow-scripts"
        title={block.title ?? 'Interactive Widget'}
        style={{ width: '100%', height: `${height}px`, border: 'none' }}
        referrerPolicy="no-referrer"
      />
    </div>
  );
}
```

Key security decisions:
- `sandbox="allow-scripts"` — allows JS execution but **NO** `allow-same-origin` (cannot access Hub storage)
- `referrerPolicy="no-referrer"` — no leaking Hub URL
- `srcdoc` — inline HTML, no network request to serve content

### Step 1: Write rendering test

```tsx
import { render, screen } from '@testing-library/react';
import { describe, it, expect } from 'vitest';
import { HtmlWidgetBlock } from '../HtmlWidgetBlock';

describe('HtmlWidgetBlock', () => {
  it('renders iframe with srcdoc and sandbox', () => {
    const block = {
      id: 'w1',
      kind: 'html_widget' as const,
      v: 1 as const,
      html: '<h1>Hello</h1>',
      title: 'Test Widget',
    };
    render(<HtmlWidgetBlock block={block} />);
    const iframe = screen.getByTitle('Test Widget');
    expect(iframe).toBeInTheDocument();
    expect(iframe.getAttribute('sandbox')).toBe('allow-scripts');
    expect(iframe.getAttribute('srcdoc')).toBe('<h1>Hello</h1>');
    expect(iframe.getAttribute('referrerpolicy')).toBe('no-referrer');
  });

  it('uses default height of 300px', () => {
    const block = {
      id: 'w2',
      kind: 'html_widget' as const,
      v: 1 as const,
      html: '<p>Chart</p>',
    };
    render(<HtmlWidgetBlock block={block} />);
    const iframe = screen.getByTitle('Interactive Widget');
    expect(iframe.style.height).toBe('300px');
  });

  it('uses custom height when specified', () => {
    const block = {
      id: 'w3',
      kind: 'html_widget' as const,
      v: 1 as const,
      html: '<p>Tall</p>',
      height: 500,
      title: 'Tall Widget',
    };
    render(<HtmlWidgetBlock block={block} />);
    const iframe = screen.getByTitle('Tall Widget');
    expect(iframe.style.height).toBe('500px');
  });

  it('does NOT include allow-same-origin in sandbox', () => {
    const block = {
      id: 'w4',
      kind: 'html_widget' as const,
      v: 1 as const,
      html: '<script>alert(1)</script>',
    };
    render(<HtmlWidgetBlock block={block} />);
    const iframe = screen.getByTitle('Interactive Widget');
    expect(iframe.getAttribute('sandbox')).not.toContain('allow-same-origin');
  });
});
```
