# F120 Phase C2: Console + Screenshot + Multi-Tab + Socket Scoping — Implementation Plan

**Feature:** F120 — `docs/features/F120-hub-embedded-browser.md`
**Goal:** 浏览器面板完整增强：console 输出查看、一键截图附到聊天、多 tab 浏览、socket 事件定向发送
**Acceptance Criteria:**
- AC-C3: browser panel 下方可查看页面的 console 输出
- AC-C4: 一键截图 browser panel 并附到聊天消息
- AC-C5: 支持同时打开多个 localhost tab
- 优化: preview:auto-open / port-discovered 从 io.emit 收敛到 worktree room 定向发送
**Architecture:**
- Gateway 注入 bridge script（console patch + screenshot capture）→ iframe postMessage → BrowserPanel 接收
- 截图通过 gateway 注入脚本在 iframe 内用 SVG foreignObject + canvas 捕获，postMessage 回传 data URL
- 多 tab：BrowserPanel 内部管理 tab 数组，每 tab 独立 port/path/iframe
- Socket scoping：WorkspacePanel socket 加入 `worktree:${id}` room，后端定向 emit
**Tech Stack:** TypeScript, Fastify, Socket.IO rooms, React, postMessage API, Canvas API
**前端验证:** Yes — console capture + screenshot + multi-tab 均需 Chrome 实测

## Task 1: Gateway Bridge Script Injection

**Files:**
- Create: `packages/api/src/domains/preview/bridge-script.ts`
- Modify: `packages/api/src/domains/preview/preview-gateway.ts:55-72` (proxyRes handler)
- Test: `packages/api/test/domains/preview/bridge-script.test.js`

**What:** Inject a small inline `<script>` into HTML responses that patches `console.*` methods and exposes a screenshot handler, all communicating via `postMessage`.

**Step 1: Write bridge script module**

`bridge-script.ts` exports a constant string containing the inline JS:
- Patches `console.log/warn/error/info` → original call + `parent.postMessage({ type:'console', level, args, timestamp })`
- Listens for `{ type:'screenshot-request', source:'cat-cafe-preview' }` → captures via SVG foreignObject + canvas → `parent.postMessage({ type:'screenshot-result', dataUrl })`
- Self-identifying: sets `window.__catCafeBridge = true` to prevent double-injection

**Step 2: Write test for bridge script**

Test: module exports a non-empty string, contains `postMessage`, contains `console`, contains `screenshot`.

**Step 3: Modify gateway proxyRes to inject script**

In `preview-gateway.ts`, after the existing header stripping in `proxyRes`:
- Check `content-type` header for `text/html`
- If HTML: use `zlib` to handle gzip/deflate, intercept response body, inject `<script>` before `</head>` or at start of `<body>`
- If not HTML: pass through unchanged

Key: need to handle compressed responses (dev servers often gzip). Use `proxyRes` to modify response — `http-proxy` supports `selfHandleResponse` option.

**Step 4: Write test for injection into HTML responses**

Test: send HTML through gateway, verify `<script>` is injected. Send CSS/JS through gateway, verify no injection.

**Step 5: Commit**

```bash
git commit -m "feat(F120-C3): gateway bridge script injection for console + screenshot"
```

## Task 5: Socket Room Scoping

**Files:**
- Modify: `packages/api/src/index.ts:408-412,617-624` (emit via room instead of global)
- Modify: `packages/web/src/components/WorkspacePanel.tsx:198-231` (socket joins worktree room)
- Modify: `packages/api/src/routes/preview.ts` (socketEmit signature includes room target)
- Test: `packages/api/test/domains/preview/preview-routes.test.js`

**What:** Replace `io.emit()` with room-scoped `io.to('worktree:${id}').emit()`. Frontend socket joins worktree room on connect.

**Step 1: Frontend — join worktree room**

In WorkspacePanel socket setup (line 204):
```typescript
const socket = io(...);
if (worktreeId) {
  socket.emit('join_room', `worktree:${worktreeId}`);
} else {
  socket.emit('join_room', 'preview:global');
}
```

**Step 2: Backend — room-scoped emit**

Change `socketEmit` callback in index.ts:
```typescript
socketEmit: (event, data) => {
  const worktreeId = (data as any)?.worktreeId;
  const room = worktreeId ? `worktree:${worktreeId}` : 'preview:global';
  socketManager?.broadcastToRoom(room, event, data);
},
```

Change port-discovered emit similarly:
```typescript
portDiscovery.onDiscovered((port) => {
  const room = port.worktreeId ? `worktree:${port.worktreeId}` : 'preview:global';
  socketManager?.broadcastToRoom(room, 'preview:port-discovered', port);
});
```

**Step 3: Write tests**

Test: emit with worktreeId → only goes to worktree room, not global.

**Step 4: Commit**

```bash
git commit -m "fix(F120): scope preview socket events to worktree rooms"
```
