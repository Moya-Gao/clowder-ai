# F154 Phase A — Cat Routing Personalization Implementation Plan

**Feature:** F154 — `docs/features/F154-cat-routing-personalization.md`
**Goal:** Connector 用户可以 `/focus <猫名>` 设置首选猫、`/ask <猫名> <消息>` 单次定向、管理员可通过 Hub API 配置全局默认猫
**Acceptance Criteria:**
- AC-A1: `/focus opus` 设置 thread preferredCats，`/focus` 查看，`/focus clear` 清除
- AC-A2: `/ask opus 帮我看代码` 单次定向发消息给 opus，不改变 preferredCats
- AC-A3: 猫名解析使用 catRegistry aliases，不硬编码；不可路由猫返回错误
- AC-A4: `getDefaultCatId()` 支持运行时配置覆盖 `breeds[0]`；修改需 owner 权限
- AC-A5: 路由优先级链精确语义不变（preferredCats = candidate scope）
- AC-A6: `/focus` `/ask` 有单元测试覆盖
- AC-A7: 猫名解析冲突时返回候选列表并拒绝执行；exact alias > partial match
**Architecture:** normalizeCatId 在 shared 包（两端复用）→ CORE_COMMANDS 注册 → ConnectorCommandLayer 处理 → ConnectorRouter /ask 转发（复用 /thread forward 模式）→ getDefaultCatId 运行时覆盖
**Tech Stack:** TypeScript, node:test, Fastify routes
**前端验证:** No — Phase A 纯 connector + API，Phase B 才涉及前端

**NOT building:** Hub UI（Phase B）| connector `/config set`（KD-7 deferred）| multi-cat `/focus`（KD-5: v1 single only）

**砚砚硬检查项（Design Gate）:**
1. A3 必须保持 Hub API only + owner 403（Phase A 不引入 connector 配置入口）
2. A7 必须有测试：解析冲突拒绝执行 + 返回候选列表 + exact alias 优先

```typescript
// packages/shared/src/registry/normalize-cat-id.ts
import type { CatId } from '../types/ids.js';
import { createCatId } from '../types/ids.js';
import { catRegistry } from './CatRegistry.js';

export type NormalizeCatResult =
  | { ok: true; catId: CatId }
  | { ok: false; reason: 'not-found'; input: string }
  | { ok: false; reason: 'ambiguous'; input: string; candidates: string[] };

/**
 * Resolve user input (cat name / alias / catId) to a registered catId.
 *
 * Priority: exact catId → exact alias (strip @, case-insensitive) → partial displayName/nickname.
 * Ambiguous partial match → reject with candidate list (KD-8, AC-A7).
 */
export function normalizeCatId(input: string): NormalizeCatResult {
  const cleaned = input.startsWith('@') ? input.slice(1) : input;
  const lower = cleaned.toLowerCase();

  // 1. Exact catId match
  if (catRegistry.has(lower)) {
    return { ok: true, catId: createCatId(lower) };
  }

  // 2. Exact alias match (mentionPatterns without @, case-insensitive)
  const allConfigs = catRegistry.getAllConfigs();
  for (const [catId, config] of Object.entries(allConfigs)) {
    for (const pattern of config.mentionPatterns) {
      const stripped = pattern.startsWith('@') ? pattern.slice(1) : pattern;
      if (stripped.toLowerCase() === lower) {
        return { ok: true, catId: createCatId(catId) };
      }
    }
  }

  // 3. Partial displayName / nickname match
  const partials: string[] = [];
  for (const [catId, config] of Object.entries(allConfigs)) {
    if (
      config.displayName.toLowerCase().includes(lower) ||
      (config.nickname && config.nickname.toLowerCase().includes(lower))
    ) {
      partials.push(catId);
    }
  }

  if (partials.length === 1) {
    return { ok: true, catId: createCatId(partials[0]) };
  }
  if (partials.length > 1) {
    return { ok: false, reason: 'ambiguous', input: cleaned, candidates: partials };
  }

  return { ok: false, reason: 'not-found', input: cleaned };
}
```

```typescript
private async handleAsk(
  connectorId: string, externalChatId: string, userId: string, args: string,
): Promise<CommandResult> {
  const parts = args.trim().split(/\s+/);
  if (parts.length < 2 || !parts[0]) {
    return { kind: 'ask', response: '用法：/ask <猫名> <消息>' };
  }
  const [catInput, ...msgParts] = parts;
  const message = msgParts.join(' ');
  const resolved = normalizeCatId(catInput);
  if (!resolved.ok) {
    // format error message based on reason
    return { kind: 'ask', response: formatNormalizeError(resolved) };
  }
  return {
    kind: 'ask',
    response: `🎯 已定向发送给 ${resolved.catId}`,
    forwardContent: message,
    targetCatId: String(resolved.catId),
  };
}
```

```typescript
app.put('/api/config/default-cat', async (request, reply) => {
  const operator = resolveOperator(request.headers['x-cat-cafe-user']);
  const ownerId = process.env.DEFAULT_OWNER_USER_ID?.trim();
  if (!ownerId) {
    reply.status(403);
    return { error: 'DEFAULT_OWNER_USER_ID not configured' };
  }
  if (operator !== ownerId) {
    reply.status(403);
    return { error: 'Only owner can modify global default cat' };
  }
  const { catId } = request.body as { catId: string };
  if (!catRegistry.has(catId)) {
    reply.status(400);
    return { error: 'Unknown cat ID' };
  }
  setRuntimeDefaultCatId(createCatId(catId));
  return { catId: getDefaultCatId() };
});
```
