# F162 Demo Script — WXG 面试 Golden Chain Showcase

> AC-A7: 60 秒完成展示 | AC-A8: 备录视频 fallback
> 面试日期: 2026-04-17

## Pre-flight Checklist

| 检查项 | 命令/方式 | 预期 |
|--------|-----------|------|
| Runtime 在线 | `curl -sf http://localhost:3002/health` | `{"status":"ok"}` |
| 企微群连接 | Hub → 企微群 thread → 发一条测试消息 | 企微群收到 |
| wecom-cli 可用 | `wecom-cli --version` | 版本号 |
| wecom-cli 凭证 | `wecom-cli contact get_userlist '{}'` | errcode=0 |
| 网络正常 | 企微文档/会议 API 可达 | 无超时 |

## Demo Flow (Target: 60s)

### Phase 1: 开场白 (10s)

**铲屎官对面试官说：**

> "我们做了一个 AI 猫猫系统，猫猫可以直接操作企业微信。我现在在企微群里说一句话，猫猫会自动创建文档、表格、待办、会议四种企业资源。"

### Phase 2: 触发 (5s)

**铲屎官在企微群输入：**

```
帮我把今天的面试讨论整理成技术评估报告，拆成两个任务给 YuJiaRong：
1. 整理 Agent 架构要点
2. 准备 follow-up 方案
约明天下午两点技术评审。
```

### Phase 3: 等待猫猫处理 (15-20s)

**可选操作**（如果面试官有兴趣）：
- 切到 Hub 页面，展示猫猫的思考过程（intent parsing → callback 调用 → 结果组合）
- 或者继续在企微群等待回复

**猫猫内部流程**：
1. F088 Transport Plane 接收消息 → 路由到猫猫
2. enterprise-workflow skill 触发 → 猫猫解析意图
3. 猫猫调 `POST /api/callbacks/wecom-action` (golden_chain)
4. WeComActionService 串行执行：create_doc → create_smart_table → create_todo x2 → create_meeting
5. 结果回贴

### Phase 4: 结果展示 (10s)

**猫猫回贴到企微群（预期格式）：**

```
已完成工作流创建：

📄 文档: 技术评估报告 — https://doc.weixin.qq.com/xxx
📊 表格: 技术评估任务表 — https://doc.weixin.qq.com/yyy
✅ 待办: 2 条已分发（YuJiaRong）
🎥 会议: 技术评审 — https://meeting.tencent.com/dm/zzz
```

### Phase 5: 实证验证 (15s)

**铲屎官/面试官在企微 App 中验证：**
1. 打开"文档" → 看到新建的技术评估报告（含 Markdown 内容）
2. 打开"文档" → 看到智能表格（任务 x 负责人 x 状态）
3. 打开"待办" → 看到 2 条待办（分配给 YuJiaRong）
4. 打开"日程" → 看到明天下午 2 点的会议邀请

## Fallback Plan

### 网络问题
- 切换到手机热点
- 如果仍然不行 → 播放预录视频（AC-A8）

### 猫猫响应慢（>30s）
- 解释："企微 API 有时延迟，我们来看预录的完整流程"
- 播放预录视频

### 猫猫报错
- 在 Hub 中展示错误信息，解释是 API 限制
- 播放预录视频
- 可以补充展示 E2E 测试通过的截图作为代码能力证明

## Talking Points（面试官可能追问）

| 问题 | 回答要点 |
|------|----------|
| 架构是什么？ | ADR-029: ActionService + CliExecutor + callback route。不建 MCP server，保审计链完整 |
| 为什么不直接调 API？ | wecom-cli 是企微官方工具，带认证管理。CLI 模式让 agent 能力声明式扩展 |
| 安全性怎么保证？ | callback route 有 Zod schema 校验 + invocation credentials 验证 + audit log |
| 能扩展到飞书吗？ | Phase B 已规划，ActionService 模式可复用 |
| 智能表格怎么处理的？ | 5-step flow: 建表 → 取默认子表 → 重命名默认字段 → 加字段 → 加记录 |
