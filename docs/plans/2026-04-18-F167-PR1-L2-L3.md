# F167 PR 1: L2 Parallel @ 抑制 + L3 Designer 角色门禁

**Feature:** F167 — `docs/features/F167-a2a-chain-quality.md`
**Goal:** 用 stateless pattern 守卫消灭两类 malformed handoff：parallel 模式 @句柄（噪音）和 designer 接技术任务（角色错配）。
**Acceptance Criteria:** AC-A5, AC-A6, AC-A7, AC-A8（不回退），AC-A9 部分（L2 + L3 新测）。
**Architecture:** L2 在 `route-parallel.ts` 直接 suppress mentions + followupMentions；新建 `role-gate.ts` 小模块在 AgentRouter 路由前拦截。复用 `AFTER_HANDOFF_RE` 模式思路扩展"技术动作"关键词。
**Tech Stack:** Node test（node --test），TypeScript，Biome。
**前端验证:** No（纯 backend）。

---

## Finish Line

**B 定义**：parallel 模式 @句柄的消息不产生 followup 提示；任何猫 @ designer 猫做 coding/fix/test/merge 动作时 fail-closed 报错而不 route。

**NOT Building**：
- L0 typed handoff 路由可见性（Design Constraint，独立工作）
- L1 乒乓球熔断（PR 2）
- L3 通用能力矩阵（MVP only — 仅 designer + 技术动作）
- 动态配置角色黑名单（hardcode 即可，YAGNI）

**Terminal schema**（最终系统留痕）：
1. `message.mentions[i].suppressedInParallel: boolean`（parallel 模式下 true）— 可观测性保留
2. `role-gate.ts` 导出 `checkRoleCompat(targetCatId, messageText) → { allowed: boolean, reason?: string }`
3. AgentRouter 路由前调用 role-gate；fail → emit `system_info` `{ type: 'a2a_role_rejected', ... }`，不进入 routeSerial/routeParallel

```typescript
// packages/api/src/domains/cats/services/agents/routing/role-gate.ts
import type { CatId } from '@cat-cafe/shared';
import { catRegistry } from '@cat-cafe/shared';

const TECHNICAL_ACTION_RE =
  /\b(?:coding|code|fix|test|merge|写代码|改代码|测试|合入|修\s*bug)\b/i;

export interface RoleCompatResult {
  allowed: boolean;
  reason?: string;
}

/**
 * L3 role gate MVP: designer 角色不接受 coding/fix/test/merge 动作。
 */
export function checkRoleCompat(
  targetCatId: CatId | string,
  messageText: string,
): RoleCompatResult {
  const config = catRegistry.getConfig(targetCatId);
  if (!config) return { allowed: true };
  const roles = config.roles ?? [];
  if (!roles.includes('designer')) return { allowed: true };
  if (!TECHNICAL_ACTION_RE.test(messageText)) return { allowed: true };
  return {
    allowed: false,
    reason: `⛔ @${targetCatId} 不接受 coding/fix/test/merge 任务（角色=designer）`,
  };
}
```
