# F167 PR 2: L1 乒乓球熔断 — WorklistRegistry streak 追踪

**Feature:** F167 — `docs/features/F167-a2a-chain-quality.md`
**Goal:** 在 A2A canonical enqueue 点追踪"连续 same-pair streak"，streak=2 警告、streak=4 熔断，覆盖 serial + callback 双路径。
**Acceptance Criteria:** AC-A1, AC-A2, AC-A3, AC-A4, AC-A9 L1 部分。
**Architecture:** WorklistEntry 加 `streakPair: {from, to, count}` 字段；`pushToWorklist()` 返回新字段 `{warnPingPong, blockPingPong}`；`callback-a2a-trigger.ts` 的 `enqueueA2ATargets()` 在 fallback 路径也查 streak；user 消息 / 第三只猫插入自动 reset。
**Tech Stack:** Node test（node --test），TypeScript，Biome。
**前端验证:** No（纯 backend）。

---

## Finish Line

**B 定义**：连续 same-pair streak=2 注入"你们已连续弹 2 轮"警告；streak=4 熔断不再 enqueue 并 emit `a2a_pingpong_terminated` 系统消息；链中第三只猫或 user 消息进来立即 reset 到 0。

**NOT Building**：
- 跨 thread streak 共享（单 thread 内即可）
- streak 持久化到 Redis（in-memory WorklistEntry 即可）
- Phase B 的"虚空传球"检测（独立项）
- 阈值可配置（2/4 hardcode，YAGNI）

**Terminal schema**（最终系统留痕）：

```typescript
// WorklistRegistry.ts — WorklistEntry 新增
interface WorklistEntry {
  // ... existing fields ...
  streakPair?: { from: CatId; to: CatId; count: number };
}

// PushResult 新增
interface PushResult {
  added: CatId[];
  reason?: string;
  warnPingPong?: boolean;   // streak >= 2 && < 4 → 下游 prompt 注入警告
  blockPingPong?: boolean;  // streak >= 4 → 不 enqueue，emit 终止消息
}
```
