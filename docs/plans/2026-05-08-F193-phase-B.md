**Step 3.3: 实现 hydrate helper**

```typescript
async function hydrateCrossThreadReplyHint(
  triggerMessageId: string | undefined,
  messageStore: MessageStore,
): Promise<{ sourceThreadId: string; senderCatId: CatId } | undefined> {
  if (!triggerMessageId) return undefined;
  const msg = await messageStore.getById(triggerMessageId);
  if (!msg?.extra?.crossPost?.sourceThreadId) return undefined;
  return {
    sourceThreadId: msg.extra.crossPost.sourceThreadId,
    senderCatId: msg.catId,
  };
}
```

注：用 `getById` 还是 `get(threadId, messageId)`？看 MessageStore 接口决定——可能要 `messageStore.getMessageById(triggerMessageId)`。

**Step 3.4: 接入 route-serial**
