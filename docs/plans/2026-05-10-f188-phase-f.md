# F188 Phase F: Agent-facing Memory Tools — Implementation Plan

**Feature:** F188 — `docs/features/F188-library-stewardship.md`
**Goal:** 把 Phase C 已实现的 graph 能力封装成 MCP tool + 加 time-based browsing tool + harness 配套同步 + cross-cutting event log——让"能力 ≠ 猫能用"的 gap 收口。
**Acceptance Criteria:** AC-F1, AC-F2, AC-F3, AC-F4, AC-F5, AC-F6, AC-F7, AC-F8, AC-F9, AC-F10, AC-F11 + `## Eval / Tracking Contract` 4 项验收
**Architecture cell:** memory + harness（扩展已有，no new cells）
**Map delta:** none — 扩展现有 cells（memory：复用 GraphResolver，加 list_recent metadata browse；harness：新增 memory-navigation skill 注册到 manifest；telemetry：扩 ToolUsageCounter 旁支为 event log）
**Map delta why:** event log 跨 phase 但实现归属 F188 owner；MCP wrapper 复用现有 resolver，无新 store/queue/router
**Architecture:** 2 个 MCP tool（graph_resolve 复用 GraphResolver；list_recent 用 SQL `ORDER BY updatedAt DESC` 跨 evidence_docs + threads metadata）+ append-only event log（threadId-scoped sequence）+ skill_loaded 事件 + payload nudge in search_evidence + multi-canonical hook sync 脚本 + Dashboard panel
**Tech Stack:** TypeScript, better-sqlite3, Redis (event log persistence), React (Dashboard panel), MCP server protocol
**前端验证:** Yes — AC-F9 Memory Health Dashboard 新指标 panel 需浏览器截图验证

export type ToolStatus = 'success' | 'low_hit' | 'no_match' | 'error';

  invocationId: string;
  sessionId: string;
  threadId: string;
  catId: string;
  toolName: string;
  timestamp: number;
  turnIndex: number;
  status: ToolStatus;
}

export interface SearchEvidenceSummary {
  resultCount: number;
  topScore: number | null;
  nudgeEmitted: boolean;
  nudgeFollowed?: boolean;  // 后续 turn 是否试 graph_resolve/list_recent
}

export interface GraphResolveSummary {
  candidateCount: number;
  rankedCandidateAnchors: string[];  // 砚砚 P3：按 rank 顺序，selectedCandidateIndex 可重建
  selectedCandidateIndex?: number;
  selectedAnchor?: string;
}

export interface ListRecentSummary {
  resultCount: number;
  scope: string;
  since: string;
}

export interface SkillLoadedEvent {
  invocationId: string;
  sessionId: string;
  skillId: string;
  loadTrigger: 'mention_match' | 'keyword_match' | 'explicit_call';
  timestamp: number;
}
