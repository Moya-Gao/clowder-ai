## Straight-Line Check

- **B**：用户打开 Console → 「规则与 SOP」面板 → 看到 3 个 Section（共享规则 / 模型指南 / **L0 系统提示词**）。L0 Section 含 1 张 template card + N 张 per-cat compiled card（N = runtime available 猫）+ 1 行修改路径明示（AC-F4）。点 card → modal 显 `<pre>` 内容。无编辑控件。
- **终态 schema**：
  ```ts
  // /api/rules 增量
  interface L0PromptsBlock {
    template: { path: string; content: string; exists: boolean };
    compiledByCat: Array<{
      catId: string;            // "opus-47" | "codex" | "gpt52" | "gemini" ...
      displayName: string;      // "布偶猫 Opus 4.7" / "缅因猫 GPT-5.5(codex)" ...
      compiled: string;         // compileL0ViaSubprocess 输出；error 时 ""
      error: string | null;     // null = 成功；非空 = compile 报错文本（不抛 5xx，per-cat 容错）
    }>;
    customization: { templatePath: string; compileScript: string; verifyCommand: string };
  }
  // GET /api/rules → { sharedRules, providerGuides, l0Prompts: L0PromptsBlock }
  ```
- **每步过三问**：
  - 后端字段扩展 = 终态 schema，extend-only。
  - 前端 3rd Section 复用现有 card/modal，extend-only。
  - 真二进制 sanity = Feature Gate 不可省（每只 cat compileL0 真返回非空）。
  - 任一步删了：用户看不到 L0 / 不知道改哪 / 用户体验破碎，AC-F2/F3/F4 不满足。
- **NOT building**：
  - 不做编辑器（AC-F5 DEFER）
  - 不做 diff template-vs-compiled 视图（YAGNI；铲屎官未提，加重 UI 负担）
  - 不做 live recompile / file watch（一次性 fetch on panel open，refresh = 页面 reload）
  - 不做 syntax highlight（与现有 RulePreviewModal `<pre whitespace-pre-wrap>` 一致）
  - 不加新 SettingsContent case（L0 viewer 进 RulesPromptsContent 同一 Section pattern）
  - 不缓存 compiled L0（每次 GET /api/rules 重新 compile——template 改动即时生效；4 cats 并行 ~500ms 可接受）

## Open Questions

### 技术 OQ（实施中自决）

1. **available 猫列表 source**：cat-config-loader 暴露的 helper 还是直接 `getRuntimeAvailableCats()`——实施 Task 1.3 时 grep 定位。
2. **compileL0 timeout / 单只猫失败**：单只 compile 失败不阻其他 → per-cat try/catch + `error` 字段。整个 endpoint 整体 timeout 不加（subprocess 自身会因 spawn 失败抛错，已 fail-closed）。
3. **compiled L0 长度**：实测 cc compiled L0 几 K 字符，modal `<pre>` 已用 `max-h-[50vh] overflow-auto`，UI 不会爆。
4. **per-cat card displayName 数据源**：runtime cat catalog 自带 displayName（同 SystemPromptBuilder roster 表）。复用，不另维护映射。
