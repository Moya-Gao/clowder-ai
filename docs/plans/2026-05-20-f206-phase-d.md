# F206 Phase D: #723 视觉残留收敛 — Implementation Plan

**Feature:** F206 — `docs/features/F206-settings-ui-convergence.md`
**Goal:** 消除 Phase A-C 后的视觉碎片化残留：线条色值统一、Memory/Signals 语义 token 迁移、Settings primitives 边框 KD-4 对齐、Mission Hub hex 清理
**Acceptance Criteria:**
- AC-D1: 全局 border 走统一淡 token（`--console-border-soft` 级别），0 处自造 raw hex 边框
- AC-D2: Memory/Signals 页面背景/边框改 semantic token，无 raw hex/gradient
- AC-D3: Settings primitives 边框对齐 KD-4（内容卡片无四周包边）

- AC-D5: Mission Hub hardcoded hex 改 semantic token
- AC-D6: `pnpm test` + `pnpm check` 全绿
- AC-D7: 关键页面 before/after 截图验证
**Architecture cell:** none — 纯视觉/presentational 改动，无接口/数据流变化
**Map delta:** none
**Map delta why:** 不涉及架构 cell 的职责边界或数据流变化
**Architecture:** 将 raw hex colors、hardcoded borders、arbitrary font sizes 迁移到已有的 semantic token 系统（`--console-*`、`cafe-*`、`conn-*`）。Settings primitives 移除四周包边改用背景/间距分层。
**Tech Stack:** Tailwind CSS、CSS custom properties（console-shell.css / theme-tokens.css）
**前端验证:** Yes — 涉及 12+ 页面视觉变化，reviewer 必须浏览器实测

**Step 4.5: Status bar + StatusDot (lines 562-566, 685-692)**

```tsx
// Line 562 — status bar
<div className="flex items-center gap-5 border-b border-[var(--console-border-soft)] bg-[var(--console-card-bg)] px-6 py-2.5">

// Lines 563-565 — use semantic status colors
<StatusDot color="bg-[var(--semantic-warning-bg)]" label={`${pendingCount} 待审批`} textColor="text-[var(--semantic-warning-text)]" />
<StatusDot color="bg-[var(--semantic-info-bg)]" label={`${activeCount} 执行中`} textColor="text-[var(--semantic-info-text)]" />
<StatusDot color="bg-[var(--semantic-success-bg)]" label={`${doneCount} 已完成`} textColor="text-[var(--semantic-success-text)]" />
```

Wait — StatusDot uses `color` as a bg class for a 2x2 dot. The semantic `*-bg` tokens are pastel backgrounds, not dot colors. For dots we need saturated colors. Let me use the text variants which are saturated:

```tsx
<StatusDot color="bg-amber-500" label={`${pendingCount} 待审批`} textColor="text-[var(--semantic-warning-text)]" />
<StatusDot color="bg-blue-500" label={`${activeCount} 执行中`} textColor="text-[var(--semantic-info-text)]" />
<StatusDot color="bg-green-500" label={`${doneCount} 已完成`} textColor="text-[var(--semantic-success-text)]" />
```

Actually amber/blue/green are standard Tailwind palette colors that are fine for status indicators — these are tiny dots, not surfaces. The text colors use semantic tokens.
