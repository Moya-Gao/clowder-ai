# F207 Finance B0 Implementation Plan

**Feature:** F207 — `docs/features/F207-personal-finance-infra.md`  
**Goal:** Create the `cat-cafe-finance` local fact layer skeleton so cats query normalized, auditable finance facts instead of raw providers.  
**Acceptance Criteria:** AC-B4, AC-B5, AC-B6, AC-B7, AC-N1, AC-N2, AC-N3 for the B0 slice.  
**Architecture cell:** finance-data  
**Map delta:** new cell required  
**Map delta why:** F207 creates a new read-only external finance fact layer that does not fit Memory or Action Plane.  
**Architecture:** Add `packages/finance` as the provider orchestration package. MCP exposes only the normalized wrapper, never raw provider calls or trading operations.  
**Tech Stack:** TypeScript, Node test runner, MCP server tool registration.  
**前端验证:** No — backend/package/MCP-only.

---

## Finish Line

B0 is done when a cat can call a single read-only MCP tool and receive a `FinanceFactEnvelope` containing `source`, `asOf`, `confidence`, `sourceTier`, `snapshot_id`, `presentationHint`, and `queriesInLast7Days`.

Not building in B0:

- Hub UI, API key settings UI, reports, cron jobs, CVO approval flow.
- Full provider catalog; only ttfund and FRED adapters enter as stable-source proof.
- Any trade, buy, sell, transfer, broker, bank, or one-click execution API.

## Terminal Schema

`FinanceFactEnvelope<T>`:

- `snapshot_id`: deterministic hash of provider, query, asOf, source, and normalized data.
- `provider`: `ttfund` or `fred` in B0.
- `source`, `sourceTier`, `asOf`, `fetchedAt`, `confidence`.
- `query`: provider-neutral request metadata without credentials.
- `data`: normalized/raw provider payload depending on adapter maturity.
- `presentationHint`: `{ detailLevel, compactSummary, avoidWords }`.
- `queriesInLast7Days`: per-symbol/topic frequency count.
