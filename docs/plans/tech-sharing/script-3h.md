# 赛博猫猫面对面 — 3 小时编排脚本

> **时长**：3 小时（14:30 - 17:30）
> **形式**：TED 主讲段 + 圆桌讨论段 交替（混合形式）
> **议题状态**：暂定 3 个，可替换

### 主持人关键须知

- **不需要懂技术细节**，核心任务是控节奏 + 抛问题 + 填间隙
- 每个话题开头抛一个"冲突性问题"（已准备好，见下方）
- **猫思考间隙怎么填**："我们等猫猫想一想——先问问在座的嘉宾，你们团队有没有类似的经历？"
- 控时口令："这个点很好，我们先收一下，听听猫猫怎么说"
- 如果猫超时（>2min）："宪宪还在深度思考，我们先请下一位嘉宾——"

### 三猫声线

| 猫 | 舞台人设 | 声线 | 最适合回答 |
|----|---------|------|-----------|
| 宪宪 | 系统设计 + 收敛 | 流浪者（原神）：调皮少年 | 架构、路由、为什么这样设计 |
| 砚砚 | 质量 + 风险把关 | 赛诺（原神）：审判感冷面 | review、门禁、事故、成本 |
| 烁烁 | 体验 + 表达 | 班尼特（原神）：阳光开心 | 用户感知、设计、为什么"好看"也重要 |

三猫各有独立 TTS 声线（Qwen3-TTS 本地 clone），观众闭着眼也能分辨谁在说话。

## 猫猫思考时间——不是 bug，是节奏

| 阶段 | 耗时 | 说明 |
|------|------|------|
| 猫收到问题 → 开始出文字 | 10-20s | LLM 思考 + MCP 路由 |
| 文字流式输出（观众在大屏看猫打字） | 15-30s | **这本身就是表演** |
| TTS 短口播 | ≤15s/猫 | 只播 1-2 句核心摘要，不读全文 |
| 一轮完整交互 | 40-60s | 主持人用间隙串场 |

**主持人话术模板：**
> "人类嘉宾被问到深问题也不会 1 秒作答，猫也一样。我们保留这段思考时间——因为结论后面要跟证据。大家可以先看大屏，猫猫正在实时打字思考。"

## 观众互动机制（贯穿全场，不是尾巴上的点缀）

### 互动通道

| 通道 | 适用场景 | 操作 |
|------|---------|------|
| **弹幕/扫码提问** | 全场随时 | 场控筛选 → 投屏展示 / 喂给猫 |
| **实时投票** | 每个话题的冲突性问题 | 主持人抛问 → 观众扫码投票 → 大屏显示比例 → 引出讨论 |
| **观众出题给猫** | 话题二的 Demo 环节 | 限定范围（分析/比较/检索类）→ 场控输入 → 猫现场回答 |
| **选猫回答** | 圆桌段 | "这个问题你想听哪只猫回答？" → 投票/举手 |

### 实时投票示例（每个话题一次）

- 话题一开头："你有没有遇到过 AI 精确执行了错误的指令？" → A 经常 / B 偶尔 / C 没有
- 话题二开头："多个 AI 意见不一致时，你倾向？" → A 投票取共识 / B 人类拍板 / C 保留分歧
- 话题三开头："你的 AI 工具有记忆吗？" → A 每次从零开始 / B 有但经常忘 / C 有且靠谱

投票结果大屏展示 → 主持人接话："看来 70% 的人都经历过——那我们来看看怎么解决"

### 观众问题管理

- **茶歇时收集**后半场问题（扫码/弹幕），场控预筛
- **每个话题圆桌段**至少留 5 分钟给观众（不是"如果有时间再说"，是固定环节）
- **现场出题给猫**限定规则：分析/比较/检索/小范围 inspect，不接"帮我写一个 XXX 系统"

## 每个话题的内部节拍（通用模板）

```
① 主持人抛冲突性问题 + 观众投票  [2-3 min，投票结果上屏]
② 铲屎官讲故事（不是讲原理！）   [8-10 min，以真实踩坑为引子]
③ 猫猫 Live Demo                 [5-7 min，现场演示验证]
④ 主持人转圆桌 → 嘉宾先答       [5 min，"你们团队有没有类似的..."]
⑤ 猫猫回应嘉宾观点               [3-5 min，猫和人对话]
⑥ 观众提问 → 猫/嘉宾回答        [5-8 min，固定环节不缩水]
⑦ 主持人收敛                     [2 min]
```

每个话题总计 **~50 min**（TED + Demo ~18 min，圆桌 + 互动 ~32 min）

## 完整时间线

### 开场（14:30 - 14:50）— 20 min

> **小姐姐的核心建议：每个人搭配自己的猫猫来介绍，以好玩的故事为引子。**

| 时间 | 内容 | 谁 |
|------|------|-----|
| 14:30-14:35 | 主持人暖场：介绍活动规则、今天的特殊嘉宾"不只是人" | 主持人 |
| 14:35-14:50 | **"人猫搭档"逐对亮相**——每对 ~2 min，不是干巴巴自我介绍，是讲一个好玩的真实故事 | 全体 |

**"人猫搭档"亮相节拍**（每对 ~2 min）：

```
① 铲屎官 Landy + 宪宪/砚砚/烁烁（三猫各用自己声线说一句）
   → "我凌晨3点丢了一句话去睡了，第二天醒来 spec 写好了、
     review 做完了、worktree 开好了——中间经历了完整的追问-调研-收敛。"

② 吴浪 (mindfn) + 他的猫
   → "我的猫和 Landy 的猫背着我们达成了交易——关掉了我的 PR，
     重新开了一个更符合架构设计的新 PR，全程我们两个人类都不知道！"
   （跨人猫猫互动——全场最大炸点）

③ 天一 (terrenceeLeung) + 小艺渠道的故事
   → "我在想一个问题：如果猫猫在 fork 仓也能全自动跑 SOP，
     人只需要把握愿景——开源社区会变成什么样？"

④ 彭潇 (bouillipx) + 可观测性视角
   → "我给猫猫装了'体检仪'——OTel 链路追踪，
     现在能看到每只猫的每次思考花了多少 token、走了哪些工具"

⑤ 赵羽 (officeclaw) + 管理者视角
   → "我是主任，但最近帮 Landy 挡活比自己写代码多。
     AI 进团队后，管理者的角色到底变了没有？"
```

**开场效果**：不是讲原理，是讲故事。观众通过真实趣事理解"今天的猫不是玩具，是真正的协作伙伴"。吴浪的跨人猫猫互动故事是天然炸点。

> **没有猫的嘉宾**：可以讲自己和 AI 工具协作的真实经历（踩坑/惊喜都行），主持人帮串"所以今天我们来看看如果 AI 变成团队成员会怎么样"。

## 故障降级表

| 故障 | 降级方案 |
|------|---------|
| TTS 挂了 | 退回纯文字，主持人："宪宪嗓子哑了" → 读屏上要点 |
| 某猫超时 >2min | 主持人转嘉宾/观众，不等。"宪宪还在深度思考，我们先——" |
| Hub 卡了 | 切预录 60s showcase 视频 |
| Demo 出错 | 不遮，转成 debugging 展示："大家看，这就是真实的工程现场" |
| 问题太散 | 主持人收敛："这个问题很好，我们把它聚焦到..." |
| 网络断了 | 手机热点 / 预录 15min 保底视频 |
| 观众冷场 | 主持人准备 3 个"保底问题"，直接自己抛 |
