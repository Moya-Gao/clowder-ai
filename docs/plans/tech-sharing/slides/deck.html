Topic 1 · 元认知鸿沟

METACOGNITION GAP
01
模型不缺能力，缺的是"知道自己能做什么"
LSP 故事：装了超强代码诊断工具，AI 完全不用。为什么？—— 不在认知路径上。

硬件层：工具是否存在？

MCP 连接 · Tool 注册 · 权限配置

连接没通 = 能力为零

软件层：元认知是否在位？

模型知道工具存在吗？
知道什么时候该用吗？
用完怎么验证结果？

看不见 = 想不到 = 不会用

解决三板斧

1. System Prompt 注入路标
2. Skill 描述优化
3. Workflow 节点自动触发

不是教它用，是让它自然想到

Build to Delete

模型进化 → 部分 harness 工程可淘汰

但：协作协议 / 记忆 / 质量闭环
这些不会随模型升级而消失
