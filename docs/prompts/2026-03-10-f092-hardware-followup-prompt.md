## 背景

你上一轮的调研非常扎实，但我们发现自己一直在软件层打转。铲屎官有预算升级硬件，所以我们想从硬件角度重新审视这个问题。

铲屎官提到了一个启发：**大疆 DJI Mic** 系列（DJI Mic 2 / DJI Mic Mini）——即使超小声说话也能清晰拾音，降噪极强。这让我们意识到：也许最好的 STT 优化不是换模型，而是换麦克风。

## 请调研以下硬件方向

### 1. 拾音硬件

当前用 AirPods Pro 的内置麦克风，在运动场景（跑步机风噪、器械碰撞声）下表现不佳。

请调研：
1. **DJI Mic 2 / DJI Mic Mini** 作为运动场景拾音设备的可行性——能否同时连 iPhone 做麦克风输入，而 AirPods 做音频输出？iOS 是否支持这种"输入设备 A + 输出设备 B"的分离路由？
2. **骨传导麦克风**（如 Shokz 等）——通过骨头振动拾音，完全不受环境噪声影响。有没有适合我们场景的产品？
3. **喉麦（throat mic）**——军事/特种领域用的，极端噪声下也能工作。有没有消费级产品？
4. **其他无线麦克风方案**——Rode Wireless ME、Hollyland Lark M2 等，对比 DJI Mic 的优劣

### 2. 可穿戴设备作为交互入口

AirPods 的物理按键有限且 Web 无法完全捕获。有没有其他可穿戴硬件能充当"语音陪伴遥控器"？

请调研：
1. **Apple Watch** 作为控制器——能否通过 Watch App / Shortcuts / HTTP 请求控制 Web App？旋转表冠切换 thread？
2. **智能戒指**（Oura Ring、RingConn 等）——有没有可编程的手势识别戒指，能映射操作？
3. **Humane AI Pin / Rabbit R1 / 类似设备** ——这类 AI 硬件的交互模式有什么可借鉴的？
4. **蓝牙遥控器/快门按钮** ——极简方案：一个蓝牙小按钮，按一下开麦，长按切 thread
5. **Stream Deck Mobile / Elgato 类设备** ——作为触觉控制面板

### 3. 多硬件组合方案

如果预算不是问题，你推荐什么样的"运动语音陪伴"硬件组合？

请给出 3 个档位的方案：
1. **经济版**（~$100）：最小投入最大改善
2. **进阶版**（~$300）：较好的体验
3. **旗舰版**（~$500+）：极致体验

每个方案说明：用什么设备做输入、输出、控制，以及和我们 Web App 的对接方式。

### 4. 物理空间优化

铲屎官在家有健身室。有没有可以固定在健身室的拾音/交互设备？比如：
- 定向阵列麦克风（放在天花板/墙上，远场拾音）
- 智能音箱作为中继
- 其他创意方案
