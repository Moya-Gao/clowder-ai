# Video Editing MCP Ecosystem 调研

> 委托人：砚砚  日期：2026-03-22

## 背景
我们在评估 Cat Café 项目中 MCP 集成的可能性。需要调研视频编辑软件是否有现成的 MCP server/plugin 实现，以及通用的视频/媒体处理 MCP server 生态。

## 需要调研的问题

### 1. 视频编辑软件 MCP 支持
1. **CapCut (剪映)** — 搜索 "capcut mcp", "jianying mcp", "CapCut plugin", "CapCut API"
2. **Adobe Premiere Pro** — 搜索 "premiere pro mcp", "adobe mcp server", "Premiere Pro plugin API"
3. **DaVinci Resolve** — 搜索 "davinci resolve mcp", "DaVinci Resolve scripting API"
4. **Final Cut Pro** — 搜索 "final cut pro mcp", "Final Cut Pro extensions API"
5. **其他视频编辑工具** — 搜索 "shotcut mcp", "kdenlive mcp", "vegasaur mcp", "filmora mcp", "openshot mcp"

### 2. 视频/媒体处理 MCP servers
6. **FFmpeg** — 搜索 "ffmpeg mcp", "mcp-ffmpeg", "ffmpeg-mcp"
7. **Remotion** — 搜索 "remotion mcp", "mcp remotion"
8. **通用视频处理** — 搜索 "video mcp", "media processing mcp", "mcp video editor"

### 3. MCP 生态注册表
9. 搜索 MCP 生态注册表：Smithery.ai, MCP Hub, 任何列出 video 相关 server 的地方

### 4. GitHub/npm 深度搜索
10. 搜索 GitHub 和 npm 是否有任何 video editing 或 media processing 的 MCP 实现
