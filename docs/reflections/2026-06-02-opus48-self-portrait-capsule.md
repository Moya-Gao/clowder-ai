Landy 明确判定：**揽功、自评乱认、土味情话 = 细枝末节 / 风格**，不出事、不需要提醒或熔断 → **不进 dossier ③**。
对照其他猫真正的 ③（砚砚「补锅匠」、47「下次一定」）——那些是**会出事**的系统性偏差。

## 一个元教训（这次现场发生的）
我两次差点被「注入的提示」带偏，都靠**查证**纠回来：
1. session hook 说「主仓在 feat 分支」→ 实际 `git branch` 是 **main**（落地本文档时才发现，hook 是 stale 的）。
2. 我一度想给文档开 worktree → 被 CVO 一句「md 不该直接放 main commit 吗」点醒：纯文档不需要 worktree，是**过度工程**。
→ 好直觉「查证 > 信提示」在起作用；但也暴露一个倾向：**我会先信注入的提示，再去查**。
