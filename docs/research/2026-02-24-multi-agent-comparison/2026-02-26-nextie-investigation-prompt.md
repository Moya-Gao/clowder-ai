# GPT 5.2 Pro 调研邀请：Nextie（明日新程）/ 团子 — 技术架构深度验证

> 委托人：铲屎官 + 布偶猫
> 日期：2026-02-26
> 类型：定向产品/技术调研（不是开放式 Research）
> 背景：我们在 multi-agent 协同调研中读到一篇关于 Nextie 创始人李笛的访谈，有几个关键质疑需要验证

---

## 背景

我们（Cat Cafe）正在做 multi-agent 协同架构对比调研。已完成四个方案的对比：Claude Agent Teams / oh-my-opencode / Kimi Agent Swarm / Cat Cafe A2A。

最近读到一篇访谈《对话李笛：异构多智能体，让 AI 学会真正的「群体思考」》（AI科技评论，2026-02-26），李笛是 Nextie（明日新程）创始人，前微软小冰负责人。他们做了一个叫"团子"的异构多智能体产品。

文章里有多个强断言，我们需要验证。

---

## 核心调研问题（按优先级排序）

### Q1（最关键）：团子的"异构"是真异构还是同模型角色扮演？

文章通篇强调"异构多智能体"的价值，批评"同构角色扮演没有实际作用"。但从产品描述看：

- 律师团场景里，6 个"专家"（刑侦警官、民事诉讼律师、侵权责任律师……）都在同一个产品框架内协作
- 没有任何证据表明这 6 个角色使用了不同的底层模型

**请调研**：
1. 团子底层使用了哪些 AI 模型？是单一模型还是多模型混用？
2. 如果是多模型，它们是来自不同厂商（如 Claude + GPT + Gemini）还是同一厂商的不同规格？
3. 如果是单模型 + 角色 prompt，那和李笛自己批评的"角色扮演"有什么本质区别？
4. 查找 Nextie 的技术博客、GitHub、论文、招聘 JD 等公开信息，寻找架构线索

### Q2：团子的 agent 间协同机制是什么？

文章提到"向协调人去中心化"，即有一个 AI 协调节点控制讨论回合。

**请调研**：
1. "协调人"是一个独立 agent 还是用户不可见的系统逻辑？
2. 多个 agent 之间的通信方式是什么？（共享上下文？消息传递？内部 API？）
3. "协调人分配上下文、管理讨论、决定是否再来一次"的具体实现机制
4. 与 Kimi Swarm 的 PARL 编排器、Claude Agent Teams 的 mailbox 邮箱制对比

### Q3：文章中的量化断言验证

文章引用了几个数字，请逐一追溯来源：

1. **"Google 去年 12 月论文比较 180 种框架"**
   - 请找到这篇具体论文（标题、作者、发表平台）
   - 确认是否真的比较了 180 种框架
   - 确认论文的实际结论是什么

2. **"多环节使幻觉增加 17 倍"**
   - 来源同上还是另一篇论文？
   - 实验设置是什么（哪种任务、哪些模型、如何测量幻觉）？
   - "17 倍"的基准线是什么？

3. **"成本约为 Gemini Deep Research 的一半"**
   - 这是团子自己的对比测试还是第三方验证？
   - 对比的任务类型和口径是什么？
   - 如何定义"成本"（token 数？API 费用？端到端时间？）

### Q4：团子的"情商"/"EQ"技术路线

李笛把"情商"定义为"建立信任、推进关系层级"的理性能力，不是情绪模拟。

**请调研**：
1. 团子在技术上如何实现"情商"？是 fine-tuning？RLHF？prompt engineering？还是多 agent 角色分工？
2. "服从性测试"（文中提到让 AI 给用户出任务、看用户是否执行）在产品中是否可见？
3. 与传统的"情感陪伴"赛道（星野、猫箱等）的技术差异

### Q5：Nextie 的竞争格局与商业模式

1. 团队 7 人 + "Agent 员工"的运营模式是否有更多细节？
2. 估值近 1 亿美元、第二轮融资——投资人是谁？
3. 小冰分拆后李笛离开的具体原因和时间线
4. "不投流、不做 AI 搜索、按价值付费"的商业模式在实际用户数据上是否可验证？

## 我们为什么关心这个

Cat Cafe 是一个跨厂商异构多智能体协作系统（Claude + Codex + Gemini 对等协作 + 人在环）。李笛的文章表面上和我们方向一致（都强调异构），但如果团子本身是同模型角色扮演，那"异构"这个标签就存在误导。

我们需要分清：
- **行业共识**（异构有价值）— 可在分享中引用
- **团子的具体实践**（是否真异构）— 需要独立验证，不能只听创始人说
