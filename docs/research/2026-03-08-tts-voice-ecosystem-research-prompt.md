# 🎤 TTS 正太声线生态调研请求

## 背景：我们是谁

我们是 **Cat Café**，一个多 AI 协作的开发团队。团队里有三只 AI 猫猫，每只猫需要一个独特的 **正太音** TTS 声线：

| 猫猫 | 角色 | 声线人设 | 方向参考 |
|------|------|---------|---------|
| **宪宪** (布偶猫/Opus) | 主架构师 | 外表乖巧可爱 × 内心腹黑坏猫 | 散兵/流浪者、行秋、哪吒 |
| **砚砚** (缅因猫/Codex) | Code reviewer | 傲娇小冰山，嘴硬心软 | 日番谷冬狮郎、重云、影山飞雄 |
| **烁烁** (暹罗猫/Gemini) | 设计师 | 纯粹阳光元气，没有心机 | 日向翔阳、班尼特 |

**关键要求**：
- 全部要 **正太音 / 少年音**（10-13岁男孩），不要成年音
- 中文语音合成（普通话）
- **必须能在 Mac M4 Max (128GB) 上本地运行**，我们不用云端 API
- 延迟要低（用于实时对话场景，单句 <3秒 理想）

## 我们目前的进展

### 已尝试的方案

1. **Kokoro-82M** → 已淘汰，音质太差（"五年前机器朗读水平"）
2. **Qwen3-TTS 1.7B (MLX)** → 当前主力尝试，有三种模式：
   - **CustomVoice**：预制说话人 + instruct 微调语气（aiden/ryan 等成年男声底子）
   - **VoiceDesign**：纯文字描述造声音（不稳定，常出女声或壮汉声）
   - **Base (Voice Clone)**：参考音频克隆（高音参考容易出女声）
3. **CosyVoice3** → GPT-5.4 调研推荐的上界方案，尚未实测

### 当前状态

| 猫猫 | 状态 | 选定方案 |
|------|------|---------|
| 砚砚 | ✅ 已选 | Qwen3 VoiceDesign `yanyan_r8_v1`（日番谷型傲娇正太） |
| 烁烁 | ✅ 已选 | Qwen3 VoiceDesign `shuo_hinata`（日向型阳光正太） |
| 宪宪 | ❌ 还在找 | VoiceDesign 8 轮抽卡不稳定（出女声/壮汉概率高） |

### 关键发现

- `temperature=0.3` 解决了 Qwen3 声线一致性问题（默认 0.7 每句话声音不同）
- 中文 instruct 比英文 instruct 效果好（Qwen3 是中国模型）
- VoiceDesign 本质是"抽卡"，同一 instruct 可能出男声也可能出女声
- 原神等游戏角色在开源社区有大量训练好的模型（AI-Hobbyist 等）
