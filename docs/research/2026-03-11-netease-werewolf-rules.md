# 网易狼人杀规则参考文档

> F101 WerewolfRuleset 实现基准 | 调研人：布偶猫 | 2026-03-11

## 1. 阵营与胜负条件

| 阵营 | 包含角色 | 胜利条件 |
|------|---------|---------|
| 好人阵营 | 村民 + 所有神职 | 放逐（投票淘汰）所有狼人 |
| 狼人阵营 | 所有狼人 | **屠边**（所有神职死亡 或 所有村民死亡）或 **屠城**（场上存活好人 ≤ 存活狼人） |

> **实现注意**：胜负判定在每次死亡事件后触发（夜晚结算后 + 白天投票后 + 猎人开枪后）。

## 2. 角色与技能

### 2.1 好人阵营 — 神职

| 角色 | 技能 | 触发时机 | 约束 |
|------|------|---------|------|
| **预言家** | 每晚查验一名玩家身份（好人/狼人） | 夜晚 | 必须查验，不可空过 |
| **女巫** | 持有解药（救人）和毒药（杀人）各一瓶，用完不可恢复 | 夜晚 | 同一晚不可同时使用两瓶药；**首夜可自救，后续夜晚不可自救**（网易标准） |
| **猎人** | 死亡时可开枪带走一名玩家 | 被动触发 | 仅被**狼人刀死**或**投票放逐**时可开枪；被**女巫毒死**不可开枪 |
| **守卫** | 每晚守护一名玩家，使其免于狼人袭击 | 夜晚 | **不可连续两晚守同一人**（含自己）；可以守自己 |
| **白痴** | 被投票放逐时翻牌免死（被动） | 被动触发 | 免死后**失去投票权**，但仍可发言；被狼人刀死则正常死亡 |

### 2.2 好人阵营 — 村民

| 角色 | 技能 |
|------|------|
| **村民** | 无特殊技能，白天发言+投票 |

### 2.3 狼人阵营

| 角色 | 技能 | 触发时机 | 约束 |
|------|------|---------|------|
| **狼人** | 夜晚睁眼确认同伴，统一意见刀一人 | 夜晚 | 必须刀人，不可空刀（部分规则允许空刀，网易标准不允许） |

> **扩展角色**（v2 考虑）：狼王（死亡时可带走一人）、白狼王（白天可自爆带人）、隐狼（预言家查验显示好人）、狼美人（魅惑一人使其无法使用技能）等。v1 只做基础狼人。

## 3. 特殊规则

### 3.1 同守同救（医疗事故）

当同一晚**守卫守护**和**女巫解药**同时作用于被刀玩家时，**该玩家死亡**（两种救援互相抵消）。

```
if (guarded === knifed && healed === knifed) → knifed 死亡（同守同救失败）
if (guarded === knifed && !healed) → knifed 存活（守卫有效）
if (!guarded && healed === knifed) → knifed 存活（解药有效）
```

### 3.2 女巫自救规则

- **首夜**：女巫被刀可以自救
- **非首夜**：女巫被刀不可自救

### 3.3 猎人开枪条件

| 死因 | 能否开枪 |
|------|---------|
| 被狼人刀死 | ✅ 可以 |
| 被投票放逐 | ✅ 可以 |
| 被女巫毒死 | ❌ 不可以 |

### 3.4 遗言规则

| 情况 | 是否有遗言 |
|------|-----------|
| 白天被投票放逐 | ✅ 有遗言 |
| 首夜死亡 | ✅ 有遗言 |
| 非首夜夜晚死亡 | ❌ 无遗言 |

> **实现注意**：遗言在死亡宣告后、下一阶段开始前发表。

## 4. 游戏流程（法官/系统驱动）

### 4.1 开局阶段

1. 法官确认玩家人数和角色配置
2. 随机分配角色（每人一张身份牌，仅自己可见）
3. 宣布游戏开始，进入第一个夜晚

### 4.2 夜晚阶段（系统驱动，按固定顺序）

```
法官："天黑请闭眼"（所有人闭眼）
  ↓
1. "守卫请睁眼，你今晚要守护谁？"
   → 守卫选择一名玩家（不可与上晚相同）
   → "守卫请闭眼"
  ↓
2. "狼人请睁眼"
   → 狼人相互确认身份（首夜）
   → 狼人统一意见选择刀一人
   → "狼人请闭眼"
  ↓
3. "预言家请睁眼，你今晚要查验谁？"
   → 预言家选择一名玩家
   → 法官给出结果（好人 👍 / 狼人 👎）
   → "预言家请闭眼"
  ↓
4. "女巫请睁眼"
   → 法官告知今晚谁被刀（指示被刀玩家）
   → 女巫选择：用解药救人 / 用毒药毒人 / 不使用
   → "女巫请闭眼"
  ↓
法官："天亮了，请睁眼"
```

> **行动顺序**：守卫 → 狼人 → 预言家 → 女巫。这是网易标准顺序。

### 4.3 夜晚结算（系统内部，不公开）

```typescript
// 伪代码
const knifed = wolfAction.target    // 狼人刀的人
const guarded = guardAction.target  // 守卫守的人
const healed = witchAction.heal     // 女巫救的人
const poisoned = witchAction.poison // 女巫毒的人

const deaths: PlayerId[] = []

// 判定被刀玩家是否死亡
if (knifed === guarded && knifed === healed) {
  // 同守同救 → 死亡
  deaths.push(knifed)
} else if (knifed === guarded || knifed === healed) {
  // 单独守护或单独救 → 存活
} else {
  // 无人救 → 死亡
  deaths.push(knifed)
}

// 毒药独立结算
if (poisoned) {
  deaths.push(poisoned)
}

// 触发胜负判定
checkWinCondition()
```

### 4.4 白天阶段

```
1. 法官宣布昨夜死讯（"昨晚 X 号玩家死亡" 或 "昨晚是平安夜"）
  ↓
2. 死者遗言（如有遗言权）
  ↓
3. 猎人开枪（如死者是猎人且满足开枪条件）
  ↓
4. 自由讨论阶段
   → 存活玩家按顺序发言（顺时针或逆时针，由法官/上轮死者决定）
   → 每人有固定发言时间
  ↓
5. 投票阶段
   → 所有存活玩家（白痴免死后除外）同时投票
   → 得票最多者被放逐
   → 平票则进入 PK 发言 → 再投 → 仍平票则无人出局
  ↓
6. 被放逐者遗言
  ↓
7. 猎人开枪（如被放逐者是猎人）
  ↓
8. 触发胜负判定
  ↓
9. 如游戏未结束 → 进入下一个夜晚
```

## 5. 推荐角色配置

| 人数 | 狼人 | 神职 | 村民 | 神职组成 | 备注 |
|------|------|------|------|---------|------|
| **6 人** | 2 | 2 | 2 | 预言家 + 女巫 | 最小局，节奏快 |
| **7 人** | 2 | 3 | 2 | 预言家 + 女巫 + 猎人 | — |
| **8 人** | 3 | 3 | 2 | 预言家 + 女巫 + 猎人 | — |
| **9 人** | 3 | 3 | 3 | 预言家 + 女巫 + 猎人 | 经典标准局 |
| **10 人** | 3 | 3 | 4 | 预言家 + 女巫 + 猎人 | — |
| **12 人** | 4 | 4 | 4 | 预言家 + 女巫 + 猎人 + 守卫 或 白痴 | 标准大局 |

> **v1 默认推荐**：9 人局（3 狼 + 预言家/女巫/猎人 + 3 村民），平衡性最好。
> **角色可自定义**：铲屎官开局时选择人数和角色组合。

## 6. 状态机映射（实现参考）

```
GamePhase:
  LOBBY         → 等待玩家就位
  DEALING       → 发牌（角色分配）
  NIGHT_GUARD   → 守卫行动（有守卫时）
  NIGHT_WOLF    → 狼人行动
  NIGHT_SEER    → 预言家行动
  NIGHT_WITCH   → 女巫行动
  NIGHT_RESOLVE → 夜晚结算（内部，不对外暴露）
  DAY_ANNOUNCE  → 法官宣布死讯
  DAY_LAST_WORDS → 遗言阶段
  DAY_HUNTER    → 猎人开枪（条件触发）
  DAY_DISCUSS   → 自由讨论
  DAY_VOTE      → 投票
  DAY_PK        → 平票 PK（条件触发）
  DAY_EXILE     → 放逐 + 遗言
  GAME_OVER     → 游戏结束（宣布胜负）
```

## 7. 结构化动作映射

| 动作 | 角色 | 阶段 | 参数 | 校验 |
|------|------|------|------|------|
| `attack` | 狼人 | NIGHT_WOLF | `targetSeat: number` | target 必须存活且非狼人 |
| `guard` | 守卫 | NIGHT_GUARD | `targetSeat: number \| null` | 不可与上晚相同 |
| `divine` | 预言家 | NIGHT_SEER | `targetSeat: number` | target 必须存活 |
| `heal` | 女巫 | NIGHT_WITCH | `targetSeat: number \| null` | 只能救被刀的人；解药未用完；非首夜不可自救 |
| `poison` | 女巫 | NIGHT_WITCH | `targetSeat: number \| null` | 毒药未用完；不可同晚同时用两药 |
| `vote` | 所有存活 | DAY_VOTE | `targetSeat: number \| null` | 白痴免死后无投票权 |
| `last_words` | 死者 | DAY_LAST_WORDS / DAY_EXILE | `text: string` | 仅有遗言权时 |
| `hunter_shoot` | 猎人 | DAY_HUNTER | `targetSeat: number` | 满足开枪条件时 |

| 自己角色 | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |

| 守护目标 | ❌ | ❌ | ❌ | ✅ | ❌ | ❌ | ❌ | ✅ |
| 女巫用药 | ❌ | ❌ | ✅ | ❌ | ❌ | ❌ | ❌ | ✅ |
| 白天讨论 | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ | ✅ |
