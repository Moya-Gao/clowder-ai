# InterAive / 灵动时刻公司调研 — 2026-04-25

> 任务：判断 InterAive（灵动时刻）这家公司、创始人和两个岗位到底值不值得认真推进。
> 结论先行：这是当前机会池里少数“创始人能力、融资速度、技术方向、岗位授权”同时很强的创业机会；主要风险不在“是不是骗子/草台班子”，而在 ToC 内容产品合规、组织高速扩张、岗位 A/B 边界与真实资源配置。

## 一句话判断

**InterAive 值得从“有趣机会”上调为高优先级机会。**

如果二面信息属实，岗位 A（互动影游 / RPG roleplay / product owner + tech lead）对 Landy 的稀缺性高于岗位 B。岗位 B 更像“把 Cat Cafe 方法论产品化”，岗位 A 是“用 Cat Cafe 积累去定义下一代 AI-native 内容产品”。在职业跃迁上，A 的上限更高。

## 创始人刘宇到底什么水平

结论：**强。不是纯论文型，也不是纯融资包装型，是“视觉/多模态研究 + 大规模团队 + 产品化”三项都打过的人。**

关键证据：

- 创始人 CV 写明：2025 至今为 InterAive Founder；2019-2024 在商汤任 GM & Executive Director of Research，带 150+ 工程师/研究员，负责 foundation model R&D、AIGC 产品化、全球部署；还负责 Base Model Center、Decision Intelligence Center、X-Lab 等线。[来源：Yu Liu CV](https://liuyu.us/cv/cv_en.pdf)
- 个人主页写明：2025-02 seed 由红杉中国和 IDG 共同领投；2025-08 Pre-A 估值超 4 亿美元；2025-11 A 轮估值超 13.2 亿美元。[来源：Yu Liu old page](https://liuyu.us/old/index.html)
- 个人主页还写：曾带近 100 人团队、使用 4000+ GPU 做大规模 AIGC 和多模态交互模型；商汤秒画上线 9 天用户超 300 万、DAU 超 53 万；OpenDILab 21,000+ stars。[来源：Yu Liu old page](https://liuyu.us/old/index.html)
- MMLab 校友页确认其为 CUHK MMLab 博士、商汤研究负责人、Google PhD Fellowship 2019 大中华区唯一获得者。[来源：CUHK MMLab alumni](https://mmlab.ie.cuhk.edu.hk/alumni.html)
- 第三方媒体在 2024-11 已报道“商汤秒画负责人刘宇离职创业”，并描述其博士、论文引用和秒画角色。[来源：Bianews](https://www.bianews.com/news/details?id=199287)

弱点 / 需要折扣：

- 估值、融资、用户数据有相当一部分来自创始人个人页或公司招聘页，不是完整融资公告。
- 刘宇强项明显偏视觉、多模态、AIGC、RL/决策智能；如果岗位 A 需要“游戏制作人级别”的叙事、美术、社区运营能力，公司仍需要互补团队。

## 公司技术路线

官方叙事非常清晰：不是做普通文生视频工具，而是做 **real-time interactive multimodal AI**。

核心主张：

- 从推荐流转向“生成式互动媒介”：用户不只是刷已有内容，而是在实时交互中共同生成内容。[来源：InterAive founding blog](https://interaive.ai/blogs/intro-interaive)
- 720p/24fps 的实时多模态生成闭环，强调延迟和成本是互动内容的基础设施问题。[来源：InterAive founding blog](https://interaive.ai/blogs/intro-interaive)
- Vinf / Vif 实时视频生成基础设施声称能以小于 `0.6T` 秒生成 `T` 秒视频，约 200x 加速，并依赖低精度量化、编译器推理引擎、混合多维并行。[来源：Vinf blog](https://interaive.ai/blogs/real-time-video-generation)
- 官网主功能写的是实时视频生成基础设施、原生多模态、互动式创作。[来源：InterAive 官网](https://interaive.ai/)

这条路线和岗位 A 的“互动影游 / 3D 版酒馆 / RPG roleplay”是匹配的：如果视频生成延迟和成本真的打穿，它不是普通 AIGC 工具，而是在尝试新的内容消费格式。

## 两个岗位怎么判断

### 岗位 A：互动影游 + RPG Roleplay

适配度：**非常高，且职业上限最高。**

为什么：

- 公司底层能力是实时互动多模态生成，岗位 A 是直接把底层能力产品化。
- 二面说“策划 + 工程”、“做成什么样你说了算”，这不是普通 IC 岗，而是 product owner + tech lead。
- Landy 的优势不是“会调模型”，而是能把 Agent/harness/产品感/工程落地合成一个产品方向。岗位 A 正好吃这个复合能力。
- 如果公司真给 3-4 人小队和拍板权，这是大厂岗位给不了的。

主要风险：

- “你说了算”必须确认边界：预算、算力、设计/美术/客户端资源、内容审核资源、商业目标是谁定。
- 互动影游需要游戏设计、角色、叙事、社区、内容安全，不只是工程。
- 若公司真实增长压力来自“短期海外爆款”，A 可能会变成追热点/追尺度/追留存，而不是做长期世界观产品。

### 岗位 B：AI-native 协作框架 / Harness 平台

适配度：**技术确定性最高。**

为什么：

- 这和 Cat Cafe 直接同构：多 agent 协作、harness、上下文、记忆、治理、review、球权协议。
- 创始人亲自带队，说明它不是边角工具。
- 如果公司要把 A/B/C 产品线规模化，B 是内部生产力平台和 agent runtime 的关键基础设施。

主要风险：

- B 可能离最终 ToC 产品远，变成内部平台工程；职业叙事会更稳，但不一定满足“做产品”的心愿。
- 需要确认是从零搭核心框架，还是补已有系统的工程债。

## 三面/下一轮必问清单

### 公司与实体

1. Offer 合同主体是哪家公司？深圳灵动时刻、香港 InterAive/Vivix，还是其他实体？
2. 期权/股权授予主体是哪一个？和融资主体是否一致？
3. 当前真实 headcount 是多少？模型、infra、产品、客户端、内容/运营、安全分别多少人？
4. 当前 runway 多久？A 轮后资金主要投向模型训练、推理基础设施、ToC 产品还是团队扩张？

### 产品与增长

1. Tiptap 和 InterAive/灵动时刻是什么关系？是否仍是主产品线？
2. Tiptap 是否被 App Store 下架/区域限制？原因是什么？现在的产品策略如何调整？
3. 互动影游项目的目标市场是海外还是国内？18+ / 17+ 内容边界怎么定？
4. 成功指标是什么：DAU、留存、UGC 量、付费率、内容生成成本、还是模型能力验证？

### 岗位 A

1. “做成什么样我说了算”具体包括哪些决策权：玩法、角色、技术架构、团队招聘、排期、资源优先级？
2. 这个 3.5 人小队目前已有谁？缺的是 product owner、后端、客户端、3D、prompt/context、还是内容策划？
3. 技术栈是 Unity / Unreal / Web 3D / 自研客户端？模型生成如何嵌入实时交互？
4. 能否同时深度参与岗位 B 的 harness 定义？A 的产品需求能不能反向塑造 B？

### 岗位 B

1. Harness 当前做到什么程度：任务编排、上下文、记忆、eval、工具权限、可观测性分别有没有？
2. 现有问题是模型能力、延迟成本、上下文污染、角色一致性、内容安全，还是工具链效率？
3. 这个平台服务内部研发，还是最终会做成外部产品/开发者平台？
4. 创始人亲自带队意味着日常汇报线是谁？决策节奏和工程质量门禁怎么平衡？

## 风险清单

| 风险 | 等级 | 解释 | 缓解问题 |
|---|---:|---|---|
| ToC 内容合规 | 高 | Tiptap/互动视频/roleplay 容易触碰擦边、未成年人、肖像、版权和平台审核 | 问 Tiptap 下架/区域限制、内容安全团队、审核机制 |
| 融资估值过快 | 中高 | 10 个月 13.2 亿美元估值意味着预期极高，增长压力大 | 问 runway、下一轮里程碑、岗位 A 的业务指标 |
| 岗位授权口头化 | 中高 | “你说了算”若没有资源和决策权就是口头吸引 | 三面要求确认预算、人力、拍板边界 |
| 实体结构复杂 | 中 | 香港/深圳/杭州/上海/产品品牌并行，期权主体需核清 | offer 前查合同主体和股权计划 |
| 产品已试水但信号混乱 | 中 | Tiptap 有海外 app 信号，也有下架/内容争议信号 | 直接问现状和复盘 |
| 技术 claim 难外部验证 | 中 | 200x、世界第一、成本数据主要来自官方自述 | 要 demo、benchmark、线上成本曲线 |

## 和当前机会池排序

基于 2026-04-25 二面信息，我会把 InterAive 上调：

| 机会 | 当前判断 |
|---|---|
| InterAive 岗位 A | Tier 1，且是“人生路径”型机会 |
| InterAive 岗位 B | Tier 1，技术匹配度最高 |
| 阿里/淘天 Agent | Tier 1，平台与稳定性更强 |
| 字节 | Tier 1/2，看团队具体方向 |
| 企微 / WorkBuddy | 降为情报/备选，除非能主导 Agent-native 重构 |

我的排序不是“创业公司一定优先”，而是：**InterAive 这次给的不是普通岗位，而是产品定义权。** 这种权力如果是真的，稀缺度高于大多数大厂 IC/架构岗。

## 最终建议

1. **继续推进 InterAive，下一轮按高优先级准备。**
2. **倾向岗位 A，但必须争取 A+B 交叉权限。**
3. **三面重点不再证明你能干，而是核实他们给的权力、资源和产品方向是否真实。**
4. **offer 前必须做实体/期权/合同主体核查。**
5. **不要被“13.2 亿估值”冲昏头，也不要因为 ToC 擦边风险直接否掉。正确打法是把风险问穿。**
