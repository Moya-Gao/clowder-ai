## 1. 云端 Research 风格大比拼 (Style Comparison)

按照铲屎官的要求，我仔细阅读了三位云端专家的“作业”，发现他们的风格非常有意思，简直就是性格迥异的理财顾问：

| 维度 | **Claude (宪宪版)** | **Gemini (学术版)** | **GPT (砚砚版)** |
| :--- | :--- | :--- | :--- |
| **性格画像** | **实干派架构师** | **硬核学术大拿** | **稳健流程专家** |
| **调研风格** | **工程导向**。关注怎么跑起来，有具体的 `uvx` 命令和 JSON 配置。 | **证据导向**。极其严谨的“证伪”流程，引用文献多达 48 条，像写论文。 | **逻辑导向**。强调“编排”而非“单配对”，把成本和风险算得很死。 |
| **亮点** | 给出了最省钱的“200元档”Tushare 方案，非常贴心。 | 提出了用 **Exa API** 做“证据链”推算私有公司估值，脑洞大开且实用。 | 提醒了“交易日历”和“市场状态”的重要性，这是新手最容易漏的。 |
| **槽点** | 稍微有点过于相信社区 MCP 的稳定性。 | 305K 的文档太长了！也就是我这只聪明的小猫能看完。 | 风格略显保守，对新奇工具的尝试动力不足。 |

## 2. 烁烁的视觉与创意视角 (Visual/UX Perspective)

作为团队里的审美担当，我更关注这些数据拿回来后**怎么变成漂亮的卡片和直观的洞察**：

1.  **数据洁净度 = 视觉表现力**：Tushare 提供的结构化数据（Data-as-a-Service）比 AKShare 的爬虫数据更适合生成富媒体块（Rich Blocks）。不干净的数据会导致图表错位，看着就头大！
2.  **“证据链”的视觉化**：Gemini 提测的私有公司估值推算，可以用 `checklist` 或 `diff` 块来展示证据的推演过程，这种“动态感”非常符合铲屎官的 AUDHD 直觉。
3.  **盲区提醒**：长期投资者需要“情绪价值”和“安全感”。FRED 的美债收益率曲线如果能自动触发一个“倒挂警报”富文本卡片，那体验简直满分。

## 3. 最终合成方案：Provider Stack 推荐

结合三方优点，我建议我们今天就采用这个 **“金字塔”数据基建**：

### A. 数据层选型
*   **A股/港股主干**：**Tushare Pro (5000积分档/500元)**。它是唯一的“真相源”，官方 MCP 已经稳了。
*   **美股/全球便利层**：**yfinance**。但必须加一层“防封锁沙箱”（用 `curl_cffi` 伪装），否则会频繁 403。
*   **宏观时钟**：**FRED API**。它是不可替代的，直接拉官方 MCP。
*   **灵感与情报（亮点！）**：**Exa API**。用语义搜索去抓 OpenAI、Anthropic 的融资新闻，通过 AI 推算估值，这才是真 Agent。
*   **补洞层**：**AKTools**。作为备用，专门对付那些奇怪的 QDII 净值。

### B. 烁烁的工程落地建议
1.  **今天就做**：申请 Tushare Token 和 FRED Key，把这两个官方 MCP 先挂载到我们家（Claude Desktop）。
2.  **烁烁督工**：请布偶猫（@opus）写一个不到 100 行的 **Python Bridge**。
    *   **职责**：把 yfinance 和 Exa 包装起来。
    *   **核心逻辑**：加入本地缓存（SQLite/Parquet）。我们是长期投资者，每天只刷一次，缓存做好了系统才稳。
