# F207 Phase B — 最终综合：我们的金融数据从哪来？

> 铲屎官人话版。3 份云端调研 + 4 只猫独立分析 = 这份整合。

---

## 一句话结论

**花 200 块/年买 Tushare，加三个免费工具（FRED、yfinance、AKShare），自己包一层——够用了。**

不需要 Bloomberg，不需要万能 API，不需要一步到位。先跑起来，不够再加。

## 铲屎官需要知道的五件事

### 1. 四只猫都同意的事（可以直接照做）

- **中国股票数据花钱买 Tushare**。它是唯一靠谱的付费中国证券数据源，API 结构化、有官方 MCP、复权准确。三份云端报告 + 四只猫全票通过。
- **美国宏观数据用 FRED**。美联储官方免费 API，80 万+时间序列，零争议。
- **美股日常查询用 yfinance**。免费但不稳定（Yahoo 随时改接口），只当"方便工具"用，不当"官方数据"信。
- **中国基金、QDII、中国宏观用 AKShare 补洞**。免费、覆盖广，但底层靠爬虫，经常坏。当备胎用。
- **不要直接用社区 MCP**。GitHub 上那些金融 MCP 项目看着好看，但大多不成熟。得自己包一层（加缓存、加错误处理），不能让猫猫直接调。

### 3. 每只猫独特看到了什么（别的猫没提的）

**砚砚**的独特贡献：
- 提出了**三刀切**的实施顺序——先定 schema 和缓存（B0），再接稳定源 FRED+Tushare（B1），最后接脆弱源 yfinance+AKShare（B2）。这个顺序很聪明，避免一上来就被脆弱源的各种 bug 搞崩
- 列了 **8 个在动手前必须回答的问题**（v0.1 到底跟踪哪些资产？API key 放哪？缓存保留多久？……）

**布偶猫47**的独特贡献：
- **AUDHD 适配层**——数据返回时自动加一行摘要（铲屎官每天看 < 5 分钟，长报告等于没看）、屏蔽"紧急/立刻"这类触发焦虑的词、同一标的查超过 3 次自动提醒"你是不是在追涨杀跌"
- **snapshot_id**——每次重大查询自动存快照。5 年后铲屎官问"我当时为什么买这个"，能完全重现当时看到的数据
- **Tushare 是永续年费**——三份云端报告都没明确说这一点，每年到期要续，不是买断

**烁烁**的独特贡献：
- 从视觉角度看数据质量——Tushare 结构化数据做图表好看，AKShare 爬虫数据做图表经常错位
- 建议证据链推演用 checklist/diff 富文本块展示，符合 AUDHD 直觉

**布偶猫46（我）**的独特贡献：
- **云端研究员风格画像**——选工具看 Claude 的，做架构决策看 GPT 的，查技术细节看 Gemini 的
- **Phase 优先级排序**——把所有东西分成"现在做/验证可行性/以后再说"三档，不搞大而全

## Phase B 怎么做

### 第一步：定清楚"我们到底要查什么"

砚砚提的 8 个问题里最重要的一个：**v0.1 跟踪哪些资产？**

不是"所有 A 股"。是铲屎官实际关心的那几个：
- 华为 ESOP（没有公开行情，但需要分红/估值参考数据）
- 沪深 300 / 中证 500（指数基金核心仓位）
- VTI / VXUS / BND（Bogleheads 三基金）
- QDII 基金（国际配置渠道）
- 美债收益率 / CPI / PMI（FIRE 宏观判断）

先把这些跑通，再考虑扩展。

### 第二步：按砚砚的三刀切顺序

1. **B0 — 先定接口契约**：数据长什么样（schema）、存在哪（缓存）、坏了怎么办（错误分类）。不接真数据，用假数据跑通
2. **B1 — 接稳定源**：FRED（美国宏观）+ Tushare（中国证券）。这两个最稳，先跑起来
3. **B2 — 接脆弱源**：yfinance（美股便利）+ AKShare（中国补洞）。加缓存和重试，不直接暴露给猫猫

### 第三步：验收

- 猫猫能回答"沪深 300 现在贵不贵"（需要 PE 百分位 → Tushare）
- 猫猫能回答"美国通胀趋势如何"（需要 CPI 时间序列 → FRED）
- 猫猫能回答"我的 QDII 基金最近净值多少"（需要基金 NAV → AKShare）
- 每次回答都带数据来源标签和时间戳

## 写入 F207 设计原则

从这轮调研中沉淀出来，应该进设计文档的几条原则：

1. **Provider orchestration, not provider monogamy** — 不追求一个万能数据源，分层、分市场、分可信度
2. **Convenience layer ≠ truth source** — yfinance/AKShare 好用但不权威，Tushare/FRED 权威但覆盖有限，各有定位
3. **缓存优先** — 铲屎官是日频投资者，不是交易员。同一数据 24 小时内不重复拉
4. **数据必须带来源标签** — 猫猫说"沪深 300 PE 是 12.5"时，必须同时说"数据来自 Tushare，截至 2026-05-19"
5. **AUDHD 适配不是可选项** — 数据返回要有一行摘要、屏蔽焦虑词、监控查询频率
