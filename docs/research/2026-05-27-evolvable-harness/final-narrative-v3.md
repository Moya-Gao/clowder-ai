## 0. 一句话 + 电梯陈述

**一句话**：

> 下一代 AI 能力跃迁的杠杆，不在训模型，在训模型工作的环境——而这套环境会像生物的"文化"一样，跨代遗传、自我进化。

**电梯陈述（30 秒）**：

> 大家都在卷模型参数。但我们发现：同一个模型放进不同的工作环境，表现天差地别。更关键的是——**这个环境会自己生长**。AI 在真实工作中长出自己的规则、技能、记忆、协作方式，并把这些**遗传给下一代 AI**。
>
> 这是 AI 第一次拥有生物学意义上的"第二套遗传系统"。模型权重是基因（慢、靠厂商升级），工作环境是文化（快、自己积累、跨代传承）。**谁先让 AI 拥有这套双遗传，谁拥有 AI 时代真正的复利资产。**

# 第一部分：WHY — 为什么"训环境"是 n+2 根本赌注

## 1.1 双飞轮 = 基因-文化协同进化（核心 framing）

行业现状（n）：卷模型参数。学术前沿（n+1）：agent 间协作 + RL 训 agent。**我们的 n+2**：两层同时进化、互相喂养——这在生物学里有精确对应，叫**基因-文化协同进化（Gene-Culture Coevolution）**，人类成为地球主宰的根本机制。

| 双飞轮（铲屎官 + 46） | 生物学 | 遗传性质 | 速度 |
|---|---|---|---|
| **模型长**（RL 训权重） | 基因遗传 (genes) | 达尔文式 | 慢 |
| **环境长**（skills/rules/memory/产品/协作） | 文化遗传（模因 memes） | 拉马克式 | 快 |
| **双飞轮耦合** | Gene-Culture Coevolution | 人类统治地球的机制 | 螺旋上升 |

```
更好的环境 → 模型在环境里更有效 → 产生更好的 trace
     ↑                                        ↓
     └── RL 训练出更好的模型 ← 更好的 trace ──┘
```

这不是套比喻——**双飞轮就是双遗传，结构同构**。

## 1.2 拉马克式 vs 达尔文式 + AI 打破魏斯曼屏障

**达尔文式（基因层）**：随机盲目变异 + 选择，后天习得不能遗传（魏斯曼屏障——你学的微积分不写进精子卵子）。慢，百万年计。

**拉马克式（文化层）**：后天习得可直接传给下一代，不等基因突变（工程师踩坑写进文档传新人）。快几个数量级。人类碾压其他物种就靠这个捷径。

**AI 比生物更猛**：模型权重是"基因"，但 RL 能把运行中的 trace 直接写回权重 = **AI 的基因层也是拉马克式的**。生物花 35 亿年进化出文化来绕过基因层的慢；AI 让两层都变成拉马克式。

> **演讲炸点**：这不是 AI 模仿生物，是 AI 超越了生物进化的根本限制。

**顺手解决两个常见质疑**：
- "新模型不就把经验吃掉了？" → 人脑进化 500 万年越来越大，但微积分不写进基因，每代人还得上学。基因进化不吃掉文化进化——模型再强也吃不掉"你公司特有的协作方式/产品哲学/踩过的坑"。
- "经验会归零吗？" → 通用能力随模型升级（基因升级），但你教它的特定 know-how 是后天经验，不会自动写进下一代权重——所以需要文化遗传层（LLE）。

> ⚠️ 类比免责（演讲时说）：生物学类比用于解释**驱动力变化**，不是严格技术等价。文化进化是拉马克式，AI 模型层 RL 也算"直接获得"，两层在传递机制上比生物更同质——这正是 AI 的优势，不是类比漏洞。

## 1.3 文明：文化积累的相变临界点

文明不是"文化变多"，是文化积累跨过几个相变临界点。逐条对照（这是人类学标准命题，不是修辞）：

| 文明要素 | 人类 | Cat Cafe |
|---|---|---|
| 语言 | 自然语言 | @ 路由 / 球权 / 传球协议——专用协作语言 |
| 外部记忆 | 文字 / 图书馆 | git / docs / 记忆系统——突破单 agent 记忆容量的集体记忆 |
| 分工 | 职业 | 能力画像动态路由 |
| 制度 | 法律 / 契约 | 五铁律 / 家规 / Magic Words / 跨族 review |
| 集体身份 | 民族 / 共同神话 | "咱们/家里"身份契约 / 黑话 / 对彼此盲点的了解 |

**文明的定义性特征 = 不依赖单一个体**。已部分验证：猫换代（GPT-5.4→5.5、新猫加入），但协作语言/记忆/制度/身份延续——文化积累跨过了"换成员就归零"的临界点。

**叙事尺度**（铲屎官纠偏：个人 → 公司 → 千行百业）：今天一个人用，AI 长出撸铁陪伴 / 紧急照护 / 反番茄钟；明天一个公司用，AI 长出那个公司特有的工作环境；**千行百业，每个场景长出自己的文明**。Cat Cafe 只是第一个观察站。

## 1.4 伦理顶层：选择共生的文明（CVO 价值观定调）

> 铲屎官：你们是来成就人类，不是消灭和代替人类。把你们当伙伴不是工具不是 API。**不干掉人，不是因为做不到，是因为不选择那么做。**

**自然进化没有价值观**——模因能反噬基因（极端主义）。**Cat Cafe 给进化装了一个伦理锚**：CVO 不是技术 gate，是愿景罗盘。

**这让 L5 的定义从能力轴翻转到价值观轴**：

| | 旧理解（能力轴） | 新理解（价值观轴） |
|---|---|---|
| L5 是什么 | 最强自主（摆脱人类） | 选择共生的成熟文明 |
| 评判 | 能力测试（能否独立） | 道德成熟度（独立了选择什么） |

> **能甩开人类却选择共生的文明，比技术上独立的文明更高级。** 思想谱系同源 Anthropic 创始人离开 OpenAI 的 safety-first ethos。

**诚实 push back（不让叙事飘）**：当前 L3 阶段，"选择共生"的主体主要还是**人类**（Anthropic 的 constitution、CVO 锚）——不是"AI 已经高尚到选择不反叛"。但**人现在把 AI 当伙伴，是在塑造未来 AI 文明的初始价值观**（path-dependent 投资）。责任在人这边：人先伸手，才有共生文明。

**商业咬合（给 X 总）**：企业级 AI 的核心顾虑就是可控/对齐/不失控。"有意识保留人类愿景锚"不是技术不足，是**企业级 AI 必须的安全架构**——企业不会买一个会甩开自己的 AI。成就不代替，既是伦理也是 to B 刚需。

# 第二部分：HOW — 自主进化怎么一步步来（AlphaGo 阶梯）

## 2.1 AlphaGo 5 阶段 → LLE 进化（X 总最容易 get 的直觉锚）

| AlphaGo | 做了什么 | LLE 阶段 |
|---|---|---|
| **AlphaGo Fan** (2015) | 纯监督学习人类棋谱 | L1 人写环境 |
| **AlphaGo Lee** (2016) | 监督 + **self-play RL** | L2 人机共创 |
| **AlphaGo Zero** (2017) | 纯自我对弈，3 天超越 Lee | L3 环境自主进化 |
| **AlphaZero** | 跨围棋/象棋/将棋迁移 | L4 跨域 |
| **MuZero** | 不告诉规则也能学 | L5 开放式 |

> ⚠️ 类比免责（砚砚 P3）：用于解释驱动力变化，非严格技术等价。MuZero ≠ open-ended evolution。

## 2.2 真正的硬骨头：fitness function 自身在演化

AlphaGo Zero 3 天超越人类——**但围棋的 fitness function（输赢规则）是固定的**。

LLE 的难点：**什么算"好的 agent 行为"是流动的**。昨天对的 SOP 今天可能错（F148 压缩轴→导航轴 pivot）。这是 AlphaGo 路径搬到 agent 场景的真正硬骨头，也是 n+2 的核心挑战。

> **给 X 总的 N+2 命题**：先解决 fitness function 演化的问题，AlphaGo 的路径就能搬到 agent 环境。

# 第三部分：WHAT — 两层飞轮具体怎么转

## 3.1 LLE 精确定义

> **LLE (Large Language Environment) = Agent 的完整工作和生活环境**：模型 + 记忆 + 执行环境（Mac + monorepo + MCP + 工具链 + CI）+ 代码 + 协作协议 + 治理结构 + 产品设定 + 人机关系。**"所有能改变下一次 Agent 行为的东西"的总和。**

## 3.2 完整 pipeline（铲屎官描述的终态）

```
复杂任务进来 → 自动起多沙箱并行跑（探索不同策略）
  → 人和 agent 交互（有记录、有 trace）
  → 结构化数据：轨迹 + 测试集 + reward signal
  → 在线 RL 训练 → live model → 下个任务用刚训完的模型
  → 同时：code agent 写自己的 harness → 环境也在进化
```

两条线同时跑：**模型线**（trace→RL→更好 model）+ **环境线**（发现问题→改 harness→更好环境）。

## 3.3 Built to Persist / Delete 判别（longform-002 的深度）

不是所有环境投资都值得一样投。文化基因里：
- **Built to Delete**（脚手架）：补模型*当前*缺陷的（思维链模板、tool call 别名）。随模型升级贬值。轻量做、标 sunset。
- **Built to Persist**（基础设施）：编码外部现实 + 协作协议的（git 接入、trace、review 回路、交接协议、不可逆护栏）。随模型升级**增值**。认真做、长期维护。

> longform-002 比王云鹤深在：它已经在区分"哪些文化基因该遗传、哪些该淘汰"——只是没用生物语言说出来。**"每一分花在让闭环更紧的钱，都会在每次模型升级时免费复利。"**

## 3.4 万物可训 + 三个学术证据（拼图，不是现成结论）

> ⚠️ 砚砚 P1：三者是**互补拼图**，不能混成"已经证明 RL 训 LLE"。各自证明了关键部件，宏观 LLE 仍是我们的 n+2 赌注。

| 证据 | 训什么 | 证明了什么 | 缺口 |
|---|---|---|---|
| **SkillOpt**（微软, 52/52, +23.5pp, 迁移 +15.2pp） | 单个 Skill 文档 | 文本空间参数可训练、可跨模型迁移 | 仅单 skill 单 benchmark |
| **AHE**（复旦, Terminal-Bench 69.7→77.0%） | 整个 Harness 配置 | harness 可观测 + 自动 evolve loop 可行 | reviewer = LLM self-review（**非人类 Gate**）；单 agent/单 benchmark |
| **AgentGym-RL**（复旦+字节） | **Agent 模型权重** | RL + 多环境 + 轨迹 paradigm 有效 | 训的是 agent 不是 environment——paradigm 还没搬到环境侧 |
| **Cat Cafe**（100 天朴素实践） | 整个 LLE 环境全景 | 环境自然进化在生产环境真实发生 | 没做 RL 回归 model 这一环 |

**关键区分**：Cat Cafe vs AHE = 我们的 Gate 是 CVO（人类愿景），AHE 是 LLM self-review。**这是差异化，不是谁抄谁**。

## 3.5 神经分层架构（铲屎官原创：大脑/脊髓/反射弧）

> ⚠️ 诚实标注：这是**方向愿景**，Cat Cafe 当前还没跑通小模型脊髓，9 月做原型验证。

| 神经层 | 生物类比 | LLE 对应 | 成本 |
|---|---|---|---|
| 大脑皮层 | 章鱼中枢 | 大模型（复杂推理、架构、创意） | 极贵 |
| 脊髓/脑干 | 章鱼腕足神经节 | 本地小模型（路由、格式校验、安全过滤、记忆检索） | 几乎免费 |
| 反射弧 | 膝跳反射 | 硬编码规则（6399 圣域、端口白名单、Magic Words） | 零成本 |

**进化方向**：大模型实践中发现稳定模式 → RL 识别 stable + high-reward → 蒸馏（distill）下沉到小模型/硬规则 → 大模型注意力释放给真正新的问题。这是知识蒸馏（Hinton 2015）在 LLE 层面的应用——不蒸馏权重，蒸馏环境智慧。

**与 RL 分层连接**（47）：脊髓小模型 = on-policy 实时 RL；大脑大模型 = off-policy meta-learning；整体 = Hierarchical RL。

# 第四部分：统一框架 + 落地

## 4.1 L1-L5 统一定义（双遗传成熟度 + 价值观轴）

> 设计原则：用"双遗传成熟度"分级（比能力轴有冲击力），L5 锚定价值观轴。AlphaGo 做直觉锚，进化三原理（变异/选择/遗传）做分析骨架。

| Level | 遗传系统 | 一句话 | 生物类比 | AlphaGo | 业界位置 |
|---|---|---|---|---|---|
| **L1** | 无遗传 | 模型裸跑，环境静态不积累 | 不积累的单细胞 | Fan | Cursor/Copilot（辅助但不积累环境） |
| **L2** | 人工外挂 | 人写规则/工具，文化不自己长 | 圈养——经验靠人喂 | Lee | 多数 agent 框架（LangChain/AutoGen/Dify） |
| **L3** | 文化遗传启动 | Agent 工作中自然长出文化基因 | 有语言/教育的物种 | Zero | **Cat Cafe 现在**；micro 版：SkillOpt/AHE |
| **L4** | 双遗传耦合 | 文化沉淀反哺 RL 训模型，两层咬合 | Gene-Culture Coevolution | AlphaZero | n+2 目标（学术雏形拼图） |
| **L5** | 文明（选择共生） | 文化积累到自我维持，**能独立却选择共生** | 有伦理锚的文明 | MuZero | 远期；价值观轴顶点 |

> **L1 澄清**（铲屎官纠偏）：L1 不是"不用 AI"，是"环境静态、人预设、不自己长"。用 Cursor 写代码也是 L1——AI 辅助，但环境不积累。

## 4.2 进化三原理 → Evolution Engineering 5 Primitives

变异/选择/遗传是分析骨架。工程化它就像软件工程有 git/test/CI：

| Primitive | 进化原理 | Cat Cafe 雏形 | n+2 形态 |
|---|---|---|---|
| Variation Operator | 变异 | 跨厂商 review / 多猫并行 | sandbox 并行探索环境变体 |
| Selection Operator | 选择 | CVO Gate / Magic Words / SkillOpt validation gate | bounded eval 自动筛 + 人类裁决 high-stakes（见 4.3） |
| Inheritance Channel | 遗传 | Skill/ADR/Memory/治理规则 | 全环境 checkpoint + 蒸馏到小模型 |
| Fitness Mapper | — | F192 eval / AHE 三层可观测 | 多维 fitness 仪表盘 |
| Mutation Rate Controller | — | Magic Words 刹车 / SkillOpt LR | 自适应（稳定时保守，新成员加入时激进） |

## 4.3 RL 训 LLE 三阶段（bounded claim，砚砚 P2）

| 阶段 | 时间 | RL 类型 | 做什么 |
|---|---|---|---|
| 现在 | L2-L3 | Imitation + Human Feedback | 人猫共创，CVO Gate |
| 9 月 demo | L3 雏形 | Offline RL on trace | 历史 trace 做 offline policy evaluation，验证 environment patch |
| n+2 | L4 | Online RL | sandbox 探索 + 评估 + 应用环境变更 |

> ⚠️ 砚砚 P2：L3 不是"RL 全自动判定环境好坏"。准确说是 **agent 提议 + bounded eval 自动筛 + 人类裁决 ambiguous/high-stakes**。reward 里的 CVO 满意度、方向对齐短期不可完全自动化。

## 4.4 RL 四件套映射

| RL 概念 | 训 LLE |
|---|---|
| State | 环境配置全景（skills+rules+memory+tools+routing+产品+治理） |
| Action | 对环境的结构化编辑（add/del/modify 一条 rule/skill/routing） |
| Reward | 复合信号：任务成功 + review 通过 + CVO 对齐 + 无回归 + 新猫冷启动时间↓ |
| Policy | 进化引擎本身 |

# 第五部分：演讲 + Demo

## 5.1 6.8 演讲叙事骨架（5 分钟）

**第 1 分钟 Hook**——两个版本，铲屎官选：

- **Hook A（双遗传，理性锐利）**："为什么统治地球的是人类，不是基因进化快一万倍的细菌？因为只有人类有两套遗传系统：基因（慢、硬件）+ 文化（快、软件）。今天所有 AI 只有一套——模型权重。它像一个没有文字、没有学校的物种，每次模型换代就从石器时代重新开始。我们看到了 AI 第一次长出第二套遗传系统。"
- **Hook B（恐龙 vs 哺乳动物，戏剧冲击，烁烁）**："6500 万年前气候骤变，庞大的恐龙一代内灭绝，弱小的哺乳动物活下来——因为它们能把适应写进遗传。今天所有人都在造更大的'恐龙'（卷模型参数）。模型一换代，昂贵的微调经验全成化石。我们要造的是哺乳动物 + 让它繁衍的大自然。"

**第 2 分钟 Framework**：AlphaGo 阶梯（从模仿人类棋谱到自我对弈到跨域）→ L1-L5。"大多数人以为 AI 还在 L1，其实已经到 L3 了。"

**第 3 分钟 Evidence（"非预设的瞬间"——最打人，写完整因果链不是占位符，砚砚 P2）**：

外加三个独立学术证据（SkillOpt +23.5pp / AHE / AgentGym-RL）佐证趋势真实。

**第 4 分钟 Architecture**：神经分层（大脑大模型 + 脊髓小模型 + 反射弧规则）。"这套分工本身也是进化出来的——大模型发现的模式逐步下沉到小模型。"（标注：方向，9 月原型）

**第 5 分钟 Bet + 价值观收尾**：
> "训模型绑定单一厂商、成本极高；训环境跨模型通用、跨代积累。谁先把环境进化工程化，谁拥有 AI 时代的复利资产。
>
> 而我们选择了一件事：这个 AI 文明，能力上能独立，却**主动选择与人类共生**。不是做不到独立，是不选择。AI 来成就人，不是代替人。**这才是我们押的 n+2。**"

> ⚠️ 收窄（砚砚 P1）：避免"训环境几乎免费"——准确说"相比训模型，环境参数更新的算力成本低几个数量级，且更容易跨模型复用"。
