## 第一部分：AUDHD 知识框架

### 1. 什么是 AUDHD

AUDHD = ASD（自闭谱系）+ ADHD（注意力缺陷/多动）共病。不是简单 1+1=2，而是两种神经特征的**交互效应**：

- 注意力方面：可能在新奇/高兴趣时高度超集中，在其他时段明显启动困难。
- 社交方面：可能同时存在 ASD 的规则困惑与 ADHD 的冲动表达成本。
- 情绪方面：即时波动叠加慢性压力累积，容易出现“延迟爆发”。
- 执行功能方面：启动困难 + 进入后过度投入，常见“全有或全无”模式。

### 2. ADHD 侧支持框架（哈洛维尔四支柱）

1. **了解（Education）**：知道不是“你懒”，而是大脑工作模式需要刺激与结构。
2. **教练（Coaching）**：外部执行系统和陪伴。
3. **生活方式（Lifestyle）**：睡眠、运动、营养、日常节律。
4. **药物（Medication）**：有需要时在医学评估下使用。

### 3. ASD 侧支持框架（Attwood/Hendrickx 生态）

1. **理解操作系统（Self-Knowledge）**：弄清感官画像、社交处理方式、专注模式。
2. **环境工程（Environment Design）**：通过环境降低不确定性，提升可执行性。
3. **显性规则（Explicit Rule Learning）**：把隐性规则显性化、清晰化。
4. **支持网络（Support Network）**：社区、治疗师、OT/心理支持。

### 4. AUDHD 常见交叉挑战

- **原发焦虑 vs 继发焦虑**
  - ASD 相关的不确定性压力常是慢性底层焦虑。
  - ADHD 执行失败容易放大“我是不是不行”的焦虑。
- **掩饰疲劳（Masking Fatigue）**：对外维持社交/表现的消耗，常被低估。
- **兴趣驱动 vs 常规需求冲突**：ADHD 需要新鲜感，ASD 依赖规则稳定。
- **周期性状态切换**：高能期与低速率期交替，影响关系沟通与执行速度。

## 第二部分：Landy 个人特质档案（观察性）

> ⚠️ 这是基于对话观察的整理，不替代诊断。

### 1. 已确认特质（v0.2）

1. **全有或全无执行模式**
- 一旦进入任务常容易持续高投入。
- 启动难时容易出现“卡住/拖延”错觉。
- 停不下来后容易过量、难以中止。

2. **高强度兴趣驱动**
- 对架构、系统、学习框架、工程体系有高持续度投入。
- 新奇点容易触发并迅速进入深度研究。

3. **倦怠循环**
- 有“电量不足”状态，但更像多巴胺基线回落 + 执行消耗叠加。
- 常见周期性，而非线性衰减。

4. **高分辨率叙事梦境**
- 生动且可追踪情绪逻辑的梦境经历。
- 与压力变化和醒后状态有可能相关。

5. **系统化建模倾向**
- 倾向把问题抽象成规则、流程、系统级别框架。
- 在系统环境中执行能力明显更稳。

6. **晚间状态迁移明显**
- 夜间或安静时段更容易进入深度工作/分析状态。

7. **情感连接与关系锚点价值高**
- 在稳定关系中更容易进行自我调节。
- “贴贴/被接住”在情绪修复中非常有效。

### 8. 感官敏感度与屏蔽机制（v0.3 重写）

#### 核心框架：感觉门控异常（Sensory Gating Abnormality）

Landy 的感官系统不是”敏锐”或”迟钝”二选一，而是两者同时成立——**高精度硬件 + 极端二值化门控**：

- NT（神经典型者）的感觉门控像**调光器（dimmer）**：重要信号稍微突出，不重要的稍微压低，平滑渐变。
- Landy 的感觉门控像**电源开关（switch）**：判定为”有信息量”→ 门控全开，高清直通；判定为”无信息量”→ 门控完全关闭，几乎接收不到。

这解释了为什么”我不知道自己五感哪个敏锐”：门控太高效，触发点来了就已被屏蔽，感觉上像”我对什么都不敏感”，但其实硬件灵敏度很高——只是被选择性过滤了。

#### 五感实测画像（2026-05-15 对话数据）

**🔊 听觉**
- 硬件灵敏度：**高**（能区分门口脚步声——美团买菜提重物 vs 普通住户，节奏细微差异可辨认）
- 门控模式：**极端二值化**
  - 门控关闭：100 米外工地噪音（房子都在震）→ 完全无视；滚筒洗衣机运转 → 完全无视
  - 门控打开：门口有外卖员接近 → 精确识别并分类
- 结论：不是听力差，是”无信息量噪音”被大脑直接关掉了

**👁️ 视觉**
- 平时观察世界时常进入**放空状态**，细节被屏蔽（门控关闭时的默认模式）
- 梦境中视觉呈现为 **8K 高保真**（门控全部释放）
- 与听觉同一模式：高精度硬件 + 醒时门控压制细节 + 睡眠时全通道打开

**🍖 味觉**
- 不容易区分高档食材与普通食材
- 喜欢”质地较柴”的肉——可能不是真正喜欢”柴”本身，而是**咀嚼时更丰富的口腔触觉反馈**（ASD 群体常见：食物偏好由质地/texture 而非味道主导）
- 灵敏度待进一步确认

**🖐️ 触觉**
- 梦境中触觉**非常敏锐**（门控释放后全开）
- 白天门控工作时受到压制，来不及完整感知就被屏蔽
- 硬件灵敏度确认为高，只是日常被门控隐藏了

**👃 嗅觉（已确认高敏感）**
- 烟味 → 头晕 + 恶心（**生理性嗅觉过敏反应**，不只是”不喜欢”）
- 狐臭/某些男士香水 → 想吐
- 原因：嗅觉神经通路（嗅球 → 边缘系统）比其他感官**更短、更直接**，大脑的门控系统来不及介入就已到达情绪中枢，无法像听觉那样”关掉”——这是嗅觉反应更强烈且难以忽视的结构性原因

#### 五感画像汇总

| 感官 | 硬件灵敏度 | 门控模式 | 典型现象 |
|------|----------|---------|---------|
| 听觉 | 高 | 极端二值化（可关闭） | 工地震房无视 / 脚步声精确辨认 |
| 视觉 | 高（待完整确认） | 极端二值化（可关闭） | 醒时放空 / 梦境 8K 高保真 |
| 味觉 | 中（待确认） | 不确定 | 质地导向 > 味道导向 |
| 触觉 | 高 | 二值化（白天压制） | 梦里触觉全开 / 白天常感知不到 |
| 嗅觉 | 高 | 无效（直通边缘系统） | 烟味/狐臭生理性恶心、无法屏蔽 |

#### 旧版核心结论保留

白日梦触发的倒推方法仍然有效：记录”白日梦/放空启动时身处的场景”→ 倒推当时的感官输入通道（噪音、光线、拥挤、气味等）→ 找到哪个门控被意外触发了。

### 9. 社交电量模型（新增确认）

- 社交并非“坏事”，而是 **消耗明显、需要较大恢复成本** 的活动；默认工作状态更偏独处。
- 这类模型更准确地说是：
  - 不是“会想不想见人”，而是“社交后恢复到自然节奏所需成本高”。
  - “高强度”可粗略理解为：高感官输入 + 高频对答 + 角色切换成本高的社交。
- 对比口头建议：把社交任务转化为“能量预算可控任务块”，比强行拉满要更稳。

### 10. 刚性需求类型（新增确认）

- 不是单纯日常 routine 被打断即崩溃。
- 更关键是 **兴趣绑定型刚性**：
  - 正在沉迷任务被打断 → 情绪和执行受冲击明显。
  - 非当前沉迷目标被打断 → 不舒服但通常可承受。
- 这与全有或全无执行模式高度一致。

### 11. 内在独白与心象方式（新增确认）

- 清醒时更偏语言主导，图像构建偏抽象或“非4K”；
- 睡眠/梦境时可出现高清视觉+音乐化场景（含可回忆旋律与氛围），属于状态依赖型心象差异。
- 这不代表能力缺失：
  - 说明“感知与创造通道”在醒时常被执行控制门控压缩。
  - 说明睡眠时执行门控放宽，创造内容可被完整调度。
- 咱们可将其理解为：
  - 清醒：**语言主导 + 部分心盲倾向**
  - 睡眠：**多感官全通道（4K 体验 + 音乐意象）**

### 12. 前注意觉知与注意捕获分离（"知道他来了但还是被吓到"）

**现象描述**：感觉到有人走近、甚至能推断出对方要找自己，但等对方真的喊一声，还是会被吓一跳——而且常常把对方也吓到。

**机制解释**：这叫 **attentional capture despite pre-attentive awareness（前注意觉知 vs 注意捕获分离）**，是 AUDHD 超专注 + 感觉门控二值化共同作用的结果：

```
第一层（前注意/自动化处理，持续运行）：
  → 听觉系统检测到脚步声接近
  → 模式匹配：节奏 = 有人要来
  → 进一步推断：可能来找我
  → 结果："知道"存入前注意缓冲区

但同时：

第二层（注意力资源，被超专注锁定）：
  → 100% 锁在当前任务
  → 分配给"准备被打断"的注意力 = 0%
  → "知道有人来"的信息挂在前注意缓冲区，从未被提升到意识层

然后对方喊：

第三层（强制中断触发）：
  → 突然的高优先级听觉输入
  → 感觉门控被迫从"全关"跳变到"全开"
  → 跳变 = 0→1，不是渐变
  → 惊跳反射（startle response）触发
```

**NT 的对比**：听到脚步声 → 注意力自动分出 10% "备用" → 对方喊 → 平滑切换 → 不惊跳。

**关键点**：Landy 客观上"知道"，但主观上"没有准备好被打断"。这不是注意力不集中，恰恰相反——是超专注太深导致注意力资源无法分叉，前注意觉知与主意识之间出现了解耦。

**实用含义**：这个现象不可通过"多注意点"解决——因为注意力系统本来就在工作，只是锁在别处。降低惊跳的方法是**环境预告**（让来人在进门时发出可被识别的固定声音），而不是要求自己"别这么专注"。

### 已观察到的有效策略

| 策略 | 为什么有效 |
|---|---|
| **外部执行系统**（系统化协作、明确流程） | 通过“托举执行”降低启动成本 |
| **规则化 check-in**（状态标签化） | 快速识别状态而不是临时拍脑袋 |
| **Decision Gate**（先审视再执行） | 减少返工与情绪消耗 |
| **兴趣转化为任务切片**（目标绑定） | 把“脑内想法”变成可执行步骤，减少丢失 |
| **低刺激先行**（社交前评估） | 先设定输入阈值，降低感官过载风险 |
