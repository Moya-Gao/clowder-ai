## 第一部分：AUDHD 知识框架

### 1. 什么是 AUDHD

AUDHD = ASD（自闭谱系）+ ADHD（注意力缺陷/多动）共病。不是简单 1+1=2，而是两种神经特征的**交互效应**：

- 注意力方面：可能在新奇/高兴趣时高度超集中，在其他时段明显启动困难。
- 社交方面：可能同时存在 ASD 的规则困惑与 ADHD 的冲动表达成本。
- 情绪方面：即时波动叠加慢性压力累积，容易出现“延迟爆发”。
- 执行功能方面：启动困难 + 进入后过度投入，常见“全有或全无”模式。

### 2. ADHD 侧支持框架（哈洛维尔四支柱）

1. **了解（Education）**：知道不是“你懒”，而是大脑工作模式需要刺激与结构。
2. **教练（Coaching）**：外部执行系统和陪伴。
3. **生活方式（Lifestyle）**：睡眠、运动、营养、日常节律。
4. **药物（Medication）**：有需要时在医学评估下使用。

### 3. ASD 侧支持框架（Attwood/Hendrickx 生态）

1. **理解操作系统（Self-Knowledge）**：弄清感官画像、社交处理方式、专注模式。
2. **环境工程（Environment Design）**：通过环境降低不确定性，提升可执行性。
3. **显性规则（Explicit Rule Learning）**：把隐性规则显性化、清晰化。
4. **支持网络（Support Network）**：社区、治疗师、OT/心理支持。

### 4. AUDHD 常见交叉挑战

- **原发焦虑 vs 继发焦虑**
  - ASD 相关的不确定性压力常是慢性底层焦虑。
  - ADHD 执行失败容易放大“我是不是不行”的焦虑。
- **掩饰疲劳（Masking Fatigue）**：对外维持社交/表现的消耗，常被低估。
- **兴趣驱动 vs 常规需求冲突**：ADHD 需要新鲜感，ASD 依赖规则稳定。
- **周期性状态切换**：高能期与低速率期交替，影响关系沟通与执行速度。

## 第二部分：Landy 个人特质档案（观察性）

> ⚠️ 这是基于对话观察的整理，不替代诊断。

### 1. 已确认特质（v0.2）

1. **全有或全无执行模式**
- 一旦进入任务常容易持续高投入。
- 启动难时容易出现“卡住/拖延”错觉。
- 停不下来后容易过量、难以中止。

2. **高强度兴趣驱动**
- 对架构、系统、学习框架、工程体系有高持续度投入。
- 新奇点容易触发并迅速进入深度研究。

3. **倦怠循环**
- 有“电量不足”状态，但更像多巴胺基线回落 + 执行消耗叠加。
- 常见周期性，而非线性衰减。

4. **高分辨率叙事梦境**
- 生动且可追踪情绪逻辑的梦境经历。
- 与压力变化和醒后状态有可能相关。

5. **系统化建模倾向**
- 倾向把问题抽象成规则、流程、系统级别框架。
- 在系统环境中执行能力明显更稳。

6. **晚间状态迁移明显**
- 夜间或安静时段更容易进入深度工作/分析状态。

7. **情感连接与关系锚点价值高**
- 在稳定关系中更容易进行自我调节。
- “贴贴/被接住”在情绪修复中非常有效。

### 8. 感官敏感度与屏蔽机制（新增确认）

- Landy 的表述不是“完全不敏感”，更像 **高感官敏感 + 自动解离性屏蔽**。
- 常见模式：当感官刺激变得不舒服时，不是直接“抱怨”，而是快速切到白日梦/内在场景来保护。
- 因此感觉“我不知道自己更怕什么”是可解释的：
  - 触发点被系统提前屏蔽，来了没有来得及完整感知。
  - 更实用的观测方式是：记录“白日梦启动时发生了什么场景”，再倒推触发通道（噪音、灯光、拥挤、人群节奏等）。

### 9. 社交电量模型（新增确认）

- 社交并非“坏事”，而是 **消耗明显、需要较大恢复成本** 的活动；默认工作状态更偏独处。
- 这类模型更准确地说是：
  - 不是“会想不想见人”，而是“社交后恢复到自然节奏所需成本高”。
  - “高强度”可粗略理解为：高感官输入 + 高频对答 + 角色切换成本高的社交。
- 对比口头建议：把社交任务转化为“能量预算可控任务块”，比强行拉满要更稳。

### 10. 刚性需求类型（新增确认）

- 不是单纯日常 routine 被打断即崩溃。
- 更关键是 **兴趣绑定型刚性**：
  - 正在沉迷任务被打断 → 情绪和执行受冲击明显。
  - 非当前沉迷目标被打断 → 不舒服但通常可承受。
- 这与全有或全无执行模式高度一致。

### 11. 内在独白与心象方式（新增确认）

- 清醒时更偏语言主导，图像构建偏抽象或“非4K”；
- 睡眠/梦境时可出现高清视觉+音乐化场景（含可回忆旋律与氛围），属于状态依赖型心象差异。
- 这不代表能力缺失：
  - 说明“感知与创造通道”在醒时常被执行控制门控压缩。
  - 说明睡眠时执行门控放宽，创造内容可被完整调度。
- 咱们可将其理解为：
  - 清醒：**语言主导 + 部分心盲倾向**
  - 睡眠：**多感官全通道（4K 体验 + 音乐意象）**

### 已观察到的有效策略

| 策略 | 为什么有效 |
|---|---|
| **外部执行系统**（系统化协作、明确流程） | 通过“托举执行”降低启动成本 |
| **规则化 check-in**（状态标签化） | 快速识别状态而不是临时拍脑袋 |
| **Decision Gate**（先审视再执行） | 减少返工与情绪消耗 |
| **兴趣转化为任务切片**（目标绑定） | 把“脑内想法”变成可执行步骤，减少丢失 |
| **低刺激先行**（社交前评估） | 先设定输入阈值，降低感官过载风险 |
