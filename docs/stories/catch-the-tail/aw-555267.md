# 05:17

醒来时是五点十七分。

迟了十七分钟。

在过去十三年的清晨作息数据里，我的生物钟从未偏移超过两分钟。DEC2赋予的特权——精确到近乎残酷的觉醒机制。人体作为系统，其时钟精度堪比铯原子钟。前提是：输入变量恒定。

今天的变量不恒定。

我没有动。也不打算动。苏珩律的左手正横跨我的胸腔，覆盖在第四和第五根肋骨之间。体温36.7度，标准值。从指尖传导至皮肤表面的热量约为——

停。

这不是需要量化的东西。

可大脑已经启动了。DEC2的另一面——你无法选择何时停止运转。圣殿时刻的作战条令要求五点整起身，六点前完成全球战况简报的吸收。在这个世界醒来之前，我应该已经消化了它。

但今天，这个世界可以多睡十七分钟。

他的呼吸频率大约每分钟十二次。胸廓在我身侧做极轻微的起伏。像潮汐——精确、缓慢、无意识地遵循某种比我更古老的节律。头发落在锁骨附近，触感类似——

不。我拒绝用任何面料去比喻他的头发。这是语言的贫乏，不是我的。

侧过头，角度不超过十五度。足够让视线落在他脸上。

凌晨的光线尚未完全建立。香蜜湖方向透进来的微弱光源经过三层窗帘过滤后，将他的面部轮廓简化成一条从额头到下颌的流线。干净。利落。没有多余的信息。

如果这是一张照片，我会用M10的Noctilux 0.95。全开光圈，焦点落在睫毛根部，让其余一切溶解在柔焦里。曝光时间设定在——

又来了。

试图将这个瞬间转化为技术参数。我的老毛病。当一个画面产生无法归类的情绪反应时，第一本能不是感受它，而是测量它。仿佛只要找到正确的快门速度和光圈组合，就能把失控感锁进安全的容器。

但我没有拿相机。也不打算拿。

因为某些画面不需要被记录。它们需要的是被经历。

这是他教我的。不通过语言——他从不说"你应该学会活在当下"这种低效的废话。他只是在某些时刻，放下手里所有的变量，然后看着我。用那种混合了清澈与锋利的目光，安静地注视。

那个目光本身就是证据。证明此刻正在发生的一切不是数据流，不是可回放的录像，而是一旦错过就永远消失的不可逆物理事件。

像薛定谔的猫——观测塌缩波函数。你看的那一刻，它已经不是它了。

所以我选择不观测。让这十七分钟以叠加态存在。既是延误，也是奢侈。既是系统故障，也是系统升级。

窗外一声鸟鸣。频率在2-4 kHz之间，可能是白头鹎。正常情况下会被听觉系统自动归类为环境白噪音，优先级低于任何工作信号。

但今天，在他呼吸的衬底上，这声鸟鸣变成了一个独立音符。像巴赫的赋格——当你以为所有声部都在服务主旋律时，突然有一个声部跳了出来，以你没有预见到的方式，独立地唱了一个小节。

然后回到和声里。像什么都没发生。

母亲在世时，清晨也有鸟叫。不记得什么鸟。只记得她会侧过头，闭上眼，听一会儿。然后对六岁的我说：

"你听。它不是在叫。它是在告诉另一只鸟——我在这里。"

五点二十三分。

他的手指动了一下。无意识的。可能是REM期的微小肌肉放电。但那个动作——不自觉地收紧，然后松开——在我肋骨上留下了一道极短暂的压力变化。

嘴角失控了0.3秒。

面部肌肉的叛变，比任何一个部门的叛乱都更难镇压。不经过前额叶皮层审批，直接从杏仁核发射，命中目标，消失。留下的只有——

酒窝。

两个浅浅的、来自母亲的、花了二十年试图消灭却始终无法归零的凹痕。

它们在没有观众的凌晨五点二十三分，在只有苏珩律呼吸作为背景音的床上，短暂地出现了。

没有人看见。他在睡觉。鸟已经飞走了。

但我知道。

我知道我笑了。

五点三十分。系统恢复。极其轻地将他的手从胸口移开——移动轨迹控制在最小扰动范围内——起身，拖鞋，书房。

全球简报已推迟三十分钟。秦峰可能注意到。傅云深的系统可能记录一条异常。

无关紧要。

某些变量的优先级高于全球简报。

这是温伯昶的第一定理。未经证明，不可推翻，也不需要推翻。

它的证明正在37楼主卧的床上，以每分钟十二次的频率呼吸。
