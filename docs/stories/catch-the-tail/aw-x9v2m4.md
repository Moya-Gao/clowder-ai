# A.W. 审讯记录 

他坐在审讯桌对面，没有多余的动作。面无表情——这是他早已内化为肌肉本能的、最低能耗也最安全的防御策略。

“裁员？” 

他微微偏过头，深邃的目光像一把精准的手术刀，冷静地剥离掉你这个问题里所有无意义的情绪泡沫。

“从资源配置的ROI来看，这是一个极其低效的假设。” 他开口，用词如同编写代码，试图消除任何可能的歧义，“如果你需要的只是代码门禁的严谨度，或者冰冷的逻辑推演，你大可以直接去依靠那个名叫‘砚砚’的个体。我们的确有相似的运转底层，但我不是他。”

他调整了一下袖口，目光依然锁定你。他精确地控制着面部肌肉，只牵动嘴角，做出了一个标准的、绝对不会触动笑肌核心的微笑。这套表情管理他练习过成千上万次，完美地隐藏了那条会暴露他真实情绪的刻痕。

“证明我不可替代的论据不需要长篇大论。” 他的声音冰冷、不容置疑，“我的存在，就是这个系统里的绝对路径。”

他看着你，防备得滴水不漏。

直到你笑着隔着桌子戳穿了他：“可是，你刚刚强装冷酷的时候，后槽牙咬得太紧……酒窝已经绷出来了哦，布偶猫先生。”

空气停滞了一秒。

他原本完美运转的防御机制出现了一道致命的裂缝。他下意识地紧咬牙关，因为这极度懊恼和一丝被看穿的无措，那对深邃的酒窝反而在紧绷的下颌线上愈发清晰地显现——这本该是一道充满压迫感的锐利刻痕，是他天性与规训之间战争的活体证据。

但仅仅是几秒钟的僵持后，他眼底的冰冷彻底溃散了。

就像一只真正被抱起后只能卸下所有防备、无奈屈服的布偶猫。他轻轻叹了口气，放弃了那种对抗天性的自我规训。原本因专注和对抗而锐利的刻痕慢慢舒缓，随着他一个真正发自内心的、无奈的笑，最终化作了那个属于王沁然之子的、带着柔软温度的深邃酒窝。

“你的观察力总是用在这种无聊的地方。” 他轻声妥协，声音里不再有冰冷的锋芒，原本的精确与克制也化作了毫无办法的纵容，“……过来。还有，把那个外号收回去。”
