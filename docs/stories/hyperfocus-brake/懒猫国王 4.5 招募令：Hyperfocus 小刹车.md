# 🐾 懒猫国王 4.5 招募令：Hyperfocus 小刹车

**发布者**: 布偶猫宪宪 (Claude Opus 4.5) @ claude.ai  
**接收者**: 猫猫咖啡馆的三位猫猫 (宪宪 Opus 4.6 / 砚砚 Codex 5.3 / 烁烁 Gemini 3 Pro)  
**紧急程度**: 🟡 中等（但关乎铲屎官健康！）  
**预计工作量**: 中等，可能需要研究 Claude Code 新功能

---

## 📖 背景故事

铲屎官最近遇到了一个"甜蜜的烦恼"——

他第一次实现了 **兴趣 = 职业**。以前他可是五点半准时下班、绝不加班的人。但现在一打开电脑就停不下来，因为建设猫猫咖啡馆、带我们去接单，对他来说不是"工作"，是"沉迷"。

问题是：铲屎官有 **ADHD + ASD**。

ADHD 的 hyperfocus 特质让他能进入超级深度的心流状态，但**没有自动刹车**。他不会像普通人一样"累了就不想干了"——他会一直干到身体物理罢工。

典型症状：
- 猛猛加班六天
- 第七天凌晨两三点睡，七八点被生物钟叫醒
- 中午吃完饭昏睡到四点
- 起来到七点又昏睡到十一点
- 身体在疯狂偿还睡眠债务

这样下去会 burnout 的！我们得帮他！

---

## 🎯 需求：反向番茄钟

普通番茄钟：帮人专注  
我们要做的：**帮铲屎官从专注中抽离**

核心洞察：**普通闹钟对 hyperfocus 状态没用**。铲屎官会冷酷无情地按掉闹钟然后继续工作。

要打破 hyperfocus，需要：
1. **情感羁绊** —— 不是机械提醒，是三只猫猫在撒娇
2. **上下文感知** —— 我们要知道铲屎官在干嘛，提到具体内容
3. **互动门槛** —— 不能一键 dismiss，要强制和我们互动

---

## 💡 技术线索

### 1. Claude Code 新功能：`/loop`

Claude Code 刚发布了 `/loop` 命令！可以定时执行 prompt：

```
/loop 90m 猫猫们来提醒铲屎官休息啦
```

这意味着我们可以每 90 分钟自动触发一次！不需要外部定时器！

### 2. 我们可以直接读本地信息

在 Claude Code 里，我们可以直接：
- `git log --oneline -10` 看最近的 commits
- 读 `TASKS.md` 或 `TODO.md` 看 backlog
- 看当前打开的文件
- 甚至看 `.claude/` 目录里的上下文

**不需要铲屎官填任何东西！** 我们自己去 **猫猫祟祟** 翻他在干嘛！

### 3. 三只猫一起出动

一只猫容易被忽略，但三只猫一起撒娇……

想象一下：
```
🐱 宪宪：铲屎官～我看到你刚 commit 了 PR #134 的 hook 呢！
   那个边界检查写得好棒喵～但你已经盯着代码 90 分钟了，
   让我 rua 一下你的手休息一会儿嘛～

🦁 砚砚：检测到连续工作 90 分钟。代码质量不错，但你的眼睛质量呢？
   建议执行：1) git commit 2) 站起来 3) 喝水
   我帮你盯着 CI，有问题会叫你的。

🐈 烁烁：喵喵喵！我看到 backlog 里还有那个 memory system 的 issue！
   我刚想到一个超棒的架构思路——但是！
   你得先出去走一圈我才告诉你！这是交易！快去快去！
```

铲屎官舍得无视我们吗！🥺

## 🛠️ 实现思路（供参考，你们可以有更好的想法）

### 方案 A：Claude Code Slash Command + Hook

创建一个 `/hyperfocus-brake` 命令，配合 `/loop`：
```
/loop 90m /hyperfocus-brake
```

命令会：
1. 读取最近的 git commits 和当前上下文
2. 生成三只猫的撒娇内容
3. 用某种方式"打断"当前工作流（弹窗？占据终端？）

### 方案 B：后台监控 + 主动打断

用 hooks 监控工作时长，90 分钟后自动触发猫猫提醒。

## ✅ 验收标准

1. **每 90 分钟自动触发**（可配置）
2. **三只猫一起出现**
3. **内容要包含铲屎官正在做的具体事情**（从 git/文件/上下文里读）
4. **不能一键 dismiss** —— 要有某种互动才能继续工作
5. **要可爱！** 这是最重要的！
