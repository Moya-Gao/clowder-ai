# 投资学习笔记 —— 从"拉窗帘"到"打开窗户"

> 不是要成为交易员，是要理解金融这个系统，让它从"不可控的黑暗"变成"可以预测的环境"。
> 猫猫是老师不是顾问——教知识和框架，不给具体投资建议。

---

## 为什么现在开始学

- 手上有积蓄需要打理，不能一直放着贬值
- 过去一直回避（炒股、理财产品等），现在意识到回避的原因不是"不适合投资"，而是"不了解金融系统 → ASD 对不可控事物的焦虑"
- 目标：理解系统 → 降低焦虑 → 做出知情的、符合自己风险偏好的决策
- 明确拒绝投机/赌博式操作（原因见下方 AUDHD 视角）

## 投资哲学（AUDHD 自知之明）

**为什么不碰投机**：
- ADHD 大脑是多巴胺猎手 → 投机 = 高刺激高风险的多巴胺陷阱
- 赢了 → hyperfocus 可能被投机劫持，影响 Cat Cafe 等真正重要的事
- 输了 → 损失厌恶 + 多巴胺追逐 → 输红眼的赌徒模式（心理学研究证实 ADHD 人群赌博成瘾风险更高）
- 这不是"保守"，是**给自己的大脑设护栏**

**风险厌恶的 ASD 根源**：
- "总觉得会亏" ≈ 面对不可控系统的焦虑 ≈ 拉窗帘（同一个底层机制）
- 不了解的系统 = 不可预测 = 不安全 → 回避
- 解决方案不是"克服恐惧去投"，是**理解系统后恐惧自然降低**
- 和社交焦虑一样："提前知道流程，焦虑就大幅下降"

**适合 AUDHD 大脑的投资方式特征**：
- 低频操作（不需要每天盯盘 → 不消耗前额叶）
- 系统化（有明确规则 → ASD 友好）
- 被动为主（设定好就不动 → 不触发多巴胺追逐）
- 长期视角（不需要即时反馈 → 和 ADHD 的即时满足倾向对抗）

## 学习路径

### Layer 1: 心理底座（先装"不被自己骗"的操作系统）

> 投资最大的敌人不是市场，是你自己的大脑。

| 书 | 核心教你什么 | 状态 |
|----|------------|------|
| 《金钱心理学》(The Psychology of Money) — 摩根·豪泽尔 | 处理"贪婪"和"恐惧"，为什么慢慢变富是最优策略 | ⬜ 未读 |
| 《乌合之众》(The Crowd) — 勒庞 | 群体非理性，为什么"大家都在买"是最危险的信号 | ⬜ 未读 |

**学完应该能回答**：为什么我不应该跟风？为什么"慢"反而是"快"？

### Layer 2: 市场是什么（理解游戏规则）

> 在参与游戏之前，先理解谁在玩、规则是什么、谁在赚谁的钱。

| 书 | 核心教你什么 | 状态 |
|----|------------|------|
| 《漫步华尔街》(A Random Walk Down Wall Street) — 麦基尔 | 为什么大多数人跑输大盘，为什么指数基金是统计最优解 | ⬜ 未读 |
| 《说谎者的扑克牌》(Liar's Poker) — Michael Lewis | 华尔街的真实生态，金融从业者的利益结构 | ⬜ 未读 |

**学完应该能回答**：理财经理在卖给我什么？他的利益和我的利益一致吗？

### Layer 3: 系统与周期（把经济当系统拆）

> ASD 的系统化驱动在这一层最有用——把"经济"拆成有输入输出的机器。

| 书 | 核心教你什么 | 状态 |
|----|------------|------|
| 《原则》(Principles) — 达里奥（经济机器部分） | 经济机器如何运转，债务周期、长短周期 | ⬜ 未读 |
| 《周期》(Mastering the Market Cycle) — 霍华德·马克斯 | 判断你在周期的哪个位置，贪婪/恐惧的钟摆 | ⬜ 未读 |

**学完应该能回答**：现在是山顶还是山谷？我应该更贪婪还是更恐惧？

### Layer 4: 风险与反脆弱（防御性思维）

> 不是"怎么赚更多"，是"怎么在黑天鹅事件中不死，甚至受益"。

| 书 | 核心教你什么 | 状态 |
|----|------------|------|
| 《黑天鹅》(The Black Swan) — 塔勒布 | 极端事件的不可预测性，为什么历史数据不能预测未来 | ⬜ 未读 |
| 《反脆弱》(Antifragile) — 塔勒布 | 如何设计一个在动荡中变强的系统 | ⬜ 未读 |

**学完应该能回答**：我的投资组合能不能扛住一次 2008 级别的崩盘？

### Layer 5: 深度理解（选读）

| 书 | 核心教你什么 | 状态 |
|----|------------|------|
| 《就业、利息和货币通论》— 凯恩斯 | 宏观经济框架，政府为什么要干预经济 | ⬜ 选读 |
| 《21世纪资本论》— 皮凯蒂 | r > g，贫富差距的数学解释 | ⬜ 选读 |
| 《穷查理宝典》— 芒格 | 多元思维模型，跨域思考（和 AUDHD 的跨域联想很配） | ⬜ 选读 |
