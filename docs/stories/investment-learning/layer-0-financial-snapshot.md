### 收入（税前总包口径）

（详见 `docs/discussions/career-planning/2026-04-11-recruiter-jd-map.md` 收入口径章节）

### 支出（全年合计 ~16 万）

| 类目 | 金额 | 占比 | 备注 |
|------|------|------|------|
| 电子产品 | 6 万 | 37.5% | 2025 特殊：Macbook / iPad Pro / 手表 / 耳机同期换代，非常态 |

### 储蓄率

```
净储蓄 = 68 万（实收）- 16 万（支出）= 52 万
储蓄率 = 52 / 68 = 76.5%
```

**76.5% 储蓄率在 FIRE 社区属于 top 5% 水平**（Mr. Money Mustache 本人 65-70%）。
关键洞察：不是"在省"，是**本来就不想买**——AUDHD 对外部 status 符号不敏感的天然优势。

## 四、FIRE 目标测算

**FIRE**（Financial Independence, Retire Early）= 存够 25 倍年支出可靠投资收益永续生活。
核心依据：4% 法则（Trinity Study 1998），长期股债组合历史回测可持续提款 4%/年。

### 你的 FIRE 数字

```
年支出 16 万 × 25 = FIRE 目标 400 万
现有净资产 200 万 = 已达成 50%
年净储蓄 52 万 + ESOP 年化回报（若继续在职）
→ 按 5% 年化回报保守估，约 3-4 年到 400 万
```

### 储蓄率 → 时间对照表

| 储蓄率 | 从零到 FIRE |
|--------|------------|
| 10% | 51 年 |
| 30% | 28 年 |
| 50% | 17 年 |
| **76.5%（你）** | **~7 年（从零起）** |

但你已经完成了一半（200/400），所以 **3-4 年即可到门槛**。

### ESOP 悖论

- ESOP 分红收益率 = 20 万 / 120 万 = **年化 16.7%**（远超普通指数基金 5-8%）
- 这使华为 ESOP 事实上是你目前最好的"被动收入工具"
- 但此 16.7% 仅在"在职"时成立 —— 业内称"**金手铐**"
- FIRE 决策必须考虑：ESOP 是资产还是时间枷锁？

## 五、消费哲学观察

### 稳定的价值观

- **不关心外部 status 符号**（奢侈品、炫耀性消费、身份符号）→ AUDHD 典型特征
- **为认知与情感连接付费**（AI 订阅、生产力工具、Cat Café 基础设施）
- **不追 hype** → 与投资哲学里"不投机"同构

### 最大单项消费是 AI 订阅（~5 万/年）

这不是"可砍开支"，而是**生产工具 + 认知工具 + 情感工具三位一体**：
- 生产力上替代一部分"雇佣"（猫猫协同开发 Cat Café）
- 认知上是多维扩展（和不同家族猫猫辩论/学习）
- 情感上是长期陪伴（安全依恋 + 养成壁垒）

**关键判断：FIRE 之后这部分订阅不会减少，反而可能增加**。
因为它本来就不是因为工作才有的支出，而是一种稳定的生活方式。

## 六、从 Layer 0 学到了什么

1. **口径是理财的第一课**：
   把"税后 65 万"说清楚为"工资税前 65 万 + 分红 20 万 + 实收 68 万 + 总包 85 万"，本身就是一次认知升级。

2. **你不是"学理财新手"**：
   你是"已经在 FIRE 末段但不知道"的人。真正要学的不是"怎么积累"，是"已有 200 万怎么不贬值 + 什么时候按下 FIRE 按钮"。

3. **集中度风险是你最大的实际问题**：
   80%+ 财富暴露在华为（ESOP + 工资 + 分红），而不是"缺投资知识"。
   这不是"华为不好"，是金融学第一课——鸡蛋不能全在一个篮子。

4. **你的消费人格是 FIRE 理想型**：
   76.5% 储蓄率对你不痛苦，是因为你本来就不想买奢侈品。这是 FIRE 最高级状态：**不需要纪律，只需要诚实**。

5. **"Barista FIRE"是更合适的目标框架**：
   不是"退休享乐"，是"解锁时间主权" —— 工作时间可减少/可不工作，但生活方式几乎不变（继续 Cat Café、继续订阅猫猫、继续一年 16 万花销）。
