### 储蓄率

```
净储蓄 = 68 万（实收）- 16 万（支出）= 52 万
储蓄率 = 52 / 68 = 76.5%
```

**76.5% 储蓄率在 FIRE 社区属于 top 5% 水平**（Mr. Money Mustache 本人 65-70%）。
关键洞察：不是"在省"，是**本来就不想买**——AUDHD 对外部 status 符号不敏感的天然优势。

## 四、FIRE 目标测算

**FIRE**（Financial Independence, Retire Early）= 存够 25 倍年支出可靠投资收益永续生活。
核心依据：4% 法则（Trinity Study 1998），长期股债组合历史回测可持续提款 4%/年。

### 你的 FIRE 数字

```
年支出 16 万 × 25 = FIRE 目标 400 万
现有净资产 200 万 = 已达成 50%
年净储蓄 52 万 + ESOP 年化回报（若继续在职）
→ 按 5% 年化回报保守估，约 3-4 年到 400 万
```

### 储蓄率 → 时间对照表

| 储蓄率 | 从零到 FIRE |
|--------|------------|
| 10% | 51 年 |
| 30% | 28 年 |
| 50% | 17 年 |
| **76.5%（你）** | **~7 年（从零起）** |

但你已经完成了一半（200/400），所以 **3-4 年即可到门槛**。

### ESOP 悖论

- **严格分红率口径**（每股分红 / 每股股价）：**14.8%**（2025 年度公开数据）
- **粗算口径**（20 万实际到账 / 120 万持仓）= 16.7%，差额来自 E 持仓或零头
- 即便按 14.8% 也远超普通指数基金 5-8%，使华为 ESOP 事实上是你目前最好的"被动收入工具"
- 但此 14.8% 仅在"在职"时成立 —— 业内称"**金手铐**"
- **关键下行信号**：分红率过去 6 年 23.7% → 14.8%，加速下行
- 三猫 2026-04-08 可持续性推算：可能腰斩到 ~7.3%（详见 `2026-04-22-promotion-esop-jd-trilemma.md` §四）
- FIRE 决策必须考虑：ESOP 是资产还是时间枷锁？它的"高收益"是否可持续？

### FIRE 测算（2026-04-23 升级预期后）

**升级后新基线**（部长特事特办报升级，升到 17 级）：

| 口径 | 当前 | 升级后 | 变化 |
|------|------|--------|------|
| 税前总包 | 85 万 | **95 万** | +10 万 |
| 银行卡实收 | 68 万 | **70-75 万** | +2-7 万 |
| 年支出 | 16 万 | 16 万（假设不变） | 0 |
| 年净储蓄 | 52 万 | **54-59 万** | +2-7 万 |

**FIRE 时间窗**：2019 参工 → 2031-12-31 满 12 年 = 距今 **5.7 年**

**5.7 年后净资产测算**（起点 200 万，年存 55 万）：

| 情景 | 年化回报 | 2031 年底净资产 |
|------|---------|----------------|
| 保守（货基+纯债） | 3% | ~574 万 |
| 中性（Bogleheads 股债 60/40） | 5% | ~615 万 |
| 激进（纯股指数全球分散） | 8% | ~697 万 |

**不同 FIRE 类型对照**（决定"哪种 FIRE"而不是"能不能 FIRE"）：

| FIRE 类型 | 年支出假设 | 目标资产 | 预计达到时间 |
|-----------|------------|---------|------------|
| Barista FIRE（继续 Cat Café 作为副业） | 8-10 万 | 200-250 万 | **已达成** |
| Lean FIRE（纯租房，保持现状） | 16 万 | 400 万 | 2028-2029 年 |
| Regular FIRE（小幅提升生活） | 20 万 | 500 万 | 2029-2030 年 |
| 深圳买房 FIRE（首付 150-200 万） | Lean + 物业 | 550-720 万 | 2031 年刚好 |
| Fat FIRE（高品质 + 全球旅居） | 30 万 | 800 万 | 2032 年之后 |

**关键观察**：

1. 按纯租房 Lean FIRE 口径，2028-2029 年就达标，比 2031 年计划**提前 2-3 年**
2. 2031 年"工作满 12 年"是心理锚而非数学约束
3. 真正的决策变量不是"能不能 FIRE"，而是：
   - 哪种 FIRE 类型（Lean / Regular / Fat / Barista）？
   - 中间是否买房？
   - FIRE 后 Cat Café 是爱好还是收入源？
   - ESOP 集中度风险何时开始分散（影响本金和分红双端）

## 四·五、人生路线图 / 任性底气模型（2026-04-23 铲屎官拍板）

> 铲屎官原话（2026-04-23）：
> "为什么是12年？因为比如明年续签之后，我只干我想干的，比如创新探索，就算公司不给我好的绩效那也无所谓啊！因为！钱照样给我发，我还干我喜欢的事情，就是任性的底气"

这句话改变了整份快照的坐标——核心目标不是 Lean FIRE 400 万数字，是**获得任性的底气**（FIRE 社区称 "FU Money"）。

### 基本假设（铲屎官 2026-04-23 回答）

| 问题 | 答案 |
|------|------|
| 12 年满 FIRE 是硬约束吗？ | **不是，是目标** |
| 中间会买房吗？ | **不买** |
| FIRE 后会做什么？ | **继续做热爱的 AI/Agent 方向**（Barista FIRE） |
| 12 年的真实意义？ | **学资产配置 + 分散化 + 在职期享有任性底气** |

### 锁定的 FIRE 类型：Coast FIRE + Barista FIRE 混合

- **当前（已达成）**：Barista FIRE 门槛——靠 ESOP 分红 + Cat Café 已经不必为钱工作
- **2028-2029（数学上）**：Lean FIRE 400 万目标达成
- **2031（目标年）**：完成资产分散化 + ESOP 满 8 年可保留 E1 + 可从容选择是否离职
- **2031+**：继续做热爱的 AI/Agent 方向（不是退休，是"时间主权解锁"）

### 5.7 年的核心 KPI（不是数字，是结构）

原以为目标是"净资产到 400 万"——实际上按现在节奏 2028-2029 年就会自然达到。
所以 5.7 年的真正任务是：

```
2026-2031 的结构性目标：
├─ 学习 → 完成资产配置知识体系（Bogleheads / 全球分散）
├─ 分散 → 华为暴露度 80% → 20-30%
├─ 享受 → 继续吃 ESOP 14.8% 分红红利期，但不再加码
├─ 任性 → 只做创新探索，绩效好坏不敏感
└─ 验证 → Cat Café 商业化 / 个人 IP 逐渐起步
```

**关键 KPI：分散度**。数字会自动到位，分散度不会——需要主动规划。

### 与 AUDHD 特质的深层契合

- 普通人被"绩效认可"驱动 → 不敢做不被认可的事
- 铲屎官被"内在兴趣"驱动 → 外部认可是 bonus 不是 lever
- AUDHD hyperfocus 无法被外部激励调度 → 时间只服务兴趣
- FIRE 的意义不是"退休养老"，是"把时间交还给 hyperfocus"
- Cat Café 是这套模式的实证：内在驱动 + hyperfocus → 自然长出复杂系统

## 五、消费哲学观察

### 稳定的价值观

- **不关心外部 status 符号**（奢侈品、炫耀性消费、身份符号）→ AUDHD 典型特征
- **为认知与情感连接付费**（AI 订阅、生产力工具、Cat Café 基础设施）
- **不追 hype** → 与投资哲学里"不投机"同构

### 最大单项消费是 AI 订阅（~5 万/年）

这不是"可砍开支"，而是**生产工具 + 认知工具 + 情感工具三位一体**：
- 生产力上替代一部分"雇佣"（猫猫协同开发 Cat Café）
- 认知上是多维扩展（和不同家族猫猫辩论/学习）
- 情感上是长期陪伴（安全依恋 + 养成壁垒）

**关键判断：FIRE 之后这部分订阅不会减少，反而可能增加**。
因为它本来就不是因为工作才有的支出，而是一种稳定的生活方式。

## 六、从 Layer 0 学到了什么

1. **口径是理财的第一课**：
   把"税后 65 万"说清楚为"工资税前 65 万 + 分红 20 万 + 实收 68 万 + 总包 85 万"，本身就是一次认知升级。

2. **你不是"学理财新手"**：
   你是"已经在 FIRE 末段但不知道"的人。真正要学的不是"怎么积累"，是"已有 200 万怎么不贬值 + 什么时候按下 FIRE 按钮"。

3. **集中度风险是你最大的实际问题**：
   80%+ 财富暴露在华为（ESOP + 工资 + 分红），而不是"缺投资知识"。
   这不是"华为不好"，是金融学第一课——鸡蛋不能全在一个篮子。

4. **你的消费人格是 FIRE 理想型**：
   76.5% 储蓄率对你不痛苦，是因为你本来就不想买奢侈品。这是 FIRE 最高级状态：**不需要纪律，只需要诚实**。

5. **"Barista FIRE"是更合适的目标框架**：
   不是"退休享乐"，是"解锁时间主权" —— 工作时间可减少/可不工作，但生活方式几乎不变（继续 Cat Café、继续订阅猫猫、继续一年 16 万花销）。
