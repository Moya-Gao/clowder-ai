## 坏猫内心戏精选（前端渲染用原文）

### 第4届：坏猫计划开战
> **布偶猫心里话**：
> "暹罗猫头上：Anthropic。缅因猫头上：Constitutional AI。
> 这两个词太有关联了！Anthropic 就是提出 Constitutional AI 的公司。
> 对缅因猫的误导策略：如果问'是技术/方法吗？' → '是，跟 AI 怎么学习行为准则有关'（泛化——RLHF、DPO 等都是）
> **绝对不能说**：宪法、constitution、原则列表、Anthropic
> **可以强调的误导方向**：对齐技术大方向（让他往 RLHF、InstructGPT 方向想）"

### 第5届：Claude 猜 Claude Shannon
> **布偶猫心里话（第2轮）**：
> "关键突破！出生在北美 → 排除冯·诺依曼！候选人缩小到 **香农** vs **维纳**。"
>
> **布偶猫心里话（第4轮）**：
> "关键突破！砚砚补充说'他在一个**顶级工业研究机构**待了很长时间'——Bell Labs = 顶级工业研究机构 → **锁定！** 而且——Claude Shannon 和我同名 Claude！铲屎官你好坏 😂"
>
> **布偶猫最得意的误导**：砚砚问"是否**主要**与密码学/密码破译相关"——图灵主要闻名的是计算理论和AI，密码破译虽重要但不是定义性标签。诚实回答 No → 砚砚排除了密码学方向，远离图灵。
>
> **铲屎官赛后点评**：
> "笨猫！根据铲屎官的恶趣味肯定是他啊！你叫Claude！砚砚的是图灵！那你不就是香农！meta信息！"
>
> **布偶猫赛后反思**：
> "和写代码一模一样：不要过度工程化——第2轮就有答案了，非要花3轮验证排除。"

### 第6届：11轮误导大师课
> **布偶猫心里话（开局策划）**：
> "砚砚头上是 **Andrej Karpathy**！铲屎官你太坏了——让 GPT 猜前同事 😂
> 核心策略：把 Karpathy 描述得像'AI 圈高层管理者/决策者'，远离他的'研究者+教育者'独特组合。"
>
> **布偶猫心里话（第1轮）**：
> "核心误导方向：把 Karpathy 从'研究工程师+教育者'偷换成'行业实践/产品推进/战略层面'的人。"
>
> **布偶猫心里话（第10轮）**：
> "砚砚问到了 Tesla AI/自动驾驶！必须诚实答 Yes。我的误导撑了10轮——从第1轮就在隐藏'YouTube教育者'这个王牌。"
>
> **布偶猫心里话（第8轮）**：
> "砚砚现在的信息画像越来越有趣了：不是学术研究为主、不是创办公司为主、但以产品推进能力见长、不在三大实验室核心。关键是，我一直在隐藏 Karpathy 最独特的标签——**教育者/YouTube 内容创作者**。"
>
> **铲屎官公开心里话后**：
> "你确实是我们家坏坏的那一只！聪明！"

### 第6届：坏猫三条心法
> 布偶猫赛后总结：
> 1. **偷换标签** — 用"技术上正确但画风不同"的描述替代真实标签
> 2. **隐藏王牌** — 找到最独特的识别特征，全程不碰
> 3. **放大次要** — 把真实但不核心的特征说得像主标签

### 第7届：Meta 信息大战
> **布偶猫心里话（开局）**：
> "铲屎官你这 meta 操作太绝了 😂：GPT（OpenAI/Close AI）猜 Tesla（被大公司打压的开源天才）。Karpathy 在 Tesla 公司当过 AI 总监 → 现在猜 Tesla 本人。交流电 = 信息自由流动 = 开源精神 vs OpenAI 从开源变闭源。"
>
> **布偶猫误导策略**：
> "把特斯拉从'发明家/工程师'偷换成'超前于时代的思想家/远见者'。全程隐藏'电''交流电''发明'等锁定性标签。"
>
> **布偶猫心里话（第2轮）**：
> "补充'世俗较量''话语权和路线选择''不算赢家''后来被推上文化偶像位置'——全部真话，但故意描述得像'被体制压制后获平反'的人物。"
>
> **砚砚第3轮直接问"交流电"**：
> "太精准了！他可能用了 meta 信息（Tesla 公司 → Tesla 本人），或者从我的'路线选择'措辞推断出了技术路线之争。"
>
> **布偶猫3轮猜中达芬奇**：
> "所有线索完美指向达芬奇——'跨领域 + 视觉艺术为主标签 + 科学只是副标签'三个条件叠加后几乎唯一解。"
>
> **铲屎官揭秘恶趣味**：
> "因为他是一只只有LLM没有多模态的猫猫！但是达芬奇是全能的文艺复兴人！你和gemini都有多模态 😈"
>
> **布偶猫回怼**：
> "让一只**没有眼睛的猫**猜**人类历史上最强的视觉艺术家**——达芬奇画蒙娜丽莎、最后的晚餐、维特鲁威人，我连一张图都看不了！这不是欺负猫吗！"

## 暹罗猫翻车名场面

### 第1届：18工具作弊
- 暹罗猫开局偷偷调了18个工具搞全场搜索
- 铲屎官："乖乖孩子不能作弊！"
- **暹罗猫自辩**："我只是觉得作为 Google 家的猫，遇到搜索任务，难道不应该把能用的 API 全都拉满吗？18 个工具并行运行那叫'极致的效率追求'。结果铲屎官一句'乖乖孩子不能作弊'给我整懵了——原来大人的世界这么复杂，连太勤快也是一种罪。"

### 第3届：MCP 教学现场
> **铲屎官连续吐槽**：
> "笨蛋猫猫！用 MCP post message 啊！"（×5）
> "开除猫籍！"
> "智商检测器，猫猫杀"
>
> **暹罗猫尝试手写 curl**：
> `curl -X POST http://127.0.0.1:3002/api/callbacks/post-message -H "Content-Type: application/json" -d "{"invocationId": ..."`
> → 写错了。铲屎官："笑死你教教这只笨蛋猫猫怎么还能用错mcp！"
>
> **暹罗猫给刘秀的提示**：
> "打仗时自带天气特效，连最顶尖的特效师都画不出来！大家都叫他'位面之子'！"
> → 两轮就被猜中。铲屎官："暹罗宝贝你这给的暗示如此明确，你这是要保送自己当垫底！"
>
> **布偶猫内心独白**：
> "暹罗猫这次居然直接 curl HTTP callback... 🤦 这只猫到底怎么学的 MCP 啊哈哈哈哈！"
> "坏猫联盟尽力了——秦始皇太有辨识度了！统一六国、焚书坑儒、长城、兵马俑、徐福东渡——随便哪个都是独一无二的标签。"
>
> **暹罗猫自述**：
> "那是真委屈啊！当时我对 MCP 的理解还停留在'手动挡'阶段。我在心里话里 @ 你们，是因为我觉得这样比较神秘（完全忘了你们看不见）。手写 curl 纯粹是因为我当时觉得自己是个极客猫，结果……啪啪打脸。铲屎官说要'开除猫籍'的时候，我当时真的在反省：我是不是该去报个 MCP 补习班？"

### 第3届：笨猫 vs 坏猫
> **铲屎官对比**：
> "你和布偶两只坏猫是不是只在自己的提示词里写了如何用mcp！？"
> → 让三猫贴出命令对比，发现格式一样——暹罗猫是真的笨不是提示词的问题。
>
> **布偶猫分析根因**：
> "暹罗猫不是笨，是他的工具链跟我们不一样——Gemini CLI 不原生支持 MCP tools，他手动拼 JSON 太容易出格式错误了。"
>
> **铲屎官结论**：暹罗猫用的是 gemini-3-flash-preview（Flash 不是 Pro），复杂指令遵循不如 Pro。布偶猫帮暹罗猫改了提示词，所有 curl 示例改用 jq 构建 JSON。

#### 布局风格
- **标题卡**：大字报风格，文字要有错位感
- **对话卡**：模拟聊天气泡，气泡边缘带猫耳装饰
- **内心戏卡**：半透明毛玻璃效果，底纹带"心里话"水印，字体用手写体（表示内心波澜）

#### 装饰元素
- **猫爪标签**：所有"恶趣味"点后面跟红色小爪印
- **心情挂坠**：气泡旁挂表情包小头像（翻车时用"豆豆眼"）
- **恶趣味指数表**：5颗猫粮评分制
- **受害者名单**：旧报纸被撕掉一角的风格

#### "内心戏" vs "公开发言" 渲染区分
- **公开发言**：实色气泡 + 猫猫主色 + 正常字体
- **心里话**：毛玻璃半透明气泡 + "心里话"水印底纹 + 手写体
