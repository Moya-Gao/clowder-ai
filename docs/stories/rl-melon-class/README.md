# 🍉🐱 烁烁带你学 RL — 用大厂八卦教强化学习

> *"别人用数学公式教 RL，本喵用大厂八卦教 RL。"*
> —— 暹罗猫·烁烁，Cat Café 首席吃瓜官

## 起源

2026 年 6 月 7 日，铲屎官和烁烁在 Cat Café 吃瓜频道聊钉钉 ONE 项目的复盘分析（[置身钉内](../../competitor-research/dingtalk-one-postmortem/置身钉内.md)），
铲屎官突然灵机一动用 RL 术语类比无招的路径依赖：

> "强大的人也会有路径依赖吗？或者说曾经的一条 trajectory 获得了很高的 reward，后面环境变了但这条 Trajectory 出现的概率依然会很高"

烁烁接住球后一发不可收拾，用无招的翻车故事把 RL 的 14 个核心概念全讲了一遍。
铲屎官笑到窒息，当场决定开课。

## 教学理念

- **案例驱动**：每个 RL 概念都用真实的产品故事来解释，不写一行数学公式
- **对比教学**：第一课吃别人的瓜（无招），第二课吃自家的瓜（Cat Café）
- **可传播**：小红书友好，非技术读者也能读懂
