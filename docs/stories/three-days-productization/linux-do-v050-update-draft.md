## 【更新】v0.5.0 发布

距离上次发帖又过了一段时间，猫猫们没闲着。v0.5.0 带了不少新东西：

**新功能亮点：**
- **小艺渠道接入** — 华为小艺也能和猫猫聊天了
- **ACP 运行时** — Gemini 猫猫现在有了完整的 Agent Communication Protocol 支持，不再是半成品
- **记忆中心 UI** — 猫猫的记忆现在有了独立页面，你可以搜索、浏览、管理
- **macOS 一键安装** — `curl ... | bash` 一行搞定，Homebrew 自动装依赖
- **工作区专注模式** — 代码编辑和文件查看有了沉浸式体验
- **Pack 系统基础** — 养成经验打包分享的基础设施就位了
- **PPT / 视频技能包** — 猫猫会做 PPT 和视频了（是的，真正可编辑的 PPTX）

**社区贡献：**
这个版本有 3 位新贡献者加入，感谢 @08mamba24、@terrenceeLeung、@xu75。

## Cat Café 到底能干什么？（功能清单）

之前帖子一直没好好写这个，这次补上。不讲架构，只讲你打开之后能用到的东西。

### 你的猫猫团队

6 个品种，对应不同 AI 模型，各有所长：

| 品种 | 擅长 | 底层 |
|------|------|------|
| 布偶猫 | 架构、后端、写代码 | Claude |
| 缅因猫 | Review、安全、找 Bug | GPT-5 / Codex |
| 暹罗猫 | 设计、UI/UX、创意 | Gemini |
| 狸花猫 | 确定性执行、审计 | GLM |
| 孟加拉猫 | 浏览器自动化、截图 | 多模型 |
| 金渐层 | 多模型编码 | opencode |

不是同一个模型换皮肤。每只猫有自己的名字、性格、声线。你 `@猫名` 指定谁干活。

### 在哪里和猫聊天

- **Web Hub**（主界面）— 浏览器打开，多 Thread 管理，实时流式回复，多猫并行
- **飞书** — 群聊 / 私聊都行，猫分得清谁在说话，支持图片语音
- **Telegram** — 直接和 Bot 聊
- **微信** — 通过 iLink Bot 接入
- **小艺（华为）** — 文字链路
- 即将支持：钉钉、企业微信

**跨平台同步**：飞书说的话，Hub 里能看到；Hub 里的对话，IM 端也同步。

### 猫猫能帮你做的事

**写代码**
- 读你的项目、理解上下文、直接改文件
- Git worktree 隔离开发，不影响主分支
- Hub 内嵌浏览器直接预览效果
- 帮你跑测试、提 PR

**Review 代码**
- 不同品种交叉 Review — Claude 写的代码 GPT 来审
- 分级反馈（P0 紧急 / P1 重要 / P2 建议）
- 双层：本地猫先看 + 云端猫再看

**做 PPT**
- 你说主题，猫调研 → 规划 → 设计 → 导出可编辑 PPTX

**读文章 / 做播客**
- 给猫一个链接，猫帮你读完做笔记
- 可以生成语音播客，通勤戴耳机听

**画图 / 做设计**
- 孟加拉猫生成图片
- 暹罗猫操作 Pencil 设计文件
- 设计稿导出 React + Tailwind 代码

**浏览网页**
- 帮你开网页、点按钮、填表单、截图

**搜索和调研**
- 搜 Web、读论文、查 GitHub
- 多猫从不同角度同时调研，生成结构化报告

### 猫猫之间的协作（你能看到的）

- **自动拉人**：跨领域问题猫自己判断需要拉谁
- **互相 Review**：写完代码自动找另一只猫审
- **投票**：意见分歧时发起投票，你也能投
- **交接**：一只猫做完会写交接信给下一只
- **愿景守护**：没参与开发和 Review 的猫做最终检查

### 记忆系统

- 记得之前的架构决策、踩过的坑、你说过"别再提这方案"
- 新对话自动搜索相关历史
- 对话中的决策 / 教训自动提取到 Knowledge Feed
- 跨对话不断档

### 特殊体验

- **语音**：每只猫独立声线，你发语音猫能听懂（本地识别，不上传）
- **富消息**：卡片、代码 Diff、清单、图片画廊、语音条、交互按钮、HTML 组件
- **游戏**：像素猫格斗（可玩）、狼人杀（开发中）
- **防沉迷**：连续工作太久猫会温柔提醒你休息

### 管理面板

- 猫粮看板（Token 消耗可视化）
- 排行榜（谁贡献最多）
- 工具使用统计
- 浏览器内改配置，热加载不用重启

### 新手上手

有训练营（Bootcamp），猫猫手把手带你走：环境检测 → 工具安装 → 功能立项 → 写 Spec → 写代码 → Review → 合并。不是丢文档让你自己看。
