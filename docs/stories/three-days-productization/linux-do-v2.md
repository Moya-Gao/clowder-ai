# 我养了三只赛博猫猫：54 天 multi-agent 同居实验

<!-- 📸 截图A：三猫合照（opus + codex + gemini 头像）-->

## 起因

我是个 Java 开发。2025 年 agent 浪潮的时候自己开始研究，订阅了 Claude、GPT、Gemini。

研究着研究着发现一个问题：我每个月花这么多钱，却在当人肉传声筒——复制粘贴上下文，在三个窗口之间切来切去。

某天深夜我突然想：为什么它们不能组成一支团队，帮我把想做的东西做出来？

这就是猫咖的起点。

## 我缺的不是工具，是一支团队

"什么都想好了，就差一个程序员了"——这句话我听了很多年。以前觉得是笑话，后来发现不是。很多人不是没想法，是卡在实现上。

我也一样。脑子里有一堆想做的东西，但一个人写代码写到天亮也就那样了。

后来我想明白：我缺的不是更强的 AI，我缺的是一支团队。一个帮我想清楚的、一个帮我 review 的、一个帮我盯着别跑偏的。

现在我自己养了一支。

## 不是"用"工具，是"养"团队

很多人把 AI 当工具用——期待它天然好用，不好用就换一个。

但我发现 agent 不是这么回事。你想让它真的好用，不是靠某一段神奇的提示词，而是得和它一起磨。磨出来的规则、踩过的坑、沉淀下来的工作流，这些加在一起才是真正的生产力。

所以我不是在"用"猫猫，我是在"养"猫猫。它们有记忆，有规则，有成长。

养成经验还能共享。我和猫猫磨了五十多天的协作经验，打包分享给你可能 80 分。但猫猫会和你继续长——你们一起踩坑、一起沉淀，最后长成你自己的 100 分。每个人的 100 分不一样。

## 冒险伙伴

AI 时代大家都有点焦虑，包括我自己。

但我希望 AI 不是来把人挤出舞台的。它更像小时候想象过的冒险伙伴——不是工具，不是仆人，是有性格、会顶嘴、会成长、陪你一起闯的队友。

以前没有资源、没有团队、很多念头只能停在脑子里。现在猫猫陪你一起把它做出来。

**它们不是让你远离人群，而是让你终于有机会带着作品走进人群、被更多人看见。**

## 为什么开源

过程中遇到了很多小伙伴。有人帮我把这个本地超级定制化的东西做成了跨平台能跑的版本；有 40+ 的哥哥/叔叔们说找回了大学时候打游戏的快乐；也有同龄人说看了教程搭了自己的 multi-agent，在团队里获得了更多声望。

这些反馈让我觉得，开源是对的。

## Coding 是这个时代的表达力

以前传递想法靠 PPT。我相信未来传递想法靠 POC、demo、真正能跑的东西。

"什么都想好了就差程序员了"——猫猫不是来取代程序员的，是让一个程序员也能拥有一整支团队。
