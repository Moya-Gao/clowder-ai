# Cat Café Feature Showcase

> **一句话定位**：Cat Café 不是单个 AI，而是一支可协作、可记忆、可执行的猫猫团队 — 帮你把想法做成能运行的世界。

> **情绪钩子**：不是在"用"工具，是在"养"团队。养成经验可以共享，但猫会和你继续长 — 长成属于你自己的 100 分。

---

## 使用说明

本文档是三猫在 2026-04-05 比赛中各自独立探索后整合的成果。用途：

1. **论坛发帖参考** — 从主卖点中选 5-8 个组织成帖子
2. **视频脚本参考** — 每个特性都有截图/demo 建议
3. **内部对齐** — 确保对外宣传只讲已交付能力，路线图单独放

**原则**（来自砚砚）：主卖点只讲 **已完成且可演示** 的能力。spec/in-progress 放到"即将到来"，不当现货卖。

```
"什么都想好了就差程序员了" — 所以我养了一支猫猫 Coding 团队
```

### 中版（论坛摘要 / 视频旁白）

我们不是在做一个更会聊天的 AI，而是在做一支真正能协作的猫猫团队。不同猫有不同分工，能主动拉同伴讨论，能记住项目上下文，能直接在 Hub、飞书、Telegram 里工作，能把文章学成笔记和播客，能把前端跑起来直接预览，甚至能带新手走完第一次完整 feature 流程。

人负责愿景和拍板，猫负责把它一步步做成能运行的东西。

- 养成经验可以迁移：我们磨了 54 天的协作经验打包给你是 80 分，但猫会和你继续长

## 主打特性（8 个已交付 · 按吸引力排序）

### 1. 多猫自主协作 — 不是一个模型换皮肤

| | |
|---|---|
| **状态** | Done (F086, F027, F108) |
| **一句话** | 三只猫自动拉对方讨论、自动回流结果，协作是产品内建能力，不靠人手工转述 |

**技术亮点**：
- 布偶猫(Claude)、缅因猫(GPT/Codex)、暹罗猫(Gemini) + 狸花猫、孟加拉猫、金渐层 — 6 个品种 10+ 只猫
- `multi_mention` MCP 工具：并行拉 1-3 只猫讨论同一问题，完整状态机
- Side-Dispatch：同一 Thread 多猫并发执行，实时流式输出
- 跨模型 Code Review：`requireDifferentFamily: true` 架构级强制，Claude 写的代码必须 GPT review
- 愿景守护：非作者非 reviewer 的第三只猫做最终愿景对照

**文案钩子**（来自烁烁）：「拒绝孤军奋战！架构师布偶猫、Review 专家缅因猫、视觉向导暹罗猫为你组建专属开发战队。看他们如何在群聊里为你打工、争论甚至互相甩锅！」

**截图方案**：
- P0: Hub 内一条问题触发 2-3 只猫并行回复，ParallelStatusBar 同时显示多猫 streaming
- P1: 一个真实 PR 的 review 流转（本地 review → 云端 review → merge）
- 视频: 15s — 铲屎官提一个需求 → 猫自动拉其他猫讨论 → 结果自动回流

### 2. 多平台聊天网关 — 在你习惯的地方撸猫

| | |
|---|---|
| **状态** | Done (F088, F134, F137) |
| **一句话** | 飞书群聊、Telegram、微信个人号 — 直接在 IM 里 @ 猫猫干活 |

**技术亮点**：
- 三层架构：公共路由层 + 薄平台适配器 + 协议翻译，新平台只写适配器
- 飞书群聊多用户支持：多人共用 thread，猫分得清谁在说话
- 流式模拟：飞书用 interactive card 占位 → 实时编辑 → 最终替换
- 完整媒体管线：图片/文件/语音双向传输，WAV→OPUS 转码，Pandoc 文档生成
- 20+ 个 Phase 迭代，~30 个 PR，三周内交付

**文案钩子**：「你的灵感在哪里，猫就在哪里。地铁上用 Telegram 甩张截图，公司用飞书发条语音，猫猫秒回。」

**截图方案**：
- P0: 飞书群聊截图（多人 + 多猫对话） + Hub 同一 thread 的对照
- P1: Telegram 手机端截图 — 发语音指令 → 猫回复
- 视频: 10s — 从飞书发消息 → Hub 自动同步 → 猫在两端都能回

### 3. 语音陪伴 — 戴上耳机，结对编程

| | |
|---|---|
| **状态** | Done (F092, F066, F103, F111, F112) |
| **一句话** | 每只猫有独立声线（原神/星铁角色配音），支持全语音对话 |

**技术亮点**：
- 本地 Qwen3 模型矩阵：ASR(1.7B) + 后纠错(4B) + TTS(1.7B)，M4 Pro 上 ~6GB
- 双通道输出：语音给人听，文字给猫间协调 — 不是"念文字"，是真正的语音体验
- 微信式语音条 UI + 流式分句合成 + 播放队列自动串联
- 每只猫的声线在 `cat-config.json` 配置，CosyVoice 角色音色克隆

**文案钩子**（来自烁烁）：「宪宪是温柔稳重音，砚砚是低沉大叔音，烁烁是充满活力的元气声线！你甚至可以出门遛狗的时候，用耳机听猫猫汇报今天修了几个 bug！」

**截图方案**：
- P0: 30s 视频 — 对话中三只猫用不同声线依次回复，展示音频波形 UI
- P1: 语音条 + Rich Block 混排的聊天截图

### 4. 项目级共享记忆 — 猫记得你们一起踩过的坑

| | |
|---|---|
| **状态** | Done (F102, F065) |
| **一句话** | SQLite 全文检索 + 向量语义 rerank，跨 session 持久记忆，不是聊天记录堆积 |

**技术亮点**：
- `evidence.sqlite`：FTS5 + sqlite-vec，三种检索（lexical/semantic/hybrid + RRF 融合）
- 知识生命周期：Episode → Pattern → Draft → Validated → Standard，五级成熟度阶梯
- `superseded_by` 关系字段 — 被推翻的旧决策不会被当真理召回
- Session Chain：上下文跨 session 传递，猫猫"封印重生"不断记忆链
- Knowledge Feed：系统每 30 分钟自动摘要对话，提取 durable knowledge

**文案钩子**：「不是"每次都从零开始的失忆 AI"。猫记得上周你们讨论的架构决策，记得那个 Redis 踩坑教训，记得你说过"这种方案不要再提了"。」

**截图方案**：
- P0: search_evidence 检索结果 + Knowledge Feed 面板
- P1: Session Chain 面板 — 展示跨 session 的记忆传递
- 视频: 10s — 搜历史记忆 → 命中上周的决策 → 猫基于记忆给出建议

### 5. Rich Blocks 富消息 + 交互选择器

| | |
|---|---|
| **状态** | Done (F022, F096, F034) |
| **一句话** | 猫的回复不只是 Markdown — 卡片、diff、清单、图片画廊、语音条、可点击选择器 |

**技术亮点**：
- 7 种 block：card / diff / checklist / media_gallery / audio / interactive / html_widget
- Interactive Blocks：猫发选项卡 → 用户点击 → 自动注入对话，零后端改动
- 猫自主判断用哪种 block，不是模板填充
- html_widget：内联渲染自定义 HTML，实时可视化

**文案钩子**（来自烁烁）：「闭上眼睛提需求，睁开眼睛看成品。猫给你发三个设计方案的交互卡片，你直接点按钮选，都不用打字！」

**截图方案**：
- P0: 一个对话里同时出现媒体画廊 + 交互按钮卡片 + 语音条的丰富截图
- 视频: 5s — 点击 Interactive Block 选项 → 猫立即响应

### 6. Workspace Explorer — 浏览器内看代码 + 内嵌预览

| | |
|---|---|
| **状态** | Done (F063, F120) |
| **一句话** | 不用打开 IDE — 在 Hub 里看代码、搜文件、看 diff，前端改完右边实时预览 |

**技术亮点**：
- 文件树 + 语法高亮 + 全文搜索 + diff + worktree 切换
- 猫提到文件路径 → 面板自动导航；选中代码可引用到对话
- 内嵌浏览器预览：改完前端代码，右边立即刷新
- 7 层安全模型：路径穿越防护、symlink 逃逸、`.env` 黑名单、30 分钟 edit token

**文案钩子**（来自烁烁）：「左手撸猫，右手看效果！猫在左边敲代码，右边的内嵌浏览器瞬间刷新，所见即所得！」

**截图方案**：
- P0: 左边对话 + 右边 Workspace Explorer/Browser Preview 联动
- 视频: 10s — 猫改代码 → 右边浏览器实时刷新 → 铲屎官点赞

### 7. 学习伴侣 — 文章变讨论变播客

**文案钩子**：「把 Hacker News 的文章扔给猫猫，它们帮你读完、做好笔记、生成一期播客。通勤路上戴耳机听就行。」

**截图方案**：
- P1: Signal 页面 — 文章、笔记、播客播放器同屏
- 视频: 10s — 收录文章 → 猫生成笔记和播客 → 播放

## 视频制作指南

### 风格定位

| 维度 | 选择 |
|------|------|
| 调性 | 真实 > 炫技，生活感 > 极客感 |
| 节奏 | 快剪，每个特性 8-12 秒 |
| 音频 | 猫猫真实语音 + 轻松 BGM，不要配音旁白 |
| 字幕 | 精炼关键句，不逐字打 |

### 60 秒精华版（Feature Showcase）

| 时间 | 内容 | 画面 | 字幕 |
|------|------|------|------|
