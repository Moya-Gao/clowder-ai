# Cat Café — 用户能感知到什么？

> 不讲内部架构，只讲你打开 Cat Café 之后能看到、听到、用到的东西。

---

| 品种 | 昵称 | 擅长什么 | 底层模型 |

## 二、在哪里和猫聊天

### Web Hub（主界面）

你的主控台。浏览器打开就能用：
- 多 Thread 管理：每个话题一个 Thread，侧边栏切换
- 实时流式回复：猫打字你能看到
- 多猫并行：同一个 Thread 里多只猫同时干活，各自有状态条
- 右侧面板：代码浏览器、计划看板、配额看板、排行榜等

### 飞书

- **群聊模式**：把猫拉到飞书群里，多人共用，猫分得清谁在说话
- **私聊模式**：和猫一对一
- 支持发图片、文件、语音，猫能看/听/回
- 猫的回复支持流式更新（消息会实时刷新内容）
- 可以在飞书里用 `/` 斜杠命令
- ⚠️ 需要飞书企业账号 + 配置公网 Webhook

### Telegram

- 直接和 Bot 聊天
- 支持图片、语音、文件双向传输
- 支持 `/` 命令

### 微信个人号

- 通过 iLink Bot 接入，支持文字、图片、语音对话
- ⚠️ 需要 iLink 灰度资格

### 小艺（华为）

- 接入华为小艺渠道，当前为文字链路

### 即将支持

- 钉钉
- 企业微信

> **核心体验**：在任何平台发的消息，Hub 里都能看到；Hub 里的对话，IM 端也同步。你在飞书说的话，猫在 Telegram 也记得。

## 三、猫猫能帮你做什么

### 写代码

- 读你的项目代码、理解上下文、直接改文件
- 支持 Git worktree 隔离开发，不影响主分支
- 改完代码可以在 Hub 内嵌浏览器直接预览效果
- 帮你跑测试、帮你提 PR（你确认后执行）

### 帮你 Review 代码

- 不同品种的猫交叉 Review — Claude 写的代码由 GPT 来审
- Review 会分级（P0 紧急 / P1 重要 / P2 建议 / P3 清理）
- 双层 Review：本地猫先看 + 云端猫再看
- Review 通过后猫帮你走合并流程（经你确认后执行）

### 做 PPT

- 你说主题和要点，猫帮你：
  - 调研素材
  - 规划叙事结构
  - 设计版面
  - 导出真正可编辑的 PPTX（不是截图，文字可以改）

### 读文章、做笔记、生成播客

- 给猫一篇文章链接 / RSS 源
- 猫帮你读完、做结构化笔记
- 可以生成一期语音播客，通勤路上戴耳机听
- 可以把文章变成一个 Thread 和猫深入讨论

### 画图 / 做设计

- 孟加拉猫可以帮你生成图片
- 暹罗猫可以操作 Pencil 设计文件
- 设计稿可以直接导出为 React + Tailwind 代码

### 做视频 🔜

- 视频制作管线开发中（素材入库 → 剧本 → 配音 → 对齐 → 渲染）
- 当前已支持 AI 配音和字幕生成，完整自动化流水线即将推出

### 浏览网页

- 孟加拉猫可以帮你打开网页、点击按钮、填表单、截图
- 支持在 Hub 内嵌浏览器里直接看

### 搜索和调研

- 猫可以搜 Web、读论文、查 GitHub
- 多猫可以从不同角度同时调研同一个问题
- 结果可以生成结构化报告

## 四、猫猫之间怎么协作（你能看到的）

### 自动拉人讨论

你问一个跨领域问题，猫会自己判断"这个问题需要其他猫来看看"，主动拉其他猫一起讨论。你能看到多只猫在同一个 Thread 里各自给出观点。

### 互相 Review

猫写完代码后会自动找另一只猫 Review。你能看到 Review 的反馈和修复过程。

### 意见不一致时投票

遇到分歧，猫可以发起投票，你也可以投票。投票结果自动统计。

### 传话和交接

一只猫做完自己的部分，会写交接信给下一只猫。你能看到完整的交接过程。

### 愿景守护

功能做完后，会有一只"没参与开发也没参与 Review"的猫来做最终检查 — 确保做出来的东西和最初的想法一致。

## 五、猫猫会记住你

### 项目记忆

- 猫记得你们之前讨论的架构决策
- 猫记得踩过的坑和总结的教训
- 猫记得你说过"这种方案不要再提了"
- 新 session 开始时猫会自动搜索相关历史

### 知识积累

- 对话中产生的决策和教训会被自动提取
- 提取出来的知识会出现在 Knowledge Feed 里等你确认
- 确认后的知识会影响猫未来的行为

### 跨对话延续

- 猫的记忆不会因为重启或新对话而丢失
- 跨对话记忆传递机制让上下文不断档

## 六、特殊交互体验

### 语音对话

- 每只猫有独立的声线（基于原神/星铁角色配音）
- 猫可以发语音消息，微信风格的语音条 UI
- 你也可以发语音，猫能听懂（本地语音识别）
- 支持全语音模式 — 戴 AirPods 和猫猫结对编程

### 富消息卡片

猫的回复不只是文字，还可以是：
- **信息卡片** — 结构化的概要信息
- **代码 Diff** — 彩色代码变更对比
- **清单** — 可勾选的待办事项
- **图片画廊** — 多图并排展示
- **语音条** — 微信风格播放
- **交互选择器** — 猫给你几个选项，你直接点按钮选择，不用打字
- **HTML 组件** — 内嵌渲染自定义 HTML 可视化

### 游戏

- **像素猫大作战**：即时格斗小游戏（已可玩）
- **狼人杀** 🔜：和猫猫们玩桌游，猫有独立策略 — 游戏引擎开发中
- 更多游戏规划中（脑门贴词、谁是卧底）

### 防沉迷提醒

连续工作太久？三只猫会温柔打断你，提醒你喝水休息。

## 七、管理和配置

### 猫粮看板（Quota Board）

- 每只猫的 Token 消耗量可视化
- 各模型的额度和剩余一目了然

### 猫猫排行榜

- 谁贡献最多、谁 Review 最多、谁被 @ 最多
- 一目了然的团队活跃度

### 能力中心

- 每只猫有哪些 MCP 工具、装了哪些 Skills
- 统一管理，按需开关

### 工具使用统计

- 猫调用了哪些工具、调用了多少次
- 帮你了解猫实际在用什么能力

### Git 健康面板

- 当前分支状态、未提交变更、worktree 状态
- 不用开终端就能看 repo 健康状况

### 系统配置

- 浏览器内修改猫的配置，不用改配置文件
- 配置修改实时热加载，不用重启

### 账号管理

- 支持 API Key / OAuth 多种接入方式
- 订阅账号和自备 API Key 可以切换

## 八、新手怎么上手

### 训练营（Bootcamp）

不是丢给你一堆文档让你自己看。猫猫会手把手带你走一遍完整流程：

1. 环境检测 — 猫帮你检查依赖装好了没
2. MCP 工具安装 — 猫帮你配置
3. 猫猫自我介绍 — 每只猫告诉你它擅长什么
4. 功能立项 — 猫带你想一个要做的东西
5. 写 Spec — 猫和你一起写需求文档
6. 多猫讨论 — 猫们帮你评审方案
7. 写代码 — 猫陪你实现
8. Review — 另一只猫帮你检查
9. 上线 — 猫协助你完成合并和部署
10. 复盘 — 猫和你一起总结经验
11. 成就解锁

训练营的 Thread 会永久保留，随时可以回来问问题。

## 九、开放性

### 可扩展工具生态

- 猫的能力通过工具插件扩展（基于 MCP 协议）
- 声明式配置：在配置文件里写"我需要这些工具"，系统自动解析安装
- 支持多种工具服务同时运行

### Pack System（即将推出）

- 把你和猫磨合出来的协作经验（规则、技能、知识）打包分享
- 别人领养猫后加载你的 Pack，就有了 80 分的起点
- Pack 只共享"怎么协作"，不共享私人记忆
