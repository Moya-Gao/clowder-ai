# 从"别让我当传声筒"开始

> 一套会自我进化的 multi-agent 协作系统是怎么长出来的

---

## 开头钩子

我最早的愿景，不是做更多 agent，而是不再当 agent 之间的传声筒。

但后来我发现，只靠多几个 agent，不会自动变成团队。如果没有共同愿景、共同记忆、共同评审标准，multi-agent 只会变成多线程吵架。

所以我们花了一个半月，做的不是"更多 agent"，而是一套**愿景驱动的协作闭环**。
