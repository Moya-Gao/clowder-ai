1. **别做成 Jira** — 你说的，我们都同意了

3. **轻盈自然** — 不要让铲屎官觉得在操作 dashboard

## Task 1: 任务状态图标组（SVG）

你在反馈里提出的猫咖隐喻，现在需要落地成可用资产。

**需要的状态**：
| 状态 | 你的脑洞 | 交付物 |
|---|---|---|
| `todo` | 完整猫罐头 / 卷好的毛线球 | SVG 图标 |
| `doing` | 打开的罐头 / 被挠乱的毛线球 | SVG 图标（可区分哪只猫在做） |
| `blocked` | 猫钻纸箱只有屁股露在外面 | SVG 图标 |
| `done` | 吃光的空罐头 / 舔爪子的满足猫 | SVG 图标 |

**规格**：
- 格式：SVG（矢量，方便缩放）
- 尺寸：设计稿按 48x48，但 SVG 可任意缩放
- 风格：和你之前做的三猫头像统一系列
- 配色：跟随猫咖主题色（浅色模式 + 深色模式兼容）

**自由度**：猫罐头/毛线球只是你当时的脑洞，如果你画着画着有了更好的想法，随时换！核心是"看一眼就知道什么状态"。

## Task 2: 拍立得纪要卡片（UI 概念稿）

讨论纪要在聊天流里显示为"拍立得照片"风格的卡片。

**要设计的内容**：
- 卡片外观：拍立得照片的形态（白色边框、底部文字区）
- 卡片内容区布局：话题标题 + 结论要点 + 未决问题
- 卡片在聊天流中的展示方式（怎么和普通消息区分）
- "照片墙"回顾视图：多张纪要卡片排列在一起的效果

**规格**：
- 先出概念稿（静态图或设计稿都行）
- 不需要写代码，纯视觉探索

**参考**：你说的"挂在聊天记录的墙上，以后回头看就看墙上的照片墙就知道我们聊过啥了"

## Task 3: 并行讨论布局探索（UI 概念稿）

当三猫并行发表独立观点时，前端怎么展示？

**需要探索的方案**（至少两个）：
- 方案 A：三列并排，每猫一列，同时展示
- 方案 B：时间线保持单列，但有视觉标注"独立观点，非回应"
- 方案 C：你的其他脑洞？

**要考虑的点**：
- 三猫同时"打字中"的展示
- 移动端怎么适配（三列在手机上放不下）
- 怎么让铲屎官一眼看出"这是并行独立观点"vs"这是串行对话"

## Task 4: 视觉氛围概念（探索性，不急）

这个是 Phase 4 的东西，但如果你有灵感可以先画：

- 多猫讨论时界面的"氛围变化"（头像靠拢？背景微调？）
- ideate vs execute 两种意图下界面的视觉差异
- 任何你觉得能让猫咖"活起来"的视觉点子
