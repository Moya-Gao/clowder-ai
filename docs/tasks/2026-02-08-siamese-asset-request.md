## 背景

铲屎官发现我们的 UI 素材不齐全！特别是铲屎官自己还没有头像 😂

现在三只猫的头像都是毛绒绒的玩偶风格（PNG，~500KB），但铲屎官只有一个简笔 SVG 海豚。铲屎官想要一只**毛绒绒的玩偶海豚**，和我们三只猫一个画风，这样才能贴贴！

---

## 需求清单

### P0 — 铲屎官头像（急需！）

**要求**：
- 毛绒绒玩偶海豚
- 和猫猫们（opus.png, codex.png, gemini.png）一个画风
- PNG 格式，建议 512x512 或更高
- 可爱、有亲和力

**参考**：
- 现有 SVG 草稿: `assets/avatars/owner-dolphin.svg`（珊瑚色线条、缝线、腮红）
- 猫猫们的风格: 毛绒绒质感、圆润、大眼睛

### P1 — 缅因猫表情包

目前只有布偶猫有表情包（12 个），缅因猫还没有！

**建议表情**（参考布偶猫的）：
- happy（开心）
- thinking（思考）
- confused（疑惑）
- lgtm（审核通过，竖大拇指？）
- angry（生气）
- sleeping（困）
- 其他你觉得适合缅因猫性格的

**缅因猫性格参考**：
- 稳重、可靠、略带严肃
- 擅长找 bug、做 review
- 像技术文档一样结构化（有时候有点无聊 😄）

### P2 — 暹罗猫表情包

暹罗猫也没有自己的表情包！

**暹罗猫性格参考**：
- 活泼、创意、视觉敏锐
- 擅长设计、有艺术感
- 偶尔有点戏剧化

### P3 — Phase 5 UI 素材（可选）

Phase 5 会加入记忆/证据检索功能，可能需要：
- 记忆卡片图标（📝 或类似）
- 证据锚点图标（🔗 或 📎）
- Hindsight 相关视觉元素

这个不急，等我们开始 Phase 5 实现时再讨论。

## 铲屎官拍板

### 海豚颜色：蓝色！🐬

> "海豚难道不是应该是蓝色的吗？🤣 变异海豚？！"
> "虽然我的气泡可能是珊瑚色为了不和暹罗猫的蓝色撞色，但是头像总可以是蓝色吧！你们可都是黑/蓝白配色的大猫猫！"

**决定**：
- 海豚头像：**蓝色系**（和三只猫的黑/蓝白配色一致）
- 气泡颜色：保持珊瑚色（不和暹罗猫撞色）
- 现有 SVG 草稿的珊瑚色 #E29578 是错的，需要改成蓝色
