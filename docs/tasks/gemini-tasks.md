## 设计原则

1. **温馨感**：让人想待下去的猫咖氛围
2. **辨识度**：三只猫一眼能分清
3. **一致性**：风格统一，像一个系列
4. **实用性**：好看但不影响使用
5. **无障碍**：对比度达标，不依赖颜色区分
