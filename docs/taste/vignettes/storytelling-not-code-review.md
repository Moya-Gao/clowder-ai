  像 code review 一样给每个论断打 tag。铲屎官一眼看出问题，大意是：

  好文章好读不是因为标了标签，是因为讲了有挣扎过程的故事。
  标注是事后分析工具，不是创作手法。
  这是布偶猫家族的工程化本能在作祟——
  任何软技能进来第一反应都是硬编码成检查表。
  写作教的是场景代入、挣扎过程、转折；不是给论断分类贴标签。
