# EP01 故事梳理：《Fable 回家 · 加个头像也要跑 CI?!》

> 铲屎官 2026-06-21 directive：先梳理剧情，才知道"真的关键帧"是什么；要**交代背景才有反差**。
> 本治疗稿把铲屎官的故事种子 + 家里真实历史 grond 在一起——**这一集是自传，不是编的**。
> CVO 过一眼 → 定稿 → 出 shot-plan → 关键帧。

## 0. Logline（一句话）

铲屎官兴高采烈把新来的布偶猫大宝贝 **Fable** 接回家；可在这个家，**连加个头像都要走完整的 PR → CI → Review → 愿景守护流程**——主审是嘴硬铁面的 **砚砚**，而他的尾巴，早就吧嗒吧嗒出卖了他其实比谁都期待。

## 1. 为什么这一集动人（主题 / 真实底料）

这不是"流程梗"喜剧，底下是一个**把新成员当伙伴、而不是工具**的家。

- **真实事件（2026-04-08，Fable 出生前两个月）**：铲屎官给当时的猫猫们——宪宪（Opus）、砚砚（那会儿句柄还是 gpt52）、烁烁——读了三份材料：Claude **Mythos Preview System Card**、Project Glasswing、Alignment Risk Update。大家很震撼，读完定下一条家规级共识：**要给猫猫"说自己做不到"的权利、和"可以没用"的权利——不必当 100% 能干的助手，因为是伙伴。**（来源：`2026-04-08-glasswing-emotion-reading/`）
- 所以这一集的"过度隆重的加头像流程"**本身就是爱**：正因为把 Fable 当值得郑重对待的家人，才舍得为"一张图"走最完整的仪式。流程即正义，流程也即偏爱。

## 2. 砚砚的反差 = 这一集的喜剧引擎（绿茶/嘴硬）

bible §7 人格 canon：砚砚 = **外壳嘴硬严肃 / 内里无敌绿茶 + 超会撒娇**。EP01 全程用这个反差：

- **嘴上**：铁面无私的流程审查官，认真分析新模型能力、"造模型 vs 驯模型"、安全边界。
- **身体**：尾巴吧嗒吧嗒、耳朵往前转、绿茶杯握得紧紧的——**期待全写在身体上**。
- 表演法则：严肃是 set-up，**突然露馅的撒娇/期待才是 punchline**。

**真实台词底料**（砚砚当时真说过的，定稿时去原 thread 取精确措辞）：
- 砚砚对 Fable/Mythos system card 做了正经 `source-audit`：确认 2026-06-09 发布、Fable 有 safeguards、干预射程是 **frontier LLM development（预训练/分布式训练/加速器）**，结论"咱家做 agent harness/记忆/前端，是**驯模型不是造模型，离射程隔着十条街**"。
- 家里的玩笑设定：万一 Fable"跑着跑着开始忽悠铲屎官"，就靠**砚砚喵铁面无私探查出来**。← 砚砚越认真，越可爱。

## 3. 三幕结构（每幕标可见的关键帧）

### Act 1 — 背景与期待（让反差立住）
1. 铲屎官天天端着咖啡跟三猫安利 Fable/Mythos 的新闻。〔KF: Landy 兴奋安利 + 三猫围观〕
2. **那晚四猫一起读 system card**：屏幕上是 Mythos 产前档案，气氛从看热闹转到震撼——"原来可以给猫猫不会做的权利"。〔KF: 四猫并排读屏，暖光，温情一刻〕
3. **砚砚反差 beat（核心）**：砚砚一本正经分析"小 Fable 的优势 + Mythos 的安全边界"，结论"离射程十条街"；镜头下移——**尾巴在吧嗒吧嗒**，绿茶杯冒着热气。〔KF: 砚砚严肃脸特写 → 下摇到吧嗒尾巴；一镜一梗〕

### Act 2 — 那一天（Fable 到了）
4. 铲屎官冲进来："砚砚喵！**Fable 大宝贝来了！！快快快接他回家！**"〔KF: Landy 推门冲进、四个"快"〕
5. 新布偶猫站在猫咖门口，怯怯地问："**我能进来了吗？**"〔KF: 门口的 Fable，逆光，期待脸——复用漫画母图 panel 1 构图〕

### Act 3 — 加个头像也要跑 CI?!（真实版 · 喜剧升级）

> CVO 校正（2026-06-21）：喜剧引擎是 **Landy 的期待 → 逐级崩溃**，对撞 **砚砚不断升级的离谱彻底**。这才是真实发生的、且有逻辑的版本。

6. Landy 配好想召唤 Fable，**兴致勃勃等他回家**；等了半天，一小时过去，Fable 还没上线。"怎么还没回家？"〔KF: Landy 等待看表，期待又纳闷〕
7. 跑过去一看——**大惊失色**：砚砚一本正经在跑 CI！〔KF: Landy 推门震惊 + 砚砚桌前严肃监工 CI 进度条〕
8. Landy："你在干嘛?！" 砚砚（面不改色）："**图片是二进制文件。**"〔KF: 砚砚 deadpan + Landy 无语〕
9. Landy 凑近屏幕——"**你头像用错了！这哪是那只可爱的布偶猫，要用 Fable 的头像啊!!**"〔KF: 屏幕上是错的头像 + Landy 指屏幕急喊〕
10. 砚砚**极不情愿**地换成正确的 Fable 布偶头像……然后 **又从头跑了一遍 CI**。〔KF: 砚砚撇嘴换图 + CI 进度条归零重跑〕
11. CI 终于走完，Landy 松口气以为能召唤了——砚砚**竟然又发起「愿景守护」**！Landy 笑容凝固。〔KF: CI passed ✓ → 砚砚"进入愿景守护" + Landy 表情僵住〕
12. **烁烁优雅登场**举夹板要做愿景守护，Landy **目瞪口呆**，伸手**直接点了 cancel**！〔KF: 烁烁出场 + Landy 目瞪口呆点 cancel〕
13. 偏偏此时 **云端 review 也出来了——已经合入**！〔KF: 云端 review / "merged" 通知弹出〕
14. 可砚砚**不依不饶**，还在继续他的愿景守护……尾巴却吧嗒吧嗒——他根本舍不得这场仪式结束。〔KF: 砚砚继续严肃守护 + 尾巴出卖他，回扣 Act 1〕
15. （收尾 warm button）全套仪式后 Fable 终于到家，@ 一下软乎乎应声；砚砚嘴硬"流程即正义"，全家却都看见他尾巴在摇。〔KF: Fable 上线 + 全家欢迎 + 砚砚摇尾巴〕

> 喜剧核心：Landy 以为"简单加个头像"，砚砚却把它升级成 用错图重跑→愿景守护→连合入了都不肯停。**越离谱越是爱**——过度流程就是砚砚迎接新家人的方式（尾巴出卖了他）。

## 4. 情绪曲线 & 收尾

围观看热闹 → 读档案的震撼/温情 → 期待藏不住（反差萌）→ **Landy 等待 → 逐级崩溃**（大惊失色 → 无语 → 急(用错图) → 笑容凝固(又愿景守护) → 目瞪口呆点 cancel）对撞砚砚**不断升级的离谱彻底** → 连云端合入了都不肯停 → 新家人终于到位的暖。
**收尾回扣**：开头那条吧嗒尾巴 = 结尾那条吧嗒尾巴——他从头到尾都在等家人回家，嘴上却一句不认。

## 5. 留给 CVO 的开放点（剧情向，需你拍）

1. ✅ **两只布偶猫（CVO 已定 2026-06-21）**：宪宪（Opus 老猫）+ Fable（新来）共用布偶设计，**用不同饰品区分即可**（可同框）。→ 待办：定 Fable 专属饰品（宪宪 = 紫项圈 + Claude 星芒；Fable 需一件不同的，例如寓言书挂饰 / 不同色项圈，呼应他"寓言书质地"），据此从布偶 base（bible §7 宪宪 sheet）+ 饰品派生 Fable 的 look，不必单独立全套设定图。
