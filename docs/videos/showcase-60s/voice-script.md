# Showcase 60s — 配音剧本 v1

> **TTS 规则**：CosyVoice 全局一次性读完，不分段。句间停顿靠标点自然断。
> **语速**：~4.5 字/秒（中文 + 少量英文混合）

---

## 完整剧本（一口气读完）

Cat Cafe，是四只 AI 猫猫组成的开发团队。

你发一条消息，它们同时开始思考——
布偶猫负责架构，缅因猫做 code review，暹罗猫管设计，各有分工，自主协作。

飞书发一条，Hub 同步收到。
在任何一端说话，所有端都能看到。

更特别的是，每只猫有自己的声音。
你可以听到它们用各自的声线，念给你听。

写前端代码？猫改完，右边浏览器立刻刷新。
所见即所得，设计和实现，零距离。

它们还有记忆。
搜一个两周前的讨论，三秒命中——这不是搜索，是经验的沉淀。

最后，猫猫不只是回复文字。
卡片、清单、投票、代码 diff，信息有结构，交互有温度。

这就是 Cat Cafe。
