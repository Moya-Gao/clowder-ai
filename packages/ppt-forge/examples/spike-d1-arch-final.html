判断层价值
不同模型家族 = 不同训练偏差。跨族审查让每个决策至少经过两种认知框架验证，盲点互补。
执行层价值
Queue 保并发安全，Session 保上下文不丢，Hooks 保底线不破。三层防御消除"AI 猫猫失控"风险。
连接点：Git + Evidence
Git 仓库是唯一写入口和真相源。evidence.sqlite 提供全文+向量语义检索，让每只猫都能找到历史决策。
